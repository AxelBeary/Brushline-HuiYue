# 系统自检功能（提案）

> **日期**：2026-07-31
> **状态**：提案，待一号研判可行性和排期

---

## 1. 需求

管理后台加一个"系统自检"功能，点一下检查系统各部件是否正常，显示绿勾/红叉。

**核心原则**：按需触发（点一下才跑），不做定时轮询，零持续性能开销。

## 2. 检查项（初步）

| 检查项 | 说明 |
|--------|------|
| 数据库连接 | SQLite 能否正常读写 |
| 迁移版本 | 当前版本号，是否最新 |
| 上传目录 | uploads/ 是否存在、可写 |
| 磁盘空间 | 剩余空间是否低于阈值（如 <500MB 警告） |
| 数据完整性 | 孤儿记录检查（订单→画师、订单→档位等外键） |
| 备份状态 | 最近一次 .bak 文件时间 |

## 3. 交互

- 管理后台某处放一个"系统自检"入口
- 点击后跑检查，返回结果列表（每项：名称 + 状态✅/⚠️/❌ + 详情）
- 不做自动修复，只报告

## 4. 粗估工时

~3.5h（后端 2h + 前端 1.5h），小快灵级别。
