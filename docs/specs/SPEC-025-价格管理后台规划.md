## 二、目标结构：一主四辅

```
价格管理（菜单名建议从"档位"改为"价格"或"画风与价格"，⚠️ 待一号定文案）
│
├── 【画风与价格】（主 tab，默认打开）★ 核心
│   ├── 顶部：多画风开关（关=只见默认画风可编辑；开=全部）
│   ├── 画风卡片 ×N（拖拽排序）
│   │   ├── 封面图 + 名称 + 描述
│   │   ├── 尺寸行列表（拖拽排序）：名称 / 价格 / 图缩略 / 描述 / 天数摘要 → 点开编辑
│   │   └── 增项区：从增项库导入的项，每项可 启用/禁用 + 改价（style_addons，已有能力）
│   └── ＋新建画风（封面/描述 + "从增项库导入"勾选）
│
├── 【增项库】（模板仓库）：增项的唯一定义处。开关/数量/单选三类控件 × 固定/按个/按选项三种计价。画师在这里定义一次，各画风按需导入
├── 【倍率】：使用场景/加急倍率（不动）
├── 【流程】：流程节点与收款比例（不动）
└── 【折扣码】：（不动）
```

**心智模型（一句话）**：画师的价格 = 几个画风货架，每个货架上摆尺寸（带图带价）和可加的料（增项）；增项的"配方"统一放在增项库这个仓库里，货架从仓库拿货、可以就地改价。

## 三、五条核心动线（做完后逐条验收）

1. **第一次开店**：建画风"默认" → 加尺寸（头像 ¥50 / 半身 ¥120…）→ 每个尺寸传一张图 → 去增项库建几个增项 → 回画风导入 → 完成。全程只在"画风与价格"+"增项库"两个 tab 之间。
2. **加一个画风**：开多画风开关 → ＋新建画风 → 勾选"从增项库导入"（增项一次到位）→ 调个别增项价格 → 完成。增项不用重配。
3. **临时关掉多画风**：关开关 → 客户端只剩默认画风，其余画风后台变灰但数据在 → 想恢复时开回来，一切原样。
4. **改某个尺寸的价格/图**：主 tab 直接点尺寸行 → 改 → 即时生效（沿用 v0.34 确立的上传即时保存模式）。
5. **加一种新料（如"画宠物 +¥30"）**：增项库新建 → 在需要的画风里导入启用 → 客户端下单页立即可选。

## 四、交互原则（实施时的硬约束）

1. **空间优先，不用勾选矩阵**：增项的"导入/启用"不做成一张 N 画风 × M 增项的勾选大表；在画风卡片内列出已导入项逐个开关（现状 ArtStyleManager 已如此，保持）。
2. **所见即客户端所得**：尺寸行的摘要（名/价/图缩略）与客户端展示柜一一对应；开关、停用的灰色态与客户端不可见严格联动。
3. **上传即时保存**：一切上传类操作沿用 v0.34 确立模式（编辑已有实体=立即 PUT 失败回滚；新建=提示确定后生效）。
4. **拖拽排序**：画风之间、尺寸之间均支持拖拽排序（现状已有，重构时不丢失）。
5. **旧概念零残留**：完成后台不应再出现"档位"入口、旧"增项"tab、showcase/展示专用字样（迁移脚本除外）。
6. **单画风画师无负担**：开关关闭时界面不出现"多画风"相关提示噪音，体验等同现在的单档位管理。
