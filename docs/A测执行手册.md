## 二、AUTH_DEV_MODE 关闭检查单（A 测启动时执行）

> 依据：STATUS 已拍板规则 9（2026-08-05 用户拍板「随 a测关闭」）+ 待修复清单 H1。AUTH_DEV_MODE=true 时，TOTP 绑定接口会返回密钥明文 `_dev_secret`（代码 `auth.service.ts:39`），生产/真实画师环境必须关闭。

### 前置条件（逐项核对，缺一不可）

| # | 检查项 | 状态 | 说明 |
|---|--------|------|------|
| 1 | 管理员 TOTP 已绑定 | ✅ 2026-08-05 已实跑（STATUS 规则 10） | 未绑定则关闭后无人能绑定画师，必须先绑 |
| 2 | **至少一位测试画师完成 TOTP 绑定**（场景 1 已走通） | ☐ 待 A 测现场确认 | 关闭后新画师绑定只能靠管理员二维码，测试画师先绑好避免现场卡壳 |
| 3 | 所有测试账号已能正常 TOTP 登录 | ☐ 待 A 测现场确认 | 关闭开发模式后旧登录码机制已不存在，只能 TOTP 登录 |

### 关闭步骤（管理员执行）

1. 在服务器项目根目录编辑 `.env`：把 `AUTH_DEV_MODE=true` 改为 `AUTH_DEV_MODE=false`（不存在该行则新增）。
2. 重建容器使环境变量生效：
   ```bash
   docker compose down && docker compose up -d --build
   ```
3. 验证关闭生效：
   ```bash
   # ① 环境变量已为 false（预期输出 false 或空）
   docker compose exec web printenv AUTH_DEV_MODE
   # ② 绑定接口不再泄露密钥明文：管理员在 /admin/artists 对任一画师点「绑定」，
   #    用浏览器 DevTools 看 bind-init 响应体 —— 应只含 qrDataUrl/otpauthUri，不含 _dev_secret
   ```
4. 端到端抽查：管理员 + 一位测试画师各做一次 TOTP 登录，确认登录链路正常。

### 回滚路径（万一登录全挂）

1. `.env` 改回 `AUTH_DEV_MODE=true`。
2. `docker compose down && docker compose up -d --build`。
3. 排查原因后再关。**回滚只是临时通道，A 测期间应尽快修好重新关闭**（H1 是上线前必做项）。

### 归档流程（执行人 → 四号/五号）

```
画师反馈单

   │       └─ 确认是缺失功能 → 四号整理 REQ（原声+现状+验收标准）
   ├─ 🟢/💡 体验/建议 → 四号收集，A 测结束后按优先级并入 REQ 池
```

- 画师说「不对」先当事实记录，不反驳；判断归五号/四号。
- 每条反馈必须有「操作场景 + 发生了什么 + 期望」三段，缺一不可。
