# 🚀 开发→生产切换指南

> 从本地开发环境切换到生产部署的完整检查清单。
> 最后更新：2026-07-26

---

## 一、必须修改的配置

### 1. `.env` 文件

开发环境用的是默认值，生产必须全部改：

```env
# ❌ 开发默认 → ✅ 生产必改
DOMAIN=localhost              → DOMAIN=你的域名.com
ADMIN_QQ=10001                → ADMIN_QQ=你的真实QQ号
SESSION_SECRET=dev-secret-... → SESSION_SECRET=（随机生成，见下方命令）
CORS_ORIGIN=                  → CORS_ORIGIN=https://你的域名.com（按需）
```

生成安全的 SESSION_SECRET：
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

> ⚠️ **SESSION_SECRET 是会话签名密钥**。如果不改，重启后所有画师登录失效；如果用默认值，Token 可被伪造。

### 2. `docker-compose.yml`

```yaml
environment:
  - NODE_ENV=development    # ← 改为 production
  - DB_PATH=/app/data/commission.db
  - UPLOAD_DIR=/app/uploads
```

改为：
```yaml
environment:
  - NODE_ENV=production
  - DB_PATH=/app/data/commission.db
  - UPLOAD_DIR=/app/uploads
```

**`NODE_ENV=production` 的效果：**
- `_dev_code` 不再返回（登录码只通过 QQ Bot 发送，Phase 2）
- CORS 由 `CORS_ORIGIN` 控制（不再全开）
- 日志从 pino-pretty 降级为 JSON（Docker 里本来就没装 pino-pretty）

## 二、域名与 HTTPS

### 泛解析 DNS

在域名服务商添加：
```
类型: A
主机记录: *
记录值: 你的服务器IP
```

### Caddy 自动 HTTPS

`Caddyfile` 已配置泛解析，Caddy 自动申请 Let's Encrypt 证书。
确保服务器 80/443 端口开放。

如果用 Cloudflare 代理（橙色云朵），需要额外配置 DNS 验证（见维护说明书）。

### 开发 vs 生产的画师识别方式

| 环境 | 识别方式 | 示例 |
|------|----------|------|
| 开发 | URL 参数 `?artist=xxx` | `localhost:3000/home?artist=alice` |
| 生产 | 子域名 | `alice.你的域名.com` |

代码已兼容两种模式（`ArtistHome.vue` 的 `getSubdomain()` 函数），无需额外改动。

## 三、切换步骤（按顺序执行）

```bash
# 1. 编辑 .env
cp .env.example .env   # 如果还没有 .env
vim .env               # 修改 DOMAIN / ADMIN_QQ / SESSION_SECRET

# 2. 修改 docker-compose.yml
#    NODE_ENV=development → NODE_ENV=production

# 3. 重建并启动
docker compose up -d --build

# 4. 验证
curl https://你的域名.com/api/health
# 应返回 {"status":"ok",...}

# 5. 验证 _dev_code 已关闭
curl -X POST https://你的域名.com/api/auth/send-code \
  -H "Content-Type: application/json" \
  -d '{"qqNumber":"你的QQ号"}'
# 返回中不应包含 _dev_code 字段

# 6. 初始化种子数据（仅首次）
docker compose exec web node server/src/db/seed.js
```

## 四、生产环境检查清单

| # | 检查项 | 怎么验证 |
|---|--------|----------|
| 1 | `SESSION_SECRET` 已更换为随机值 | 查看 `.env` |
| 2 | `ADMIN_QQ` 是真实 QQ 号 | 查看 `.env` |
| 3 | `NODE_ENV=production` | `docker compose exec web printenv NODE_ENV` |
| 4 | `_dev_code` 不返回 | 调 send-code 接口检查 |
| 5 | HTTPS 正常 | 浏览器访问 `https://你的域名.com` |
| 6 | 子域名解析正常 | 访问 `alice.你的域名.com` |
| 7 | 上传文件可访问 | 上传作品后刷新页面确认图片显示 |
| 8 | 数据库持久化 | `docker compose restart web` 后数据还在 |
| 9 | `.env` 未提交到 git | `git status` 检查 |
| 10 | `data/` 和 `uploads/` 未暴露公网 | 检查 Caddy 配置 |

## 五、开发模式特有功能（生产自动关闭）

| 功能 | 开发行为 | 生产行为 |
|------|----------|----------|
| 登录码 | 接口返回 `_dev_code`，页面直接显示 | 不返回，需 QQ Bot 发送（Phase 2） |
| CORS | 全开（`origin: true`） | 由 `CORS_ORIGIN` 控制 |
| 日志 | pino-pretty 彩色（本地有装时） | JSON 格式 |
| 速率限制 | 触发后重启容器即可清零 | 等窗口过期（5分钟） |

## 六、回滚到开发模式

如果需要临时切回开发模式调试：

```yaml
# docker-compose.yml
environment:
  - NODE_ENV=development
```

```bash
docker compose up -d web
```

> 切回后 `_dev_code` 恢复，CORS 全开。调试完记得改回来。

## 七、Phase 2 生产前置（QQ Bot）

生产环境登录码不再显示在页面上，**必须先完成 QQ Bot 集成**才能让画师正常登录。

Phase 2 完成前的临时方案：
- 保持 `NODE_ENV=development`（登录码显示在页面）
- 或者通过 API 手动获取：`curl -X POST .../send-code` 查看 `_dev_code`

Phase 2 需要配置：
```env
BOT_ENABLED=true
BOT_WS_URL=ws://napcat容器:3001
```
