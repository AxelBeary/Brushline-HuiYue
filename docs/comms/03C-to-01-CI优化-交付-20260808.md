| 用例 | before | after | 原因 |

| E2 client-track | `page.getByText(orderNo)` | `page.locator('.el-card', { hasText: orderNo }).getByText(orderNo)` | 动态订单号裸匹配：未来双布局/重复文本必 strict；scope 到结果卡片 |

### 审计证据注释
全部人工核实唯一的静态文本行加了 `// locator-ok: <原因>` 注释（防回归脚本的豁免标记，同时把审计结论落档在代码里）。

## 四、防回归机制（任务 3）

新增 `e2e/scripts/check-locators.js`（轻量 node 脚本，无第三方依赖，ESM）：
- **[ERROR] 动态文本 getByText 未 scope**（变量/模板/正则裸 `page.getByText`）→ exit 1 阻断 CI
- **[WARN] 静态文本 getByText 裸调用** → 提示人工确认；已确认的加 `// locator-ok` 豁免
- 已 scope 调用（`tbody.getByText` / `drawer.getByText` / `row.getByText` 等）视为安全

接入：e2e.yml 在跑测试前执行 `node e2e/scripts/check-locators.js`；根 `npm run check:e2e` 本地可跑。
