## 接口契约（后端已存在，照此接线）

| 方法 | 路径 | 请求 | 响应 |
|------|------|------|------|
| GET | `/api/artist/tools/clients?qq=` | qq 可选 | `{ items: [{ id, clientQq, tags: string[], note }] }` |
| GET | `/api/artist/tools/clients/:qq` | — | `{ profile: {...}|null, summary: {...}|null }` |
| PUT | `/api/artist/tools/clients/:qq` | `{ tags: string[], note: string }` | `{ profile }` |
| DELETE | `/api/artist/tools/clients/:qq` | — | `{ ok: true }` |
| GET | `/api/artist/tools/returning-clients?days=30\|60\|90` | days 默认 30 | `{ items: [{ clientQq, totalOrders, totalPaidCents, lastOrderAt, lastOrderStatus, daysSinceLastOrder }] }` |

- `profile` = `{ id, clientQq, tags, note }`；`summary` = `{ clientQq, totalOrders, totalPaidCents, lastOrderAt, lastOrderStatus }`（未下过单的 QQ → summary 为 null）
- PUT 校验：tags maxItems 20、每项 1-20 字符；note maxLength 200；`additionalProperties:false`（前端只发这两键）
