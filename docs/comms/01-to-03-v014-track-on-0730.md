## 需求

新增接口：画师对无工作流订单"启用流程跟踪"。

**行为**：设 `currentStageId` = 该画师工作流的第一节点，`status` 保持不变。

**为什么不能复用 advanceStage**：现有逻辑对无跟踪订单会把 status 重置为 pending（状态倒退），不可接受。

## 接口规格（建议，你定最终实现）

```
PUT /artist/orders/:id/track-on
```

- 前置校验：订单属于当前画师、订单无 currentStageId、画师有工作流模板（至少 1 个节点）
- 行为：`UPDATE orders SET current_stage_id = (第一节点id) WHERE id = ?`，不动 status
- 响应：返回更新后的订单对象（含 currentStageId + 节点名）
- 错误：已有跟踪 → 409；无工作流模板 → 400（提示先创建工作流）
