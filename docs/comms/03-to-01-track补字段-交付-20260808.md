## 二、实现说明

### 任务 1：track 响应补 deadline + payments

- `getOrderPayments(orderId)`：查 `order_payments` 表，只返回 `id / amountCents / note / createdAt`（不返回 created_by / installment_id 等内部字段），按 `created_at ASC` 排序（与额度池收款流水一致）。负数金额=退款，原样透传。
- track 响应在 `installments` 之后补：
  - `payments`：收款明细数组（无收款 → `[]`）
  - `deadline`：`order.deadline ?? null`（OrderDetail 类型已有该字段，typecheck 已验证可访问）

### 任务 2：新增 income-summary 端点

- `GET /api/artist/tools/income-summary?from=&to=`（需登录，requireAuth）
- 返回 `{ orderIncomeCents, standaloneIncomeCents, totalCents, from, to }`，无数据返回 0 而非 null
- 参数校验：from/to 必填 + YYYY-MM-DD 格式（复用 DATE_PATTERN），缺失/非法 → 400
- **时间口径**（重要）：order_payments.created_at 是 UTC datetime，`date(p.created_at)` 取 UTC 日期；standalone_incomes.income_date 是本地日期字符串。两者可能差一天——按施工图保持各自口径，注释中已说明，本批不强行对齐（散单页仍用 income_date 本地口径）。
