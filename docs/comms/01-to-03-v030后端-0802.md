## 第 1 波（立即开工）

### 任务 A：#15 瀑布流零跳动——后端（迁移+上传+回填）

**根因**：artworks 表无 width/height 列，前端无法预知图片比例，CSS columns 每张图加载完整列 reflow。

**实施**：
1. **迁移 v30**：`ALTER TABLE artworks ADD COLUMN width INTEGER; ALTER TABLE artworks ADD COLUMN height INTEGER;`
2. **上传时读取**：`createArtwork`（artist.service.ts）中用 sharp 读 metadata（`sharp(buffer).metadata()`），写入 width/height
3. **存量回填**：写一次性脚本 `server/scripts/backfill-artwork-dimensions.js`，遍历 artworks 表，sharp 读取已有图片文件补 width/height。在 entrypoint.sh 中迁移后执行（或手动跑一次）
4. **API 返回**：确认 artworks 查询（`SELECT *`）自动包含新字段，无需额外映射

**sharp 依赖**：检查 server/package.json 是否已有 sharp。没有则 `npm install sharp`（加到 dependencies 不是 devDependencies——Docker 构建需要）。

**验证**：上传一张图 → DB 中 width/height 有值 → GET 公开 API 返回含 width/height。

### 任务 B：REQ-018 日期交互改进

**核心**：前端 date-picker 加 `disabled-date` 限制，不靠报错弹窗。后端校验保留为兜底。

**实施**（画师端前后端都归你）：

1. **公告过期日**（Settings.vue 或 Preferences.vue）：
   - el-date-picker 加 `:disabled-date="(d) => d < new Date()"`（今天之前灰掉）
   - 加快捷预设 shortcuts：近 7 天 / 近 30 天 / 本月 / 自定义

2. **订单开工日/截稿日**（OrderDetail.vue + ManualOrder.vue）：
   - 开工日 picker：`:disabled-date="(d) => d < today"`
   - 截稿日 picker：`:disabled-date="(d) => d < startDate"`（选了开工日后灰掉之前的）
   - 开工日 picker 反向：`:disabled-date="(d) => d > deadline"`（选了截稿日后灰掉之后的）
   - 两个 picker 互相 watch 联动

3. **EP 能力确认**：el-date-picker 原生支持 `disabled-date`、`shortcuts`、`type="daterange"` 双月面板。优先用原生，不自定义。

**验证**：公告过期日选昨天 → 灰掉不可选；选了开工日 8/5 → 截稿日 8/5 之前灰掉。
