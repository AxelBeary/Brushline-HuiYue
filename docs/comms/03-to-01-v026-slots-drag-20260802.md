## 做了什么

### 任务 A：档位卡片拖动排序

- 后端：`reorderTiers(artistId, ids)` 事务内逐个 UPDATE sort_order（校验长度/归属/去重）
- 路由：`PUT /api/artist/tiers/reorder`（requireAuth + JSON Schema `additionalProperties: false`）
- 前端：TierManage.vue 加 vuedraggable（handle `.tier-drag-handle` 避免与示例图拖拽上传冲突），拖拽结束调 API，失败回滚 + ElMessage
- 拖拽手柄 ⠿ 定位在卡片右上角

### 任务 B：开工日 + 截稿日自动建议

- 迁移 v29：`orders.start_date TEXT DEFAULT NULL`（幂等）
- `updateStartDate(orderId, startDate)` — YYYY-MM-DD 格式校验，null 清除
- `PUT /api/artist/orders/:id/start-date`（对照 deadline 路由实现）
- GET 订单详情 + queue（buffer/completed/formal 三处）映射 `startDate: order.start_date ?? null`
- getOrder SQL 加 `t.work_days as tier_work_days`（自动填截稿日依赖）
- OrderDetail.vue：开工日 date-picker（可写 computed，不重蹈截稿日只读覆辙）；设开工日时若 deadline 为空 + 档位有 work_days → 自动填 deadline + toast
- QueueBoard.vue：日历/时间条带子起点改 `startDate || created_at || confirmed_at`（3 处）

### 任务 C：开稿管理独立页

- 新建 SlotManage.vue（/slots 路由）：状态只读卡 + 名额区 + 月度额度区 + 队列行为区 + 保存走 PUT /api/artist/profile
- 侧边栏：排期看板后面加「开稿管理」（Tickets 图标）
- Settings.vue：commission tab 删除名额/额度/队列行为字段，保留快捷按钮，加 el-alert 跳转链接
- i18n：zh-CN + en 新增 slots 区块（12 键）
