4. 添加备注输入框移到时间线底部（含附图按钮 + 待发送预览，R19 功能完整保留）
5. 状态卡标题键 `statusTitle` → `activityTitle`（文案不变：中文"订单状态"/英文"Order status"）
6. 老订单（无工作流）时间线正常可用（系统备注 + 画师备注混排不依赖工作流）
7. 操作条触发状态变更后后端写系统备注，loadOrder 刷新后时间线即时显示

**R53 看板焦点图替换**
1. 已有焦点图区域加 `.focus-img-wrap` 包装层：点击 → 文件选择器，拖拽 → 半透明遮罩"拖入替换焦点图" + 松手替换

4. 左滑进详情排除列表加 `.focus-img-wrap`（防触屏替换操作误触发导航）
5. 非图片/超 10MB 复用现有校验提示
6. 不需要确认弹窗（用户明确拍板）
