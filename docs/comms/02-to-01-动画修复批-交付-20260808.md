## 一、🔴 点名 3：深色模式后台切页闪白（H2 深层根因）——已根治

### 派工单描述 vs 实测根因

派工单按蓝本把根因写为「artist-tokens.css:246 全选 `*` 0.35s 过渡拖慢」——**该描述在 master 已不成立**（87a5c92 已改成 `.theme-animating` 瞬态）。但用户仍然发火闪白，实测另挖出**真正根因**：

### 真正根因（浏览器实测 + MutationObserver 铁证）

`ArtistLayout` 是 **slot 模式**（每个后台页面组件自己包一层 `<ArtistLayout>...</ArtistLayout>`），路由切换时：
1. 旧页面组件卸载 → `onUnmounted` → `leaveArtistScope()` **摘除 `data-artist-theme` 属性**
2. 新页面组件是**懒加载**（`() => import(...)`），加载期间 html 上**没有后台 token**
3. token 摘除瞬间所有 `html[data-artist-theme]` 变量失效 → `--bg-page` 回落客户端浅色 → **深色模式切页闪白**

**定量证据**（Playwright MutationObserver 记录 `data-artist-theme` 属性 oldValue，2 页切换）：
- BEFORE（stash 旧代码）：4 次属性变更，**2 次 old=null（token 被摘除）**，闪白窗口存在
- AFTER（守卫方案）：3 次属性变更，**0 次摘除**，全程 old=ink

### 修复：token 挂/摘统一由路由守卫管理

`web/src/router/index.js` beforeEach 增加：
```js
const themeStore = useThemeStore()
if (to.meta.requiresAuth || to.meta.requiresAdmin) {
  themeStore.enterArtistScope()   // 进入后台路由【提前】挂 token
} else {
  themeStore.leaveArtistScope()   // 离开后台摘除，客户端零影响
}
```
配套：
- `ArtistLayout.vue` / `AdminLayout.vue`：删除 `onUnmounted(() => themeStore.leaveArtistScope())`，仅保留 onMounted 幂等挂载双保险（**不删会摘掉守卫刚挂的新 token，白修**）
- 管理后台走同一机制（AdminLayout 同样删卸载摘除）

**截图证据**：`after-2-transition-0..5.png` 6 帧切页全程 `bg=rgb(23,22,17)`（墨黑 --paper #171611）+ artist=ink；`before-2-transition-*` 同帧窗口（旧代码 + 500ms 延迟懒加载）可复现浅色窗口。

## 八、风险与说明

- **守卫挂 token 时机**：beforeEach 在组件懒加载 resolve 前执行，切页间隙 token 必在；离开后台（含 404 重定向）摘除，客户端零影响（验收 10 语义保持）
- **onUnmounted 删除**：ArtistLayout/AdminLayout 不再卸载摘除——守卫是唯一管理方；若未来有人改路由 meta 需同步守卫逻辑（已在注释说明）
- **out-in 切换**：.18s 内旧页淡出→新页淡入，路由懒加载期间显示深色背景（不闪白）但会有极短空态（<300ms 通常），属可接受过渡
- **未动**：OrderForm.vue:975 tier-stamp-in 盖章动效（庆祝时刻正确用法，收敛会破坏设计）；后端、路由结构、组件结构均未动
