### 改动清单

**server/src/features/tracking/tracking.service.ts**
- `platform_config` key `stats_mode`（'off'/'hidden'/'on'），默认 'hidden'；`getStatsMode()` 读取时**回退旧 `artist_stats_visible`**（'true'→on / 'false'→hidden），双 key 同步写（stats_mode 为主 + 旧 key 同步，兼容旧读取方）
- `setStatsMode(mode)`：非法值回落 'hidden'；INSERT OR REPLACE 双 key
- `getArtistStatsVisible()/setArtistStatsVisible()` 保留为兼容层（on↔true；旧写 false→hidden 匹配旧语义：仅隐藏显示、事件仍收集）
- 无迁移：platform_config 为 KV 表，直接读写，无需 DDL（施工图"迁移如需要 v46"——不需要）

**server/src/features/tracking/tracking.routes.ts**
- `POST /api/events`：stats_mode=off 时**静默丢弃**（返回 `{ ok: true, received: 0 }` 不落库，前端无感知）
- `GET /api/artist/tracking/summary`：响应新增 `mode` 字段（替代 enabled，enabled 保留兼容）；mode≠on 时不返回统计数据（画师端不可见）
- `GET /api/admin/tracking-config`：返回 `{ statsMode, artistStatsVisible }`（新字段 + 旧字段兼容保留）
- `PUT /api/admin/tracking-config`：JSON Schema 双字段（statsMode enum off/hidden/on + artistStatsVisible boolean，additionalProperties:false）；body 二选一，两者皆缺 400；响应 `{ statsMode, artistStatsVisible }`（向后兼容旧前端）
