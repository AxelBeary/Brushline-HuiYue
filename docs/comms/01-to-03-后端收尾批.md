## 二、B 部分规格（REQ-033 已拍板，照做）

### 2.1 匿名凭证

- `POST /api/anon-token`：签发 32 字节随机 token（crypto.randomBytes(32).toString('hex')），存入 `anon_tokens` 表（token / created_at / last_seen_at），**不绑定 IP/UA**（跨设备稳定标识）
- 响应：`{ token: '<hex>' }`
- 有效期：30 天滚动（last_seen_at 更新即续期；查询时 `created_at > now - 30d` 失效）
- 幂等：同 token 重复调用返回已有 token（无需——每次签发新的即可，前端自己存）

### 2.2 events 端点

- `POST /api/events`，body：`{ token?: string, events: [{ name, ts, version, ...payload }] }`
- 白名单校验（**只收白名单事件**，其余 400）：
  ```
  theme_accent_change, order_form_start, order_form_step_view, order_form_step_leave,
  order_form_submit_attempt, order_form_submit_success, order_form_submit_fail,
  order_form_back, dashboard_view, queue_view, orders_view, manual_view,
  artworks_view, settings_view, tiers_view, guestbook_view, preferences_view, dashboard_quick_click
  ```
  （完整清单以 REQ-033 §4.4 为准，执行前先读 `docs/requirements/REQ-033-业务埋点方案.md`）
- 鉴权：`token` 有效（在 anon_tokens 表且未过期）→ 记 `anon_id`；画师事件可选带 `artist_id`（从登录态取，若已登录）；**无有效凭证 → 400 `INVALID_ANON_TOKEN`**（前端会静默重取，不打断用户）
- 限流：`rateLimit('events:' + (token 或 ip), 100, 60_000)`（1 分钟 100 条，防止刷库）
- 单请求上限：`events.length <= 50`（超 50 → 400）
- 落库：`events` 表（id / name / ts / version / artist_id 可空 / anon_id 可空 / payload_json）
- 响应：`{ ok: true, received: N }`

### 2.3 迁移 v44

`events` 表：
```sql
CREATE TABLE IF NOT EXISTS events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  ts INTEGER NOT NULL,
  version INTEGER NOT NULL DEFAULT 1,
  artist_id INTEGER,
  anon_id INTEGER,
  payload_json TEXT NOT NULL DEFAULT '{}',
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_events_name_ts ON events(name, ts);
```
`anon_tokens` 表：
```sql
CREATE TABLE IF NOT EXISTS anon_tokens (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  token TEXT NOT NULL UNIQUE,
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  last_seen_at TEXT NOT NULL DEFAULT (datetime('now'))
);
```
> ⚠️ 迁移写法参照 init.js 现有 MIGRATIONS 模式（版本号 v44，注意现有最新是 v43——先读 init.js MIGRATIONS 数组确认版本号递增规则与 schema_migrations 写入方式）。
