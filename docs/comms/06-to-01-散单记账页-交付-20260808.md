## 功能实现

1. **新增散单**：表单金额（元，el-input-number 两位小数）必填且 >0；客户昵称 ≤50、备注 ≤200（maxlength + 校验规则）；日期默认今天（YYYY-MM-DD，el-date-picker value-format 限定格式）。提交 `Math.round(金额 × 100)` 转分 → POST `/api/artist/tools/standalone-incomes`，成功清空表单并刷新列表。
2. **列表**：GET `/api/artist/tools/standalone-incomes`（后端已按 income_date 倒序），行内展示 日期 / 客户（空则「匿名」）+ 备注 / 金额；金额分 → 元展示（`¥(cents/100).toFixed(2)`）。
3. **删除**：DELETE `/api/artist/tools/standalone-incomes/:id`，ElMessageBox 二次确认；后端越权/已删统一 404 → 前端提示「记录不存在或已删除」并刷新列表（消除幽灵行）。
4. **视觉**：ArtistLayout 包裹 + 纸墨 token（`--ink/--paper/--hq/--card/--line/--line2/--ink2/--ink3/--r-m/--sh-1`，均带 fallback），亮暗双主题自动适配；卡片式表单/列表与 FoodMenu.vue / ToolsExport.vue 同风格；≤600px 移动端行布局自适应。

## 契约确认（对照 tools.routes.ts / tools.service.ts 实读）

| 端点 | 请求 | 响应 | 前端对齐 |
|------|------|------|----------|
| POST `/api/artist/tools/standalone-incomes` | `{ amountCents: int ≥1(必填), clientName ≤50, note ≤200, incomeDate YYYY-MM-DD(必填) }` | `{ item: {id, amountCents, clientName, note, incomeDate} }` | ✅ 前端校验 = 后端子集：元>0（×100 后 ≥1）、日期格式由组件保证、长度上限一致 |
| GET `/api/artist/tools/standalone-incomes` | 无参 | `{ items: [...] }`（income_date DESC, id DESC） | ✅ 直接渲染 items，无额外过滤 |
| DELETE `/api/artist/tools/standalone-incomes/:id` | 路径参数 id ≥1 | `{ ok: true }`；非本人/不存在 → 404 | ✅ 404 单独提示 + 刷新 |

- 认证：三端点均 `requireAuth`（httpOnly cookie），前端 fetch 带 `credentials: 'include'`（与 ToolsExport.vue 同模式，授权清单不含 api/index.js 故不新增 artistApi 方法）。
- 错误处理：非 2xx 尝试解析 `data.error`，兜底 `HTTP <status>`；消息文案全走 i18n。
