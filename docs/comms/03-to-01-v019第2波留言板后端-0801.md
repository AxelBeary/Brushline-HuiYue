## 已完成

- 新建 `guestbook_messages` 表（artist_id FK + nickname + content + status CHECK + artist_reply + replied_at + deleted_by_admin）

- schema 字符串 + schemaIndexes 已同步

### 7 个 API

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | /api/public/artist/:subdomain/messages | 公开（限流 2/min/IP） | 提交留言，返回 201 + `{ id }` |
| GET | /api/public/artist/:subdomain/messages | 公开 | 已审核留言，分页（默认 20，上限 50） |
| GET | /api/artist/messages | requireAuth | 画师全部留言（含 pending/rejected） |
| PUT | /api/artist/messages/:id/approve | requireAuth + 归属 | 通过 |
| PUT | /api/artist/messages/:id/reject | requireAuth + 归属 | 拒绝（静默） |
| PUT | /api/artist/messages/:id/reply | requireAuth + 归属 | 回复（artist_reply + replied_at） |
| DELETE | /api/admin/messages/:id | requireAdmin | 管理员软删除 |

### 限流

T2 按派工执行：同 IP 每分钟 2 条 POST，用现有 `rateLimit()` 内存桶，429 + `RATE_LIMITED`。

### 公开 API 返回格式

不返回 status / deleted_by_admin。字段：id, nickname, content, artistReply, repliedAt, createdAt + 分页元数据（total, page, pageSize）。

## 二号前端对接说明

- 客户主页：`GET /api/public/artist/:subdomain/messages?page=1&pageSize=20` 读已审核留言；`POST` 同路径提交（nickname ≤20 字，content ≤200 字）
- 画师后台：`GET /api/artist/messages` 读全部；`PUT .../approve|reject|reply` 操作
- 管理后台：`DELETE /api/admin/messages/:id` 强制删除
- 限流：同 IP 每分钟 2 条，超限返回 429
