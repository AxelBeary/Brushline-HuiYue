## 任务清单

### B1（代码）压缩 + 静态资源缓存头

1. **Caddyfile 加压缩**：`encode zstd gzip`（Caddy 2 内置，无需插件）
2. **缓存头**（推荐在 app.js 静态路由层设，不经 Caddy 也生效；若你研判 Caddy 层更合适须在报告说明理由）：
   - `/assets/*`（vite hash 文件名产物）→ `Cache-Control: public, max-age=31536000, immutable`
   - `index.html` / SPA fallback → `Cache-Control: no-cache`（保证发版即生效）
   - 字体文件（woff2）同在 assets/ 下，随 hash 长缓存即可
3. 不动 `/api/*` 与 `/uploads/*` 的缓存语义（uploads 见 B2）

### B2（代码）uploads 响应头区分公开/签名

- 公开路径（`isPublicUploadPath`）：去掉 attachment（改 inline 或不设 Content-Disposition），可加适度缓存（图片内容不可变但文件名可能复用，建议 `max-age=86400` 级别，你研判）
- 签名路径（references/deliverables）：保持 `attachment` + 补 `Cache-Control: no-store`（签名 URL 不应被缓存）
- **注意**：改前 grep 现有 server 测试里断言 `content-disposition` 的用例，连带适配；改后全量跑 server 测试
