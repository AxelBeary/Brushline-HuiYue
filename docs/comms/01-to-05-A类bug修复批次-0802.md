### 2. #54 可约稿+已约满矛盾（高）

**根因**：`artist.status='open'`（画师手动设置）+ 月度额度耗尽时，`computeSlotDisplay()` 返回 `'本月已约满'`，但 `statusText('open')` 仍显示 `'✅ 可约稿'`。TplStatusBadge 同时渲染两者 → 矛盾。

**修复方案**（后端）：在公开 API（`GET /api/public/artist/:subdomain`，artist.routes.ts L60-78）的返回值中新增 `effectiveStatus` 字段：
```typescript
// 额度耗尽时 effectiveStatus 覆盖为 'full'
const slotDisplay = artistService.computeSlotDisplay(artist)
const effectiveStatus = (artist.status === 'open' && slotDisplay === '本月已约满') ? 'full' : artist.status
```
返回对象加 `effectiveStatus` 字段（保留原 `status` 不动，向后兼容）。

**前端适配由二号做**（TplStatusBadge 改用 effectiveStatus），你只管后端。

**验证**：补测试——画师 status='open' + monthly_quota=1 + 已有 1 个 confirmed 订单 → GET 公开 API → effectiveStatus='full'。

### 8. #66 问候语 placeholder {name} 被吞（低）

**位置**：管理端问候语编辑组件。

**根因**：vue-i18n 把 `{name}` 当 ICU 插值语法解析，未传参 → 渲染空字符串。

**修复**：placeholder 中的 `{name}` 改为不被 i18n 解析的写法。方案：用 `t('key', { name: '{name}' })` 传参，或把 placeholder 文案改为不含花括号的提示（如"输入问候语，可用 {name} 变量"→ 用 HTML 实体或转义）。最简方案：locale 文件中该键用 `{'{'}name{'}'}` 转义花括号。
