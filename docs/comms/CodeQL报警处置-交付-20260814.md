## 已修：sanitize.ts（CodeQL #18/#19，security high）

**问题**：`server/src/shared/sanitize.ts` removeTagPairs 结束标签正则 `<\s*\/\s*(script|style)\s*>`
要求 `</script>` 后紧跟空白+`>`。但浏览器容错解析会把 `</script foo="bar">`、`</script/foo>`
当作 script 结束标签，旧正则匹配不到 → `<script>alert(1)</script foo="bar">` 整对残留入库。

**修复**：结束标签放宽为 `<\s*\/\s*(script|style)\b[^>]*>`（与开始标签同构，`\b` 防 `</scriptx>` 误匹配）。

**验证**（均在 worktree 独立复跑）：
- 修复前实测：带属性/斜杠结束标签 → 残留 `<script>`（复现 CodeQL 报警）
- 修复后实测：7/7 用例无残留，正常富文本原样保留
- 新增 TC-F5-20/21 锁死两类绕过
- 全量 1426 tests 通过 + tsc --noEmit 0
- master 合入后复跑：21/21 通过

**影响面**：sanitizeStoredText 是留言/画师bio/作品描述/须知/问候语/工作流等所有用户文本写入口的入库清洗，
