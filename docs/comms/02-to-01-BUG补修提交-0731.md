**Commit 1** `cf03537` — `fix(client): BUG-4 比例条右拖不回弹+报错`

PaymentBar.vue 右拖逻辑与左拖不对称：
- 条件 `newRight < ELASTIC_THRESHOLD`(150) → `newRight < MIN_BP`(500)：右拖进入弹性区的阈值与左拖一致
- `detachId.value = rightId`（无条件脱离）→ `detachId.value = newRight < ELASTIC_THRESHOLD ? rightId : null`：只有拖到 150 以下才脱离，150~500 区间保持弹性态可回弹

根因：右拖 150~500 区间掉进 else 分支清空 elasticId/detachId，松手时 `onPointerUp` 的弹性回弹逻辑找不到 elasticId，既不回弹也不 emit，表现为"卡住+报错"。

**Commit 2** `407f30b` — `fix(client): BUG-1 焦点图闪烁 + BUG-2 补充`

BUG-1（三处修复）：
1. `.focus-large-img` + `.focus-img-wrap` 加 `background: var(--bg-card)`：图片加载/刷新期间容器有底色，不再白闪

3. 加最大重试计数（2 次）：@error 触发的刷新连续失败 2 次后不再重试，避免无限循环；定时刷新（10min）走 `doRefresh` 直调，不受上限限制，定期兜底不被阻断；成功后重置计数
