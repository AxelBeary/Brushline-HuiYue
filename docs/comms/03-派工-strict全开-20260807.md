## 二、任务步骤（精确）

### Step 1：改 tsconfig
- `server/tsconfig.json`：`"strict": false` → `"strict": true`
- 其余项不动（strictNullChecks 等保留；`include`/`exclude` 不动）

### Step 2：修 120 个错误（逐文件，先跑再修）
- 在 `server/` 下跑 `npx tsc --noEmit --strict` 拿到当前错误清单，**逐个文件修**，修完一个文件重跑确认该文件清零
- 修复模式（TS7006 参数隐式 any）：
  - 路由 handler 参数：`request` → `request: FastifyRequest`、`reply` → `reply: FastifyReply`（**注意：reply 若没用可标 FastifyReply；Fastify 路由回调参数类型 Fastify 会推断，但 strict 下回调参数不推断，需显式标注**）
  - 文件顶部补 `import type { FastifyRequest, FastifyReply, FastifyInstance } from 'fastify'`（照 tracking.routes.ts L6）
  - 工具函数参数：按实际语义补类型（string/number/Array<...>）
- TS7053（索引签名，4 个）：
  - `app.ts` L301 附近：`MIME[ext]`——ext 是 string 但 MIME 对象只有已知扩展名键。修法：`MIME[ext as keyof typeof MIME]` 或先判断 `if (ext in MIME)` 再取
  - 其余 3 个在哪个文件以实际 tsc 输出为准，同类修法
- **不改变任何业务逻辑**：只加类型标注/断言，不动代码行为
