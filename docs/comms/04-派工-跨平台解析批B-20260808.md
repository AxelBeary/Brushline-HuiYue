## 本批范围（MVP-1，纯前端）

### 功能
1. **入口**：ManualOrder 页顶部（`web/src/views/artist/ManualOrder.vue` 标题下方）加「粘贴消息解析」按钮
2. 点击 → 弹窗/抽屉：粘贴框（textarea）+「解析」按钮
3. **解析规则（正则/关键词，不引 AI 不引外部 API）**：
   - QQ 号：5-15 位纯数字串（消息中第一个独立数字串）
   - 需求描述：全文作为 description 预填
   - 金额线索：`预算 x 元` / `x 元`（识别为线索提示，不自动填）
   - 日期线索：`x号前` / `x月x日`（识别为线索提示）
4. **预填后人工确认**：解析结果填入表单对应字段（client_qq / description），**不自动提交**——画师检查补全后手动提交
5. **解析不出就不猜**：QQ 号识别不到留空，绝不用假值凑
