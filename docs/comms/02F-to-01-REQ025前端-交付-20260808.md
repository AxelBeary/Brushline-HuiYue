1. 后端 `getOrderInstallments`（`server/src/features/order/order.service.ts:664-692`）：
   `SELECT id, label as name, amount_cents as amountCents FROM order_payment_installments ...`
   **SELECT 不含 locked / locked_reason 列**，返回结构（id/name/amountCents/paidCents/remainingCents/status）无 locked。
2. 路由层 `order.routes.ts:61/237/1010` 透出的 `installments` 均为 `getOrderInstallments` 产物——全链路 API 不返回 locked。
3. 前端：OrderDetail.vue / useOrderPaymentPanel.js / PaymentPanel.vue / OrderTimeline.vue 全无 locked 消费点（grep 零命中）。
4. 节点渲染位置：收款节点列表在 `PaymentPanel.vue`（L47-70 pool-ref-row）、流程时间线在 `OrderTimeline.vue`——**均不在本批授权文件内**（授权仅 OrderDetail.vue + locales）。

**结论**：无数据源 + 渲染组件授权外 → 本批不写代码（前端造无数据源的锁定 UI = 技术债，违反用户铁律）。locked 已在 DB（init.js v40 列 + order.service.ts 锁定引擎），缺口在「API 未透出」。

**建议（后续批联动）**：
