### 2. 动画速度滑块 + 减少动效开关（用户拍板⑪）

- 新增共享 util `web/src/utils/animSpeed.js`（对齐 `fontSize.js` 模式：读 / 写 / 应用 / 归一化，旧值、无值、非法一律 → 1）。
  - localStorage 键：`huiyue_admin_anim_speed`（0.5~2，step 0.25，七档）；safe 封装（`storage.js`）。
  - 应用口径：`document.documentElement.dataset.animSpeed = '0.5'|...|'2'`。
  - 减少动效键：`huiyue_admin_reduce_motion`（'1'/'0'），开 → `dataset.reduceMotion='on'`，关 → 摘掉。
- `artist-tokens.css` 动画段新增七档枚举：`html[data-artist-theme][data-anim-speed='N']` 覆写 `--dur-fast/mid/slow = 0.15s/0.25s/0.35s ÷ 速度系数`（速度快时长缩短，0.5×→0.30/0.50/0.70s … 2×→0.075/0.125/0.175s）。选择器锁 `html[data-artist-theme]`，客户端与登录页零影响。
- 减少动效：`html[data-artist-theme][data-reduce-motion]` 下 `--dur-*` 全压 0.01s，并追加 scoped 全局降级（过渡/动画时长 0.01ms、动画仅 1 次）；声明在速度档之后，同特异性后声明胜出 → 减少动效优先，与动画速度互不干扰。既有 `@media (prefers-reduced-motion)` 组件规则一字未动。
- `ArtistLayout.vue` 挂载时应用存储值（`applyAnimSpeedFromStorage` / `applyReduceMotionFromStorage`，与 `applyFontSizeFromStorage` 同一 onMounted 点位）。
- 预览：滑块旁「点我看速度」按钮 + 演示条（点一次淡入、再点淡出，走 `--dur-mid`，无循环、无位移、无缩放）。

#### 两处明确不动的自查结论

- 问候语逐字洇墨（GreetingNote）：逐字时序是 JS `i * 55ms` + 硬编码 `ink-in .7s`，不走 `--dur-*`；全句 swap 淡入（`.g-text.swap-in`）走 `--dur-mid` 属普通过渡，不属逐字洇墨，随速度档位属预期行为。
- 登录页天光漂移（Login.vue）：`lg-light-drift 240s linear` 硬编码，且登录页位于 `html[data-artist-theme]` 作用域之外，动画速度与减少动效属性均不触及。
