## 一、需求一：留言功能画师可手动关闭（关闭即全站隐藏留言）

### 后端
- **迁移 v68** `server/src/db/migrations/v68-artists-guestbook-enabled.ts`：`artists` 加 `guestbook_enabled INTEGER NOT NULL DEFAULT 1`。
  - 幂等守卫：`PRAGMA table_info(artists)` 命中列即跳过（重复执行/失败残留安全）；
  - 备份：迁移前 `backupDbBeforeMigration(68)`（与 v67 同款，备份失败即中止）；
  - schema.ts 基线同步（`guestbook_enabled INTEGER NOT NULL DEFAULT 1`），types/entities.ts 同步。
- **GET/PUT `/api/artist/profile`**：GET 回显 `guestbook_enabled`（DTO 蛇形）与 `guestbookEnabled`（显式布尔）；PUT 接受 `guestbookEnabled: boolean`（keyMap + updateArtist 白名单 + 布尔转整数，对齐 notify_enabled 口径）。
- **客户端公开数据与留言读写接口（关闭时隐藏/空）**：
  - `GET /api/artists/:subdomain` 返回 `guestbookEnabled: false`（前端据此隐藏整个留言板块）；
  - `GET /api/public/artist/:subdomain/messages` 返回 `{ messages: [], total: 0, page, pageSize }`（历史留言不暴露）；
  - `POST /api/public/artist/:subdomain/messages` 返回 `403 GUESTBOOK_DISABLED`（暂停接收）。
  - 画师端留言读接口（`/api/artist/messages`）不受影响：历史留言不删，重新打开即恢复。

### 画师端
- **开关位置**：账号设置 → 设置页「基本资料」tab（`SettingsProfileTab.vue`，说明在左控件在右，复用 818-H 行结构）。说明：任务书原话允许「SettingsProfileTab 或偏好页通用区」，但红线明确「勿碰 Preferences（M路）」，故落在 SettingsProfileTab 并同步 Settings.vue 表单/保存/脏标记基线。
- **关闭后**：
  - 「留言审核」导航隐藏：`ArtistLayout` menuGroups 过滤 `/guestbook`（移动端抽屉同源，天然同步）；
  - 留言角标隐藏：菜单项整体消失；`refreshPendingMsgCount` 短路为 0 且不再发请求；
  - 仪表盘留言模块隐藏：`Dashboard.vue` dashModules 在 `guestbook_enabled===0` 时强制 `guestbook:false`（个人模块开关之外的总闸）；
  - 直接访问 `/guestbook`：空态页（`guestbookManage.disabled`，选空态而非重定向，理由：URL 可保留、无需路由改动，与 /stats 同口径）。

### 客户端
- 四个主页模板（atelier/classic/gallery/folio）留言板块 `v-if="artist.guestbookEnabled !== false"` 整块隐藏；Folio 固定导航的「留言」锚点同步隐藏；
- `TplGuestbook` 增加 `enabled` prop 双保险（false 时根节点不渲染，不发读请求）。

## 二、需求二：统计功能管理员开关（未开则画师后台隐藏整个统计导航）

### 后端
- `platform_config` 新键 `stats_enabled`，**默认 `'0'`=隐藏**（`migrate.ts` INSERT OR IGNORE，新装/存量库一致）；
- `tracking.service.ts` 新增 `getStatsEnabled()`/`setStatsEnabled()`（'1'/'0' 落库，读回 boolean）；
- 管理员读写 API：扩展既有 `GET/PUT /api/admin/tracking-config`（无通用 platform_config 读写接口，最小新增）；PUT 接受 `{ statsEnabled: boolean }`，与三态 `statsMode` 相互独立不覆盖；
- 画师端下发：`GET /api/artist/profile` 新增 `statsEnabled`（走既有 profile 链路）。

### 管理端
- 开关入口放**「埋点看板」（TrackingAnalytics）**，报告说明理由：页面已有「画师门面统计可见」三态开关，总开关放同页天然成组、语义连续；PlatformManage 是社交平台管理（不相关），AdminDashboard 是运营总览（入口藏得深）。
- 行结构「说明在左控件在右」（复用该页 819-I 已拉齐的 `.row` 结构）；关闭时画师后台隐藏整个统计导航，开启后仍由下方三态开关控制画师可见性（文案已写明）。

### 画师端
- `ArtistLayout` menuGroups 在 `profile.statsEnabled === false` 时过滤 `/stats`（桌面侧栏 + 移动端抽屉同源）；
- 直接访问 `/stats`：空态（`stats.featureDisabled`），与留言同口径；profile 未加载时先 `fetchProfile` 再判定。

## 三、联动语义
- 关闭=隐藏+暂停接收；重新打开即恢复，历史留言/统计数据不删（后端只读开关位，无数据变更）。
