## 问题

GitHub Code Scanning 新报警 #21（js/incomplete-multi-character-sanitization, high）：
`server/src/shared/sanitize.ts` 在 #18/#19 修复后仍报「This string may still contain <script」。

**根因**（实测复现）：
1. `<scr<script></script>ipt>` —— 标签对正则删除内层 `<script></script>` 后，外层 `scr`+`ipt>` 拼出**无闭合**的 `<script>`；标签对正则要求成对匹配，循环 10 次也删不掉这个孤立开始标签。
2. `<script>alert(1)` —— 无闭合开始标签，标签对正则同样匹配不到，整段残留。
3. 危害比成对标签更重：浏览器遇到无闭合 `<script>` 会把后续内容当脚本**直到文档尾**。

## 修复

`removeTagPairs` 链式 replace 加两条兜底（在标签对/自闭合删除之后）：
```
.replace(/<\s*(script|style)\b[^>]*>/gi, '')        // 残留开始标签
.replace(/<\s*\/\s*(script|style)\b[^>]*>/gi, '')   // 残留结束标签
```
此时剩余的 script/style 标签必为孤立（成对已被第一条删除），正常富文本不含
script/style 字样不受影响。
