## 三、任务 2：匿名凭证（anon-token）链路调查与加固

### 3.1 调查结论（如实陈述，未编造根因）

1. **客户端下单与手动录单路径不存在「上传先于凭证就绪」时序缺陷**：`useOrderForm.js`（客户端下单）与 `ManualOrderLeft.vue`（画师手动录单）自 G-7（commit `25bc08f6`）起均为 `await getAnonToken()` 后再调 `/api/upload/reference`，请求头携带 `x-anon-token`。时序上上传必在凭证签发之后。
2. **代码层面可坐实的同错误信息来源（两处画师侧漏带 token）**：grep 全部 `uploadApi.reference` 调用方发现：
   - `web/src/composables/useOrderGallery.js`（订单详情「订单图库」画师加图）直接 `uploadApi.reference(file)`，未带 `x-anon-token`；
   - `web/src/components/artist/queue/QueueBoardList.vue`（队列看板焦点图上传）同样未带。
   
   自 G-7 起服务端 `/api/upload/reference` 强制校验 `x-anon-token`（`upload.routes.ts` F-10 分支），这两处必然返回 400 `INVALID_ANON_TOKEN`、错误文案正是「缺少有效匿名凭证（x-anon-token）」。报障文案虽写「客户端下单」，但这两处是当前代码里唯一确定会触发该报文的路径，列为最可疑坐实点。
3. **客户端下单路径的残余风险 = 本地缓存凭证失效后无换新重试**：`track.js` 的 `getAnonToken()` 命中本地缓存（localStorage + 模块变量）即直接返回，不做有效性预检；凭证可能已过期（服务端 30 天 TTL）、被 GC 回收（`upload-gc` 定期删除 30 天前 token）或库重建后失效。旧逻辑收到 `INVALID_ANON_TOKEN` 直接报错，不换新不重试 → 公网用户（本地存储来自更早测试/旧库）会看到服务端原文错误。本机未复现的合理解释：本机库与 localStorage 始终同源，无失效凭证。
4. **另一个外部可能（无法在本仓库坐实）**：若公网容器实际跑的是 G-7 之前的旧前端构建（上传根本不带 header），同样会出现该报文——需一号在公网复验时核对部署构建版本。
5. **服务端错误分支信息保持现状未放宽**：`upload.routes.ts` 的 `INVALID_ANON_TOKEN` 分支一字未动，安全口径不变。

### 3.2 加固实现

新增统一链路 `web/src/utils/anonUpload.js`（`uploadReferenceWithAnonToken`）：

1. 上传前 `await getAnonToken()`——凭证先于请求就绪；
2. 服务端判 `INVALID_ANON_TOKEN` 时调用新增的 `getFreshAnonToken()`（`track.js` 新导出：清缓存 + `ensureAnonToken(force=true)` 强制重新签发）并重试一次；
3. 返回本次上传实际成功的 token，供下单提交复用（服务端 F-10 归属校验要求参考图与订单同源凭证）。

全部四处调用方统一接入：

| 调用方 | 原行为 | 现行为 |
| --- | --- | --- |
| `useOrderForm.js` 文件选择/粘贴 | await 一次凭证，无重试 | helper；记录成功凭证供提交复用 |
| `ManualOrderLeft.vue` 文件选择/粘贴 | await 一次凭证，无重试 | helper |
| `useOrderGallery.js` 订单图库 | **漏带 token** | helper（修复必报错路径） |
| `QueueBoardList.vue` 队列焦点图 | **漏带 token** | helper（修复必报错路径） |

`useOrderForm.submit()` 改为优先使用上传成功时记录的 token（`refUploadToken`），埋点链路中途清缓存换 token 也不再导致下单与参考图归属不一致；无凭证兜底逻辑保留。

凭证获取失败（签发网络失败/被拒）时各调用方按既有 i18n 文案提示（`orderForm.anonTokenRequired` / `manualOrder.anonTokenRequired`），新增 `orderDetail.anonTokenRequired` zh/en 成对键供订单图库/焦点图路径使用。
