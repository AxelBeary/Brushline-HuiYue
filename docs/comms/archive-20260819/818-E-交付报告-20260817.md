## 三、实现要点

### 1. Tour 组件自研（禁 npm install，零第三方依赖）

- **高亮**：固定定位聚光框（目标元素透明挖孔 + 四周 9999px 大阴影压暗 + 花青细线描边），rAF 跟踪滚动/缩放，`scrollIntoView(block:center)` 把不可见目标带回可视区。
- **气泡**：优先目标下方，放不下翻上方；水平贴目标中线并钳制视口；上一步/下一步/跳过 + 步骤指示；最后一步按钮变「逛完啦」。
- **稳健优先**：目标 50ms 轮询、单步 3s 超时，找不到就自动跳过该步不崩；路由跳转失败（如会话失效被守卫弹回）立即收尾；步进带竞态序号，快速连点旧响应作废。
- **Esc 退出**：TourOverlay 全局 keydown 监听。
- **克制动效**：仅淡入（`--dur-fast`），无位移/弹跳；`prefers-reduced-motion` 直接停。
- **不引第三方**：未执行任何 npm install。

### 3. 触发与重置

- 首次进入仪表盘：OnboardingCard 加载且卡片可见（未 dismissed、必做项未全完成）时，`localStorage` 无 `inkglean_tour_seen_v1` 标记即自动启动；启动即记 seen，中途刷新不重复弹。
- 重置入口：卡片主按钮「跟我逛一遍后台」→ `useTour().start()`，已看过也能随时重看；start 不检查 seen。
- 编程接口：`useTour().start()/stop()/next()/prev()/skip()/hasSeen()` 已导出，供下批偏好页挂「再看一遍」。
- 克制纪律：dashModules 隐藏卡片时自动启动不触发，但其它入口仍可 start（本批入口即卡片按钮）。
- 持久化键：`inkglean_tour_seen_v1`，读写走 `safeGetItem/safeSetItem`（存储禁用静默降级）。
