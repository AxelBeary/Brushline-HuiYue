## 现象
画师上传头像后，后台侧边栏左下角身份区始终显示文字头像（名字首字符），不显示上传的图片。

## 根因
`web/src/components/ArtistLayout.vue` 的三处头像渲染点（展开侧边栏 / 折叠态 / 移动端抽屉）只渲染 `avatarChar`（名字首字符），从未读取 `store.profile.avatar`。数据链路正常（API 返回 avatar 路径、文件存在、`/uploads/images/` 公开可访问），纯前端组件未消费该字段。

## 修复
ArtistLayout.vue 单文件，+9/-3：
- 新增 `avatarUrl` computed（`store.profile?.avatar` → `/uploads/` 拼接）
- 三处渲染点：有头像显示 `<img>`，无头像回退原文字头像
- 新增 `.avatar--img { object-fit: cover }` 样式
