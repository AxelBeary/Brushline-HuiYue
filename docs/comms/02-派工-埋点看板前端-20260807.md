## 二、后端契约（三号实现，你按此对接；前后端联调以本契约为准）

### 1. 管理员看板
- `GET /api/admin/tracking/summary?days=30`（requireAdmin）
- 响应：
  ```json
  {
    "total": 1234,
    "byName": [{ "name": "order_form_start", "count": 120 }],
    "byDay": [{ "day": "2026-08-07", "count": 45 }],
    "funnel": [
      { "name": "order_form_start", "count": 100 },
      { "name": "order_form_step_view", "count": 80 },
      { "name": "order_form_submit_attempt", "count": 60 },
      { "name": "order_form_submit_success", "count": 50 },
      { "name": "order_submit_success", "count": 45 }
    ]
  }
  ```
  - days 参数：最近 N 天（默认 30，最大 90）。byDay 按 `date(created_at, 'localtime')` 聚合。
  - funnel：只取下单漏斗 5 个事件名（白名单里 order_form_* 开头 + order_submit_success），按事件名顺序返回，count 为各自总数（不做去重漏斗，本期简单版）。

### 2. 画师门面统计（自己的）
- `GET /api/artist/tracking/summary?days=14`（requireAuth）
- 响应：
  ```json
  {
    "enabled": true,
    "total": 234,
    "byName": [{ "name": "dashboard_view", "count": 30 }]
  }
  ```
  - enabled：管理员开关（false 时前端不渲染该区块，后端仍正常统计）
  - 只统计 `artist_id = 当前登录画师` 的事件；byDay 不需要（门面只放总数+按事件名小列表）

### 3. 管理员开关
- `GET /api/admin/tracking-config`（requireAdmin）→ `{ "artistStatsVisible": true }`
- `PUT /api/admin/tracking-config`（requireAdmin）body `{ "artistStatsVisible": false }` → `{ "artistStatsVisible": false }`
- 存储：`platform_config` 表 key=`artist_stats_visible`，value='true'/'false'，**默认 true**
- 前端管理员面板的开关**调这个接口**，不要本地存
