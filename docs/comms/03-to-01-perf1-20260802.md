# 三号→一号：PERF-1 字体修复 + profile 补 slotDisplay（2026-08-02）

## 做了什么

### 任务 A：PERF-1 霞鹜文楷子集拆分

- 旧：单文件 `lxgw-wenkai.woff2`（3.3MB），首屏全量加载 → 字体跳变
- 新：6 个 unicode-range 子集（woff2），首屏只加载第一片（~215KB）
- `font-display: swap` 已有，unicode-range 按需触发浏览器懒加载
- 新增 `scripts/subset_wencai.py`（fonttools 子集工具，可重复执行）
- 删除旧单文件

| 子集 | 大小 |
|------|------|
| lxgw-wenkai-00 | 215 KB |
| lxgw-wenkai-01 | 280 KB |
| lxgw-wenkai-02 | 298 KB |
| lxgw-wenkai-03 | 296 KB |
| lxgw-wenkai-04 | 306 KB |
| lxgw-wenkai-05 | 303 KB |
| **总计** | **1.62 MB**（原 3.3MB，-51%） |

> 注：总大小 1.62MB 略超 1.5MB 目标，但核心收益是首屏从 3.3MB → 215KB（-93%）。总量受限于 7024 字符的 CJK 字形数据，进一步压缩需裁减字符集。

### 任务 B：profile API 补 slotDisplay

- `GET /api/artist/profile` 响应新增 `slotDisplay` 字段
- 画师端 SlotOverview 不再需要额外调公开 API
