## 一、讨论背景

- 用户原话：「画师价格管理-画风与价格这里 增项的交互有更好的解决方案吗」
- 位置：`web/src/components/artist/ArtStyleManager.vue` L102-174（画风卡片内「增项区」）
- 现状：REQ-023 多画风模型 + REQ-029 手动录单 + v0.35 补漏后形成

## 二、现状（代码实测，一号已核实）

增项区 = 每个画风卡片内一行式列表：
```
[✓ 增项名] [类型tag] [¥价格输入框] [展开尺寸覆盖按钮]
```
- checkbox：启用/禁用（即时保存）
- 类型 tag：control 类型（radio/switch/quantity/checkbox）
- 价格输入：`el-input-number`，placeholder 显示模板默认价，change 即时保存（防抖 500ms）
- 「展开尺寸覆盖」按钮 → 垂直展开面板：每尺寸一行 = [尺寸名] [价格输入] [隐藏 checkbox]

**用户痛点（一号分析）**：
1. 增项多 + 多尺寸时**行很长、横向拥挤**（每增项一行 4 控件）
2. 尺寸覆盖面板**垂直展开**挤占卡片空间（1 增项展开 = N 尺寸 × 2 控件）
3. 价格输入 `:step="10"`——低价增项微调不便
4. 多个增项同时展开面板时页面很长

## 三、候选方案（详谈起点，可扩展）

### 方案 A：表格化（推荐起点）
增项区从「行列表」改 **el-table**：
- 列：增项名 / 类型 / 模板默认价 / 本画风价格（行内编辑）/ 尺寸覆盖（「N 尺寸」按钮 → 弹窗/抽屉管理）
- 优势：对齐、批量可读、增项多时滚动一致、视觉专业
- 代价：改动中等（模板 + 状态管理重构）

### 方案 B：抽屉管理
增项区只显示「已启用增项胶囊」（名称+价格），点「管理增项」进抽屉：
- 抽屉内表格管理全部增项 + 尺寸覆盖
- 优势：画风卡片清爽、复杂操作收进抽屉、与「画师后台工具页」风格一致
- 代价：多一层跳转（高频操作变两步）

### 方案 C：行式优化（最小改动）
保留行式但优化：
- 尺寸覆盖改 hover 图标 → popover 小表（不垂直展开占空间）
- 价格 `:step="10"` → `:step="1"` + 直接输入
- 启用 checkbox 与价格合并（未启用则价格灰）
- 优势：改动最小、风险最低
- 代价：本质还是行式，长行问题未根治

### 方案 D（可探讨）：按尺寸分页/折叠
增项按「启用中 / 未启用」分组 + 尺寸覆盖默认折叠只显示价格，点开才看隐藏

## 四、决策点（详谈需用户拍板）

1. **主形态**：表格（A）/ 抽屉（B）/ 行式优化（C）/ 其他？
2. **尺寸覆盖交互**：弹窗表格 / 抽屉 / hover popover / 行内展开（现状）？
3. **价格输入体验**：步进值、是否保留「即时保存」vs 改为「显式保存」？
4. **启用 vs 价格**：是否合并为一个控件（未启用=灰）？
5. **多画风一致性**：是否所有画风统一表格形态（vs 单画风特判）？

## 五、约束

- 用户铁律：「避免屎山，禁止技术债，代码要优雅！」
- 克制动效纪律：一次性动画、不位移 hover
- 纸墨 token 双主题
- 不引新依赖
- 后端零改动（增项结构已定型：addon_templates + art_style_addons + size_overrides）
