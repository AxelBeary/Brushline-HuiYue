## Bug 1：管理员默认流程模板只读（用户：「默认流程模板为什么不能改？怎么还是灰色的？」）

### 根因（一号已核实）
- `web/src/views/admin/DefaultWorkflowEditor.vue:12` 用 `<WorkflowPaymentEditor mode="template" />`
- `web/src/components/artist/WorkflowPaymentEditor.vue:9` `:readonly="mode === 'template'"` → **管理员看到的默认流程编辑器全部灰色只读**
- 后端 PUT `/api/admin/default-workflow`（admin.routes.ts:417-440）**完整可写**，无问题

### 修复
- DefaultWorkflowEditor 应该用**可编辑模式**（管理员要能改默认模板）
- 方案：给 WorkflowPaymentEditor 加 `mode="admin"` 或复用 `mode="artist"` 的可编辑逻辑（先读 WorkflowPaymentEditor 完整代码确认 artist 模式的行为——它带保存按钮 + api.update；管理员编辑默认模板需要**自己的保存按钮调 PUT /api/admin/default-workflow**）
- 保留画师端「查看默认模板预览」时的只读（那是 artist 设置页引用 template 的场景，**不要误伤**——先 grep 谁在用 mode="template"）
- **若 WorkflowPaymentEditor 的 template 模式同时被画师预览和 admin 编辑共用**：拆开——admin 编辑用新 prop（如 `editable`），保存走 adminApi.updateDefaultWorkflow（先 grep adminApi 确认方法名）

### 验收
- 管理员打开「默认流程」页：节点名称/描述/收款开关/话术都可编辑，保存调 PUT /api/admin/default-workflow 成功
- 画师端预览默认模板仍只读（不误伤）

## Bug 2：主页快捷按钮「仪表盘」没删（用户：「主页右边快捷按钮的仪表盘怎么还没删？」）

### 修复
- 从 QUICK_ACTION_POOL **删除 dashboard 项**（用户已拍板不要）
- 检查 QUICK_ACTION_POOL 其余项：确认没有其他「多余导航型」按钮（如指向 /stats /settings 的纯跳转——若用户没拍板删，保留但报告列出）
