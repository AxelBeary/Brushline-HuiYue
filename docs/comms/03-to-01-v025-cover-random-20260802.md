## 做了什么

### 任务 A：封面图指定 + 轮播

- 迁移 v27：`artworks.is_cover INTEGER DEFAULT 0`（幂等）
- `PUT /api/artist/artworks/:id/cover`：设为封面（事务内同画师其他作品自动取消）
- `DELETE /api/artist/artworks/:id/cover`：取消封面
- 公开 API `GET /api/artists/:subdomain` 返回的 artworks 封面排第一（`ORDER BY is_cover DESC, sort_order ASC`）
- 无封面时排序不变（向后兼容）

### 任务 B：多模板随机

- 迁移 v28：`artist_workflow_stages.random_template INTEGER DEFAULT 0`（幂等）
- `PUT /api/artist/workflow/:id` 增加 `randomTemplate` 布尔字段
- `order-workflow.service.ts` 话术消费点接入随机选择：`speech_template` 以 `\n` 分隔多模板，`random_template=1` 时随机选，`=0` 时始终第一个
- `workflow.service.ts` 新增 `resolveSpeechTemplate()` 导出（供未来其他消费点复用）
- `StageCamel` 输出增加 `randomTemplate: boolean`

### 顺手修复

- `entities.ts` 补 `Tier.visibility`（v0.24 遗留 tsc 错误）

## 数据库变更

- v27：`ALTER TABLE artworks ADD COLUMN is_cover INTEGER DEFAULT 0`
- v28：`ALTER TABLE artist_workflow_stages ADD COLUMN random_template INTEGER DEFAULT 0`
- 回滚：两列均 DEFAULT 0，删除列即回滚（SQLite 3.35+ DROP COLUMN）
- 存量数据无影响（默认 0 = 无封面 / 不随机）
