## 任务 C：S5 额度池设计

### 额度池是什么

画师可设置的**月度接单配额**：每月最多接 N 单，跨月自动重置。与现有 `batch_limit`（同时在途上限）互补：

| 维度 | batch_limit（现有） | 额度池（新增） |
|------|---------------------|----------------|
| 时间 | 无时间窗口，看在途数 | 月度窗口，看当月已确认数 |
| 触发 | 在途订单 ≥ N → 满 | 当月确认订单 ≥ M → 本月不再接 |
| 重置 | 订单交付/取消后释放 | 每月 1 日自动重置 |

### 数据模型

```sql
ALTER TABLE artists ADD COLUMN monthly_quota INTEGER DEFAULT NULL;  -- NULL=不启用
-- 不需要新表：当月已用额度 = COUNT(orders WHERE artist_id=? AND status NOT IN ('cancelled') AND created_at >= 月初)
```

不新建表。`monthly_quota` 为 NULL 时不启用（与 batch_limit 的 NULL 语义一致）。已用额度实时计算，不存计数器（避免漂移）。

### API 草案

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | /api/artist/profile | 新增 `monthlyQuota` 字段（integer\|null, 0~999） |
| GET | /api/artists/:subdomain | 返回 `monthlyQuota` + `monthlyUsed` + `quotaDisplay`（如"本月 3/10"） |

下单拦截：`createOrder` 时若 `monthly_quota` 非 NULL 且当月已用 ≥ quota → 400 `QUOTA_FULL`。

### 与 batch_limit 的交互

两者独立检查，任一触发即拒绝：
1. batch_limit：在途 ≥ N → BATCH_FULL
2. monthly_quota：当月 ≥ M → QUOTA_FULL
