## Bug 1（P0）：流程比例板块 SyntaxError: Invalid token in placeholder: '客户名'

**根因**：`web/src/components/artist/StageListView.vue:72`

```vue
:placeholder="$t('workflow.speechPlaceholder')"
```

locale 字符串 `'{客户名}，你的订单已{节点名}。'` 中的 `{客户名}` 被 vue-i18n message compiler 当 ICU 占位符解析，中文不是合法标识符→崩溃。

**修复**：这个 placeholder 是后端变量契约的示例文案，中英界面都保持中文原文（locale 注释已写明）。两种修法选其一：
- A（推荐）：不走 `$t()`，直接硬编码 placeholder 文案（或用 `t('workflow.speechPlaceholder', {}, { escapeParameter: true })` 不行——根本问题是花括号）
- B：locale 里转义花括号：`"{'{'}客户名{'}'}，你的订单已{'{'}节点名{'}'}。"`

改 zh-CN.js:478 和 en.js:478 两个文件。

## Bug 2（P0）：详细计价展开崩溃 TypeError: Cannot read properties of undefined (reading 'length')

**根因**：`web/src/views/client/OrderForm.vue:133`

```vue
<div v-if="pricePreview.installments.length > 1" class="installment-row">
```

v0.19 修复时给 266 行和 303 行加了可选链（`pricePreview?.installments?.length`），**漏了 133 行**。当 pricePreview 存在但 installments 为 undefined 时崩溃。

**修复**：第 133 行改为 `pricePreview?.installments?.length > 1`。同时全局搜索 OrderForm.vue 和 ManualOrder.vue 中所有 `pricePreview.` 直接访问（非可选链），确认无遗漏。

## Bug 3（P2）：约稿页亮暗/中英按钮位置反直觉

**根因**：`OrderForm.vue:465` 和 `TrackOrder.vue:309`

```css
.page-prefs { position: absolute; top: 16px; right: 16px; z-index: 10; }
```

从画师主页跳转到约稿页后，ThemeToggle 突然跑到右上角，与主页位置不连贯。

**修复**：将 `.page-prefs` 改为跟随页面头部布局（不用 absolute），与画师主页的 ThemeToggle 位置保持一致。具体位置参考 ArtistHome 系列模板中 ThemeToggle 的放置方式。

## Bug 4（P1）：看板"开始制作"报错"不能进行此状态转换"

**根因**：`web/src/views/artist/QueueBoard.vue` 按钮显示逻辑穿透。

- 第 95 行：`v-if="element.currentStageId != null && canAdvance(element)"` → 工作流推进按钮
- 第 102 行：`v-else-if="nextAction(element.status)"` → 固定状态按钮（如"开始制作"）

当订单已接入工作流（currentStageId 不为 null）但 canAdvance 返回 false 时，v-if 失败穿透到 v-else-if，显示了不该出现的固定状态按钮。点击后走 updateStatus → 后端状态机拒绝。

**修复**：第 102 行 v-else-if 加条件：

```vue
v-else-if="element.currentStageId == null && nextAction(element.status)"
```

确保工作流订单不会穿透到固定状态按钮。
