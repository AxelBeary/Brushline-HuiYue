## 二、实现说明

### canvas 合成逻辑（web/src/utils/watermark.js）

- **布局纯函数**（无 DOM 依赖，可单测）：
  - `wmAnchor`：单枚锚点（四角 + 中央 5 选 1，margin 距边，负值夹 0，水印大于画布时夹到 0）
  - `wmCorners`：四角各一枚（派工单「四角」模式）
  - `wmTileGrid`：平铺网格（步进 = 元素尺寸 + 间距，非法输入返回空数组）
- **绘制** `drawWatermark(ctx, { image, mode, position, opacity, fontSize, spacing, margin, logo, text, logoScale })`：
  - 签名保留派工单全部参数；`image` 参数为兼容派工单保留（当前布局不依赖）
  - `paintWatermarkAt`：文字/LOGO 统一绘制入口，绕元素中心旋转，opacity 夹 0~1
  - 文字：canvas 字体栈跨平台回退（-apple-system/Segoe UI/PingFang SC/Microsoft YaHei）
  - LOGO：`logoScale`（0~1，相对画布宽比例）保持原始宽高比缩放
  - 三种模式：
    - `corner`（四角）：position='corners' → 四角各一枚；position=单角/中央 → 该位置一枚；margin 控制边距
    - `stretch`（拉伸）：LOGO 等比 cover 铺满全图（不变形，裁掉溢出）；文字居中大字号；opacity 半透明铺底
    - `tile`（平铺）：按间距重复排列覆盖全图；文字斜置 -45°（经典平铺水印样式），LOGO 正置
- **完整链路** `composeWatermarked(src, options) → Promise<dataURL>`：loadImage → 建 canvas（原图尺寸）→ 画背景 → 叠水印 → `toDataURL('image/png')`

### 同源处理（REQ-035 §六 铁律已落实）

- 作品图 `/uploads/{image_path}`、完稿图 `deliverables[].url`（后端签名 URL）均同域（fastifyStatic 托管）→ canvas.drawImage 无污染，可安全 toDataURL
- 新传图走 FileReader dataURL（不发服务器）
- **UI 无外部 URL 输入入口**（避免画布污染 SecurityError）
- 合成失败（极端污染/加载失败）统一捕获 → 清空预览 + 提示 `watermark.renderError`，不静默

### 页面（Watermark.vue）

- 左区：图片来源 radio（新传图拖拽/点击选图 / 作品图网格缩略图 / 完稿图订单下拉→完稿图缩略图）+ 实时预览（参数防抖 300ms 重绘）
- 右区：水印类型（文字：可编辑文字 + 字号滑块；LOGO：本地上传 PNG + 缩放滑块）+ 透明度滑块 + 模式（四角/拉伸/平铺）+ 模式相关参数（四角=边距+位置；平铺=间距）+ 导出按钮
- 无图时导出按钮禁用（`:disabled="!src"`）
- LOGO 持久化：localStorage key `huiyue_wm_logo_<artistId>`，下次进入自动加载；重新上传即覆盖；类型白名单 `image/png`
- 默认文字水印 = 画师展示名（store.artistName，getProfile 未加载时自动 fetchProfile）
- 视觉对齐纸墨 token（--card/--line/--ink/--hq），双主题亮暗自适应；窄屏双栏自动堆叠

### 设计决策说明（施工图两处含糊点的务实处理）

1. **position 与「四角」模式的语义**：施工图要求「位置（四角 + 中央，5 选 1）」同时要求「四角：四角各一枚」，两者字面冲突。落地：position 选项 = 四角（默认，四角各一枚）/ 左上 / 右上 / 左下 / 右下 / 中央；选具体角或中央时仅该位置一枚。即「四角各一枚」是默认态，位置选择是细调。i18n 补 `watermark.positionAll` 键。
2. **LOGO 缩放滑块**：施工图参数列表无 logoScale，但需求明确「LOGO 缩放滑块」。落地：扩展 `logoScale` 参数（0.05~0.5，默认 0.2），i18n 补 `watermark.logoScale` 键。
3. **新增补充 i18n 键**（双语成对）：sourceSection / watermarkSection / logoScale / modeLabel / positionAll / posTopLeft~posCenter / preview / renderError / fileTypeError。派工单列出的键全部覆盖。
