## 背景（用户点名）

画师后台每条页面上方有 54px 高的顶栏，只放页面标题 + 主题切换 + 语言切换，用户认为"直接浪费了大片空间"。v0.38 之前主题切换本来就在侧边栏左下角，v0.38 骨架重做时搬上了顶栏。目标：**桌面端干掉顶栏，主题/语言切换回侧边栏底部；移动端保留顶栏**（移动端无侧边栏）。

## 改动（全部在 `web/src/components/ArtistLayout.vue`）

### A1. 顶栏只保留移动端

第 106 行：
```html
<header class="topbar">
```
改为：
```html
<header class="topbar" v-if="isMobile">
```

### A2. 侧边栏底部（展开态）加回主题 + 语言

第 75-79 行现状：
```html
<div class="footer-actions">
  <el-button text size="small" class="logout-btn" @click="logout">
    {{ $t('menu.logout') }}
  </el-button>
</div>
```
改为：
```html
<div class="footer-actions">
  <div class="footer-tools">
    <ThemeToggle />
    <button
      class="lang-btn" @click="toggleLang"
      :title="locale === 'zh-CN' ? 'English' : '中文'"
      :aria-label="locale === 'zh-CN' ? 'Switch to English' : '切换到中文'"
    >
      {{ locale === 'zh-CN' ? 'EN' : '中' }}
    </button>
  </div>
  <el-button text size="small" class="logout-btn" @click="logout">
    {{ $t('menu.logout') }}
  </el-button>
</div>
```

### A3. 侧边栏底部（折叠态）加回主题 + 语言

第 82-99 行折叠态 `<template v-else>` 内、`</el-tooltip>` 之后加：
```html
<div class="collapsed-tools">
  <ThemeToggle />
  <button
    class="lang-btn" @click="toggleLang"
    :title="locale === 'zh-CN' ? 'English' : '中文'"
    :aria-label="locale === 'zh-CN' ? 'Switch to English' : '切换到中文'"
  >
    {{ locale === 'zh-CN' ? 'EN' : '中' }}
  </button>
</div>
```

### A4. 样式

在 `<style scoped>` 末尾（`.drawer-footer` 之后）加：
```css
.footer-tools { display: flex; align-items: center; gap: 8px; }
.collapsed-tools { display: flex; flex-direction: column; align-items: center; gap: 8px; margin-top: 10px; }
```

> 说明：`.lang-btn` 样式已存在（502-513 行，scoped 内全局生效），ThemeToggle 组件自带样式，无需新增按钮样式。
