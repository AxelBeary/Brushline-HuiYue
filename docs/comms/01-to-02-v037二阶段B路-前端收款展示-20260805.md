## 背景（一号已实锤，不要重新侦查）

用户终验反馈：「画师前一个节点忘记收钱，不能把所有待收加起来提示」——当前 OrderDetail 顶部横幅只显示第一个未收节点的待收（nextDueInstallment），画师看不到客户总共还欠多少。**已核实：enrich 响应里已有 `remainingCents` 字段（= 总价 − 已收，order.routes.ts L57）**，总横幅零后端依赖，本任务可独立合入。

## 任务 1：订单级待收总横幅（核心，立即生效）

OrderDetail.vue 顶部 `next-due-banner` 改造：
- **主信息**：「共待收 ¥X」——X = `order.remainingCents`（订单级总待收，已含所有未收节点之和）
- **副信息**：当前节点提示保留（第一个 remaining > 0 的节点）：「当前：{name} ¥Y」
- 两者都有才显示横幅；点击仍 scrollToPayment
- locales 新键（zh-CN.js + en.js 的 orderDetail 段）：如 `totalDueLabel: '共待收 {amount}'` + `currentDueSuffix: '当前：{name} {amount}'`——键名你定，风格对齐既有

**边界**：remainingCents 为 0 或 null 时不显示横幅（现有 `v-if="!isTerminal && nextDueInstallment"` 改为 `!isTerminal && remainingCents > 0`）。
