## 任务

### A. 迁移 v20：artist_workflow_stages 加 speech_template 字段

```sql
ALTER TABLE artist_workflow_stages ADD COLUMN speech_template TEXT DEFAULT '{客户名}，你的订单已{节点名}。';
```

存量节点回填默认话术。schema 字符串同步。自动备份。

### B. 节点编辑 API 扩展

PUT 工作流节点时接受 speechTemplate 字段（可选，不传则不改）。

### C. 订单详情返回话术（变量替换）

getOrder() 或新增字段：根据订单当前节点（current_stage_id）取对应 speech_template，替换 9 个变量后返回 `speechText` 字段。

变量替换规则：
- {客户名} → client_name（空则空串）
- {客户QQ} → client_qq
- {订单号} → order_no
- {档位名} → tier name（无档位则空串）
- {节点名} → 当前节点 name
- {截稿日} → deadline（格式化为 X月X日，无则空串）
- {总价} → ¥ + final_price_cents/100
- {已付} → ¥ + 已 paid 分期合计/100
- {待付} → ¥ + (总价-已付)/100

无对应数据时替换为空字符串（不显示 undefined 或花括号）。

### D. 客户沟通数据

订单详情返回额外字段供前端"客户沟通"小块使用：
- clientQq
- totalPriceCents / paidCents / unpaidCents（价格小结）
- speechText（已替换变量的话术）
