## 第 1 波（立即开工，不等后端）

### 任务 A：#15 瀑布流零跳动——前端

**根因**：CSS columns + el-image lazy + skeleton 固定 200px ≠ 真实高度 → 每张图加载完整列 reflow。

**实施**（后端迁移 v30 加 width/height 字段，三号在做。你先改前端，字段缺失时兜底）：

1. **TplGallery.vue**：el-image 外层 div 绑定 aspect-ratio
   ```html
   <div :style="art.width && art.height ? { aspectRatio: art.width + '/' + art.height } : {}">
     <el-image ... />
   </div>
   ```
2. **skeleton 保留**：作为无 width/height 时的兜底（存量未回填的图片）
3. **el-image 加 `fit="cover"`**：确保图片填满 aspect-ratio 容器
4. **4 模板验证**：Classic/Folio/Gallery/Atelier 都用 TplGallery，改一处全生效

**验证**：build 通过。实际零跳动效果需后端 width/height 就绪后容器内验证。
