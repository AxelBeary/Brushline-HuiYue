## 第一部分：批F 时间条拖拽平移（§八B）

### 现状（已实测）
- `QueueBoardCalendar.vue` 已有 4 档缩放（`TL_ZOOMS`：14/30/90/182 天 × dayWidth 48/32/12/7px）
- 已有 `tlCanvasStart/End`（画布覆盖订单实际范围，上限 2000px）+ `tlGoToday`（回到今天）
- 已有订单横条拖拽改期：`onTlBarDown`/`onTlHandleDown`

### 要做
1. **日期刻度区（顶部轴区/空白区）按住拖拽 = 平移画布**：
   - 新增 pointer 事件（`pointerdown/move/up` + `setPointerCapture`）绑定在刻度区容器
   - 拖拽中按 `deltaX` 移动画布 scrollLeft（或平移 tlCanvasStart/End 的 offset），松手停止
   - **轻移阈值**（~4px）防误触；与横条拖拽事件**区分**：事件绑在刻度区（axis），横条区仍走原逻辑
2. **缩放档位 = 视野宽度**（不是数据范围）：
   - 现有 TL_ZOOMS 的 days 同时决定视野和画布裁剪——改为**画布始终覆盖全部订单日期范围**，缩放只改 dayWidth/视野中心
   - 「两周」时默认视野 14 天，但可左右滑动看窗口外订单
3. **缩放切换不丢视野中心**：切换 TL_ZOOMS 时保持当前视野中心日期不变（不是跳回今天）

### 验收
- 刻度区按住拖动 → 画布跟随平移，松手停新位置
- 「两周」档位下订单超出视野 → 可继续拖动查看
- 拖订单横条 → 仍是改期（不触发平移）
- 切换缩放 → 视野中心保持

## 第二部分：批F2 滚轮缩放 + 双指缩放（§八B2）

### 要做
1. **刻度区滚轮 = 缩放**（向上放大 2w→1m→3m→6m，向下缩小），复用 TL_ZOOMS 档位循环
2. **内容区（订单横条区）滚轮 = 保持原生滚动**（不触发缩放）——事件绑定在刻度区
3. **移动端双指 pinch**：`touchstart` 记录 `e.touches.length`，双指时记录间距，`touchmove` 按间距变化切档；单指水平滑动 = 平移（与批F一致）
4. **缩放后三处状态同步**：tlZoom + radio 选中态 + localStorage（`saveTlZoom` 已有）
5. **防抖动**：连续滚轮快速触发合并（rAF 或 throttle）

### 验收
- 刻度区滚轮向上 → 逐级放大；向下 → 逐级缩小
- 订单横条区滚轮 → 不缩放（保持滚动）
- 双指捏合/张开 → 切档
- 缩放后 radio + localStorage 同步

## 第三部分：批G 月历优化（§八C）

### 现状（已实测）
- 月历视图已有：翻月头（←/→ + 回今天）、42 格网格、今天/周末高亮、订单色带（正式实心/缓冲半透明/无截稿斜纹/逾期朱砂/完成石绿）+ 图例 + tooltip + 点击跳订单详情、每格最多 3 条 + "+N" 溢出

### 要做（MVP）
1. **「可接单/已满」标识**：
   - 无订单覆盖的日期格 = 「可接单」轻量标识（石绿系浅色角标/底色，视觉区分）
   - 有订单覆盖 = 保持现有订单带（不额外加"已满"——MVP 只做有无的轻量标识，深度口径 P2）
2. **日视图展开**：点击 "+N"（或日期格）→ 弹出当天完整订单列表（弹窗/抽屉，复用 OrderList 行样式：订单号/客户/档位/状态/点击跳详情）
3. **跳转指定月份**：表头加月份选择器（el-date-picker 月粒度 或 输入年月），选后直接跳月

### 验收
- 无订单日期格有「可接单」标识
- 订单 >3 条的日期格点 "+N" → 弹当天完整列表
- 表头月份选择器 → 直接跳该月
