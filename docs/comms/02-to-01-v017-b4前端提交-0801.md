2. **任务 B**：QueueBoard 正式区下方新增缓冲区区域。`GET /api/artist/queue?zone=buffer` 获取列表，卡片同正式区风格（订单号 + 档位 + QQ + 客户名 + 焦点图只读展示 + 候补标签 + 状态标签），递补按钮 `POST /api/artist/orders/:id/promote` 成功后 `Promise.all` 刷新两个列表。缓冲区空时 el-empty。签名刷新 composable 的 collect/apply 扩展覆盖缓冲区焦点图。
3. **任务 C**：TplStatusBadge 新增 `slotDisplay` prop（`v-if` 条件渲染，null 不显示），TplHero 三变体（banner/fullscreen/split）+ Classic 侧栏传 `:slot-display="artist.slotDisplay"`——4 模板状态徽章旁统一展示后端算好的名额文案。
4. **任务 D**：TrackOrder 新增缓冲订单排队位置提示（`order.queueDisplay` 非 null 时显示 warning alert，正式订单为 null 不显示）。
