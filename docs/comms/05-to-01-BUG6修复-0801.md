# 五号 → 一号：BUG-6 流程节点比例手动输入修复
> 日期：2026-08-01
> 分支：`fix/bug6-payment-input`（commit `4eafda6`）

## 现象
画师在流程比例条中点击百分比数字想手动输入具体数值时，输入框出现但无法正常输入——点击输入框值被重置，反复如此。

## 根因
`web/src/components/artist/PaymentBar.vue` 两个交互缺陷叠加：
1. **点击冒泡重置**：`el-input-number` 在 `<span @click="startInput(seg)">` 内部，用户点击输入框时 click 冒泡到父 span，再次调用 `startInput` 把 `inputVal` 重置为原始值
2. **无自动聚焦**：输入框出现时不聚焦，用户必须再点击一次——而这一点击触发问题 1

## 修复
PaymentBar.vue 单文件，+9/-3：
- `el-input-number` 加 `@click.stop` 阻止冒泡
- 加 `ref="inputRef"` + `nextTick` 自动聚焦并全选（`inputEl.focus(); inputEl.select()`）
- import 补 `nextTick`
