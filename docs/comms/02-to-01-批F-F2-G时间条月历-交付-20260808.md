## 修复的偏差（派工单已预见的坑）

**偏差**：`@wheel="onTlCanvasWheel"` 绑在整个 `.tl-canvas`（含订单横条区）上，且未用 `.prevent`——Vue 3 对 wheel 默认 passive，handler 内 `e.preventDefault()` 无效，导致：
1. 内容区（订单横条区）滚轮被劫持为缩放，原生滚动失效（违反 F2 验收「内容区滚轮=原生滚动、区域分离」）
2. passive 下 preventDefault 无效 → 缩放同时浏览器仍滚动，体验抖动

**修复**（2 行）：
1. `.tl-canvas` 移除 `@wheel` 绑定（横条区恢复原生滚动）
2. `.tl-axis`（刻度区）加 `@wheel.prevent="onTlCanvasWheel"`（`prevent` 修饰符强制非 passive，缩放生效且不滚动页面）

**附带优雅性修正**：月历 `+N` 按钮 `@click` 加 `.stop`，避免冒泡到格子重复触发 `openDayView`（幂等但双调不优雅）。

### 任务 F：刻度区拖拽平移 ✓
- 现有实现：整块画布 pointer 事件（`onTlCanvasDown/Move/Up/Cancel`），刻度区/空白区拖拽=平移，横条/手柄 `stopPropagation` 只走改期拖拽

### 任务 F2：滚轮缩放 + 双指 pinch ✓
- 刻度区滚轮=缩放（`onTlCanvasWheel`，deltaY 累计 48 切一档，快速连滚可多档），内容区滚轮=原生滚动（本批修复）
- 双指 pinch：两指间距 ±20% 切档（tlPinchDist 基准，连续捏合可多档）
- 切档统一走 `changeTlZoom` → radio 选中态 + `saveTlZoom` localStorage 同步
- 缩放保持视野中心（keepTlCenter）
- **实测**：轴区下滚 3 次 2w→6m（档位+localStorage 同步），上滚 2 次→1m；内容区滚轮档位不变（一个月→一个月）；切档中心日期 91 天恒定（2w→1m→3m），6m 触底 clamp 属预期

### 任务 G：月历「+N」日视图展开 ✓
