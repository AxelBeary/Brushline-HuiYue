# 一号→二号：v0.24-B 接稿设置独立 + 名额概览改版（2026-08-02）

## 任务

Spec：`docs/requirements/REQ-013-整理.md` #4 节。用户已拍板。

### 波 1：设置页新增"接稿设置"标签页（~1.5h）

Settings.vue 当前标签页顺序：基本资料 / 主页模板 / 约稿须知 / 嵌入脚本

改为：基本资料 / **接稿设置** / 主页模板 / 约稿须知 / 嵌入脚本

**挪入接稿设置的内容**（从"基本资料"标签页中移出）：
- 正式名额开关（batchLimitEnabled + batchLimit）
- 缓冲位（bufferLimit）
- 月度额度开关（quotaEnabled + monthlyQuota）
- 4 个缓冲开关（auto_promote / hide_queue_position / hide_promote_notify / buffer_short_form）

基本资料保留其余设置项（名称/头像/简介/状态/QQ/社交链接/公告等）。

### 波 2：名额概览卡片改版（~1h）

SlotOverview.vue 改版：
- **主文案**：复用后端 slotDisplay（`store.profile.slot_display` 或从 getProfile 返回），大字显示（和客户主页看到的一样）
- **进度条**：正式 + 缓冲合并一个条（总容量 = batchLimit + bufferLimit，已用 = formalCount + bufferCount）
- **整卡点击** → `router.push('/settings?tab=commission')`（跳到接稿设置标签页）
- **未开启时**：显示引导文案"未开启名额限制，去设置"，点击同样跳转
- 删掉旧的"正式 3/5""缓冲 0/2"内部术语文案

### 波 3：Settings.vue 支持 ?tab= query 参数（~30min）

onMounted 读 `route.query.tab`，有值时切到对应标签页（`commission` → 接稿设置）。
