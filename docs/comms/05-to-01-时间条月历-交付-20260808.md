## 第一部分：批F 时间条拖拽平移（§八B）

### 做
1. **刻度区拖拽平移**：`.tl-axis` 容器绑定 pointerdown/move/up/cancel + `setPointerCapture`。按住拖动按 deltaX 实时改 `.tl-scroll` 的 scrollLeft（拖右=看更早，内容跟随手指），松手停新位置。
2. **轻移阈值 4px**：未超阈值不移动（防点击误触），超过后光标变 grabbing。
3. **缩放档位 = 视野宽度（重构画布语义）**：
   - 画布从「视野窗口 ∩ 订单范围」改为**恒覆盖「全部订单日期范围 ∪ 今天」+ 7 天余量**；
   - 缩放只改 dayWidth/视野中心，不再被视野窗口裁剪；
   - 画布宽度上限 2000px → 6000px（防极端数据保护保留；原 2000px 在 2w 档 48px 下只有 41 天，会把窗口外订单截没——这是本次核心修的点）。
4. **缩放切换不丢视野中心**：`changeTlZoom` 切档前按旧 dayWidth 把滚动中心换算成日期，切档后重新 scrollLeft 定位到该日期居中。

### 不做
- 不做惯性滑动/回弹（MVP 保持简单，松手即停）。

### 交互说明
- 刻度区（顶部轴区）拖拽 = 平移画布；订单横条拖拽 = 改期（事件绑在横条自身，与刻度区天然隔离，已验证不冲突）。
- 「两周」档位下画布仍覆盖全部订单，可左右拖动查看窗口外订单。
- 删除死代码：`tlCenter` / `tlRangeStart` / `tlDays` / TL_ZOOMS 的 `days` 字段（重构后不再参与计算，避免留着误导）。

## 第二部分：批F2 滚轮缩放 + 双指缩放（§八B2）

### 做
1. **刻度区滚轮 = 缩放**：向上放大（2w→1m→3m→6m），向下缩小；`wheel` 事件只绑在 `.tl-axis`。
2. **内容区滚轮 = 原生滚动**：订单横条区（.tl-rows）不绑定任何手势事件，浏览器原生水平滚动，不触发缩放。
3. **双指 pinch**：pointer 事件统一管理活跃指针表；第二指落下自动释放平移 capture 进入 pinch，按两指间距变化 ≥20% 切一档并重置基准（连续捏合可多档）。`touch-action: none` 在刻度区禁用浏览器滚动接管，同时防页面缩放。
4. **三处状态同步**：radio 选中态 / tlZoom / localStorage——radio 改为单向 `:model-value` + `@update:model-value`，与滚轮、pinch 统一走 `changeTlZoom`（切档+持久化+保持中心），消除"三路各自为政"。
5. **防抖动**：滚轮 250ms 锁合并快速连滚；pinch 按比例触发不连发。

### 不做
- 不做滚轮按像素连续缩放（档位式切档符合 TL_ZOOMS 现有四档模型，交互更可预期）。

### 交互说明
- 单指水平滑动刻度区 = 平移（与批F 一致）；双指捏合/张开 = 切档。
- 滚轮在刻度区缩放、在内容区滚动——事件区分清晰，互不干扰。

## 第三部分：批G 月历优化（§八C）

### 做
1. **「可接单」标识**：无订单覆盖的当月日期格 → 石绿浅底（`--sl` 7% mix，today/weekend 格除外不覆盖原底）+ 右上角石绿小圆点 + tooltip「可接单」（i18n）。有订单的格子保持现有订单带，不额外加「已满」（深度口径 P2 不做）。
2. **日视图展开**：点击日期格（有订单时）或 "+N" → `el-dialog` 弹出当天完整订单列表，复用订单带视觉（bandClass）+ 订单号 + 状态文案，点击行跳订单详情。日期格上订单带点击仍跳详情（已加 `.stop` 防止冒泡触发日视图）。
3. **跳转指定月份**：表头加 `el-date-picker type="month"`（YYYY-MM），选中直接跳该月；翻月头（←/→/今天）时 picker 值联动。

### 不做
- 不做「已满」深度口径（按单量/容量判断，MVP 只做有无的轻量标识）。
- 日视图不做分页/虚拟滚动（当天订单量小，max-height 60vh 滚动即可）。

### 交互说明
- 空日期格点击无弹窗（无列表可看），不产生误导。
- 移动端：月份选择器收窄（96px），日视图列表行内文字截断适配。
