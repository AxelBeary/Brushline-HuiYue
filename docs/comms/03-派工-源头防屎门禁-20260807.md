# 03-派工-源头防屎门禁-20260807

> 派工：一号 → 三号（backend，含前端脚本）+ 二号协作
> 用户红线（08-07 原话）：**"不要因为没问题就留，屎山只会越来越多，一定要从源头抓"**。
> 目的：建**自动门禁**，让"为了过验证而绕"和"新增屎山"在提交时就被拦下，而不是靠人工巡检事后发现。

## 一、四条防线（自动检查，合入 master 前必须全绿）

### 防线 1：禁止任何（eslint rule：no-explicit-any）
- `server/eslint.config.*`（或 .eslintrc）：开 `@typescript-eslint/no-explicit-any: 'error'`
- 效果：任何 `: any` / `as any` 提交时 lint 直接报错——**从源头禁止**（现在 any 清零后，新代码不许再引入）
- ⚠️ 注意：先确认 any 清零批完成后全库 0 any 再开（否则存量直接红一片）；若存量清理需豁免，用 `// eslint-disable-next-line @typescript-eslint/no-explicit-any` 且**必须带理由注释**（下一行写 why）
- web 端：web 是 JS+JSDoc，无 TS any——但可开 `no-undef`/`no-unused-vars` 检查（已有？确认）

### 防线 2：禁止新硬编码中文（i18n 红线自动化）
- web 端：写一个 npm script `check:i18n`（node 脚本）：
  - 扫描 `web/src` 下 `.vue`/`.js` 中**用户可见字符串**（template 文本节点、ElMessage/ElMessageBox 参数、alert/confirm、placeholder/title/label 属性）含 `[\u4e00-\u9fff]` 的
  - 排除：locales/ 文件本身、注释、`$t('...')` 参数内的中文 key 值、合法占位
  - 输出违规清单（文件:行号:字符串），exit 1 拦截
- `package.json` 加 `"check:i18n": "node scripts/check-i18n.js"`，CI 或合并前跑
- ⚠️ 这是**启发式**扫描（可能误报），报告里列误报豁免规则（如白名单字符串数组）

### 防线 3：禁止 console 残留（lint rule）
- server：eslint 开 `no-console: 'error'`（或 allow warn/error，禁 log/debug）——现有 2 处 warn 需先确认是白名单
- web：eslint 开 `no-console: 'warn'`（web 开发期允许 log，提交前 warn 提示；或直接 error 更严——三号选）
- ⚠️ 迁移/种子脚本（init.js/seed.ts）按约定豁免（文件级 disable 带理由）

### 防线 4：CI 强制检查（把上面全部进 ci.yml）
- `.github/workflows/ci.yml` 的 server job 追加：`npm run lint`（已有）+ `npm run typecheck`（已有）+ **`npm run check:i18n`（新增）**
- web job 追加：`npm run lint`（已有）+ `npm run check:i18n`
- 效果：**push 时自动拦截**，不用等一号人工审核才发现

## 二、任务步骤

1. 确认 any 清零批完成（全库 grep `: any` = 0）后，开 `no-explicit-any: error`
2. 写 `web/scripts/check-i18n.js`（node 脚本，见上）——先跑现有代码，把存量违规列出（**不修存量**，只建脚本+白名单；存量硬编码中文由巡检修复批处理）
3. server + web eslint 开 no-console（确认现有 2 处 warn 处置）
4. ci.yml 追加 check:i18n
5. 本地验证：故意塞一处中文/any/console → 检查脚本确实拦截；恢复 → 全绿
6. commit：`chore(quality): 源头防屎门禁——no-explicit-any/no-console/check:i18n/CI强制`

```bash
cd server && npm run lint && npm run typecheck && npm test
cd web && npm run lint && npm run build && npm run check:i18n
```
