## 硬约束（延续）

## 任务 A：F3 小公告前端（~1.5h）

### 共享组件

新建 `web/src/components/shared/TplAnnouncement.vue`：
- props：`artist`（含 announcement 对象：`{ text, expiresAt }` 或 null）
- 无 announcement 或已过期 → 不渲染（`v-if` 短路）
- 组件只输出内容（📢 图标 + 文字），**不写任何布局/装饰样式**
- 过期判断后端已做（公开 API 过期返回 null），前端不需重复判断

### 4 模板适配（T3 已确认）

| 模板 | 位置 | 视觉 |
|------|------|------|
| classic | 左栏吸顶信息卡顶部（头像下方、状态徽章上方） | border-left 强调线 + 底色 |
| gallery | Hero 全屏画作上浮层（左下角展签式，absolute） | 半透明底 + 展签排版 |
| folio | Hero 分屏左栏文字区（简介段落之后） | 内联文字块 + 图标 |
| atelier | Hero 全屏封面右下角便签卡（absolute，微旋转） | 便签纸感 + rotate(-1deg) |

每个模板写自己的 class，不共用。

### 画师设置页入口

Settings.vue 加公告编辑区（一个 textarea + 可选过期时间 date-picker），调 `PUT /api/artist/settings`（字段：announcement / announcementExpiresAt）。

### 后端 API 契约

公开 API `GET /api/public/artist/:subdomain` 已返回：
```json
{ "announcement": { "text": "本周休息", "expiresAt": null } }
```
无公告或已过期时 `announcement: null`。

## 任务 B：F1 点赞前端（~2.5h）

### 共享组件

新建 `web/src/components/shared/ArtworkLikeButton.vue`：
- props：`artworkId`（Number）、`initialCount`（Number）、`liked`（Boolean，初始状态）
- emit：`update:count`
- 心形图标 + 计数，点击切换赞/取消
- 微动画：点击变色+填充（CSS transition，不用 JS 动画库）
- localStorage 记录已赞作品 ID（key：`huiyue_liked_${subdomain}`，value：JSON 数组）
- **T5**：0 赞不显示数字（只显示空心 ♥），有赞才显示计数
- 组件**不写布局样式**，颜色/大小由模板 class 控制

### API 契约

- `POST /api/public/artworks/:id/like` → `{ likeCount: N }`
- `DELETE /api/public/artworks/:id/like` → `{ likeCount: N }`

### 嵌入 TplGallery

TplGallery 作品卡片内嵌入 ArtworkLikeButton。4 模板统一（因为 TplGallery 是共享组件），但按钮颜色/大小可通过模板 class 覆盖。
