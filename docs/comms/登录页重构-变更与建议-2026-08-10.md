# 登录页重构：变更与建议（2026-08-10）

> 背景：v0.49 纸墨登录页为多轮验收的「基本满意」态，但仍有「和期望差好多」的评价；v0.50–v0.57 八轮视觉试错已全部回滚（教训见 STATUS.md v64–v71）。本次重构经用户逐项拍板：构图重构（山退为远景）/ 保留 logo 引用（后续用户自换）/ 保留墨线裸 input / 完整结构清理 / 删除鼠标视差 / 记忆点 = 远山水墨晕染入场。

## 一、改了什么

### 1. 结构清理（还债）

| 变更 | 说明 |
|---|---|
| `Login.vue` 873 → ~430 行 | 瘦身为编排层：场景布局 / 品牌区 / 表单与登录逻辑 / 帮助区 |
| 新增 `components/artist/login/LoginBackdrop.vue` | 远山为幕 + 季节/自定义背景预留层（`useSeasonalBackdrop` 渲染层由 Login.vue 迁入，契约不变） |
| 新增 `components/artist/login/PaperCard.vue` | 纸叠卡壳（撕毛边/微斜垫底/主纸/纹理/噪点/纸边），slot 注入内容，材质机制与 v0.47 修复值一字未动 |
| 新增 `components/artist/login/LoginPrefs.vue` | 纸白/墨黑 + 中/EN 偏好区，主题直写 themeStore，语言切换 emit 给页面 |
| 新增 `composables/useLocaleSwitch.js` | WAAPI 交叉淡出 + 锁高度的语言切换动效（原 Login.vue 内联逻辑） |
| **全局样式迁入 `artist-tokens.css`「纸艺基线」节** | `@property` 注册 ×14、550ms token 统一缓动、`--r-paper`/`--r-s-hand` 手剪圆角族——兑现 v0.46 文件内「视觉批铺开时迁入」的承诺，消除 Login.vue 非 scoped 全局块随路由懒加载注入的隐性泄漏 |

### 2. 视觉重构：远山为幕

- 山脉 52vh 三层 → **20vh 两层**（移动端 14vh），墨色降至 ink 5%/8%（原为 7/11/16% 三档 + 白色脊线描边）；
- **删除山脊白色描边**（v0.49 截图里读成卡通轮廓线的主因）；
- 山巅加 `mask-image` 渐隐，融入纸色（大气透视/远雾感）；
- **删除页面底纤维网格层**（`repeating-linear-gradient` ×2，「屏幕蒙厚纱」的结构性来源）；
- **删除鼠标视差**（远山物理上不随视线动，强视差穿帮；顺带删掉 ~70 行阻尼插值 JS 与 rAF 管理）；
- 卡片 400→420px、内边距 32/40→40/44，场景上下留白加大（48/56px）；
- 新增**远山水墨晕染入场**：opacity + blur(8px→0) + 10px 位移，0.9s ease-out 错峰（远 0.1s/近 0.25s），一次性、reduced-motion 直出——全页唯一记忆点；
- 时辰底色（data-daypart 四档 + 240s 漂移）与 550ms 主题缓动**原样保留**。

### 3. 功能修复

| 问题 | 修复 |
|---|---|
| `?redirect=` 丢失 | 登录成功优先跳 redirect（限 `/` 开头且非 `//`，防开放跳转），兜底按 isAdmin 分流 |
| 加载态弱 | 按钮内嵌转环 + 输入框 disabled 锁定（转环为功能性状态指示，非装饰循环） |
| 成功提示不可见 | 按钮转石绿显示成功文案，500ms 后再跳转；`role="status"` sr-only 区域保底读屏 |
| 锁定错误无时长 | `api/index.js` 错误对象增量附带 `detail`（纯增量一行）；`TOTP_LOCKED`/`CODE_TOO_MANY_ATTEMPTS` 带 `remainingLockMs` 时按新增 i18n 键 `login.locked` 呈现「约 N 分钟后再试」 |
| 后端错误无字段关联 | `QQ_NOT_REGISTERED` → QQ 字段标红；`CODE_INVALID`/`CODE_EXPIRED`（遗留码）→ 口令字段标红 |
| 焦点不可见 | 输入框/登录按钮/偏好按钮/帮助开关全部补 `:focus-visible` 花青焦点环（鼠标用户不可见） |
| 错误提示无关联 | 输入框 `aria-invalid` + `aria-describedby` 指向 `#login-notice` |
| 移动端热区弱 | 输入框纵向 padding 8→10px，768 以下 12px；帮助开关 padding 补 8px |

### 4. 未动的契约

`/api/auth/verify` 请求体与 cookie、三个 localStorage key、路由名 `ArtistLogin`、`login.*` 既有 i18n 键名、问候不进登录页（宪法拍板）、全页无金、EP 按需引入机制（登录页裸 input 是宪法「只画横线不画框」的有意例外，已在代码注释说明）。

### 5. 门禁

`check:i18n` OK（无新增违规）· `eslint` 0 错 · `vitest` 254/254 · `vite build` 通过。圆角族口径自查：全部走 `var(--r-paper)`/`var(--r-s-hand)`/50%/0，零野生字面圆角。截图证据：`workspace/temp/login-redesign-{paper,ink,390,en-help}.png`。

## 二、建议进一步修改（未做，待拍板）

1. **logo 替换**：用户已表示会自换；新 logo 若与水墨语言同源（印章/手绘器物），品牌区无需再动；若继续用 Q 版吉祥物，建议至少做一版单色墨线化处理。
2. **`errors.CODE_INVALID/CODE_EXPIRED` 文案过时**：仍写「登录码错误/已过期」，是 TOTP 改造前的遗留；本次未动（非登录页当前路径触发），建议随下一轮后端清理确认是否还有返回点。
3. **远山高/淡的口味微调**：现 20vh + ink 5%/8% 是保守起点；若嫌「幕」太轻可加到 24vh 或近层 +2%，若嫌抢戏可再降——一档一改、截图对比即可。
4. **帮助区展开态在矮视口（<760px）溢出首屏**：展开后卡片超高、需滚动；可考虑展开时场景改顶部对齐，或接受现状（滚动合理）。
5. **季节背景数据源**（`useSeasonalBackdrop`）仍未立项，渲染层就绪，接通后建议在墨黑档对图片加一层 `color-mix` 暗化，防亮图炸场。
6. **副标题「画师后台」**：管理员也走此页跳 /admin（notes.md §三.2 旧案），如需中性化改 i18n `login.subtitle` 一处即可。
7. **`CODE_TOO_MANY_ATTEMPTS` 疑似死码**：后端 verify 路径现返回 `TOTP_LOCKED`，旧码仅存在于 LOGIN_CODES 白名单与 locales，建议后端确认后清理。
