## 任务 A：节点编辑页——话术输入框 + 变量标签

1. 现有工作流节点编辑 UI 中新增"话术"textarea（2~3 行高）
2. 输入框上方一排变量标签（9 个），点击插入光标位置
3. placeholder 显示默认话术 `{客户名}，你的订单已{节点名}。`
4. 保存时 PUT 节点的 speechTemplate 字段

变量标签列表：{客户名} {客户QQ} {订单号} {档位名} {节点名} {截稿日} {总价} {已付} {待付}

## 任务 B：订单详情页——"客户沟通"小块

1. 订单详情页底部新增"💬 客户沟通"卡片
2. 内容：
   - QQ: {clientQq}
   - 价格小结：总价¥X / 已付¥Y / 待付¥Z（展示，不可编辑）
   - 话术预览：当前节点话术（后端已替换变量，直接显示 speechText）
3. 按钮："复制文案并唤起QQ"
   - 点击 → 复制 speechText 到剪贴板
   - 提示："已复制节点文案，正在唤起QQ"
   - 1 秒后跳转 `tencent://message/?uin={clientQq}`
4. 无 clientQq 时按钮禁用（提示"未设置客户QQ"）
