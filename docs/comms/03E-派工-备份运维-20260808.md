## 任务 1（P0-1）：数据备份能力

### 1a. 备份脚本（server/scripts/backup-db.ts）

VACUUM INTO 备份（容器重建已实测验证过该方式，WAL 安全）：

```ts
// server/scripts/backup-db.ts — DB 定时备份（VACUUM INTO，WAL 安全）
// 用法：npm run backup 或 cron 每日执行
import Database from 'better-sqlite3'
import { mkdirSync } from 'fs'
import { join } from 'path'

const DB_PATH = process.env.DB_PATH || '/app/data/commission.db'
const BACKUP_DIR = process.env.BACKUP_DIR || '/app/data/backups'
const stamp = new Date().toISOString().replace(/[:.]/g, '-')

mkdirSync(BACKUP_DIR, { recursive: true })
const db = new Database(DB_PATH)
db.prepare('SELECT 1').get()
const dst = join(BACKUP_DIR, `commission.db.bak-${stamp}`)
db.prepare(`VACUUM INTO '${dst}'`).run()
db.close()
console.log('BACKUP_OK', dst)
```

### 1b. 保留策略（防磁盘撑爆）

备份目录内**只保留最近 7 份**（`backup-db.ts` 末尾加清理：按文件名排序删最旧，超过 7 份删）：

```ts
// 保留最近 7 份备份
import { readdirSync, unlinkSync } from 'fs'
const baks = readdirSync(BACKUP_DIR).filter(f => f.startsWith('commission.db.bak-')).sort()
while (baks.length > 7) {
  unlinkSync(join(BACKUP_DIR, baks.shift()!))
}
```
