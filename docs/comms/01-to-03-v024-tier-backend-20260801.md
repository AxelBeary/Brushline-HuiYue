# 一号→三号：v0.24-A 档位三态后端（2026-08-01）

## 任务

REQ-013 #10 档位三态后端。Spec：`docs/requirements/REQ-013-整理.md` #10 节。

## 具体工作

### 1. DB 迁移 v25

`price_tiers` 表新增列：
```sql
ALTER TABLE price_tiers ADD COLUMN visibility TEXT DEFAULT 'visible'
```
三态值：`visible`（开）/ `showcase`（只展示）/ `hidden`（不展示）

### 2. 公开 API 过滤

`GET /api/artist/:subdomain`（客户主页数据）返回的 tiers 列表：
- 过滤掉 `visibility = 'hidden'` 的档位
- `showcase` 正常返回（前端渲染灰色"暂不接单"）

### 3. 画师端 API

`GET /api/artist/tiers`（画师管理用）返回全部档位（含 hidden），每条带 `visibility` 字段。

### 4. 三态切换 API

`PUT /api/artist/tiers/:id/visibility`，body: `{ visibility: 'visible' | 'showcase' | 'hidden' }`
- 校验枚举值
- 返回更新后的完整档位对象

### 5. 下单校验

客户下单时（`POST /api/orders`），校验所选 tier 的 visibility：
- `visible` → 允许
- `showcase` / `hidden` → 拒绝（400，错误码 `TIER_NOT_AVAILABLE`）

### 6. 测试

- 迁移幂等性
- 公开 API 过滤 hidden、保留 showcase
- 画师端返回全部
- 切换三态 + 非法值拒绝
- 下单选 showcase/hidden 被拒
