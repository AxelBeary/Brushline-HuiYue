## 施工图

### 功能
1. **新增散单**：表单（金额必填 >0 / 客户昵称建议填 / 备注 / 日期默认今天）→ POST `/api/artist/tools/standalone-incomes`
2. **列表**：GET `/api/artist/tools/standalone-incomes?from=&to=`（按日期倒序），展示 日期/客户/金额/备注
3. **删除**：DELETE `/api/artist/tools/standalone-incomes/:id`（仅本人）
4. 金额单位：前端用元输入，提交转分（×100）；展示分转元
5. 纸墨 token 双主题；i18n zh/en 同步

### 接口契约（后端已就绪，tools.routes.ts）
- POST body: `{ amountCents: number(>0), clientName?: string(≤50), note?: string(≤200), incomeDate: string('YYYY-MM-DD') }` → `{ item }`
- GET 列表: `{ items: [{id, amountCents, clientName, note, incomeDate}] }`
- DELETE `/api/artist/tools/standalone-incomes/:id` → `{ ok: true }`（越权 404）

### 实现铁律
1. 不做假修复；前端校验 = 后端子集（amountCents>0 / incomeDate YYYY-MM-DD 格式对齐后端 schema）
2. i18n zh/en 同步；禁硬编码中文（check-i18n 门禁）
3. 视觉对齐既有工具页（参照 FoodMenu.vue / ToolsExport.vue 风格：ArtistLayout 包裹 + 纸墨 token）
