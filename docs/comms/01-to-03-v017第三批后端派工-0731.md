### C. 尾款重算

按 SPEC §3：
- final_price_cents = total_price_cents + Σ(extra_items.price_cents)
- 无 total_price_cents 时从 0 起算
- 手动改价后加附加项：重算覆盖（前端提示由二号做）

### D. 付款节点调整

按 SPEC §3.5：

- 所有节点已付：不影响节点，系统备注"已付清订单追加，线下结算"
- 无节点：不影响

### E. 系统备注
