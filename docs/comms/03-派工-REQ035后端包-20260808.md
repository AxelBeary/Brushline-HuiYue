## 一、迁移 v46：client_profiles 表

**文件**：`server/src/db/init.js` → MIGRATIONS 数组尾部（现 v45 之后，行 ~1686 `}` 后追加一项）

```js
{
  version: 46,
  name: 'client_profiles',
  up(database) {
    // REQ-035 批A: 画师私有客户标记（标签+备注，挂 client_qq 维度）
    database.exec(`
      CREATE TABLE IF NOT EXISTS client_profiles (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        artist_id INTEGER NOT NULL REFERENCES artists(id) ON DELETE CASCADE,
        client_qq TEXT NOT NULL,
        tags TEXT NOT NULL DEFAULT '[]',   -- JSON 数组字符串，如 '["老客户","厚涂"]'
        note TEXT NOT NULL DEFAULT '',
        created_at TEXT NOT NULL DEFAULT (datetime('now')),
        updated_at TEXT NOT NULL DEFAULT (datetime('now')),
        UNIQUE(artist_id, client_qq)
      );
      CREATE INDEX IF NOT EXISTS idx_client_profiles_artist ON client_profiles(artist_id);
    `)
  }
}
```

**迁移后验证**：`npm run migrate`（或对应脚本）无报错 + `PRAGMA table_info(client_profiles)` 8 列。

## 四、新 routes 文件：`server/src/features/artist/tools.routes.ts`（新建）

> 参照 dashboard.routes.ts 模式（fastify.get/post/delete + preHandler: requireAuth + schema additionalProperties:false）。**在 artist.routes.ts 尾部注册**（行 657-660 已有 dashboardRoutes 注册模式，照抄加一行 `const toolsRoutes = await import('./tools.routes.js')` + `await fastify.register(toolsRoutes.default)`）。

| 方法 | 路径 | body/query | 返回 |
|------|------|-----------|------|
| GET | `/api/artist/tools/clients` | querystring: `qq?`（可选过滤） | `{ items: ClientProfileRow[] }` |
| GET | `/api/artist/tools/clients/:qq` | params | `{ profile: ClientProfileRow \| null, summary: ClientSummary \| null }` |
| PUT | `/api/artist/tools/clients/:qq` | body: `{ tags: string[], note: string }`（tags 数组 ≤20 项，每项 1-20 字符；note ≤200） | `{ profile: ClientProfileRow }` |
| DELETE | `/api/artist/tools/clients/:qq` | params | `{ ok: true }` |
| GET | `/api/artist/tools/returning-clients` | querystring: `days`（enum 30/60/90，default 30） | `{ items: ReturningClientRow[] }` |
| GET | `/api/artist/tools/standalone-incomes` | querystring: `from?/to?`（YYYY-MM-DD） | `{ items: StandaloneIncomeRow[] }` |
| POST | `/api/artist/tools/standalone-incomes` | body: `{ amountCents: number(>0), clientName: string(≤50), note: string(≤200), incomeDate: string('YYYY-MM-DD') }` | `{ item: StandaloneIncomeRow }` |
| DELETE | `/api/artist/tools/standalone-incomes/:id` | params | `{ ok: true }` |
| GET | `/api/artist/tools/export.csv` | querystring: `from/to`（YYYY-MM-DD，必填） | `text/csv` 附件（Content-Disposition: attachment; filename="income-YYYYMMDD-YYYYMMDD.csv"） |

**CSV 格式（表头固定）**：
```csv
date,client,amount_cents,type,order_id
2026-08-01,123456789,30000,order,42
2026-08-02,张客户,5000,standalone,
```
> 金额为分（整数）；负数退款直接负值；UTF-8 with BOM（Excel 打开中文不乱码——**写 '\uFEFF' 前缀**）。
