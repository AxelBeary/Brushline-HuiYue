## 任务 A：HC 系统自检后端（~3h）

按 `docs/specs/plan-health-check.md` 实施。

### API

`GET /api/admin/health`（requireAdmin），返回：

```json
{
  "checks": [
    {
      "id": "db",
      "name": "数据库连接",
      "status": "ok",          // "ok" | "warn" | "fail"
      "summary": "读写正常",
      "detail": { ... }        // 展开详情用
    },
    ...
  ],
  "timestamp": "2026-08-01T12:00:00Z"
}
```

### 8 项检查

| id | 检查项 | 方法 |
|----|--------|------|
| db | 数据库连接 | `SELECT 1` + 写入临时表再删 |
| migration | 迁移版本 | 读 schema_migrations，对比 MIGRATIONS 数组最大版本 |
| uploads | 上传目录 | fs.access(UPLOAD_DIR, R_OK\|W_OK) |
| disk | 磁盘空间 | fs.statfs（标注"仅供参考"） |
| integrity | 数据完整性 | 孤儿记录检查（orders→artists, orders→price_tiers, order_extra_items→orders） |
| backup | 备份状态 | 扫描 data/*.bak.* 最新文件时间 |
| secret | JWT_SECRET | 检查是否为默认值/空值 |
| node | Node 版本 | process.version（信息项，永远 ok） |

### 诊断包下载

`GET /api/admin/health/download`（requireAdmin）：
- 打包检查结果 JSON + 最近 100 行日志（如有）为一个 JSON 文件
- Content-Disposition: attachment
- 服务器不留存

### 注意

- 按需触发，不做定时轮询
- 不存数据库、不写文件
- 磁盘空间用 fs.statfs（Node 18.15+），Docker 内值可能不准，summary 标注"仅供参考"
