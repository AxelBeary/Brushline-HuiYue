## 二、逐页决策与理由

### 1. 偏好设置页（Preferences.vue）

- 移除自绘 `<nav role="tablist">` 与 v-show 三面板，改为 `<el-tabs v-model="activeTab">`，页签仍为 通用 / 显示与字号 / 快捷入口，标签复用既有 `preferences.tabGeneral/tabDisplay/tabQuick`。
- **lazy 决策：不设 lazy（非 lazy）**。三面板含表单状态（通知开关、默认面板、看板模块、字号/动画滑块、快捷勾选），非 lazy 下 el-tab-pane 全部保持挂载（等价原 v-show），切换不丢任何表单状态；`activeTab` 仍从 `general` 起步，加载失败错误态与保存逻辑原样保留。
- 删除 `TABS` 常量与 `.pref-nav*` 样式；页签间距由 el-tabs 自带头部留白承担，与价格管理一致。

### 2. 开稿管理页（SlotManage.vue）

- 四个原分组卡片（接稿状态 / 正式名额 / 缓冲名额 / 月度额度 / 队列行为）改为四个 el-tabs 页签：status / slots / quota / queue，页签标签复用 `slots.statusSection/slotSection/quotaSection/queueSection`。
- **选择 tabs 而非保留纵排的理由**：四块本就是互相独立的功能域（即时状态 / 名额表单 / 额度表单 / 队列行为开关），拆页签后每块仍是同一套「说明在左、控件在右」行结构；为不破坏「一张表单一个保存」契约，保存按钮统一留在页签外，跨页签字段（如 batchLimit + bufferLimit 合计提示、N+M≥1 校验）因非 lazy 全挂载而始终可读、不丢未保存状态。
- 接稿状态保持即时切换（独立 API 调用），不并入保存按钮。

### 3. 排期看板页（QueueBoard.vue）

- 移除「视图切换」分组卡与 `SliderSwitch`，改为 el-tabs 三页签：列表 / 月历 / 时间条（标签复用 `queue.viewBoard/viewCalendar/viewTimeline`），`viewMode` 即页签 `v-model`，`@tab-change="saveViewMode"` 沿用 localStorage 默认视图持久化。
- **懒挂载与状态保持**：三页签均不设 lazy，全部保活——队列/缓冲/完成数据本就在父级 ref；列表滚动、月历月份游标、时间条缩放与滚动各由各自组件实例持有。月历与时间条各挂一个固定 `view-mode` 的 `QueueBoardCalendar` 实例（原组件内部按 viewMode 分支渲染），两个实例独立保活，切视图不再丢月份/缩放/滚动状态（旧实现 board↔calendar 切换会卸载重挂，月份状态会丢，本次一并修复）。
- 删除不再使用的 `SliderSwitch`、icons 导入与 `viewOptions`；页面标题补齐 `font-display` + 28/700 口径。
- 遗留 `queue.viewSwitchLabel/viewSwitchDesc` 两个 locale 键不再被引用，为最小改动未删除（zh/en 仍成对，无硬编码风险）。
