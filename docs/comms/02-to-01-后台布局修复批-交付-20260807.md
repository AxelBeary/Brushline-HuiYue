## 一、逐条结论（A1-A8）

### A1. 偏好页「保存快捷按钮」+ 提示悬浮于勾选列表中部 — ✅ 修
- **文件**：`web/src/views/artist/Preferences.vue`
- **根因**：`.el-form-item__content` 是 EP 默认 `display:flex; flex-wrap:wrap`。原结构把 `form-hint` + 保存按钮直接作为 checkbox-group 的兄弟节点，footer 被当成 flex 子项排到 group **右侧**（实测 left=437 与列表同排）→ 视觉上"悬浮于列表中部"。
- **修法**：模板把 hint+按钮包进 `.quick-config-footer`（语义独立行）；样式加 `flex-basis:100%` 强制整行换行 + `flex-wrap:wrap`（窄屏 hint/按钮自动换行）+ `align-items:center; gap:8px 16px`。
- **DOM 量化**（1440px）：footerTop 793 > 列表最后一项 bottom 785，footer 在列表**下方整行**（left 279, width 558）；移动端 375px：footerTop 681 > groupBottom 673，footer 整行（width 305）不悬浮 ✓

### A2. 订单列表表头未撑满 — ✅ 修
- **文件**：`web/src/views/artist/OrderList.vue`
- **根因**：el-table 已设 `style="width:100%"`，但全部列固定 width（合计 1004px），容器更宽时表格内部右侧留浅色块（EP 列不自动拉伸）。
- **修法**：下单时间列 `width="160"` → `min-width="160"`，让该列吸收剩余空间；其余列固定宽不变（含 fixed right 操作列）。移动端横向滚动（min-width 1004 + overflow-x:auto）不受影响。
- **DOM 量化**（1440px）：表头总宽 1154px = 容器 1154px，撑满 ✓；时间列实测 310px（吸收剩余 150px）✓；列合计 64+100+100+120+100+80+100+80+310+100 = 1154 ✓

### A3. 默认流程页卡片与提示条宽度错位 — ✅ 修
- **文件**：`web/src/views/admin/DefaultWorkflowEditor.vue`
- **根因**：el-alert 全宽（无 max-width），el-card `max-width:700px` → 提示条 100% vs 卡片 700px，宽度不一致。
- **修法**：el-alert 加 `max-width:700px`，与卡片同宽（同一列起点）。
- **DOM 量化**（1440px，admin 会话）：alertW 700 = cardW 700，alertLeft 256 = cardLeft 256 ✓

### A4. 统计页左侧选中指示条显示不全 — ⛔ 不修（实测未复现，附证据）
- **文件**：`web/src/components/ArtistLayout.vue`（巡检派工 L481-495）

  - 折叠态（sidebar_collapsed=1）：竖条同样 x=0~2 完整 ✓
  - 移动端 drawer（375px）：竖条位于 drawer nav 左缘（left 20px），完整 ✓
  - 矮窗口 600px（nav 未溢出 506=506，overflow-y:auto 未激活）：竖条完整 ✓
  - **巡检原始截图 `ui-audit-artist/stats-1440.png` 像素复核：竖条同样完整（x=0~2 花青 22/20/18 采样点）**——与 VL 描述"显示不全"矛盾

### A5. 移动端埋点看板漏斗表事件名断词 3-4 行 — ✅ 修
- **文件**：`web/src/views/admin/TrackingAnalytics.vue`
- **根因**：漏斗表事件名列无 min-width/省略，375px 下长英文词（order_form_submit_success 等）断词 3-4 行。
- **修法**：事件名列加 `min-width="120" show-overflow-tooltip`（与 byName 表同惯例——超宽省略 + hover 看全名）。
- **DOM 量化**（375px，admin 会话）：漏斗表 5 行事件名 cell 高度均 23px = 单行（原来 3-4 行）✓；表格 scrollW=clientW=301 无横向溢出 ✓

### A7. Folio 移动端档位详情卡未重排 — ✅ 修（根因在共享组件）
- **文件**：`web/src/components/templates/TplTierGrid.vue` + `TplStyleGrid.vue`（授权范围 `components/templates/**`；Folio/Gallery/Atelier/Classic 四模板档位展示均走这两个共享组件）
- **根因**：桌面 `.tpl-tier-showcase { align-items:flex-start }` 未在 `@media (max-width:768px)` 覆盖——移动端虽 `flex-direction:column`，但 `align-items:flex-start` 让详情卡不 stretch，实测 375px 下详情卡宽仅 209px（左 16px 右留白）。
- **修法**：两组件移动端 media 内补 `.tpl-tier-showcase/.tpl-style-showcase { align-items:stretch }` + `.tpl-tier-display/.tpl-style-display { width:100% }`。
- **DOM 量化**（375px alice Folio）：修复前 displayW=209；修复后 **displayW=343 = 视口 375 - 左右 padding 32**，菜单(343) 与详情(343) 同宽上下堆叠 ✓

### A8. 客户端 4 模板作品区空态无提示 — ✅ 修
- **文件**：`ArtistHomeGallery/Folio/Atelier/Classic.vue` + `locales/zh-CN.js` + `en.js`
- **修法**：作品区 section 增加 `v-else` 空态分支——保留「作品展示」标题 + 轻量居中占位文案（走 i18n）；Gallery 额外 `v-else-if="!pageLoading"` 避免分页加载中闪空态。新增键 `artistHome.noWorks`（zh: 暂无作品，敬请期待 / en: No artworks yet — stay tuned）。
