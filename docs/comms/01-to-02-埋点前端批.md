### 2.1 匿名凭证（后端已实现）

- 首次上报前调 `POST /api/anon-token` 获取 `{ token }`，存 localStorage（键 `huiyue_anon_token`）
- 后续上报带 `token`；30 天滚动续期（后端 last_seen 自动续，前端无需处理过期——除非 400 INVALID_ANON_TOKEN 时静默重取）
- 画师已登录时后端自动记 artist_id，前端不传（除非 REQ-033 有说明）

### 2.2 事件上报（后端已实现）

- `POST /api/events`，body：`{ token?: string, events: [{ name, ts, version?, ...payload }] }`
- 白名单 23 项（后端校验，前端发不在名单的会 400）：
  ```
  theme_accent_change, order_form_start, order_form_step_view, order_form_step_leave,
  order_form_submit_attempt, order_form_submit_success, order_form_submit_fail,
  order_form_back, order_form_step_back, order_form_abandon, order_submit_success,
  dashboard_view, queue_view, orders_view, manual_view, artworks_view,
  settings_view, tiers_view, guestbook_view, preferences_view, dashboard_quick_click,
  artist_page_enter, artist_action
  ```
- 限流：后端请求级 100 次/分钟；单请求 ≤50 条
- **攒批策略**（REQ-033 §2.2 待拍板建议）：每 5 秒或攒满 10 条发一次；页面关闭/跳转 `navigator.sendBeacon('/api/events', ...)` 带走剩余

### 2.3 前端 track 工具设计（骨架已有）

现有 `trackEvent(name, payload)` 骨架（console.debug + TODO）。改造为：
```js
// 伪代码，按项目现有风格实现
let queue = []
let anonToken = localStorage.getItem('huiyue_anon_token') || null
let flushTimer = null

async function ensureAnonToken() {
  if (anonToken) return anonToken
  try {
    const res = await fetch('/api/anon-token', { method: 'POST' })
    const data = await res.json()
    anonToken = data.token
    localStorage.setItem('huiyue_anon_token', anonToken)
  } catch { /* 静默，不打断用户 */ }
  return anonToken
}

export function trackEvent(name, payload = {}) {
  queue.push({ name, ts: Date.now(), version: EVENT_VERSION, ...payload })
  if (queue.length >= 10) flush()
  else if (!flushTimer) flushTimer = setTimeout(flush, 5000)
}

async function flush() {
  if (!queue.length) return
  const events = queue.splice(0, 50)
  const token = await ensureAnonToken()
  try {
    await fetch('/api/events', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ token, events })
    })
  } catch {
    queue.unshift(...events) // 失败回队，等下次（或丢弃避免死循环——按 REQ-033）
  }
}

// 页面关闭/跳转
window.addEventListener('pagehide', () => {
  if (queue.length) navigator.sendBeacon?.('/api/events', JSON.stringify({ token: anonToken, events: queue }))
})
```
