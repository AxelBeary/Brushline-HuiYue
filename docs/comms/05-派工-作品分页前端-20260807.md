## 改动清单

### A. 画师端 ArtworkManage.vue 分页（20/页 + el-pagination）

1. **数据加载改造**：现有加载逻辑（grep `loadArtworks|artworks` 找数据源函数）改为调 paged 接口：

```js
// before（grep 现有：大概 this.artworks = await artistApi.getArtworks() 之类）
// after
const page = ref(1)
const pageSize = ref(20)
const total = ref(0)

async function loadArtworks() {
  loading.value = true
  try {
    const res = await artistApi.getArtworksPaged({ page: page.value, pageSize: pageSize.value })
    artworks.value = res.items
    total.value = res.total
  } finally {
    loading.value = false
  }
}
function onPageChange(p) { page.value = p; loadArtworks() }
```

2. **模板**：作品网格后加分页器：
```html
<el-pagination
  v-if="total > pageSize"
  :current-page="page"
  :page-size="pageSize"
  :total="total"
  layout="prev, pager, next"
  @current-change="onPageChange"
  style="margin-top: 16px; justify-content: center;"
/>
```

3. **api/index.js**：加 `getArtworksPaged`（按项目 request 封装风格）：
```js
getArtworksPaged({ page = 1, pageSize = 20 } = {}) {
  return request({ url: '/api/artist/artworks/paged', params: { page, pageSize } })
}
```

> ⚠️ **封面置顶不动**：后端已实现 is_cover 排序，前端直接用返回顺序，勿重排。若 ArtworkManage 有「管理模式」操作（封面移动/删除）后需要刷新，loadArtworks() 已在操作后调用（grep 确认现有刷新链路，替换成 loadArtworks 即可）。

### B. 客户端 T2 gallery 模板「加载更多」（10/页）

1. **父组件数据源**（grep 谁把 artworks 传给 TplGallery——可能是 ArtistHome.vue 或各模板组件）：当前一次性拉全量，改为调公开分页接口：

```js
// before（grep 现有：artworks = await artistPublicApi.getArtworks(artistId) 之类）
// after
const PAGE_SIZE = 10
const artworks = ref([])
const total = ref(0)
const loadingMore = ref(false)

async function loadArtworks(reset = false) {
  const page = reset ? 1 : Math.ceil(artworks.value.length / PAGE_SIZE) + 1
  loadingMore.value = true
  try {
    const res = await artistPublicApi.getPublicArtworksPaged(artistId, { page, pageSize: PAGE_SIZE })
    artworks.value = reset ? res.items : [...artworks.value, ...res.items]
    total.value = res.total
  } finally {
    loadingMore.value = false
  }
}
function onLoadMore() { loadArtworks(false) }
```

2. **模板**（TplGallery 内部或父组件）：画廊末尾加「加载更多」按钮：
```html
<div v-if="hasMore" class="tpl-gallery-loadmore">
  <el-button :loading="loadingMore" @click="onLoadMore">{{ $t('artistHome.loadMore') }}</el-button>
</div>
```
```js
const hasMore = computed(() => artworks.value.length < total.value)
```

3. **api/index.js**：加 `getPublicArtworksPaged`：
```js
getPublicArtworksPaged(artistId, { page = 1, pageSize = 10 } = {}) {
  return request({ url: `/api/public/artworks/${artistId}`, params: { page, pageSize } })
}
```

> ⚠️ **只改 T2 gallery 模板**：4 模板中 gallery 改通，classic/atelier/folio 本批不动（版本计划明示）。若 TplGallery 是共享组件，改它的同时确认其他模板不受影响（其他模板传全量数组时 hasMore=false，按钮不显示——零影响）。
