## P1-4：send-code 泄露注册状态

`auth.routes.ts` L42-50：`...(artist ? { artistName } : {})` 让攻击者通过响应差异枚举已注册 QQ。

修复：响应统一返回 `{ success: true }`，不附带 artistName。前端如有依赖 artistName 需同步改（检查一下）。

## P1-6：health.service.ts callback API 误用

`health.service.ts` L60-73：`await (fn as any)(...)` 把 callback API 当 Promise，稳定报错。

修复：改用 `fs.promises.stat` / `fs.promises.access`，或 `util.promisify`。

## P1-7：Q4 季度收入恒为 0

`dashboard.service.ts` L80-94：`quarter+1>3 ? 0 : quarter+1` 未加年份，Q4 时 nextQuarterStart 算成同年 1 月 1 日（在过去），导致范围为空。

修复：`quarter+1>3` 时年份 +1。

## P1-5：like/unlike 无防刷

`artist.service.ts` L512-527：纯 +1/-1，无限流无去重。

修复（轻量方案）：
- 内存 Map 按 IP 限流（每 IP 每作品每分钟最多 5 次）
- 不做 DB 去重（成本太高，当前规模不需要）
- 超限返回 429
