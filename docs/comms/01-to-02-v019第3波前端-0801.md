## 任务 A：F4 留言板前端（~5h）

### 客户端：TplGuestbook.vue（共享组件）

新建 `web/src/components/shared/TplGuestbook.vue`：
- props：`subdomain`（String）
- 留言墙：GET `/api/public/artist/:subdomain/messages`，显示已审核留言列表
- 提交表单：昵称（必填）+ 内容（≤200 字）→ POST，提交后提示"等待画师审核"
- 画师回复显示在留言下方（带"画师"标识）
- 空状态："还没有留言，来说点什么吧 💬"
- 分页（默认 20 条，加载更多按钮）
- 组件**不写装饰样式**，4 模板各自定视觉

### 4 模板适配

4 模板底部统一引入 TplGuestbook，位置在约稿须知/流程之后。各模板定自己的间距和背景。

### 画师端：留言审核列表

画师后台（Dashboard 或 Settings 新 tab）：
- GET `/api/artist/messages` 获取所有留言（含 pending）
- 通过 / 拒绝 / 回复操作
- pending 留言醒目标识（如黄色底）
- 回复输入框（≤500 字）

### 管理端：留言管理

AdminDashboard 新增留言管理区（或 tab）：
- 查看所有留言（跨画师）
- 强制删除按钮（DELETE `/api/admin/messages/:id`）

### API 契约

| 方法 | 路径 | 返回 |
|------|------|------|
| POST | /api/public/artist/:subdomain/messages | `{ id }` (201) |
| GET | /api/public/artist/:subdomain/messages?page=1&pageSize=20 | `{ messages: [...], total, page, pageSize }` |
| GET | /api/artist/messages | `[{ id, nickname, content, status, artist_reply, ... }]` |
| PUT | /api/artist/messages/:id/approve | 更新后的留言 |
| PUT | /api/artist/messages/:id/reject | `{ success: true }` |
| PUT | /api/artist/messages/:id/reply | 更新后的留言（body: `{ reply }`) |
| DELETE | /api/admin/messages/:id | `{ success: true }` |

公开 API 返回的 message 字段：`{ id, nickname, content, artistReply, repliedAt, createdAt }`
