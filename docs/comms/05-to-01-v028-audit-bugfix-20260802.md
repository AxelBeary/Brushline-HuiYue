## 修复清单

### ✅ OD1：订单详情页 #undefined 拼入 UI

- **根因**：`OrderDetail.vue:3` 的 `:content` 绑定使用模板字符串 `` `${$t('orderDetail.orderNo')}${order?.order_no}` ``，当 order 为 null（订单不存在/加载失败）时，`order?.order_no` 为 `undefined`，JS 模板字符串将其拼为 `"订单 #undefined"` 直接渲染到页头
- **修复**：改为条件表达式 `order ? ... : ''`，order 为 null 时 content 为空字符串，页头仅显示返回标题
- **改动**：`web/src/views/artist/OrderDetail.vue` 第 3 行，1 行改动
- **验证**：eslint 零错误 + `npm run build` 成功

### ❌ GB3：已通过卡片显示拒绝按钮 — 不修

- **判定**：非代码 bug。`v-if="msg.status !== 'rejected'"` 使拒绝按钮对 pending 和 approved 都显示，这是"撤销通过"的合理操作路径（画师误通过后需要拒绝）。与"通过"按钮的 `v-if="msg.status !== 'approved'"` 对称。审计时标注为"语义冲突"是视觉感受，实际逻辑正确

### ⏸ T3：TierManage.vue 14 处硬编码中文未走 i18n — 需扩展授权

- **问题确认**：页面标题、4 个 Tab 标签、弹窗表单 5 个 label、2 个按钮文字共 14 处硬编码中文
- **修复需要**：在 `web/src/locales/zh-CN.js` 和 `web/src/locales/en.js` 的 `tiers` 区块新增 4 个 Tab 键（`tabTiers`/`tabAddons`/`tabMultipliers`/`tabWorkflow`），其余 10 处已有对应 i18n 键可直接替换
