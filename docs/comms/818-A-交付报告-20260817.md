## 改动明细

### 1. 新增共享 util `web/src/utils/fontSize.js`

单一事实源，Preferences 与 ArtistLayout 共用同一映射/读写/应用口径：

- `FONT_SIZE_KEY`（沿用 `huiyue_admin_font_size`）/ `FONT_SIZE_MIN=14` / `FONT_SIZE_MAX=20` / `FONT_SIZE_DEFAULT=15`
- `normalizeFontSize(value)`：旧值映射 **large→15、xlarge→17**，normal/无值/非法（非 14~20 整数）→ **15**
- `readFontSize()`：safeGetItem（存储禁用降级 15）+ 归一化
- `writeFontSize(size)`：统一存数字字符串 `'14'`~`'20'`
- `applyFontSize(size)`：设 `document.documentElement.dataset.fontSize`（**默认 15 也显式设置**）
- `clearFontSize()`：移除存储并摘 dataset（新模型正常路径不再使用，保留给清理场景）

### 2. `web/src/views/artist/Preferences.vue`

- radio 三档 → `el-slider`：`v-model="fontSize"` + `:min="FONT_SIZE_MIN"` + `:max="FONT_SIZE_MAX"` + `:step="1"` + `show-stops`（7 个档位点），右侧显示当前值「{{ fontSize }}px」
- `watch(fontSize)` 即时 `applyFontSize` + `writeFontSize`，无需点击保存
- 本地旧字号常量/映射函数删除，改走共享 util；`safeGetItem`/`safeRemoveItem` 随之从 import 移除
- 新增 `.font-size-row`（flex + gap 16px）、`.font-size-slider`（flex:1, max-width 340px）、`.font-size-value`（右侧当前值）

### 3. `web/src/components/ArtistLayout.vue`

- 本地 `FONT_SIZE_KEY`/`applyFontSizeFromStorage` 改走共享 util：`applyFontSize(readFontSize())`
- 挂载时无值/旧值也统一落 15 并显式设 `dataset.fontSize='15'`（15≠14 基线，不设会回旧默认）

### 4. `web/src/styles/artist-tokens.css`

原 large/xlarge 两档枚举重构为 7 档（14~20 每档一组），选择器统一 `html[data-artist-theme][data-font-size='N']`：

| 档 | `.artist-layout` font-size | `--el-font-size-base/small/large` | `--font-scale` |
| --- | --- | --- | --- |
| 14 | 14px | 14/12/16px | 1 |
| 15 | 15px | 15/13/17px | 1.0714 |
| 16 | 16px | 16/14/18px | 1.1429 |
| 17 | 17px | 17/15/19px | 1.2143 |
| 18 | 18px | 18/16/20px | 1.2857 |
| 19 | 19px | 19/17/21px | 1.3571 |
| 20 | 20px | 20/18/22px | 1.4286 |

作用域不变：`html[data-artist-theme]` 锁后台，客户端路由零影响；下方 `[data-font-size]` 通配规则（EP 组件 14px 族、小按钮 12px 族）无需改动。

## 兼容与迁移

- localStorage 旧值不迁移重写，读时由共享 util 映射（large→15 / xlarge→17 / normal→15），用户下次拖动滑块后自然落盘为新数字字符串
