## 一、🔴 真实问题

### 1.【中】OrderForm「复制约稿信息」在画风模式下缺档位/明细
- 位置：`web/src/views/client/OrderForm.vue:822-826`（`copyOrderSummary`）
- 现象：函数只读旧模型字段 `selectedTier.value?.name` 与 `pricePreview.value?.breakdown`；画风模式（`isStyleMode`）下两者均为 null/空 → 复制到剪贴板的文本只有订单号+总价，**缺画风/尺寸/增项明细**，客户发画师的信息不完整。
- 判定：静态代码分析确认（实测数据无画风，无法复现截图；逻辑分支明确）。
- 建议修法：按 `isStyleMode` 分支——画风模式用 `selectedStyle?.name` + `selectedSize?.name` + `stylePricePreview.addonItems` 拼行，旧模型保持现状。

### 2.【低】DeliveryPage 交付文件为空数组时双卡片同屏
- 位置：`web/src/views/client/DeliveryPage.vue:22`（卡片1，`v-if="verified && delivery"` 内含 `el-empty` noFiles）与 `:40`（卡片2，`v-if="verified && !delivery?.deliverables?.length && delivery"` 显示 `el-result` notDelivered）
- 现象：当后端返回 `delivery` 对象但 `deliverables = []` 时，两卡片同时渲染：上方"暂无交付文件"空态 + 下方"尚未交付"提示，语义重复。
- 判定：静态分析确认（需交付记录数据复现，seed 无）。
- 建议修法：卡片2 加 `delivery.deliverables != null` 守卫（未交付=数组为 null 不显示卡片1 空态），或卡片1 的 noFiles 空态与卡片2 合并只留一个。

### 3.【低】LandingPage import 位置不符合置顶惯例
- 位置：`web/src/views/client/LandingPage.vue:70`（`import { ARTIST_STATUS_TYPE }` 在 script 中部、`onMounted` 之前）
- 现象：import 混在逻辑代码中间，其余页面均置顶；eslint 若开 `import/first` 会报错（当前 lint 未报，但属规范隐患）。
- 建议修法：移到 script 顶部（line 57 附近 import 区）。
