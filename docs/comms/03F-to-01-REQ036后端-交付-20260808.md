## 二、逐任务改动

### 任务 1：删除策略 C'（REQ-036 §2.5 + 验收 14）✅

**派工方案偏差说明（重要）**：派工推荐「不动 schema，服务层 UPDATE 置 NULL」——但实测发现 **`style_addons.addon_template_id` 是 `NOT NULL` 约束**，直接 UPDATE 置 NULL 会违反约束；且置 NULL 后 JOIN addon_templates 会丢名称/价格（getStyleAddons 是 INNER JOIN）。因此采用方案 A：**迁移 v49 重建 style_addons 表**（v38 模式：事务外 + 显式关 FK + foreign_key_check），并加**模板快照列**保证解绑后独立增项可展示/计价。

- `server/src/db/init.js` v49 迁移：
  - `style_addons` 重建：`addon_template_id` 改可空 + 外键 `ON DELETE SET NULL` + 快照列 `tpl_name / tpl_control_type / tpl_pricing_mode / tpl_default_price / tpl_options / tpl_unit_label / tpl_kind / tpl_max_quantity`
  - schema 区同步（新库建表即新结构）
- `style.service.ts` `deleteAddonTemplate`：
  - 被引用 → 快照模板数据到 style_addons 快照列 → 解绑（置 NULL）→ 删模板
  - 返回 `{ deleted, referenced: N }`（前端弹窗显示 N）
  - 系统预置模板（artist_id NULL）画师不可删/改（404，管理员后台维护）
- `getStyleAddons` / `getPublicStyles` / `style-pricing` 增项查询：INNER JOIN → **LEFT JOIN + COALESCE(快照, 模板)**，解绑后独立增项正常展示/计价，新增 `detached` 字段

**验收**：TC-R36-01/02/04 + TC-AT-08 覆盖——删除被引用模板返回 referenced N，画风内增项保留（价格/隐藏/尺寸覆盖不动），独立增项仍可计价。
