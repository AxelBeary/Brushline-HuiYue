# 四号 → 一号：UI-3 订单列表焦点图加载失败

> 日期：2026-07-29

## 问题

订单管理页（OrderList），设置了焦点图的订单缩略图显示"加载失败"。排期看板正常。

## 根因（已验证）

`server/src/features/order/order.routes.js:269`，GET `/api/artist/orders` 路由：

```js
const result = orderService.getArtistOrders(...)  // 返回 { items, total, page, pageSize }
if (result.orders) {   // ❌ 键名错误，应为 result.items
```

`getArtistOrders()`（order.service.js:351）返回 `{ items, total, page, pageSize }`，路由里写成了 `result.orders`，永远为 `undefined`，签名逻辑从未执行。前端拿到裸的 `focus_image_path` 但没有 `focusImageUrl`，`<el-image :src="undefined">` → 加载失败。

## 已排除

- 签名机制正常（容器内外实测 200 / image/png / 825KB）
- 文件存在（uploads/references/iJSGtFSS6As5.png，数据库订单 27 指向它）
- 排期看板正常（GET /api/artist/queue 直接对数组 map，写法正确）

## 修复

一行：`result.orders` → `result.items`（两处，269 行和 270 行）。

## 验证方法

1. 改完后重启容器
2. 登录画师后台 → 订单管理 → 确认 ALICE-005 的缩略图列显示图片而非"加载失败"
3. 排期看板焦点图仍正常（回归）
