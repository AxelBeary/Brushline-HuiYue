## 任务 1：两个必修 bug（先修，小）

1. **切 tab 数据不刷新**（ArtStyleManager L844 onMounted(load) + TierManage el-tab-pane lazy）：切回画风页不重新拉数据 → 增项库建完模板切回看不到。修复：el-tabs `@tab-change` 或 tab-pane 非 lazy + 激活时重新 load（先读 TierManage tabs 结构）

## 任务 2：双入口（替换「导入增项」按钮）

画风卡片增项区头部两个并列按钮（§2.1）：
- **[+ 新建增项]**：弹表单（名称/控件类型/默认价/数量上限）→ 保存自动挂到本画风 + 沉淀进增项库
- **[+ 从已有挑选]**：现有导入弹窗，标记「本画风已用」避免重复
- 同名处理（§3）：新建与库中同名 → 提示「直接挂载 or 另建独立」

## 任务 3：加购项池 + 拖拽（§2.2，核心）

- 画风-尺寸下方大池子（默认空，两个按钮）
- 新加/勾选增项出现在池子（胶囊：名称+价格+类型徽标）
- **拖拽**：池→尺寸行 = 启用（仅决定启用不动价格）；拖回池 = 停用；拖到已启用 = 提示不重复
- **单点胶囊** = 三层弹窗（任务 4）
- 拖拽与点击并存
- 拖拽实现：复用 vuedraggable（项目已有）或原生 HTML5 drag——选实现优雅者，先读现状确认

## 任务 4：三层编辑弹窗（§2.4）

点池内胶囊 → 弹窗三层（从下到上）：
- **模板级**（addon_templates）：本身价/名称/控件类型；改基础属性弹「应用到所有画风 / 仅当前画风」
- **画风级**（style_addons）：本画风激活开关 + 画风价
- **尺寸级**（size_addon_overrides）：每尺寸启用开关 + 差异价 + 批量全部启用/关闭
- 价格优先级：本尺寸 > 画风价 > 本身价（与后端一致）
- 底部「移除（解绑本画风）」：解绑不动库
