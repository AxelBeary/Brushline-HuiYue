## 改动清单（2 项）

### A. i18n 懒加载（第三方报告：-60KB；实测 locales 142KB 全量进主包）

**现状**：`web/src/i18n/index.js` 静态 import 两个 locale：
```js
import zhCN from '../locales/zh-CN.js'   // 70KB
import en from '../locales/en.js'        // 72KB
// 两者都打进主包
```

**改法**：默认 locale 同步加载（zh-CN，绝大多数用户，保首屏翻译），**en 懒加载**（切英文时才 import）：

```js
// web/src/i18n/index.js
import { createI18n } from 'vue-i18n'
import zhCN from '../locales/zh-CN.js'   // 默认 locale 同步（保首屏）

const STORAGE_KEY = 'huiyue-locale'

function detectLocale() {
  const saved = localStorage.getItem(STORAGE_KEY)
  if (saved) return saved
  const nav = navigator.language.toLowerCase()
  return nav.startsWith('zh') ? 'zh-CN' : 'en'
}

export const i18n = createI18n({
  legacy: false,
  locale: detectLocale(),
  fallbackLocale: 'zh-CN',
  messages: { 'zh-CN': zhCN }   // en 不预载
})

// 懒加载 en（切英文时才 import；失败回落 zh-CN）
let enPromise = null
async function ensureEn() {
  if (!enPromise) {
    enPromise = import('../locales/en.js').then(m => {
      i18n.global.setLocaleMessage('en', m.default)
      return m.default
    })
  }
  return enPromise
}

export async function setLocale(locale) {
  if (locale === 'en') await ensureEn()
  i18n.global.locale.value = locale
  localStorage.setItem(STORAGE_KEY, locale)
  document.documentElement.lang = locale === 'zh-CN' ? 'zh-CN' : 'en'
}

export default i18n
```

**调用点适配**（grep `setLocale` 全库）：所有调 `setLocale('en')` 的地方改成 `await setLocale('en')`（或 `setLocale('en')` 内部已 await——若调用点不 await 会竞态：locale 已切但消息未载入 → 英文界面空白文案一瞬）。**先 grep 调用点，逐个加 await**（若调用点本身是 async 函数则直接 await；非 async 则改 `setLocale('en').then(...)` 或在切语言组件里 async）。

> ⚠️ **踩坑提示**：`detectLocale()` 若初始就是 'en'（英文用户首次访问），此时 messages 只有 zh-CN——**首屏会中文回退**。处理：`createI18n` 后用 `if (i18n.global.locale.value === 'en') ensureEn()` 预载（async 但首屏不阻塞——先中文回退再切英文，可接受；或 initialLocale 同步判断，看实现复杂度）。**验证**：英文用户首屏最终显示英文。

**收益验证**：`npm run build` 后对比主 chunk（`dist/assets/main-*.js`）体积——应减少 ~70KB（en.js 不进主包）。build 输出会显示 chunk 大小。

### B. focus-visible 补全 4 处（第三方报告属实，可访问性）

**现状**：4 个客户端模板各有 `outline: none`（无 focus 样式，键盘用户无焦点指示）：
- ArtistHomeAtelier.vue:273
- ArtistHomeClassic.vue:293
- ArtistHomeFolio.vue:372
- ArtistHomeGallery.vue:295

**改法**：每处 `outline: none` 的规则，补 `:focus-visible` 可访问性焦点环（只对键盘/辅助技术显示，鼠标点击无变化——不改变可见外观）：

```css
/* before（示例，读实际选择器确认） */
.xxx-btn { outline: none; }

/* after */
.xxx-btn { outline: none; }
.xxx-btn:focus-visible {
  outline: 2px solid var(--color-primary, #356B69);
  outline-offset: 2px;
}
```

> ⚠️ **读上下文**：每处 outline:none 在哪个元素上（按钮/链接/可点区），`:focus-visible` 用同选择器 + 同伪类。颜色用项目主色变量（grep 该文件现有变量）。若元素本身有 `border-radius`，outline-offset 2px 即可，无需改圆角。
