## 实现说明

### 任务 1：PuzzlePage.vue（进度对比拼图）
- 订单下拉：`artistApi.getOrders()`（status 不传取全部，pageSize 100），显示 `#order_no · tier · client`
- 选中后 `getOrder(id)` 拉详情 → `deliverables`（完稿）+ `references`（参考）统一为可选缩略图卡片，角标区分「完稿/参考」
- 勾选 2~6 张（el-tag 序号 + 上移/下移排序，未引拖拽库）
- 拼图：canvas 等高 400px 横向拼接、8px 白缝，总宽超 1500px 自动换行成网格，行内居中；实时预览（防抖 + 竞态序号）
- 导出：`toDataURL('image/png')` → `<a download>`，文件名 `puzzle-<order_no>.png`
- 边界：不足 2 张提示 `puzzle.needTwo`；无图片提示 `puzzle.noImages`；单张加载失败跳过不阻塞；导出捕获跨域污染并提示
- 视觉：纸墨 token（--paper/--ink/--hq/--card/--line），双主题自适应

### 任务 2：ScheduleSharePage.vue（排期公示）
- 数据：`getProfile()` + `getQueue()`（formal）+ `getQueue('buffer')` + `getUpcomingDeadlines()`，Promise.all 并行
- 档期状态规则（按施工图）：formal+buffer ≥10「排期较满」/ 3-9「档期正常」/ <3「档期宽松」
- 复制文本：`navigator.clipboard` + `execCommand` 兜底；模板含画师名/状态/队列概览/近期截稿 3 单
- 下载图片：canvas 绘制纸墨风格卡片（宣纸底 #F5F4EF、墨字、花青标题、状态 pill 按语义配色 busy=朱砂/normal=花青/free=石绿、朱砂语义落款），`toDataURL` 下载 `schedule-YYYYMMDD.png`
- 页面同时显示生成的卡片图预览（与下载内容完全一致，所见即所得）
- 双主题：页面预览走 token 自适应；导出卡片固定纸墨亮色（发给客户的图保证清晰可分享）

### 任务 3：菜单 + 路由 + i18n
- 菜单：tools 组加「进度拼图」（Grid）/「排期公示」（Calendar），无图标重复
- 路由：`/tools/puzzle`（ArtistPuzzlePage）、`/tools/schedule`（ArtistScheduleSharePage），均 requiresAuth
- i18n：zh-CN/en 双语全键同步（含补充键 subtitle/preview/statusLabel/textHeader/noDeadline 等），无硬编码中文
