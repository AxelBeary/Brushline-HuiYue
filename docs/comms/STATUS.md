## ⚠️ v38 迁移事故记录（长期教训）

## 重要规则提醒

- 合并到 master 后**立即推送**；操作前 `git log --oneline -5` 确认 HEAD
- 禁止对 master `git reset --hard` / `git rebase`；禁止 `git add -A`
- 并行角色必须在独立 worktree（用完即删）；Docker 环境 SQLite 用 DELETE 模式
