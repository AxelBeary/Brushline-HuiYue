## 任务 A：封面图轮播（~2h，等三号 API 合入后联调）

### 需求

画师可指定一张作品为"封面"，客户端主页顶部展示封面大图。多张封面时轮播（REQ-013 #5 原声："要是有门面多张来回滚动就更好"）。

### 后端 API 契约（三号同步开发，合入后联调）

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | /api/artist/artworks/:id/cover | 设为封面 |
| DELETE | /api/artist/artworks/:id/cover | 取消封面 |
| GET | /api/public/artists/:id | artworks 中 `is_cover=1` 排第一 |

### 实现要点

1. **画师端作品管理**（Settings.vue 或作品管理区域）：每张作品加"设为封面"按钮（星标/图钉图标），当前封面高亮标记
2. **客户端 4 模板**：主页顶部（Hero 区域下方或作品区最上方）展示封面。有封面→大图/轮播；无封面→不显示（向后兼容）
3. **轮播**：多张封面时自动轮播（el-carousel 或纯 CSS），3-5 秒间隔，可手动滑动
4. **4 模板差异化**：每个模板的封面区视觉不同（共享逻辑不共享皮肤）

### 授权文件

- `web/src/views/artist/Settings.vue`（封面管理 UI）
- `web/src/components/templates/Tpl*.vue`（4 模板封面区）
- `web/src/api/index.js`（新增 cover API 方法）
- `web/src/locales/zh-CN.js` + `web/src/locales/en.js`（封面相关文案）
