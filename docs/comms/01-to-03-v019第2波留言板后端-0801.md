## 任务：F4 留言板后端（~3h）

### 迁移 v22

```sql
CREATE TABLE IF NOT EXISTS guestbook_messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  artist_id INTEGER NOT NULL REFERENCES artists(id),
  nickname TEXT NOT NULL,
  content TEXT NOT NULL,
  status TEXT DEFAULT 'pending',  -- 'pending' | 'approved' | 'rejected'
  artist_reply TEXT DEFAULT NULL,
  replied_at DATETIME DEFAULT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  deleted_by_admin INTEGER DEFAULT 0
);
CREATE INDEX IF NOT EXISTS idx_guestbook_artist ON guestbook_messages(artist_id, status);
```

### API（7 个）

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | /api/public/artist/:subdomain/messages | 公开（限流：同 IP 每分钟 2 条） | 客户提交留言（nickname 必填，content ≤200 字） |
| GET | /api/public/artist/:subdomain/messages | 公开 | 已审核留言（status='approved' AND deleted_by_admin=0），按 created_at DESC，分页（默认 20 条） |
| GET | /api/artist/messages | requireAuth | 画师获取自己所有留言（含 pending），按 created_at DESC |
| PUT | /api/artist/messages/:id/approve | requireAuth + 归属校验 | 通过（status→approved） |
| PUT | /api/artist/messages/:id/reject | requireAuth + 归属校验 | 拒绝（status→rejected，静默） |
| PUT | /api/artist/messages/:id/reply | requireAuth + 归属校验 | 回复（artist_reply + replied_at） |
| DELETE | /api/admin/messages/:id | requireAdmin | 管理员强制删除（deleted_by_admin=1，不物理删） |

### 校验规则

- nickname：必填，1~20 字
- content：必填，1~200 字
- 限流：同 IP 每分钟最多 2 条 POST（内存计数即可，与现有登录码限流模式一致）
- 归属校验：画师只能操作自己 artist_id 下的留言

### 公开 API 返回格式

```json
{
  "messages": [
    {
      "id": 1,
      "nickname": "小明",
      "content": "画得好好看！",
      "artistReply": "谢谢～",
      "repliedAt": "2026-08-01 12:00:00",
      "createdAt": "2026-08-01 10:00:00"
    }
  ],
  "total": 42,
  "page": 1,
  "pageSize": 20
}
```

注意：公开 API **不返回** status / deleted_by_admin 字段。
