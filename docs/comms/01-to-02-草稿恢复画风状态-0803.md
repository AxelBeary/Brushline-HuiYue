## 问题

R57 草稿防丢失（sessionStorage）只存旧模型字段，**刷新后画风选择丢失**。用户填了"选画风→选尺寸→勾增项"后刷新页面，恢复草稿只回来 description/clientQq 等文本字段，三步走选择全部归零。

## 一号已核实的代码现状（useOrderForm.js）

- `selectedStyleId` ref（L58）、`selectedSizeId` ref（L61）、`styleAddonSelections`（增项勾选）
- `saveDraft()`（L395-415）：只存 `form: { tierId, description, clientQq, clientName, notifyEnabled, usageMultiplierId, rushMultiplierId }` + addonSelections + addonToggles——**无 selectedStyleId/selectedSizeId/styleAddonSelections**
- `hasDraftContent`（L386-393）：只看旧模型字段——**画风模式下只选了画风尺寸没填文字时，不会保存草稿**
- `watch` 触发保存（L423-429）：没 watch selectedStyleId/selectedSizeId/styleAddonSelections
- `restoreDraft(draft)`（L432-444）：只恢复旧模型字段
- 初始化顺序（L570-602）：先加载 styles（单画风自动选中 L575-577）→ 再草稿恢复。**草稿恢复在自动选中之后，可以覆盖它**

## 修复要求

1. **saveDraft** 增加保存：`styleState: { styleId, sizeId, addonSelections: {...styleAddonSelections} }`
2. **hasDraftContent** 增加：`selectedStyleId.value != null`（画风模式下选了画风即算有内容）
3. **watch** 增加：`selectedStyleId`、`selectedSizeId`、`styleAddonSelections`（deep）→ scheduleDraftSave
4. **restoreDraft** 恢复画风状态，带有效性校验（画风/尺寸可能已被画师删除）：
   - `styleId` 在 styles.value 中存在 → 恢复 selectedStyleId；否则丢弃
   - `sizeId` 在该画风的 sizes 中存在 → 恢复 selectedSizeId；否则丢弃
   - addonSelections 只恢复当前尺寸可用增项（availableStyleAddons）中存在的键
   - 恢复后触发一次 `scheduleStyleCalc()` 重算价格预览
5. **模式互斥处理**：草稿可能同时含 tierId（旧模型）和 styleId（画风模型）。恢复时按当前 `isStyleMode` 决定恢复哪组——画风模式恢复 styleState，旧模型恢复 tierId，不交叉污染
6. **单画风退化路径**：styles.length===1 时自动选中已发生，草稿恢复的 styleId 若与之相同则幂等（不报错不重复弹窗）
