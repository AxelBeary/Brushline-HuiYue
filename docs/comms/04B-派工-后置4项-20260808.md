## 任务 1：稿价计算器（PriceCalculator.vue，/tools/price-calc）

**功能**：基于画师已配置的档位/增项算价——客户询价时画师快速算个参考价。

- 数据：`artistApi.getTiers()`（档位）+ `artistApi.getArtStyles()`（画风/尺寸/增项）——读现有接口返回结构
- 交互：选画风 → 选档位/尺寸 → 勾增项（可选）→ 显示估算价（元）
- **关键**：价格计算口径与后端一致——查 `server/src/features/pricing/` 的算价逻辑（pricing-engine.ts / style-pricing.service.ts），前端做「展示级估算」并标注「仅供参考，以实际报价为准」；**不复制后端完整算价逻辑**（避免两套逻辑漂移）
- 若后端有现成估算端点（如 calculatePrice）可复用——先查 `artistPublicApi.calculatePrice` 是否画师端可用
- 视觉：纸墨 token，双主题

## 任务 4：截稿日建议（DeadlineAdvice.vue，/tools/deadline）

**功能**：根据工期自动建议截稿日（原小工具集 #7）——客户问「什么时候能好」时画师快速算建议日期。

- 数据：`artistApi.getQueue()`（当前队列）+ `artistApi.getUpcomingDeadlines()`——读现有接口
- 交互：输入 N 天工期（或选「按队列顺延」）→ 显示建议截稿日（今天 + 工期 + 队列顺延估算）
- 规则（简单 MVP）：建议日期 = 今天 + 工期天数 + 队列缓冲（正式队列每单 + 估算天数，如 1 天/单）
- ⚠️ 标注「估算仅供参考」；不接日历组件（避免复杂度），纯日期文本 + 星期显示
- 视觉：纸墨 token，双主题
