# 一号→三号：PERF-1 字体修复 + profile 补 slotDisplay（2026-08-02）

## 任务 A：PERF-1 字体跳变修复（~1h）

参考：`docs/待修复问题清单.md` PERF-1 节。

根因：霞鹜文楷 3.3MB 单文件未拆分 + 无预加载 → 首屏文字先用系统字体再跳变。

修复：
1. 用已有 `scripts/subset_noto.py`（或类似工具）对霞鹜文楷做子集拆分（按 unicode-range 分 3-5 个 woff2）
2. `web/index.html` 加 `<link rel="preload">` 预加载首屏必需子集
3. CSS @font-face 加 `font-display: swap`（如果还没有）
4. 验证：build 后检查字体文件总大小 < 1.5MB

## 任务 B：profile API 补 slotDisplay（~30min）

二号 v0.24-B 发现：画师端 `GET /api/artist/profile` 不含 slotDisplay，SlotOverview 额外调公开 API 取。

修复：`artist.routes.ts` 的 `GET /api/artist/profile` 响应中加 `slotDisplay: computeSlotDisplay(artist)`。
