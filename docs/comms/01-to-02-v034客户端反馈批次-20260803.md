## 任务 B：画风展示柜「尺寸可选 + 预选跳转」（交互断链，最高优先）

**用户原声**：「选择此画风约稿功能进去又得重新点画风。（期望是选好这个画风 选好款式）」

**一号已核实的代码现状**：
- `web/src/components/templates/TplStyleGrid.vue` L40-45：尺寸行 `.tpl-style-size-row` 是纯展示 div，无点击交互
- L46-48：「选择此画风约稿」按钮 → `goOrder()`（L119-121）只 push `/artist/:subdomain/order`，不带任何参数
- `web/src/views/client/OrderForm.vue` + `web/src/composables/useOrderForm.js`：目前不读任何 query 预选参数（已搜 `route.query` 确认无）

**要求**：
1. TplStyleGrid 尺寸行改为可点击选择（选中高亮，复用现有 `tpl-style-menu-item--active` 的视觉语言），再点取消选择
2. goOrder 跳转带 query：`?styleId=<当前画风id>`；若已选尺寸再加 `&sizeId=<尺寸id>`
3. OrderForm/useOrderForm 读 query.styleId/sizeId 预选：
   - 多画风模式：selectedStyleId 直接设为该画风（跳过「选画风」步骤的重新点选）；有 sizeId 则同时预选尺寸
   - 校验：styleId/sizeId 不存在或已停用（is_active=0）时静默忽略，走正常流程
   - **与草稿恢复的优先级**：URL query 预选 > 草稿恢复（query 代表用户刚在主页做的明确选择）。restoreDraft 里若 query 已预选则不覆盖这两项
4. 单画风退化路径（styles.length === 1）同样支持 sizeId 预选

**验证**：主页选「厚涂插画」+ 点「半身像」行 → 点按钮 → OrderForm 打开即选中该画风+尺寸，价格已算出。
