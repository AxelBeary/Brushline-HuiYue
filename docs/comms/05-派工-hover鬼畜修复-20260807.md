## 鬼畜模式定义（判定标准）

`:hover` 规则改变元素**自身**的以下属性之一，导致 hover 判定范围移动/变化：
- `transform: translateY/translateX/scale`（位移/缩放）
- `padding/margin/width/height/border-width`（布局尺寸变化）

**不鬼畜的安全模式**（保留）：
- `:hover { color/background-color/border-color/box-shadow/filter: brightness }`（不改变几何边界）
- `:hover` 动画作用在**伪元素**（::after/::before）或**内层子元素**（自身不动）
