## 二、关键实现说明

1. API 接线：5 个方法严格照施工图接口契约（路径/参数/响应字段），未改后端。
2. 录单页客户信息卡：
   - ManualOrder.vue watch 回调内 Promise.all 并行加载历史订单 + 客户标记；标记接口失败/404 用 .catch(()=>null) 置 null，不阻塞历史订单查询。
   - QQ 无效/切换时同时清空 clientProfile/clientSummary（避免残留上一个客户的信息卡——边界补充）。
   - 卡片渲染条件 clientProfile 非 null：tags 胶囊循环（空数组不渲染）、note 非空显示、summary 有值显示汇总行（共 N 单 / 累计 ¥xx / 最近一单 + lastOrderStatus 状态色 el-tag，复用现有 statusType/formatDate）。
   - 样式用纸墨 token（--paper2/--line/--r-s/--ink2），与 mo-history 面板风格一致。
3. 客户标记页：顶部 QQ 搜索（getToolsClients(qq)）+ 表格（QQ/标签/备注/操作）+ 编辑弹窗（QQ 只读、el-select multiple allow-create filterable 默认清空、:multiple-limit=20、备注 maxlength 200）+ 删除 ElConfirm。保存/删除成功 ElMessage + 刷新列表；空态 i18n 提示。
4. 老客召回页：30/60/90 天 el-radio-group（默认 30）→ getReturningClients(days)；表格 QQ/单数/累计金额/最近一单/N 天未下单/复制话术；复制用 navigator.clipboard.writeText（话术含天数与 QQ），成功/失败均有 ElMessage。
5. 表单校验 = 后端子集：tags ≤20、每项 1-20 字符（trim 后过滤空项）、note ≤200，与 PUT 规则一致，不收紧。
