## 审计清单（逐项查，每项给证据：文件:行号）

### A. 状态与响应式（Vue 3 特有）
1. `ref/reactive` 误用：`reactive` 包 ref、`ref` 对象被整体替换丢响应式、`computed` 内副作用
2. **异步竞态**：请求返回顺序错乱（慢请求覆盖快请求——搜索/筛选/详情切换场景）、组件卸载后 `await` 回来 set state（内存泄漏+警告）
3. `watch` 深度监听大对象 / 无 `deep` 误用 / watch 回调内改监听源（死循环）
4. `v-for` 无 `:key` 或 key 不稳定（列表渲染 bug）
5. `v-model` 绑定 `computed` 只读值（写不进去）

### B. 交互与数据
6. 表单校验：前端校验 ≠ 后端规则子集（v0.36 教训——前端自行收紧）
7. 金额/日期：分 vs 元混用、`toFixed` 精度、UTC/本地混用（对标 TC-TR-15 教训）
8. 空态/加载态：接口失败无提示（静默 404）、loading 不结束卡死
9. 分页：page 越界、切换条件后页码不重置
10. 本地存储：localStorage 读写异常未 try-catch（隐私模式抛错）

### C. 内存与性能
11. 事件监听/定时器未清理（`onMounted` 加 `addEventListener`/`setInterval` 无 `onUnmounted` 移除）——全库 grep
12. 大列表无虚拟滚动 / 无节流防抖的滚动/输入监听
13. 组件卸载后 `ElMessage`/`ElNotification` 仍调用（无影响但可查）
14. 动态 import 未缓存（每次渲染重复加载 chunk）

### D. 安全与越权
15. 敏感信息进前端（token 存 localStorage 明文——查现状，若为既有设计标注「已知」）
16. 用户输入未转义直接 `v-html`（XSS 面）
17. 路由守卫缺失：需登录页面无 `requiresAuth`（对照 router 现状）

### E. 死代码与一致性
18. 未使用 import/组件/样式（可 grep 验证）
19. i18n 键与文案不一致（模板用了不存在的 key → 显示 key 本身）
20. 硬编码中文残留（对照 check-i18n 豁免清单，看是否漏网）
