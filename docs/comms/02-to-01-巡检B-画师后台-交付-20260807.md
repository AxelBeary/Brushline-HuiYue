## 一、🔴 真实问题（按严重度排序）

### 🔴-1 手动录单「创建后补充」失败提示硬编码中文（i18n 红线违规）— 严重度：高
- **页面**：ManualOrder（/orders/new）
- **文件:行号**：`web/src/views/artist/ManualOrder.vue` L986 / L1000 / L1009 / L1016 / L1028 / L1038
- **描述**：提交订单后的 postCreate 补写（改价/自定义增项/截稿日/开稿日/初始状态）失败时，拼接文案**全部硬编码中文**，未走 `$t()`：
  - `价格写入失败：${e.message}`
  - `自定义增项「${item.name}」写入失败：${e.message}`
  - `截稿日写入失败：${e.message}`
  - `开稿日写入失败：${e.message}`
  - `初始状态设置失败：${e.message}`
  - `订单 ${order.order_no} 已创建，但${postCreateFailed}。请在订单详情中补充。`
- **影响**：英文界面下这些提示仍显示中文（i18n 键完整性红线：所有用户可见文字必须走 `$t()`）。这是画师触发后可见的流程级提示，属红线违规。
- **建议修法**：新增 i18n 键（如 `manualOrder.postCreateFailed` / `manualOrder.postCreateWarn` 及各项失败键），文案经 `$t()` 翻译，失败项用键映射而非模板字符串拼接。
- **截图**：触发路径为错误分支，未实测截图；静态分析确认。

### 🔴-2 OrderList 移动端（375px）表格列被裁剪，无横向滚动 — 严重度：高
- **页面**：OrderList（/orders）
- **文件:行号**：`web/src/views/artist/OrderList.vue` 表格列定义（el-table-column 固定 width，合计 64+100+100+120+100+80+100+80+160+100 = 1004px）
- **实测数据（375px 视口）**：`.el-table` 容器宽 347px；`.el-table__header` 渲染宽 1018px（right=1018）；`.el-table__body-wrapper` scrollWidth=347=clientWidth 且 `overflow-x: hidden` → **表头/列超出容器被裁剪，且无法横向滚动**，移动端看不到「时间」「操作」等后部列。
- **影响**：画师手机端查看订单列表时列不完整且不可滚，操作列可能被裁（实测该订单行操作列在 1018px 位置，超出 347px 视口）。
- **建议修法**：移动端（≤768px）隐藏低优先级列（如缩略图/来源），或允许 `.el-table__body-wrapper` 横向滚动（overflow-x: auto + min-width），或改响应式卡片列表。参考 OrderDetail 的 el-descriptions 在窄屏自动换行的做法。
- **截图**：`workspace/temp/inspect-b/orders-list-375-paper.png`

### 🔴-3 页面标题字号/字体体系不一致（QueueBoard + Settings）— 严重度：中
- **页面**：QueueBoard（/queue）、Settings（/settings）
- **文件:行号**：`web/src/views/artist/QueueBoard.vue` L3（`<h2>{{ $t('queue.title') }}</h2>` 无 class、无 scoped 样式）；`web/src/views/artist/Settings.vue` L3（`<h2 class="font-display">` 仅字体类、无字号规则）
- **实测数据（1440px）**：
  - QueueBoard 标题「排期看板」：**20.25px，思源黑体（Noto Sans SC）** ← 浏览器默认 h2 兜底
  - Settings 标题「主页设置」：**20.25px，文楷**（font-display 生效但字号没跟上）
  - ManualOrder「手动录单」：28px 文楷 ✅；OrderList「订单管理」：28px 文楷 ✅
- **对照**：REQ §1.3 页面 H1 应为文楷 28/700（其他页面 `.xxx-page-title { font-size: calc(var(--font-scale,1)*28px); font-weight:700; color:var(--ink); }`）。QueueBoard 直接缺字号/字体定义，Settings 只缺字号。
- **影响**：后台页面标题视觉不统一，排期看板（最常用页）标题显小且不是文楷。
- **建议修法**：QueueBoard 标题补 `.font-display queue-page-title` 类 + 28px 样式（对齐 OrderList 模式）；Settings 标题补字号。全局可考虑加 h2 兜底规则（需评估是否影响其他页面）。
- **截图**：`queue-board-1440-paper.png`（标题区）、`settings-profile-1440-paper.png`
