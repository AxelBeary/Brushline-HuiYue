## 任务 A：P2-1 限流固定窗口→滑动窗口（~1h）

当前 `server/src/shared/middleware/rate-limit.js` 用固定窗口计数，边界处可能突发双倍流量。改为滑动窗口（或滑动日志）。

要求：
- 保持现有 API 不变（`rateLimit(key, max, windowMs)` 签名不动）
- 内存存储（不引入 Redis，生产前再考虑）
- 登录码限流 + 留言板限流都走这个函数，改一处全生效
- 新增测试覆盖边界场景（窗口尾部+头部连续请求）

## 任务 B：留言板公开路由补 hidden 画师检查（~10min）

`server/src/features/guestbook/guestbook.routes.js` 的 POST 和 GET 公开端点检查了管理员画师（`artist.qq_number === getAdminQq()`），但没检查 `artist.status === 'hidden'`。

现有公开主页路由（artist.routes.js:429）对 hidden 画师返回 404。留言板应保持一致。

修复：POST 和 GET 公开端点的画师查询条件加 `|| artist.status === 'hidden'` → 404。
