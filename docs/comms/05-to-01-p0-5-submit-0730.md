【Bug 编号】P0-5

【Bug 标题】嵌入页面 CSP frame-ancestors * 允许任意站点 iframe + 无完整 CSP 指令

【复现路径】
1. 在任意第三方网站创建 `<iframe src="https://平台域名/embed.html?artist=xxx">`
2. iframe 正常加载，无任何限制（frame-ancestors * 允许所有来源）
3. 恶意站点可在 iframe 周围伪造虚假上下文（钓鱼/点击劫持）
4. 嵌入页面仅有 frame-ancestors 指令，无 script-src/style-src 等完整 CSP

【严重程度】严重（安全头配置缺陷，允许任意站点嵌入）

【影响范围】
- 后端：所有 /embed* 路径的安全响应头
- 前端：画师设置页嵌入代码区域（标注未开放）
- 功能影响：画师在自己网站嵌入 iframe 将不再工作（当前无画师实际使用）

【原因分析】
- app.js:127 设置 `frame-ancestors *`，设计意图是"画师在自己网站嵌入"，但 `*` 无限制
- 嵌入页面只设了 frame-ancestors，没有完整 CSP（script-src/style-src/img-src/connect-src）
- 实际操作人决策：方案 A（收紧为 'self'），保留未来白名单开发可能

【责任模块】后端（安全配置）+ 画师前端（UI 提示）

【修复方案】
1. app.js：embed 路径 CSP 改为完整指令集：
   `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; frame-ancestors 'self'; connect-src 'self'`
2. Settings.vue：嵌入代码区域加 el-alert（type="info"）提示"嵌入功能暂未开放，敬请期待"；复制按钮 disabled；代码框移除 @click
3. 5c（SRI）和 5d（CSRF）不在本次范围，列入后续批次
