## 改动清单（H 级优先，逐条施工）

### H1. 滚动渐入去回弹（templates.css:8-24 + 39 + 192）

**问题**：`.tpl-reveal` 渐入用 `--ease-bounce`（超调 1.56）0.6s，所有客户端模板区块/卡片进场"弹一下"；违反 theme.css:40 自己注释"bounce 仅留给庆祝时刻"。

**改法**（三处）：

1. `templates.css:8-17` keyframes 位移 24px → 12px：
```css
/* before */
@keyframes tpl-fade-up {
  from {
    opacity: 0;
    transform: translateY(24px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
/* after */
@keyframes tpl-fade-up {
  from {
    opacity: 0;
    transform: translateY(12px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

2. `templates.css:23` 动画改 0.42s ease-out-quart（不再用 bounce）：
```css
/* before */
.tpl-reveal.tpl-visible {
  animation: tpl-fade-up 0.6s var(--ease-bounce, cubic-bezier(0.22, 1, 0.36, 1)) forwards;
}
/* after */
.tpl-reveal.tpl-visible {
  animation: tpl-fade-up 0.42s cubic-bezier(0.165, 0.84, 0.44, 1) forwards;
}
```

3. `templates.css:39` 吸底 CTA 过渡去 bounce：
```css
/* before */
.tpl-cta-enter-active,
.tpl-cta-leave-active {
  transition: transform 0.3s var(--ease-bounce, cubic-bezier(0.22, 1, 0.36, 1)), opacity 0.3s ease;
}
/* after */
.tpl-cta-enter-active,
.tpl-cta-leave-active {
  transition: transform 0.3s ease, opacity 0.3s ease;
}
```

4. `templates.css:192` receipt-btn hover 去 bounce：
```css
/* before */
  transition: transform 0.25s var(--ease-bounce, ease), background 0.2s, box-shadow 0.25s var(--ease-bounce, ease);
/* after */
  transition: transform 0.15s ease, background 0.15s ease, box-shadow 0.15s ease;
```

### H2. 后台全局 `*` 0.35s 颜色过渡 → 只挂主题切换（artist-tokens.css:246-252）

**问题**：`html[data-artist-theme] .artist-scope *` 全选把所有元素背景/边框/颜色变化拖到 0.35s——意图是主题切换平滑，副作用是所有 hover 变色都"粘"。

**改法**：把常驻全局规则改为「仅在主题切换瞬态挂载」：

```css
/* before（约 L244-252） */
/* 主题切换平滑过渡（仅后台作用域内的颜色属性） */
html[data-artist-theme] .artist-scope,
html[data-artist-theme] .artist-scope * {
  transition: background-color .35s, border-color .35s, color .35s, box-shadow .35s;
}
/* 过渡会干扰拖拽/动画性能的元素豁免 */
html[data-artist-theme] .artist-scope .tl-bar,
html[data-artist-theme] .artist-scope .cal-band,
html[data-artist-theme] .artist-scope .queue-item {
  transition: none;
}

/* after */
/* 主题切换平滑过渡（仅切换瞬态挂载，日常 hover 不背 4 条 transition） */
html[data-artist-theme].theme-animating .artist-scope,
html[data-artist-theme].theme-animating .artist-scope * {
  transition: background-color .35s, border-color .35s, color .35s, box-shadow .35s;
}
/* 过渡会干扰拖拽/动画性能的元素豁免 */
html[data-artist-theme].theme-animating .artist-scope .tl-bar,
html[data-artist-theme].theme-animating .artist-scope .cal-band,
html[data-artist-theme].theme-animating .artist-scope .queue-item {
  transition: none;
}
```

**配套 JS**（`web/src/components/artist/ThemeToggle.vue` 或主题切换实际所在组件——先 grep `theme-animating` 确认无已存在逻辑，再在切换时加类）：

在主题切换函数内（切换前）：
```js
document.documentElement.classList.add('theme-animating')
// ...原有主题切换逻辑（html dataset 赋值）...
setTimeout(() => document.documentElement.classList.remove('theme-animating'), 400)
```

> ⚠️ **先 grep 确认**：若 ThemeToggle.vue 已存在于主题切换时添加/移除类的逻辑，就地扩展；若类名 `theme-animating` 已存在则改名避免冲突（改 CSS 选择器 + JS 同步）。

### H3. 时间线脉冲 box-shadow → 伪元素 scale/opacity（templates.css:96-99 + OrderTimeline.vue:113-117）

**问题**：tl-pulse 每帧改 box-shadow（paint），1.8s infinite 常驻订单追踪/详情页。

**改法**：

1. `templates.css:96-99` keyframes 改为 scale/opacity：
```css
/* before */
@keyframes tl-pulse {
  0%, 100% { box-shadow: 0 0 0 0 color-mix(in srgb, var(--el-color-primary) 40%, transparent); }
  50% { box-shadow: 0 0 0 8px transparent; }
}
/* after */
@keyframes tl-pulse {
  0% { transform: scale(1); opacity: 0.6; }
  70% { transform: scale(1.6); opacity: 0; }
  100% { transform: scale(1.6); opacity: 0; }
}
```

2. `OrderTimeline.vue:113-117` `.tl-node.current .tl-dot` 加伪元素扩散环（保留实心点 + ::after 跑动画）：
```css
/* before */
.tl-node.current .tl-dot {
  border: 2px solid var(--el-color-primary);
  background: var(--el-color-primary-soft, color-mix(in srgb, var(--el-color-primary) 15%, transparent));
  animation: tl-pulse 1.8s ease-in-out infinite;
}
/* after */
.tl-node.current .tl-dot {
  border: 2px solid var(--el-color-primary);
  background: var(--el-color-primary-soft, color-mix(in srgb, var(--el-color-primary) 15%, transparent));
}
.tl-node.current .tl-dot::after {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: 50%;
  background: color-mix(in srgb, var(--el-color-primary) 35%, transparent);
  animation: tl-pulse 1.8s ease-in-out infinite;
  pointer-events: none;
}
```
> ⚠️ 确认 `.tl-dot` 已有 `position: relative`（读文件核实，无则补一行）。reduced-motion 已有 `animation: none`（templates.css:103）——伪元素动画同样被 `*` 全局规则覆盖，无需额外处理。
