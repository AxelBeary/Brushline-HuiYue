## 三、🟡 逐条详情

### 🟡-1 guestbook.routes.ts:118 管理端过滤参数 parseInt 宽松解析

- 位置：`server/src/features/guestbook/guestbook.routes.ts:118-119`
- 现象：`const artistId = parseInt(query.artistId ?? '')`，仅做 `if (!Number.isNaN(artistId))` 判断
- 触发条件：管理员调用 `GET /api/admin/messages?artistId=12abc` 或 `?artistId=1.9`
- 影响：`parseInt('12abc')`→12、`parseInt('1.9')`→1，非法值被静默截断为有效 ID，可能过滤到非预期的画师留言；同端点 status/replied 均为枚举白名单严格校验，artistId 口径不一致
- 危害评级：低（管理端接口 + SQL 参数化 + 结果本就可见），但属"宽松解析"隐患
- 建议：改为 `const artistId = /^\d+$/.test(query.artistId ?? '') ? Number(query.artistId) : NaN`，或复用 `Number.isInteger` 严格校验
