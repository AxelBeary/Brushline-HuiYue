### 改动点（QuickActions.vue）

1. **import SliderSwitch**（照 RevenueChart.vue 的引入方式）：
   ```js
   import SliderSwitch from '../SliderSwitch.vue'
   ```

2. **状态选项**（在 cycleStatus 附近新增）：
   ```js
   // 02B: 状态三态滑块（与 05B SliderSwitch 统一；直接点目标态替代循环）
   const statusOptions = [
     { value: 'open', label: t('dashboard.statusOpen') },
     { value: 'full', label: t('dashboard.statusFull') },
     { value: 'break', label: t('dashboard.statusBreak') }
   ]
   ```

3. **模板改造**（L52-72 的 quick-grid 内，状态卡部分）：
   - 状态卡 `quick-card--status` 内部：把「图标 + statusText」替换为 SliderSwitch（**图标可保留在卡片左上方小标或去掉**——以视觉协调为准，卡片宽度要够）
   - `@click`/`@keydown` 对状态卡要调整：`go(action)` 对 status 不再循环（点击滑块内部处理），**防止点滑块时冒泡触发 go 造成循环**——用 `@click.stop` 或状态卡单独处理
   - SliderSwitch 绑定：
     ```html
     <SliderSwitch
       v-if="action.key === 'status'"
       :model-value="store.profile?.status || 'open'"
       :options="statusOptions"
       size="small"
       @change="onStatusChange"
     />
     ```

4. **onStatusChange**（新函数，替代 cycleStatus 的循环逻辑，复用 updateProfile 链路）：
   ```js
   async function onStatusChange(next) {
     if (statusBusy.value || next === (store.profile?.status || 'open')) return
     statusBusy.value = true
     try {
       await artistApi.updateProfile({ status: next })
       store.profile = { ...store.profile, status: next }
       ElMessage.success(t('dashboard.statusUpdated'))
     } catch (err) {
       ElMessage.error(err.message)
     } finally {
       statusBusy.value = false
     }
   }
   ```
   - `cycleStatus` 函数删除（不再需要循环；若保守可保留但无调用点——**建议删除**，避免死代码，审计纪律）
   - `STATUS_CYCLE` 常量删除（无引用后）
   - `statusText`/`statusLabel` 若不再被模板引用则删除（确认无其他引用）

5. **go() 对 status 的处理**：看 `go(action)` 实现（L155 附近）——status action 原本走 `action === 'status' ? cycleStatus() : ...` 分支，改造后该分支删除或改为 no-op（滑块自己处理）。**确认 status 卡片不再响应点击循环**。
