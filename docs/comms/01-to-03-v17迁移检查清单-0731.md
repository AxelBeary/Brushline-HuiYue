## v17 迁移必须逐项确认

| # | 检查项 | 说明 |
|---|--------|------|
| 1 | **schema 字符串同步** | init.js 顶部 schema 必须包含新列，否则未来表重建迁移会丢列 |
| 2 | **JSON 字段防御** | platform_urls / inspiration_tags 用 TEXT 存 JSON，service 层 JSON.parse 必须 try-catch，默认值 NULL（不是 '[]'） |
| 3 | **不用 json_extract()** | SQLite 查询条件不用 json_extract()，性能差且版本依赖 |
| 4 | **自动备份** | 恢复 v11/v12 的 copyFileSync 备份模式，改 artists 表前备份 |
| 5 | **只做 ADD COLUMN** | 不做数据回填，降低回滚风险（SQLite DROP COLUMN 限制多） |
| 6 | **cleanDb/seedArtist 同步** | 测试 setup.js 如果涉及新表/新列，同步更新 |
