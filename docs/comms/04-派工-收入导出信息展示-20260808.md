## 施工图

### 在 ToolsExport 页加「收入概览」区（日期范围选择下方）

用户选好日期范围后，自动/点击按钮展示：

1. **收入汇总卡**（数字醒目）：
   - 总收入（分→元，含订单 + 散单）
   - 订单收入 / 散单收入 分列
   - 收款笔数（订单流 + 散单）
2. **数据源**：
   - 订单收入：`GET /api/artist/tools/export.csv?from=&to=` 解析行数/金额？**不推荐**（CSV 是下载专用）
   - 更稳：`GET /api/artist/dashboard/revenue` 按月给 bars + summary——但 period 只有 month/quarter/year，不是自定义区间
   - **推荐**：先读后端确认有没有按区间汇总的端点（tools.service.ts 有 getExportRows，但没暴露 JSON 汇总）；若没有，**用 `GET /api/artist/tools/standalone-incomes?from=&to=` 拿散单 + 前端解析（订单部分缺）→ 交付报告说明缺口**
   - ⚠️ **先 grep 后端**：`server/src/features/artist/tools.routes.ts` / `dashboard.routes.ts` 是否有区间收入汇总端点；有就用，没有就在报告说明「需要后端补一个汇总端点」，不硬造
3. 展示风格：纸墨 token 卡片（--card/--ink/--hq），双主题
