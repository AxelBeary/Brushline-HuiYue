### 迁移安全（2026-07-29 新增）

- 迁移代码中 `ALTER TABLE ADD COLUMN` 必须带 `DEFAULT`（存量行兼容）。
- service 层 INSERT 时**显式传值**，不依赖 DEFAULT（显式传 NULL 会写成 null）。
- 新增文件目录（如 notes/）必须同步检查 gcUploads 是否收集该表字段，漏做 = 数据丢失。
