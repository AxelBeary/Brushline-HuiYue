## 二、问题清单

### 🔴 P1 明显错位/交互失效

**1. 移动端悬浮控件遮挡主 CTA 按钮（Classic / Gallery / Atelier 三模板，375px）**
- 截图：home-classic-mobile.png（全宽"我要约稿"卡片按钮右端被压）、home-gallery-mobile.png、home-atelier-mobile.png（"查询进度"右半被压）
- DOM 量化（getBoundingClientRect 相交）：classic 卡片区"我要约稿"CTA（l37-338, t746-792）与悬浮件（l279-359, t746-796）**重叠 2714px²**；gallery/atelier"查询进度"按钮（l187-305, t751-796）重叠 **1170px²**；hitTest 命中 `accent-dot el-tooltip__trigger`（悬浮件遮罩在最上层）
- 初步定位：`web/src/components/client/ClientFloatingActions.vue` `.client-fab{position:fixed;right:16px;bottom:16px;z-index:95}`——右下角固定悬浮（ThemePicker+语言），无移动端安全区避让；三模板移动端 CTA 恰落同一垂直带。Folio 移动端未遮挡（该处为空白区）但同隐患。
- 影响：CTA 视觉不完整 + 按钮右半点击命中悬浮控件（误触）。raised 上移仅对吸底 CTA 模板生效，Classic 无吸底 CTA 不触发。

**2. OrderForm 移动端底部"下一步"绕过档位选择校验**
- 截图：orderform-mobile.png（底部合计栏 + mobile-cta-btn）
- 实测（Playwright 点击链路）：未选档位 → 点底部"下一步" → **直接跳到"第 2/3 步 写需求"**，无任何提示；摘要恒显示"选好档位后这里会显示价格 ¥0.00"
- 对比：桌面卡内"下一步" `:disabled="!form.tierId"`（OrderForm.vue L152）——移动底部按钮无 disabled 类、行为不一致
- 初步定位：OrderForm.vue `onMobileNext()` L670-680——旧模型分支 `if (!isStyleMode.value) { step.value = detailStep.value; return }` 不校验 form.tierId。最终 openReceipt 的 formRef.validate() 有兜底（不丢数据），但用户白填两步才发现。
- 影响：移动端下单流程断裂；底部按钮"可点击"外观误导（VL 观察同）。

## 三、已排除项（实测非 bug，不夸大不编造）

- **Classic 作品区"透明不可见"**：fullPage 截图下 tpl-reveal 区块 opacity:0 系截图工具限制（视口放大不触发 IntersectionObserver）；真实滚动后全部区块 tpl-visible opacity:1（DOM 实证 scrollTo 1500/2500 两轮）。**用户正常浏览无此问题。**
- **Folio 桌面导航"被裁切"**：DOM nav fixed t0-66 完整、链接正常；VL 初判"裁切"实为预览条遮挡（见 P3-11）与截图时机。
- **全站横向溢出 / 破图 / console 错误 / 失败请求**：32 页 0 命中（含生产真实数据页）。
- **Landing / 主页占位头像（字母圆）**：seed 无头像数据所致；生产页头像渲染正常（戴珍珠耳环少女圆形裁切，VL 确认无变形无破图）。
