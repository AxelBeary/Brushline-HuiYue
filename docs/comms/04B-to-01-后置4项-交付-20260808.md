## 各工具说明

### 1. 稿价计算器（PriceCalculator.vue）

- **数据来源**：`artistPublicApi.getPublicStyles(subdomain)`（画风+尺寸+增项，与 ManualOrder 同源）+ `artistPublicApi.getPricing(subdomain)`（倍率）
- **算价**：直接复用 `artistPublicApi.calculateStylePrice()`（POST /public/calculate-style-price）——**前端零算价逻辑**，与客户下单看到的报价完全同口径，杜绝两套逻辑漂移（施工图红线）
- **交互**：画风 → 尺寸 → 增项（switch/quantity/radio 三形态，对齐 ManualOrderRight）→ 用途/加急倍率（可选）→ 明细展示（基础价/增项/倍率/总价）
- 防抖 300ms + 竞态序号保护（慢请求不覆盖快请求）
- 单画风自动选中并算价；多画风走选择步骤
- 已标注「仅供参考，以实际报价为准」
- 视觉：纸墨 token（--ink/--paper/--hq/--card/--line），双主题自动适配

### 2. 社恐轻松回复（SocialReply.vue）

- **话术库**：`web/src/utils/reply-templates.js`（纯数据文件，零逻辑）
  - 5 类 30 条：催款 6 / 拒单 6 / 延期 5 / 谈价 6 / 日常 6，每类 ≥5 条（施工图要求）
  - 内容质量优先（用户红线）：口语化、不官腔、每条都是画师敢直接发的程度；催款「先软后明」给台阶不催命，拒单留后路，谈价守底线换条件
- **交互**：分类 tab → 话术卡片 → 复制（navigator.clipboard 优先 + execCommand 回退，含 isSecureContext 判断）
- i18n：分类名/按钮/提示全走 $t

### 3. 速记剪切板（QuickNote.vue）

- 条目列表（标题选填 + 内容必填），新增/删除/复制
- localStorage key `huiyue_quick_notes` 持久化，读写均 try-catch（隐私模式降级：读空数组 + 写失败 ElMessage 提示）
- 时间戳 MM-DD HH:mm 展示；未引 markdown/富文本（施工图简单要求）

### 4. 截稿日建议（DeadlineAdvice.vue）

- **数据**：`artistApi.getQueue()`（正式队列，算缓冲）
- **规则（简单 MVP，施工图口径）**：建议日期 = 今天 + 工期天数 + 队列缓冲（正式队列每单 + 1 天）
- 输入工期（1-365 天）→ 开关「按队列顺延」→ 算建议日期：大字号日期 + 周几（双语）
- 明细行：今天 / 工期 / 队列缓冲 / 合计；标注「估算仅供参考」
- 未接日历组件（避免复杂度），纯日期文本 + 星期
