## 一、改动清单（3 文件，全部在授权范围内）

### 1. `web/src/App.vue` — 路由过渡拆分（任务 1a）
- 模板：`router-view` 按 `isArtistRoute` 分支——
  - 后台路由（requiresAuth）：直接渲染组件，**不包 transition**（布局含侧边栏保持稳定，内容区过渡交给 ArtistLayout 内部）
  - 客户端路由（无 requiresAuth）：保留原 `fade-slide` 整页过渡 + `:key="$route.path"`
- script：新增 `useRoute` + `const isArtistRoute = computed(() => !!route.meta.requiresAuth)`
- 选择「不包 transition」而非 `name="none"`：语义更干净，避免空 transition 的类残留

### 2. `web/src/components/ArtistLayout.vue` — 内容区过渡（任务 1b）
- `<el-main class="main-content">` 内包一层 `keyed div`（`:key="$route.path"`）+ `<transition name="fade-slide" mode="out-in">`
- 复用全局 `fade-slide`（App.vue 已定义，.18s），**未新增动画类**
- `route` 变量复用现有 `const route = useRoute()`（L219 已存在，未重复声明）
- `main-content-inner` 类仅作 keyed 容器，无额外样式——padding 仍由 el-main 承担，布局不破坏（已在浏览器验证）

### 3. `web/src/views/artist/Dashboard.vue` — staggered 进入动画（任务 2）
- 8 个区域（含 F4 留言审核区）加 `enter-stagger` 类 + `--stagger` 延迟：greeting=0 → guestbook=7（60ms 步进，总延迟 420ms）
- scoped style 新增：
  - `@keyframes dash-enter`（一次性 fade-up：opacity 0→1 + translateY(10px)→0，0.3s var(--ease-out)）
  - `.enter-stagger { animation: dash-enter 0.3s var(--ease-out) both; animation-delay: calc(var(--stagger,0)*60ms) }`
  - `@media (prefers-reduced-motion: reduce) { .enter-stagger { animation: none } }` —— **显式兜底**：theme.css 全局兜底只压 duration 不压 delay，若仅靠全局兜底，delay 期间 both 填充态会让元素空白 420ms（reduced-motion 用户会看到页面空白），故显式关闭动画
- GreetingHero 未动（内部 greeting-fade 是问候语切换动画，与外层进入动画不冲突）

## 二、实现说明

- **后台路由切换链路**：App.vue 不再整页过渡 → ArtistLayout 内容区 keyed div 变化触发 fade-slide（旧内容淡出 → 新内容淡入），侧边栏/顶栏全程不动
- **首屏进入后台**：transition 无 `appear`，首次渲染不播动画 → 无闪烁
- **客户端路由**：isArtistRoute=false 走原 transition 分支，Landing→ArtistHome 仍整页 fade-slide
- 无新依赖、未动客户端模板、未动其他路由/布局
