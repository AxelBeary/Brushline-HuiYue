## 一、F1 作品链路前端（后端已在 master，零改动）

**后端契约（一号已逐行核实）**：
- `POST /api/artist/orders/:id/publish-artwork`，preHandler requireAuth + requireOwnOrder
- body：`{ deliverableIds: int[]（必填，1~50）, title: string（必填，1~100）, description: string|null（可选，≤500） }`，additionalProperties:false
- 成功 **201** `{ artworks: [{ id, imagePath, title, description }] }`（一图一条）
- 错误：非 delivered → 400 PUBLISH_WRONG_STATUS；交付物不属于本单 → 404；非图片格式（zip/psd）→ ILLEGAL_FILE_TYPE；跨画师 → 403/404

**改动点**：
1. `web/src/views/artist/OrderDetail.vue`：交付物卡区域加「发布为作品」入口——**仅 status === 'delivered' 显示**（done/进行中一律无入口，拍板规则 1）。流程：弹窗勾选图片（默认全选，非图片格式置灰不可勾）→ 填标题（必填）/描述（选填）→ 提交 → 成功后提示「已发布 N 件作品」并可跳转作品管理。
2. 可重复发布（发布不锁订单，剩余未勾图可再发）；错误态全部有提示不卡死。
3. `web/src/api/index.js`：加 publishArtwork 封装。
4. F1-验收 6/7/8/9（档位标注/客户端展示/预选/兜底）**复用现有机制**：ArtworkManage 档位多选弹窗已有（PUT 替换语义），TplGallery 档位筛选 + `?sizeId=` 预选已有（v0.35 F6）——逐模板过一遍确认不破即可，无新代码则交付报告注明「复用零改动」。
