## 改动清单

### 任务 1：订单级待收总横幅（核心）
`web/src/views/artist/OrderDetail.vue`（3 处）：
1. **横幅模板改造**：主信息「共待收 ¥X」（X = `order.remainingCents`，后端 enrich = 总价−已收），副信息「当前：{节点} ¥Y」（第一个 remaining>0 的节点，`v-if="nextDueInstallment"` 保护——无节点订单只显示总额）；点击仍 scrollToPayment
2. **显示条件**：`v-if="!isTerminal && nextDueInstallment"` → `v-if="!isTerminal && remainingCents > 0"`（remainingCents 为 0/null 不显示；null 经 `?? 0` 兜底后与 >0 比较自然为 false）
3. **新增 computed**：`remainingCents = computed(() => order.value?.remainingCents ?? 0)`；CSS 加 `.next-due-sub`（13px 次要色，不抢主信息）

### 任务 2：详情按钮排查 → **结论：自动化环境问题，非代码 bug，零改动**
- 本地 Playwright 真点击复现：首轮点击不跳转，重跑后稳定跳转成功（含事件埋点全链路：pointerdown→click→PUSHSTATE → `/orders/810?from=orders`）
- 根因实锤（vite 日志）：首次加载时依赖优化器两次触发 `optimized dependencies changed. reloading` 全页 reload，点击撞上 reload 窗口即失效；reload 完成后点击 100% 正常
- Hermes 浏览器（Browserbase）上轮复现同因：服务崩溃时 localStorage 丢失 + 页面 reload。`OrderList.vue` L78 的 `@click="$router.push(...)"` 是标准写法，代码无问题，按派工指示不动

### 任务 3：负数 label 动态切换
`OrderDetail.vue` 收款弹窗：备注 label 改为三元——`(payForm.amountYuan || 0) < 0 ? $t('orderDetail.payRefundNoteLabel') : $t('orderDetail.payNoteLabel')`，与 submitPayment 强制校验一致
