## 任务 A：画师设置页——名额与缓冲配置

1. 设置页新增"名额与缓冲"区域
2. 正式位 N：数字输入（null=不限制，0=申请制，>0=限额），默认不限制
3. 缓冲位 M：数字输入（0~999），默认 0
4. 开关：自动递补 / 隐藏排队位置 / 隐藏递补通知 / 缓冲区简表模式
5. 保存时 PUT profile，N+M≥1 校验（后端已做，前端也提示）
6. 回显：onMounted 从 profile 读取

## 任务 B：看板——缓冲区视图

1. QueueBoard 新增"缓冲区"tab 或区域（与正式区并列）
2. GET /api/artist/queue?zone=buffer 获取缓冲区列表
3. 每条显示：订单号 + 客户名 + 档位 + 焦点图（同正式区卡片风格）
4. 手动递补按钮：POST /api/artist/orders/:id/promote，成功后刷新两个列表
5. 缓冲区空时显示空状态

## 任务 C：客户主页——名额显示

1. 4 个模板展示 slotDisplay（后端已算好文案：开放中·剩N席 / 可候补 / 已接满 / 休息中）

3. 位置：画师信息区域（状态徽章附近）
4. 已满/休息时 CTA 按钮禁用逻辑已有（status !== 'open'），slotDisplay 只做展示
