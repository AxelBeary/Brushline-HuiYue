## 任务 1：删除策略 C'（REQ-036 §2.5 + 验收 14）

**现状**：`style_addons.addon_template_id` 外键 `ON DELETE CASCADE`（删模板=级联删画风引用）。C' 要求：删模板被引用时「保留独立增项 + 解除引用」，画风内数据（价格/隐藏/尺寸覆盖）完整保留。

**方案**：
- 迁移 v49：`style_addons` 外键 `ON DELETE CASCADE` → **`ON DELETE SET NULL`**（SQLite 改外键 = 重建表，需事务外 + 显式关 FK——v38 迁移教训！见 STATUS 长期教训）
- 或：**保留外键，删除模板前先 UPDATE style_addons SET addon_template_id = NULL WHERE addon_template_id = ?**（服务层处理，不动 schema——**推荐先这个，改 schema 更重**）
- 删除模板接口：若被引用 → 返回 `{ referenced: N, message: '有 N 个画风在用，删除后它们将保留为独立增项' }` → 服务层解绑再删
- ⚠️ 前端删除弹窗要显示 N（批A 的弹窗用）——接口返回 referenced 数

**验收**：删除被引用模板 → 画风内增项保留（价格/隐藏/尺寸覆盖全不动），返回 referenced N；前端可提示。
