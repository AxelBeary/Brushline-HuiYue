## 任务 P0：每日一句进入动画（用户点名，最高优先）

现状：GreetingHero.vue `onMounted → fetchGreeting()`，`greeting.text` 从空变有——首次进入直接填充。现有 `greeting-fade` Transition 只在**点击换一句**时触发（L9-11）。

**目标**：首次进入 Dashboard 时，每日一句有专门的进入动画（淡入 + 轻微上移 + 文字逐个浮现或 blur 到清晰），且与「点击换一句」的现有动画不冲突。

**方案建议**：
1. 首次加载完成（`greeting.text` 从空变非空）时触发进入动画：
   - 方案 A（推荐）：`<Transition name="greeting-enter">` 包住 h2，enter-from 加 blur(4px) + opacity 0 + translateY(6px)，0.45s ease-out——文字从模糊到清晰，有「浮现」感
   - 方案 B（更带感）：逐字浮现——需要 JS 拆字 + 每字延迟，重一点；**若做，拆成小组件且不破坏现有 key 机制**
2. 点击换一句：保留现有 greeting-fade（0.2s 淡入），**不叠加**进入动画（避免冲突）
3. 今日统计行（today-stats-row）数字：首次加载也有轻微 fade-up（delay 0.15s）——与每日一句衔接
4. reduced-motion：`@media (prefers-reduced-motion: reduce) { 动画 none }`
5. 克制动效纪律：一次性动画，不循环

**验收**：首次进入 Dashboard，每日一句从模糊到清晰浮现（约 0.5s），今日统计随之出现；点击换一句仍 0.2s 淡入；无循环动画。

## 任务 P1-2：进度条缓动

**目标**：进度条（收款进度/交付进度）加载时从 0 增长到实际值，而非直接跳。
