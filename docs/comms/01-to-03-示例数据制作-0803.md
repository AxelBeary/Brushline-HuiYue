## 任务 A：图片收集（15-20 张）

- **来源要求**：CC0 / 公有领域 / Unsplash 许可（免署名、可商用）。推荐：
  - Wikimedia Commons 古典画作（浮世绘、印象派——公有领域，直链 `https://commons.wikimedia.org/wiki/Special:FilePath/<文件名>?width=900`，注意跟随重定向）
  - picsum.photos（`https://picsum.photos/seed/<x>/800/1000`，Unsplash 许可）
- 尺寸：宽 800-1200px，单张 <500KB
- 存放：`uploads/images/<artist_id>/`（artist_id 运行时查 DB，**alice/bob 的 ID 不一定是 1/2**——当前实际在 2158/2159 附近）
- **交付报告必须附图片清单**：每张的来源 URL + 许可证（CC0/PD/Unsplash），这是合规留痕
