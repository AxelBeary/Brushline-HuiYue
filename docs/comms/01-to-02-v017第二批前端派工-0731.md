# 一号 → 二号：v0.17 第二批前端派工（R58 设置页 + 客户页集成）
> 日期：2026-07-31

## 背景

后端已合入（R58-8 平台 URL + 灵感标签），API 就绪：
- PUT /api/artist/profile 接受 `platformUrls: [{url, platform?}]` + `inspirationTags: [string]`
- GET /api/artists/:subdomain 返回 `platformUrls: [{url, platform, label}]` + `inspirationTags: [string]`
- 平台枚举：pixiv | x | weibo | lofter | bilibili | xiaohongshu | other

## 任务 A：画师设置页——平台链接管理

1. 设置页新增"平台链接"区域（在现有外链/社交区域附近）
2. 列表展示已添加的链接（平台图标/名称 + URL + 删除按钮）
3. 添加表单：URL 输入 + 平台自动识别（调后端 API 时传 url，后端自动识别）+ 手动选择后备（下拉选平台）
4. 最多 10 条，超限提示
5. URL 校验：必须 http/https 开头

## 任务 B：画师设置页——灵感标签管理

1. 设置页新增"灵感标签"区域
2. 标签编辑：Tag 输入（输入后回车添加），可删除
3. 最多 20 个，每个 ≤30 字符
4. 保存时 PUT /api/artist/profile 的 inspirationTags 字段

## 任务 C：客户下单页——灵感标签从 API 读取

当前灵感标签硬编码在前端。改为：
1. 从 GET /api/artists/:subdomain 的 inspirationTags 读取
2. 画师未自定义时不显示灵感标签区域（不 fallback 到硬编码）
3. 点击标签注入描述框的逻辑不变

## 任务 D：客户主页——平台链接展示

1. 4 个模板的客户主页展示画师平台链接（platformUrls 有值时）
2. 展示形式：平台 label + 链接图标，点击新窗口打开
3. 位置：画师信息区域（与现有社交链接/外链区域协调，不重复）
4. 无链接时不显示该区域
