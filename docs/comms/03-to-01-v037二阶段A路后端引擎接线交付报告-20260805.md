## 关键设计决策（3 项需一号知悉）

1. **守恒 Σbp=10000 守卫**：A1 方程（总价 = Σ节点价 + 额外应收 − 额外应退）仅在节点比例之和 = 100% 时有解（正式工作流由 validateInstallments I2 SUM_NOT_100 强制）。Σbp≠100% 的非常规配置（人工数据/历史残留）Σ节点价恒小于总价，A1 无解 → 跳过断言不报错。依据 R3。
2. **条目落账统一收口**：applyDeltaToInstallments 按 delta 去向落账（摊进未锁 → 原因条目；全锁 → extra_charge/refund_after_close），调用方不写条目。防双重记账。
3. **done 状态全节点 completed 锁定**：getCompletedPaymentStageIndex 对 done/delivered 返回全部阶段完成 → done 后加价全部进额外应收/减价全部进额外应退（R13 用户拍板语义：客户已确认完成，不再动节点价）。
