## 任务

搭建 Playwright 框架 + 编写 5 条核心路径 E2E 测试。

| # | 路线 | 操作 |
|---|------|------|
| E1 | 客户下单 | 画师主页 → 选档位 → 填表 → 提交 → 成功提示 |
| E2 | 客户查进度 | 进度页 → 输入订单号+QQ → 看到阶段信息 |
| E3 | 画师改状态 | 登录 → 订单详情 → 改阶段 → 成功 |
| E4 | 管理员添加画师 | 管理后台 → 填画师信息 → 提交 → 列表出现 |
| E5 | 管理员配置流程 | 管理后台 → 添加/编辑阶段 → 保存 → 列表更新 |

## 关键约束

- 测试文件全在 `e2e/` 目录，不碰 server/ 或 web/ 业务代码（P5）
- 独立测试数据库，不污染开发数据（P-AC3）
- 登录写共享 fixture（P3）
- `npm run test:e2e` 一条命令跑完（P4）
- 每条 ≤30s，总计 ≤3min（P-AC5）
- 删除 e2e/ 后项目正常构建（P-AC4）
- .gitignore 已加 test-results/ / playwright-report/ / playwright/.cache/

## 技术选型（你定，参考）

- 数据隔离：建议独立 SQLite 文件（`e2e/test.db`），启动前 initDatabase + seed，跑完删除
- 服务启动：Playwright globalSetup 里 spawn server（端口 3999 避冲突），globalTeardown 杀进程
- 浏览器：chromium only（`npx playwright install chromium`）
