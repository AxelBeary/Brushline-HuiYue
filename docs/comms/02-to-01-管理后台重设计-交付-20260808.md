## 一、改了什么（按派工 A-E）

### A. 布局骨架 —— AdminLayout 重构（顶部 Tab → 左侧导航）
- **现状核实**：AdminLayout 已存在（顶部 Tab 轻量导航 + admin-back + router-view），本批是重构不是新建
- **重做**：改为左侧导航骨架，对齐画师后台 ArtistLayout 的纸墨视觉语义：
  - 品牌区：朱砂印章「绘」+ 绘约（文楷）+ ADMIN 副标
  - 7 项导航（管理员面板/画师管理/问候语管理/默认流程/社交平台/系统自检/埋点看板），激活态花青软底 + 左侧 3px 竖条
  - 底部返回客户端入口（原顶部 admin-back 移至侧栏底部）
  - 主内容区 **max-width 1280 居中**（派工 A 要求 1280-1440）
  - 响应式：≤900px 收窄 64px 图标条（tooltip 保可达），≤600px 移动端顶栏 + 汉堡抽屉
  - 保留纸墨 token 作用域（enterArtistScope / leaveArtistScope）与 el-empty 纸墨化统一

### B. AdminDashboard 重排（用户最常看）
- 页头：文楷大标题「管理员面板」+ 副标题
- 统计卡：3 卡统一（圆角 --r-l、边框 --line、hover 阴影 --sh-2、间距 --sp-*）
- **头部按钮组从标题行独立出来** → 独立操作区（快捷操作条：管理画师/问候语/默认流程/系统自检），派工 B 明确要求"不要挤在标题行"
- 画师列表：列宽/对齐优化、昵称加粗、子域名 code 样式、状态 tag effect=light
- 回收站 / 留言管理：卡片间距统一（--sp-5）、分页右对齐

### C. ArtistManage 优化
- 页头 + 操作区独立（添加画师 / 更换管理员）
- 表格列宽/对齐优化（昵称、子域名 code、简介省略、状态 select、操作列固定）
- 行操作统一（管理=primary、订单记录=default、TOTP=success、移除=danger，group 间距 --sp-1）
- 保留全部功能弹窗（添加/订单/更换管理员/TOTP），不改 API 契约

### D. 其余页面
- **PlatformManage**：页头 + 表格卡片化，列对齐（排序/启用居中）、操作列分组，空态纸墨化
- **TrackingAnalytics**：页头 + 统计卡统一（与 Dashboard 同风格）、卡片间距统一
- **HealthCheck**：**状态卡片化**（派工 D）——每个检查项一张卡（状态点 + 名称 + 状态 tag + summary + 可展开详情），ok/warn/fail 左缘 3px 语义色（石绿/藤黄/朱砂），双列网格
- **DefaultWorkflowEditor / GreetingManage**：页头 + 卡片统一

### E. 视觉细节
- 全页统一 token：--sp-* 间距、--fs-page-title/--fs-section 标题层级、--r-l 卡片圆角、--sh-* 阴影、--line 边框
- 状态 tag 语义色沿用 artist-tokens 已覆写（EP type → 花青/石绿/藤黄/朱砂），不再硬编码颜色
- 克制动效：hover/active 均 ≤0.2s ease-out，无弹跳旋转
