## 第 1 波任务

### F3 小公告后端（~1h）

- 迁移 v21：`ALTER TABLE artists ADD COLUMN announcement TEXT DEFAULT NULL` + `announcement_expires_at DATETIME DEFAULT NULL`
- 画师设置 API 扩展：`PUT /api/artist/settings` 支持 announcement / announcement_expires_at 字段
- 公开 API 扩展：`GET /api/public/artist/:subdomain` 返回 announcement（过期则返回 null）
- 管理端无需改动（公告是画师自己的）

### F1 点赞后端（~1h）

- 迁移 v21（同批）：`ALTER TABLE artworks ADD COLUMN like_count INTEGER DEFAULT 0`
- `POST /api/public/artworks/:id/like`：like_count + 1（上限保护，如 99999）
- `DELETE /api/public/artworks/:id/like`：like_count - 1（不低于 0）
- 无需鉴权（匿名点赞），无需存访客身份
- 公开 API 返回 artworks 时包含 like_count
