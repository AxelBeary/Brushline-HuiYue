### 根因

better-sqlite3 的 `prepare().get()` / `.all()` 返回类型是 `unknown`。JS 时代无所谓，TS 下必须断言。

### 修复方案（二选一，推荐 A）

**方案 A：行级接口 + as 断言**（推荐，类型安全）

```ts
// 在文件顶部或 types/ 下定义行接口
interface WorkflowRow {
  id: number
  order_id: number
  stage: string
  // ...按实际列
}

// 查询处断言
const row = db.prepare('SELECT ...').get(id) as WorkflowRow | undefined
const rows = db.prepare('SELECT ...').all(orderId) as WorkflowRow[]
```

**方案 B：泛型工具函数**（如果查询点多，减少重复）

```ts
// shared/db-helpers.ts
export function getOne<T>(stmt: Statement, ...params: unknown[]): T | undefined {
  return stmt.get(...params) as T | undefined
}
export function getAll<T>(stmt: Statement, ...params: unknown[]): T[] {
  return stmt.all(...params) as T[]
}
```
