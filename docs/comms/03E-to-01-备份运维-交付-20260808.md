## 四、注意事项（给一号）

1. **compose 变更需重建容器生效**：logging/mem_limit 是创建容器时生效，`docker compose up -d` 不会自动应用，需 `docker compose up -d --force-recreate`（或重建）。
2. **npm ci 要求 lockfile**：Dockerfile 已 COPY package-lock.json*，两处 lock 均存在（web/ 与 server/），构建可复现；若未来手工改依赖版本忘记更新 lock，镜像构建会失败——这是预期行为（强制按 lock 装）。
3. **health 503 语义**：容器 healthcheck 已用 /api/health，DB 挂会触发容器重启（restart: unless-stopped），Caddy 也会因上游 503 返回 502/503 给用户，比之前「DB 已挂仍 200 假健康」诚实。
4. **备份调度**：脚本本身不含 cron（容器内无 cron 服务），宿主机 cron 示例已写入 docs/OPS.md §2。
5. **mem_limit 1g**：生产若内存吃紧需调大，改 docker-compose.yml 的 mem_limit 即可。
