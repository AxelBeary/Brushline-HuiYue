#### 对话式约稿风（香芋紫 #7c6cf0）— "极好！"

**可吸收：**

**可吸收：**

**🔴 必须吸收：**

- 累计稿数展示

**🟡 可选：**

**⚠️ 避坑：**
- 信息密度需要大幅精简——用户评价就是"高得离谱"
- "回复时间"等社交指标无意义，不照搬

## 三、工艺技术借鉴（不增功能，只提升质感）

### 1. 弹性缓动曲线

几乎所有好评原型共用一条曲线：

```css
cubic-bezier(.34, 1.56, .64, 1)
/*           └── 第二个值 >1 产生回弹/过冲效果 */
```

**效果**：卡片悬浮、印章弹出、价格跳动都有"物理感"——先冲过头再弹回来。

**纪律**：这个曲线只用于 `transform`/`box-shadow`，不适合 `opacity`（opacity 不能过冲到 1.2）。好评原型的做法：

```css
/* ✅ 好的做法 */
transition: transform .55s cubic-bezier(.22,1,.36,1),
            box-shadow .55s cubic-bezier(.22,1,.36,1);
transition: opacity .45s ease; /* 分开处理 */
```

**建议**：全局 CSS 变量化这个曲线，替代默认 `ease`。

---

### 2. `clamp()` 流式排版

几乎所有原型的字体/间距用 `clamp()`，没有一个固定 px：

```css
font-size: clamp(34px, 5.5vw, 46px);
padding: 0 clamp(20px, 4vw, 48px);
```

**效果**：尺寸随视口连续变化，而不是在 768px 断点处突然跳变。

**现状**：我们的 Vue 组件主要靠 Element Plus 响应式断点，文字基本固定 px。

**建议**：全局升级标题/间距/留白为 `clamp()`。

---

### 3. `minmax(0, 1fr)` 防溢出

```css
grid-template-columns: minmax(0, 1fr) 350px;
/*                     └── 不是 1fr，是 minmax(0, 1fr) */
```

纯 `1fr` 的列放长 URL 会撑破列宽。`minmax(0, 1fr)` 允许收缩到 0。

**建议**：检查现有 grid 布局，纯 `1fr` 的列全换成 `minmax(0, 1fr)`。

---

### 4. CSS 变量做 staggered 延迟

多段内容逐个淡入，不写 N 个 `animation-delay`：

```css
.reveal {
  animation: rise .65s cubic-bezier(.22,.61,.36,1) forwards;
  animation-delay: var(--d, 0s);
}
```

```html
<div class="reveal" style="--d:0.1s">第一段</div>
<div class="reveal" style="--d:0.25s">第二段</div>
```

**建议**：全局 scroll-reveal 工具类可用此模式。

---

### 5. 按钮三态物理模型

好评原型的按钮交互：

```css
.btn { }                              /* 默认："躺"在桌面上 */
.btn:hover { transform: translateY(-3px); box-shadow: 更远更深 } /* 浮起来 */
.btn:active { transform: translateY(-1px) scale(.98); } /* 按下去 */
```

**hover=浮起 / active=按下 / 不动=躺平**——真实触感。

**建议**：全局升级按钮 hover/active 状态。

---

### 6. 纹理全用内联 SVG（零外部依赖）

纸张颗粒、噪点等装饰全是内联在 CSS 里的：

```css
background-image: url("data:image/svg+xml,%3Csvg xmlns=...%3E
  %3Cfilter id='n'%3E%3CfeTurbulence baseFrequency='0.9'/%3E...");
```

**零 HTTP 请求，零额外文件。**

**建议**：需要加纸质纹理/颗粒时走这条路，不引入图片资源。

---

### 7. 动画只用合成属性

浏览了所有关键帧，**99% 的动画只改了 `transform` 和 `opacity`**——不触发 layout 重排。

这就是"丝滑"的根本原因，不是设备好。

**建议**：代码审查时检查现有动画是否改了 `width`/`height`/`left`/`top`/`margin`。

---

### 8. `backdrop-filter` 毛玻璃

```css
background: rgba(251, 251, 249, .92);
backdrop-filter: blur(10px);
-webkit-backdrop-filter: blur(10px);
```

**建议**：sticky 顶栏可以用这个代替纯色。

---

### 9. `data-*` 属性驱动 CSS 状态

```css
.card[data-priority="高"] { border-left-color: var(--hi); }
.card[data-status="已完成"] { opacity: .72; }
```

状态值是数据，不是视觉。Vue 里 `:data-priority="order.priority"` 绑定，CSS 自动匹配——比 `:class` 切换更干净。

**建议**：新建组件可考虑此模式。

---

### 10. 暗色页面自定义滚动条

```css
::-webkit-scrollbar { width: 10px; }
::-webkit-scrollbar-track { background: var(--ink); }
::-webkit-scrollbar-thumb { background: #26262b; border-radius: 8px; }
```

**暗色页面用白色系统滚动条会碎掉氛围。**

---

### 11. `prefers-reduced-motion`（无障碍）

温暖画室风做了：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
  .door-panel { display: none; }
}
```

**一行代码，兼顾无障碍+性能兜底。**

## 四、避坑清单

| 陷阱 | 后果 | 来源 |
|------|------|------|
| 信息密度过高 | 用户明确批评 | 约稿页 4 号 |
| 装饰重于功能 | "有点卡" | 订单详情原型 |
| 动画改 layout 属性 | 卡顿的根本原因 | 差评原型 |
| 筛选后网格空位不补位 | 残缺感 | 日式杂志风 |
| `will-change` 滥用 | 内存占用过高 | "有点卡"原型 |
| 社交指标（回复时间） | 对约稿场景无用 | 约稿页 4 号 |
| 非必要重功能 | 消息系统/托管/音乐 | 多个原型 |
| 纯 `1fr` 无 `minmax(0,)` | 长 URL 撑破布局 | 多处 |
| 暗色页用白色滚动条 | 氛围碎了 | 暗色原型 |
| 只做宽屏不做移动端 | 手机不可用 | 三栏/四栏布局 |
