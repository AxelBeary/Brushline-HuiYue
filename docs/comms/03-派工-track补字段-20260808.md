## 任务 1：track 响应补 deadline + payments

### 1a. order.service.ts：新增收款明细查询函数

在 `getOrderInstallments`（L664 附近）旁新增：

```ts
/**
 * 订单收款明细（客户可见字段——只返回金额/备注/时间，不含 created_by 等内部信息）
 * 按创建时间升序，与额度池收款流水一致
 */
export function getOrderPayments(orderId: number): Array<{ id: number; amountCents: number; note: string | null; createdAt: string }> {
  const rows = db.prepare(
    `SELECT id, amount_cents, note, created_at FROM order_payments WHERE order_id = ? ORDER BY created_at ASC`
  ).all(orderId) as Array<{ id: number; amount_cents: number; note: string | null; created_at: string }>
  return rows.map(r => ({
    id: r.id,
    amountCents: r.amount_cents,
    note: r.note,
    createdAt: r.created_at
  }))
}
```

> 注意：**不返回 created_by / installment_id**（客户视角无意义）。负数收款（退款）amountCents 为负，前端已有负数处理经验（v0.36 教训：前端校验须为后端子集，此处后端只透传，前端按正负展示）。

## 任务 2：新增 income-summary 端点

### 2a. tools.service.ts：新增收入汇总函数

在 `getExportRows`（L237 附近）旁新增：

```ts
export interface IncomeSummary {
  /** 订单收款合计（order_payments SUM，正数收款 - 负数退款） */
  orderIncomeCents: number
  /** 散单收入合计（standalone_incomes SUM） */
  standaloneIncomeCents: number
  /** 合计 */
  totalCents: number
  /** 区间起始/结束（与请求一致） */
  from: string
  to: string
}

/**
 * 画师收入汇总（订单收款 + 散单，按收入日期区间）
 * from/to 必填，YYYY-MM-DD；无区间数据返回 0 而非 null
 */
export function getIncomeSummary(artistId: number, from: string, to: string): IncomeSummary {
  // order_payments 按 p.created_at（datetime）date() 与订单关联过滤 artist
  const orderRow = db.prepare(`
    SELECT COALESCE(SUM(p.amount_cents), 0) AS s
    FROM order_payments p
    JOIN orders o ON p.order_id = o.id
    WHERE o.artist_id = ? AND date(p.created_at) BETWEEN ? AND ?
  `).get(artistId, from, to) as { s: number }
  const standaloneRow = db.prepare(`
    SELECT COALESCE(SUM(amount_cents), 0) AS s
    FROM standalone_incomes
    WHERE artist_id = ? AND income_date BETWEEN ? AND ?
  `).get(artistId, from, to) as { s: number }
  const orderIncomeCents = orderRow.s
  const standaloneIncomeCents = standaloneRow.s
  return { orderIncomeCents, standaloneIncomeCents, totalCents: orderIncomeCents + standaloneIncomeCents, from, to }
}
```

> 时间口径说明（重要）：order_payments.created_at 是 UTC datetime，`date(p.created_at)` 取 UTC 日期；standalone_incomes.income_date 是本地日期字符串。两口径可能差一天——**保持各自口径、在注释中说明**，不与散单页本地口径强对齐（散单页已用 income_date 本地日期；如客户需要严格对齐可后续排期，本批不扩复杂度）。
