## 改动清单（4 项，P0 半天量）

### P0-1. OrderForm 移动端底部粘性操作条（§2.2，体验收益最大）

**问题**：移动端摘要卡沉到表单最后，用户填完长表单要滚到底找"下一步"，且看不到价格。

**改法**（OrderForm.vue）：

1. **模板**：`.step-layout` 结束后加移动端专用 CTA 条（`v-if="artist"`）：
```html
<div class="mobile-cta-bar" v-if="artist">
  <div class="mobile-cta-price">
    <span class="mobile-cta-label">{{ $t('orderForm.receiptTotal') }}</span>
    <span class="mobile-cta-amt">¥{{ displayPrice.toFixed(2) }}</span>
  </div>
  <el-button type="primary" class="mobile-cta-btn" @click="onMobileNext">
    {{ step === contactStep ? $t('orderForm.submit') : $t('orderForm.nextStep') }}
  </el-button>
</div>
```
> ⚠️ 先 grep `displayPrice` 确认变量名（可能是 computed `displayPrice`），若实际为 `pricePreview.total` 或类似，用实际变量。`contactStep` 是已有 ref（grep 确认）。

2. **CSS**（scoped 内追加）：
```css
.mobile-cta-bar { display: none; }
@media (max-width: 860px) {
  .mobile-cta-bar {
    display: flex; align-items: center; justify-content: space-between; gap: 12px;
    position: sticky; bottom: 0; z-index: 60;
    margin: 0 -16px -16px;
    padding: 12px 16px calc(12px + env(safe-area-inset-bottom));
    background: color-mix(in srgb, var(--bg-card, #fff) 92%, transparent);
    backdrop-filter: blur(10px);
    border-top: 1px solid var(--border-color, #e5e5e5);
  }
  .mobile-cta-amt { font-size: 20px; font-weight: 700; color: var(--color-primary, var(--el-color-primary)); font-variant-numeric: tabular-nums; }
  .mobile-cta-btn { min-width: 128px; min-height: 44px; }
}
@media (max-width: 860px) {
  .step-nav { padding-bottom: 64px; }
}
```

3. **脚本**：加 `onMobileNext` 方法（复用现有跳转逻辑，不重复造）：
```js
function onMobileNext() {
  if (step.value === contactStep.value) return openReceipt()
  if (step.value === detailStep.value) return goNextFromDetail()
  if (!isStyleMode.value) { step.value = 2; return }
  if (step.value === 1 && isMultiStyle.value) { step.value = 2; return }
  if (step.value === sizeStep.value) { step.value = addonStep.value; return }
  if (step.value === addonStep.value) { step.value = detailStep.value }
}
```
> ⚠️ **先读 OrderForm.vue 的步骤流转逻辑**（step 值、goNextFromDetail、openReceipt、sizeStep/addonStep/detailStep/contactStep 的实际变量名）再写。蓝图给的是参考形态，实际变量名按源码对齐。改完跑 `OrderForm.stepnav.test.js` 相关测试。

### P0-2. OrderForm 步骤指示器移动端保留当前步名（§2.1）

**问题**：`@media (max-width: 860px)` 下 `.step-label { display: none }`（L1058），用户只看 5 个圆点不知在哪。

**改法**：

1. CSS（scoped 内 L1055-1060 区域）：
```css
/* before */
@media (max-width: 860px) {
  .step-label { display: none; }
}
/* after */
@media (max-width: 860px) {
  .step-label { display: none; }
  .step-label--on { display: inline; }
  .step-item:has(.step-label--on) { order: -1; }
}
```
> ⚠️ 若 `.step-label` 的 display:none 在 L1058 且父容器是 flex/grid（步骤条横排），`order: -1` 把当前步提到最前。若父容器非 flex 忽略 order 行（读上下文确认）。

2. 步骤标题上方加当前步眉题（移动端上下文）——模板中 `.step-title` 上方加：
```html
<p class="step-eyebrow">{{ $t('orderForm.stepProgress', { cur: step, total: stepDefs.length }) }}</p>
```
CSS：
```css
.step-eyebrow {
  font-size: 11px; letter-spacing: .14em;
  color: var(--text-secondary, #888); margin-bottom: 8px;
}
```

3. i18n 两条（zh/en）：
```js
// zh-CN.js
'stepProgress': '第 {cur} / {total} 步',
// en.js
'stepProgress': 'Step {cur} / {total}',
```

### P0-3. OrderList 移动端卡片视图（§5.1，后台移动端体验最差一页）

**问题**：表格 min-width: 1004px 横向滚动，手机上每行都要左右拖。

**改法**（OrderList.vue）：

1. **模板**：表格外层（grep `.order-table-wrap` 或 el-table 容器）加 `class="order-table-wrap"`，表格前加卡片容器：
```html
<div class="order-cards">
  <div v-for="row in displayedOrders" :key="row.id" class="order-card" @click="$router.push(`/orders/${row.id}?from=orders`)">
    <div class="order-card-top">
      <el-image v-if="row.focus_image_path" :src="row.focusImageUrl" fit="cover" class="order-card-thumb" :alt="$t('orderDetail.referenceImage')" />
      <div class="order-card-main">
        <div class="order-card-no">{{ row.order_no }}</div>
        <div class="order-card-sub">{{ row.tier_name || $t('common.custom') }} · {{ row.client_name || row.client_qq }}</div>
      </div>
      <el-tag size="small" :class="`status-tag status-tag--${row.status}`">{{ $t(`common.orderStatus.${row.status}`) }}</el-tag>
    </div>
    <div class="order-card-bottom">
      <span class="order-card-time">{{ formatDate(row.created_at) }}</span>
      <el-tag size="small" :class="`prio-tag prio-tag--${row.priority}`">{{ $t(`common.priority.${row.priority}`) }}</el-tag>
    </div>
  </div>
</div>
```
> ⚠️ 先 grep 确认 `displayedOrders`、`focusImageUrl`、`formatDate` 实际存在（表格已在用这些字段）。`status-tag--*`/`prio-tag--*` 颜料色类项目已有（grep 确认，无则用现有标签 class 命名）。

2. **CSS**（scoped 内追加）：
```css
.order-cards { display: none; }
@media (max-width: 768px) {
  .order-table-wrap { display: none; }
  .order-cards { display: flex; flex-direction: column; gap: 12px; margin-top: 16px; }
  .order-card { background: var(--card, #fff); border: 1px solid var(--line, #e5e5e5); border-radius: 10px; padding: 12px 16px; }
  .order-card-top { display: flex; align-items: center; gap: 12px; }
  .order-card-thumb { width: 44px; height: 44px; border-radius: 6px; flex: none; }
  .order-card-main { flex: 1; min-width: 0; }
  .order-card-no { font-weight: 700; color: var(--ink, #222); font-variant-numeric: tabular-nums; }
  .order-card-sub { font-size: 12.5px; color: var(--ink3, #888); overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }
  .order-card-bottom { display: flex; justify-content: space-between; align-items: center; margin-top: 8px; }
  .order-card-time { font-size: 12.5px; color: var(--ink3, #888); }
}
```
> ⚠️ 注意 OrderList 在后台（data-artist-theme 作用域），CSS 变量优先用 artist-tokens.css 的（--paper2/--ink/--ink3/--card/--line/--r-l/--r-s 等），先 grep artist-tokens.css 确认实际变量名再写。
