## 任务 1：导航稳定——路由过渡拆分（App.vue + ArtistLayout.vue）

### 目标
- **后台路由**（requiresAuth）：切换时侧边栏/顶栏**完全不动**，只有 `<el-main>` 内容区做淡入过渡
- **客户端路由**（无 requiresAuth）：保持现有 fade-slide 整页过渡（Landing/查单等无布局骨架，整页动合理）

### 1a. App.vue（L4-8）改造

```html
<router-view v-slot="{ Component }">
  <!-- 后台路由（requiresAuth）：整页不过渡（布局含导航保持稳定），内容区过渡由 ArtistLayout 内部处理；
       客户端路由：保留 fade-slide 整页过渡 -->
  <transition
    :name="isArtistRoute ? 'none' : 'fade-slide'"
    mode="out-in"
  >
    <component :is="Component" :key="isArtistRoute ? 'artist-scope' : $route.path" />
  </transition>
</router-view>
```

script 加：
```js
import { useRoute } from 'vue-router'
const route = useRoute()
const isArtistRoute = computed(() => !!route.meta.requiresAuth)
```

> ⚠️ 关键：后台路由用**固定 key（'artist-scope'）**——避免整页过渡触发；客户端用 `$route.path` 保持换页动画。`transition name="none"` 无动画（或直接 v-if 跳过 transition——实现选优雅者，见下）。

> 若 `name="none"` 不够干净：后台分支直接不包 transition：
> ```html
> <router-view v-slot="{ Component }">
>   <template v-if="isArtistRoute">
>     <component :is="Component" />
>   </template>
>   <template v-else>
>     <transition name="fade-slide" mode="out-in">
>       <component :is="Component" :key="$route.path" />
>     </transition>
>   </template>
> </router-view>
> ```

### 1b. ArtistLayout.vue（L149-151）内容区过渡

```html
<el-main class="main-content">
  <!-- 02C: 内容区过渡（导航稳定；keyed div 触发 fade-slide——后台路由切换只动这里） -->
  <transition name="fade-slide" mode="out-in">
    <div :key="$route.path" class="main-content-inner">
      <slot />
    </div>
  </transition>
</el-main>
```

- `main-content-inner` 类：**只做布局兜底**（若 main-content 有 padding 等样式，确认 div 包一层不破坏——先读 main-content 现有 CSS；若 main-content 样式是作用于直接子元素的，把样式迁移到 inner 或保持）
- transition 复用全局 `fade-slide`（App.vue 已定义 enter/leave 动画 .18s）——**不新增动画类**
- script 需要 `useRoute`（ArtistLayout 已 import route——确认复用现有 `route` 变量，L219 已有 `const route = useRoute()`）

### 验收

- 客户端（Landing→查单）：仍整页 fade-slide

## 任务 2：仪表盘文字进入动画（Dashboard.vue）

### 目标
Dashboard 内容不是「整体突然出现」，而是**各区 staggered fade-up**（依次淡入+轻微上移，视觉有层次）。

### 2a. Dashboard.vue

- `.dash-grid` 各区卡片加进入动画类 + 延迟：
```html
<div class="area area-greeting enter-stagger" :style="{ '--stagger': 0 }">
<div class="area area-revenue enter-stagger" :style="{ '--stagger': 1 }">
<div class="area area-stats enter-stagger" :style="{ '--stagger': 2 }">
<div class="area area-todo enter-stagger" :style="{ '--stagger': 3 }">
<div class="area area-slot enter-stagger" :style="{ '--stagger': 4 }">
<div class="area area-quick enter-stagger" :style="{ '--stagger': 5 }">
<div class="area area-activity enter-stagger" :style="{ '--stagger': 6 }">
```

- scoped style（克制动效纪律：**一次性进入动画，不循环、不位移 hover**）：
```css
/* 02C: 仪表盘各区 staggered 进入（一次性 fade-up，间隔 60ms；克制 0.3s ease-out） */
@keyframes dash-enter {
  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: none; }
}
.enter-stagger {
  animation: dash-enter 0.3s var(--ease-out) both;
  animation-delay: calc(var(--stagger, 0) * 60ms);
}
```

- ⚠️ 注意：`animation ... both` + delay 会让首屏前元素透明（from 态）——这是期望行为（依次出现）。若担心首屏 loading 期空白过长：总延迟 = 6×60ms = 360ms，可接受。
- ⚠️ `reduced-motion` 尊重：`@media (prefers-reduced-motion: reduce) { .enter-stagger { animation: none; } }`（theme.css 有全局兜底，但显式加更稳——查现有模式照抄）

### 2b. 确认各区 DOM 类名
- 读 Dashboard.vue 完整模板，确认 area 类名（area-greeting/area-revenue/area-stats/area-todo/area-slot/area-quick/area-activity 或实际名）——按实际类名加，不猜
- GreetingHero 内部已有动画，外层再叠 enter-stagger 会双动画——**确认叠加效果**：若 GreetingHero 自身动画足够，可不给它加 enter-stagger（或调整）；以视觉自然为准

### 验收
- 进入 Dashboard：各区依次淡入上移（约 0.4s 内完成），文字不再「突然出现」
- 无循环动画、无 hover 位移干扰
