### 4. 克制动效（用户第 3 条，小范围）
- **用户**："什么时候能把丝滑流畅的动画加上（同时避免 AI 味）"
- **做小范围、克制的动效**（不做全局大动）：
  - 卡片 hover 微浮起：`transform: translateY(-2px)` + 柔和阴影（0.15s ease-out）——应用在 Dashboard 主要卡片
  - 按钮按压：`transform: scale(0.98)` + 过渡
  - 弹窗/抽屉进场：淡入 + 轻微上移（opacity 0→1, translateY 8px→0, 0.18s ease-out）
  - **禁止**：弹跳/旋转/缩放入场/花哨 hover（AI 味重灾区）
  - 动效参数统一：时长 ≤0.2s、ease-out、尊重 prefers-reduced-motion（全局已有兜底）
- 范围：Dashboard 卡 + 通用按钮/弹窗（ArtistLayout 内），**不做全站扫描**
