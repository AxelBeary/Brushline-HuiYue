## 二、SliderSwitch.vue 组件（任务 2）

**文件**：web/src/components/artist/SliderSwitch.vue（新建）

**API**：
<SliderSwitch v-model="value" :options="[{ value, label, icon? }]" size="default|small" />
- 语义：容器 role="radiogroup" + tabindex=0，每项 role="radio" + aria-checked（照 EP radio 语义）
- emits：update:modelValue（v-model）+ change
- icon：@element-plus/icons-vue 组件引用（不画 SVG path、不抄用户 lottie）

**交互实现**：
- 高亮块零测量方案：CSS 变量 --sw-count（选项数）+ --sw-index（选中下标）注入 style，滑块 width: calc((100% - 6px) / var(--sw-count)) + transform: translateX(calc(var(--sw-index) * 100%))，transition: transform 0.28s var(--ease-out) 平滑滑动
- 可拖动：track 上 pointerdown → setPointerCapture → pointermove 实时按 x 坐标换算最近项下标（拖动中加 .sw-track--dragging 禁用 transition，滑块实时跟随）→ pointerup 落定选中；轻移阈值 4px 防误触
- 键盘：左右方向键切换（radiogroup 语义完整）
- 视觉：纸墨 token 双主题自适应（--hq-t 滑块底 + --hq-t2 描边、选中文字 --hq-d 加粗、轨道 --paper2 底 + --line 边），default 高 36px / small 高 28px

**单测**：web/src/components/artist/__tests__/slider-switch.test.js（6 用例全过）
1. 渲染 N 个 radio + aria-checked + --sw-count/--sw-index 正确
2. 点击切换 emit update:modelValue + change；点当前项不重复 emit
3. 键盘左右切换 + 边界（末项 ArrowRight / 首项 ArrowLeft 不动）
4. 拖动（>4px）pointermove 实时更新 --sw-index，pointerup 选中最近项
5. 轻移阈值（<=4px）不触发拖动态
6. 拖动中滑块实时跟随 + .sw-track--dragging 类
