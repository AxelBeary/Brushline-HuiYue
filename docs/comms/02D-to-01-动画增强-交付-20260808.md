## 逐任务改动说明

### P0 每日一句进入动画（用户点名，最高优先）✅
`web/src/components/artist/dashboard/GreetingHero.vue`
- Transition name 改为动态 `greetingAnimName`：**首次加载（greeting.text 从空变非空）用 `greeting-enter`**（blur(4px) + opacity 0 + translateY(6px) → 清晰，0.45s ease-out），**点击换一句仍用 `greeting-fade`**（0.2s 淡入）——两套动画互不叠加不冲突
- 首次动画结束后 500ms 切回 `greeting-fade`（避免点击换句误走进入动画）
- 今日统计行（today-stats-row）**数据到达一次性 fade-up**（0.3s，delay 0.15s 与每日一句衔接；stats 从 null → 有值时 `statsEntered` 置 true 触发，动画一次性不循环）
- reduced-motion：scoped 内显式 `@media (prefers-reduced-motion: reduce)` 关闭（theme.css 全局兜底只压 duration 不压 delay，`both` 填充态 delay 期间会空白，需显式处理——与 Dashboard enter-stagger 同款处理）

### P1-1 数字滚动 count-up ✅
- 新建 `web/src/utils/useCountUp.js`：0 → target 滚动，默认 600ms easeOutCubic，`prefers-reduced-motion` 直接跳终值；watch 目标变化**从当前值平滑过渡**（切收入维度时数字平滑变化）；首次支持 delay；onUnmounted 清理 raf/timer
- 应用三处（滚动**数值**，¥ 前缀/格式化留外层）：
  - `GreetingHero.vue`：今日统计两个金额（todayNewOrderCents / todayRevenueCents）→ 实测终值 ¥2440.00 / ¥1780.00
  - `StatCards.vue`：三个计数（pending/active/totalCompleted），加载期保持 `-`，数据到达后从 0 滚动 → 实测 2 / 5 / 4
  - `RevenueChart.vue`：汇总金额 → 实测 ¥2880.00
- ⚠️ 实现要点（自测发现并修复）：① 模板中嵌套 ref 不解包 → composable 返回 `reactive({ display })`（reactive 属性访问自动解包）；② watch getter 必须返回**值**而非 ref 对象本身（否则引用比较恒等，computed/ref 的 .value 变化不触发回调——首版滚动不生效/显示 NaN 的根因）
