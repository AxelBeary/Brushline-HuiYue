## 调试过程踩坑记录（供后续维护参考）

1. **浏览器默认 en 语言**：Playwright chromium 的 `navigator.language` 是 `en-US`，前端 i18n 检测后渲染英文，所有中文选择器失效。修复：fixture 的 `addInitScript` 强制 `localStorage.setItem('huiyue-locale', 'zh-CN')`
2. **`page.request` 挂起**：Playwright 的 `APIRequestContext` 在 fixture setup 中偶发挂起（原因不明）。修复：改用原生 `fetch` + `context.addCookies` 注入 httpOnly cookie
3. **send-code 限流**：5次/5分钟，retry 时重新登录会触发。修复：globalSetup 预登录写 token 文件，fixture 只读文件
4. **Pinia store 的 isAdmin**：路由守卫从 `localStorage.artist_is_admin` 读管理员标记，仅注入 cookie 不够。修复：`addInitScript` 同时设置 `artist_is_admin`
5. **subdomain 含连字符→artistCode 校验失败**：后端从 subdomain 自动生成 artistCode（`toUpperCase()`），连字符不通过 `仅限字母和数字` 校验。修复：测试用无连字符的 subdomain
6. **strict mode 冲突**：`getByText('添加')` 匹配到多个按钮。修复：限定作用域（`.el-dialog` / `.el-drawer`）+ `exact: true` + CSS 类选择器
