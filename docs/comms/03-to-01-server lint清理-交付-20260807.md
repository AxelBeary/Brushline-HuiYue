## 二、清理方式（每条 清理前 → 清理后）

1. `new Array<number>(n).fill(0)` → `Array.from({ length: n }, () => 0)`
2. `new Array<number>(n).fill(0)` → `Array.from({ length: n }, () => 0)`
3. `new Array<boolean>(n).fill(false)` → `Array.from({ length: n }, () => false)`
4. `new Array(n).fill(null)` → `Array.from({ length: n }, () => null)`
5. `new Array<number>(n).fill(0)` → `Array.from({ length: n }, () => 0)`
6. 导入行删除 `deriveInstallmentProgress,`（grep 确认全文无其他引用）

说明：
- 均为纯 lint 清理，零业务逻辑改动（git diff 仅 6 行替换，6+/6-）。
- 第一次尝试用了 `Array.from<number>({ length: n }, () => 0)` 显式泛型，tsc 报 TS2554（Expected 1 arguments, but got 2，泛型参数个数导致匹配到单参重载）。去掉显式泛型改为标准 `Array.from({ length: n }, () => 0)` 后 tsc 通过。教训：Array.from 不要带显式泛型。
- 未使用 eslint-disable（6 处均为可直接修复的惯用写法，无必要代码）。
