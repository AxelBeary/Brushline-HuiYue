## 第二步：重做（可上网查 Google Calendar / 飞书日历 / 滴答清单的时间条交互，学好的做法）

参考方向（用户授权「去网上找怎么做好」）：
- **缩放**：Google Calendar 是滚轮在任意位置缩放 + 内容跟随；档位切换要自然
- **拖拽平移**：按住空白/刻度区拖 = 平移，像地图拖拽；松手惯性？可选
- **日期刻度**：刻度密度自适应；今天高亮；首列「今天」按钮
- **移动端**：单指平移 + 双指 pinch 缩放要区分干净
- **性能**：拖动时无卡顿（transform 而非 scrollLeft 抖动）

## 重做要求（对标用户原话）

1. **时间条必须能用、好用**：拖拽/缩放/看窗口外订单，三个核心动作顺畅
2. **事件区分干净**：刻度区（平移/缩放）vs 横条区（改期拖拽）互不干扰
3. 缩放档位 = 视野宽度（不是数据范围），可前后滑
4. 保留已有好功能：tlGoToday / 回到今天 / 订单横条拖拽改期 / localStorage 记忆缩放
5. 移动端 pinch 与单指平移不冲突
