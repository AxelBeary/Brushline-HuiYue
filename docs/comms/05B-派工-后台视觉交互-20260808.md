- ⚠️ 同时检查是否有 **hardcode 白色背景的板块**在墨黑下不跟随（搜索 `background: #fff` / `background-color: #fff` / `#FFF` 在 `web/src/views/artist/` + `web/src/components/artist/`，发现硬编码白 → 改成 `var(--card)`）。只改明确的（后台作用域内），不要误伤客户端。

## 任务 2：新建 SliderSwitch.vue（核心新组件）

**设计规格（参考用户给的滑块，不抄 SVG）**：

```
<SliderSwitch v-model="value" :options="[{ value, label, icon? }]" size="default|small" />
```

- 语义：容器 `role="radiogroup"`，每项 `role="radio"` + `aria-checked`（照 EP radio 语义）
- **高亮块**：一个绝对定位的圆角滑块（`border-radius: 999px`，背景 `var(--hq)` 或 `var(--hq-t)`），位置跟随选中项——**用 CSS transition（left + width，0.25s var(--ease-out)）平滑滑动**，不跳变
- 布局：`display: flex`，每项等宽（`flex: 1`），滑块宽度 = 选中项宽度（用 ref 测量每项 offsetWidth/offsetLeft，或用 CSS 变量 `--selected-index` + `translateX(calc(var(--selected-index) * 100%))` 方案——**推荐 translateX 方案，零测量**）：
  ```css
  .sw-track { position: relative; display: flex; }
  .sw-thumb {
    position: absolute; top: 3px; bottom: 3px; left: 3px;
    width: calc((100% - 6px) / var(--sw-count));
    transform: translateX(calc(var(--sw-index) * 100%));
    transition: transform 0.28s var(--ease-out), background-color 0.2s;
    border-radius: 999px;
  }
  ```
  其中 `--sw-count` = 选项数、`--sw-index` = 选中下标，由组件通过 style 绑定注入。
- 图标支持：选项可带 `icon`（用 `@element-plus/icons-vue` 的组件引用，如 `Odometer`/`List`/`Clock`），渲染在 label 前；**不画 SVG path，不抄用户给的 lottie**——用 EP 图标库或纯文字
- 交互：
  - 点击某项 → 选中 + emit update:modelValue + @change
  - **可拖动**（用户强调"能拖动"）：pointerdown 在 track 上 → pointermove 拖动 → 根据 x 位置计算最近选项 → pointerup 落定选中。拖动时滑块实时跟随（pointer capture）。轻移阈值（>4px 才算拖，防误触）
  - 键盘：方向键左右切换（radiogroup 语义完整性）
- 视觉：对齐纸墨 token（--hq/--hq-t/--ink/--card/--line，双主题自适应）；文字色选中/未选中对比清晰
- 尺寸：default（高 36px）/ small（高 28px）

**组件结构**（照既有 Vue 3 + JSDoc 规范）：
```
<script setup>
defineProps({ modelValue, options: Array, size: String })
defineEmits(['update:modelValue', 'change'])
// refs: trackEl, dragging, pointerStartX, currentIndex
// computed: swCount, swIndex, thumbStyle
</script>
```
