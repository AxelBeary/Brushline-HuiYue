## 任务 F：按住日期刻度区拖拽平移（§八B）

**需求**：按住日期刻度区（顶部轴区/空白区）左右拖动 = 平移时间条画布；拖订单横条仍保持「改期」语义（不冲突——轴上拖=平移，条上拖=改期）；「两周」只是缩放维度，可前后滑动看窗口外订单。

**实现要点**：
1. 复用现有画布平移机制（`tlCanvasStart/End` 或滚动容器 scrollLeft——先读代码确认现状机制），加 pointer 事件：
   - 刻度区 `pointerdown` → 记录起点 + 当前 scrollLeft/offset → `setPointerCapture` → `pointermove` 更新 → `pointerup` 释放
   - 轻移阈值（~4px 内视为点击不算拖，防误触）
   - **事件区分**：刻度区 vs 横条区（现有 `onTlBarDown`/`onTlHandleDown` 是横条拖拽改期）——刻度区绑定在轴容器上，横条在条容器上，天然分离；确认不互相冒泡拦截
2. 缩放档位只是视野宽度：确认 `TL_ZOOMS` 切换不裁剪画布（现状已覆盖订单范围——验证即可，若 2w 档把窗口外订单裁掉则修复画布范围逻辑）
3. 缩放切换保持当前视野中心（`tlZoom` 切换时按中心锚点滚动，不跳回今天）

**验收**：刻度区按住拖动画布平移；拖订单横条仍是改期；切 2w 档能看到窗口外订单并滑动。

## 任务 F2：滚轮缩放 + 移动端双指缩放（§八B2）

**需求**：刻度区滚轮 = 缩放（向上放大、向下缩小，按 TL_ZOOMS 档位切换）；移动端双指 pinch = 缩放；单指水平滑动 = 平移（与批F一致）；缩放后保持视野中心；radio 选中态 + localStorage 同步。

**实现要点**：
1. 刻度区 `@wheel`（passive 需注意——若 preventDefault 需要非 passive 或 `{ passive: false }`；或绑定在容器上用 `@wheel.prevent`）→ 根据 `e.deltaY` 正负切档（2w↔1m↔3m↔6m）
2. 内容区（订单横条区）滚轮 = **原生滚动**（不缩放，参考 Google Calendar）——刻度区缩放、内容区滚动，事件绑定区域分离
3. 移动端：`@touchstart` 记录 `e.touches.length`——双指 = pinch（计算两指距离变化 → 切档，注意防抖）；单指 = 平移（与批F 拖动统一或复用）
4. 切档后 `tlZoom` 同步 radio + `saveTlZoom`（现有函数复用）
5. 连续滚轮快速触发防抖（rAF 合并或 throttle ~120ms）

**验收**：刻度区滚轮上下缩放；内容区滚轮仍是滚动；双指 pinch 缩放；radio + localStorage 同步；缩放后视野中心保持。
