## 现有可用接口（画师登录态）

- 画师名：`GET /api/artist/profile`（artistApi.getProfile()）→ 响应含画师展示字段（如 nickname/name，以实际返回为准，取展示名做默认文字水印）
- 作品图：`artistApi.getArtworks()` → `[{ image_path, title, ... }]`（`/uploads/...` 同源路径）
- 完稿图：`artistApi.getOrders()` → 订单列表，每单可 `artistApi.getOrder(id)` → `deliverables: [{ id, original_name, file_path, url }]`（url 为签名 URL，同源可 canvas 绘制）
- 上传：`uploadApi`（web/src/api/index.js 已有 reference/image 上传方法）——**本页优先用 FileReader 本地读图，不发服务器**（纯前端定位）

## 功能需求（全面版）

### 图片来源（三选一，画师可切换）
1. **新传图**：本地文件拖入/点击选择（el-upload 或原生 input file，`FileReader` 读 dataURL → canvas），不做服务器上传
2. **现有作品图**：右侧选图面板（`artistApi.getArtworks()` 网格缩略图），点击选中 → `<img>` 载入 canvas
3. **完稿图**：下拉选订单（`artistApi.getOrders()` 列表）→ 展示该单 `deliverables` 缩略图，点击选中

### 水印素材（二选一）
1. **文字水印**：默认取画师名（getProfile 展示名，可编辑）；字号滑块 + 透明度滑块 + 位置（四角 + 中央，5 选 1）
2. **透明底 LOGO**：本地上传 PNG（FileReader 读 dataURL）→ 存 `localStorage`（key 如 `huiyue_wm_logo_<artistId>`，画师级配置，下次进入自动加载）；LOGO 缩放滑块 + 透明度滑块 + 位置同上

### 水印模式（三种）
1. **四角**：水印在四角各一枚（间隔边距滑块）
2. **拉伸**：水印图拉满全图（半透明铺底，透明度滑块）
3. **平铺**：水印重复排列覆盖全图（间距滑块 + 透明度滑块）

### 预览与导出
- 实时预览：canvas 合成结果即时显示（参数变化即重绘，注意防抖）
- 导出：`canvas.toDataURL('image/png')` → `<a download>` 逐张下载（一次只处理一张；批量=循环逐张下载，不打包）

### ⚠️ canvas 同源铁律（REQ-035 §六 已核实）
- 本项目作品图/完稿图都在 `/uploads` 同域（fastifyStatic 托管，与 web 同域），`canvas.drawImage` 无污染，可安全 `toDataURL`
- **不要**支持外部 URL 图片输入（会污染画布报 SecurityError），UI 上不给外部 URL 入口
- 新传图走 FileReader dataURL，无跨域问题
