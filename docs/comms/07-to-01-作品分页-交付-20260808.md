## 二、分页边界处理（核实）

| 边界 | 处理 |
|---|---|
| page 越界（画师端） | 删除/批量删除当前页最后一条后 `items.length===0 && page>1` → 回退一页重拉，不出现空白页 |
| 空结果（画师端） | `el-empty` 兜底「还没有作品」 |
| 空结果（客户端） | 分页加载中不显示空态防闪烁；无作品显示 `artistHome.noWorks` |
| 加载中防重复（客户端） | `loadingMore` 标志 + el-button `:loading`（EP loading 自动禁用点击） |
| 无更多（客户端） | `hasMore` 计算驱动按钮隐藏 |
| 分页失败回退（客户端） | catch 后清空分页数据 → `galleryForTpl` 回退全量 galleryArtworks，行为与现状一致 |
| 封面置顶 | 后端排序保证，前端不重排 |
