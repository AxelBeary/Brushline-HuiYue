## 任务 1：进度对比拼图页（PuzzlePage.vue）

**功能**：画师把一个订单的「线稿→上色→完稿」多张图片拼成一张对比图，导出下载（历史小工具集 #6 蓝本）。

- 路由：`/tools/puzzle`，name `ArtistPuzzlePage`
- 交互：
  1. 选择订单：下拉（`artistApi.getOrders()`，显示 order_no + tier_name + client_name），选中后 `getOrder(id)` 拉详情
  2. 图片选择：展示该单所有 `deliverables`（完稿图）缩略图 + `references`（参考图）缩略图，画师勾选 **2~6 张**（按住顺序排列），每张可拖动排序（可简单用 el-tag 序号 + 上移/下移按钮，**不引新拖拽库**）
  3. 拼图：canvas 横向拼接（等高中宽：目标高 400px，各图等比缩放到同高，间距 8px 白缝；横向超宽则换行网格）→ 实时预览
  4. 导出：`canvas.toDataURL('image/png')` → `<a download>` 下载
- 边界：不足 2 张图时提示；deliverables+references 全空时提示「该订单暂无图片」
- 视觉对齐纸墨 token；双主题自适应

## 任务 2：排期公示页（ScheduleSharePage.vue）

**功能**：生成一份可分享的排期状态（画师当前队列概览 + 最近截稿），供画师复制文本/下载图片发客户（历史小工具集 #8 蓝本）。

- 路由：`/tools/schedule`，name `ArtistScheduleSharePage`
- 数据：
  - `artistApi.getQueue()` 拿全部队列（formal + buffer 合起来，按 queue_position 排序）
  - `artistApi.getUpcomingDeadlines()` 拿近 7 天截稿
- 交互：
  1. 生成内容（自动）：画师名（getProfile）+ 当前队列 N 单（formal/buffer 分区）+ 最近截稿 3 单（订单号 + 截稿日期）+ 一句话状态（如「本月档期已排至 X」——按队列数估算，简单规则即可：≥10 单「排期较满」/ 3-9 单「档期正常」/ <3 单「档期宽松」）
  2. 两种导出：
     - **复制文本**：navigator.clipboard 复制排期文本（i18n 文案模板）
     - **下载图片**：canvas 绘制排期卡片（画师名 + 状态 + 队列概览 + 最近截稿列表，纸墨风格配色）→ toDataURL → 下载
- 视觉对齐纸墨 token；双主题自适应
