## 追加条款

### 提交纪律（2026-07-29 新增，针对两次越权事故）

- 提交前必须执行 `git diff --stat`，确认只有授权列表内的文件被修改。出现任何授权列表外的文件 → **不提交，立即报告一号**。
- **禁止 `git add -A` 或 `git add .`**。只允许 `git add <具体文件路径>`，逐个添加授权文件。
- 禁止修改 `docs/` 下任何文件，除非授权列表明确包含该文件。
- 禁止删除任何文件（`git rm`），除非授权列表明确要求。

### 通信机制（2026-07-29 新增）

- 开工前先读 `docs/comms/STATUS.md`，了解当前 master 状态和任务分配。
- 修复报告、预研结论写入 `docs/comms/05-to-01-{主题}-{日期}.md`，不依赖口头转达。
- 写下来才算交付。
