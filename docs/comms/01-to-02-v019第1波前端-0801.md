## 共享组件硬约束（用户拍板）

**共享逻辑，不共享皮肤。** 防止 4 模板同质化。

- 共享组件（TplAnnouncement / ArtworkLikeButton / TplGuestbook）**只输出内容和状态，不写任何布局/装饰样式**（无默认 margin/padding/background/border-radius/字体大小）
- 视觉完全由各模板的 class 控制（如 `.classic-announcement { border-left: 3px solid }` vs `.atelier-announcement { background: sticky-note; rotate(-1deg) }`）
- 组件 props 只暴露数据（artist、content、状态），不暴露 position/size/variant 等视觉参数
- 4 模板适配时，每个模板必须有自己的视觉处理，不允许 4 个模板用同一套 class
