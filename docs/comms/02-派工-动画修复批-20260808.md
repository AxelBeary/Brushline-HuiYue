## 施工图（按蓝本 H/M/L + 用户点名）

### 🔴 用户点名 1：按钮切换动效（克制动效批已合入，但要补「存在感」）
- 现状：按钮 hover/active 已有按压 ≤0.2s ease-out（08-07 克制动效批），但**切换态**（选中/激活/开关）缺明显反馈
- 补：`artist-tokens.css` 统一加 `--ease-out` 快动效；关键切换（订单状态/筛选项/侧边栏激活项）加 transition（background-color .2s ease-out + transform .15s）
- **对照**：OrderForm.vue:975 tier-stamp-in 盖章动效是正确用法（庆祝时刻 bounce），本批不收敛它

### 🔴 用户点名 2：导航切换动效
- ArtistLayout 侧边栏菜单项激活态：hover/active 过渡已有，**补激活项 3px 竖条滑入动效**（transform-origin top，.25s ease-out）
- 路由切换：`web/src/router/index.js` 或 App.vue 加 `<transition name="fade-slide" mode="out-in">`（.18s 淡入+8px 上移）——先读现状看有没有；没有就加，克制（不搞 3D/翻转）
- 管理后台 AdminLayout 同套（nav-item 激活过渡）

### 🔴 用户点名 3：深色模式后台切页面模块闪白（H2 根源）
- **根因**：`artist-tokens.css:246` `html[data-artist-theme] .artist-scope * { transition: background-color .35s, ... }` 全选把所有元素颜色变化拖 0.35s——主题切换时整页「慢变色」产生闪白/粘手
- **修复（按 v0.42 H2 方案）**：改为「只在主题切换瞬间挂过渡类」——ThemeToggle 点击时给 html 加 `data-theme-switching` 类，400ms 后移除；CSS 改为 `html[data-artist-theme][data-theme-switching] .artist-scope * { transition: ... .35s }`（平时无过渡 = 切页不闪）
- 管理后台同理：AdminLayout 切主题走同一机制（后台有自己的 data-artist-theme 作用域，先 grep 确认）
- **客户端模板页**（theme.css）同样查：html.dark 切换是否有同类全选过渡，有则同方案
