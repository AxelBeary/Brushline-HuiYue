## 二、逐页改动与理由

### 1. QuickNote.vue（速记）

**改了什么**：新增表单与条目列表各收进一张分组卡片；组头带朱砂小印点；表单改为「一行一事」——标题/内容各自一行，说明文字在左（含一句人话描述），输入控件在右；底部「记一条」按钮右对齐。

**为什么**：原页面两段内容（表单、列表）平铺无层次，输入框与按钮挤在一张无标题卡片里；按三原则分组后，新增与历史记录一眼分清，表单字段也有了左说明右输入的对齐关系。

### 2. RevisionCount.vue（改稿次数）

**改了什么**：面板加组头「计数条目」+ 描述；新增条目改为「一行一事」行——左侧「新增计数条目」+ 原 addHint 描述，右侧名称输入、上限、添加按钮右对齐成组；条目卡片保持原结构（名称左、计数与按钮右）。

**为什么**：原新增行是「输入框+数字框+按钮」裸排一条，无说明锚点；现在说明在左、控件在右，与其它页面同一行结构。

### 3. Quote.vue（报价单）

**页面职能核实**：本页是**报价单生成器**（非「语录」）——填客户称呼/条目/备注后一键生成 PNG 图片或复制文字版报价（`exportPng`/`copyText` + `renderQuoteCanvas`/`buildQuoteText`），定位与任务书一致。

**改了什么**：整页拆为两张分组卡片：「报价内容」（客户称呼 / 条目列表 / 备注，每项一行一事：说明在左、控件在右）与「生成与复制」（合计行 + 生成图片/复制文字版按钮右对齐）。测试依赖的 `#quote-client`、`#quote-note`、`.quote-item-row`、`.quote-add`、`.quote-mini-btn`、`.quote-total-value`、`.quote-actions` 全部保留。

**为什么**：原页面三个字段叠放、说明只是小标签，条目列表挤在中间；分组 + 行结构后，「填什么」和「怎么导出」两件事分开，主操作按钮在右下角一目了然。

### 4. SocialReply.vue（回复模板）

**改了什么**：页头下加组头「常用话术」+ 一句描述，分类 tab 与话术列表收入同一组内；复制按钮字号/内边距对齐 4px 栅格（5px 14px → 8px 16px），列表间距 18px → 16px。

**为什么**：原页面标题后直接是 tab 和重复卡片，缺少分组锚点；组头给出「这页是干什么的」说明，重复卡片不再悬空。

### 5. PriceCalculator.vue（算价器）

**改了什么**：四个步骤（选画风 / 选尺寸 / 增项 / 估算结果）各收进一张分组卡片，组头带朱砂小印点 + 一句描述；增项行保持「名称+价格在左、控件在右」；估算结果卡头补小印点，合计右对齐。

**为什么**：原步骤标签是裸文字，各步骤区块与结果卡片视觉权重一样，看不出流程顺序；分组后「步骤→结果」层次清楚。

### 6. Watermark.vue（水印工具）

**改了什么**：左右两个面板标题升级为组头（朱砂小印点 + 一句描述）；右区参数全部改为「一行一事」：标签在左、控件在右（`grid-template-columns: 120px 1fr`），字号/LOGO 缩放/透明度/边距/间距滑块与文字输入、类型/模式/位置单选组统一行式对齐；LOGO 上传行补「水印图片」标签。

**为什么**：原右区参数是「标签一行、控件一行」的纵向堆叠，7 组参数挤成两倍行高；改为一行一事后面板高度减半、每一行都是「说明左 + 控件右」。
