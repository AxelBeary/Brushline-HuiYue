## 下单页多模板（新增需求）

用户明确：**下单页要和画师主页一样，画师可以在设置页选多款模板。**

### 机制（照搬主页现有模板系统）

- 数据库：画师表加 `order_template_id` 字段（三号迁移）
- 画师后台：设置页加"下单页模板"选择区（卡片式，和主页模板选择 UI 一致）
- 客户侧：OrderForm 按 `order_template_id` 渲染对应模板组件
- 预览：复用主页 `_tpl` 预览参数机制

### 关键约束：独立选

主页模板和下单页模板**独立选择**，不绑定。画师主页可以用画廊风，下单页用分步引导——两个页面目的不同，不该绑死。

### 实施顺序（分步）

| 阶段 | 内容 | 负责 |
|------|------|------|
| **R58** | 分步引导下单页 + **表单逻辑抽成共享核心（composable）** | 二号 |
| **R58** | `order_template_id` 字段 + 迁移 + API 读写 | 三号 |
| **R58 之后** | 加模板 = 只加布局壳（小票风/杂志风等），画师设置页加选择区 | 二号 |

核心抽取是分步引导的必然副产物（三步表单必须把逻辑从模板中剥离），不是额外工作。抽完后多模板成本极低。
