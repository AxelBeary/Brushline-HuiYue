## 〇、任务理解（人话）

用户反馈：后台字号档位（偏好页 normal/large/xlarge）**只影响个别按钮**，别的字不变。

**根因（一号已定位）**：F1 字号档位只覆盖 ① EP 组件变量（`--el-font-size-*`）② `.artist-layout` 继承字号；但后台组件有 **164 处硬编码 `font-size: 12-14px`**（三巨头 OrderDetail 42/ManualOrder 35/QueueBoard 30 就 107 处）——硬编码 px 优先级高于继承，所以不随档位变。

**A 方案（用户已拍板）**：全局 `--font-scale` 变量。把后台所有硬编码 `font-size: Npx` 改为 `font-size: calc(var(--font-scale, 1) * Npx)`，在 artist-tokens.css 定义档位变量。一次改造，全部生效。

### 改动 1：`web/src/styles/artist-tokens.css` 加变量

在现有 F1 规则（L259-271）附近**追加**：

```css
/* ═══ F1 批 4 补充（A 方案，2026-08-07）：--font-scale 全局缩放 ═══
   硬编码 font-size: Npx 的样式通过 calc(var(--font-scale, 1) * Npx) 跟随档位。
   --font-scale 默认 1（无档位/客户端 = 零影响）；large=15/14≈1.0714, xlarge=17/14≈1.2143。
   与上方 .artist-layout font-size 15px/17px 及 --el-font-size-* 保持一致。 */
html[data-artist-theme][data-font-size='large'] {
  --font-scale: 1.0714;
}
html[data-artist-theme][data-font-size='xlarge'] {
  --font-scale: 1.2143;
}
```

> 注意：`--font-scale` 定义在 `html[data-artist-theme][data-font-size]` 下，所有后台组件（ArtistLayout 内）都能继承到。

### 改动 2-12：硬编码 font-size 替换（核心，机械替换）

**规则**：对授权文件 `<style scoped>` 内所有 `font-size: <N>px`（N 为数字，12-28 常见），改为：
```
font-size: calc(var(--font-scale, 1) * <N>px);
```

**示例**：
- before：`font-size: 13px;`
- after：`font-size: calc(var(--font-scale, 1) * 13px);`

**例外（跳过不改）**：
1. `font-size: 0`（隐藏元素，乘 1 无意义但也可改——**建议跳过**，保持 diff 干净）
2. 非 px 单位（em/rem/%/inherit/var()）——不改
3. 模板内联样式（`style="font-size: 12px"`）——**要改**（也是硬编码，同样问题；用同样 calc 包装）
4. `font-size` 出现在 JS 字符串（如 `el.style.fontSize = '14px'`）——**要改**（改为 `calc(var(--font-scale, 1) * 14px)` 字符串形式——⚠️ 但 CSS var 在 JS 设置 style 时同样生效，可直接用 calc 字符串）

**优先级**：先改三巨头（2/3/4 = 107 处），再其余文件。每个文件改完立即验证 build 不炸。
