## 改动清单

### A. i18n 懒加载（web/src/i18n/index.js，唯一核心改动）

- 静态 import 只留 zh-CN（保首屏翻译）；en 改为动态 import 懒加载，切英文时才加载
- `setLocale` 改为 async：切 'en' 时先 `await ensureEn()`（消息载入 i18n.global）再切 locale.value —— **调用点零改动、无竞态**（locale 切换发生在消息载入之后，英文界面不会出现空白文案一瞬）
- 英文用户首访处理：模块顶层 `if (i18n.global.locale.value === 'en') ensureEn()` 预载（不阻塞首屏，先中文回退再切英文，符合施工图可接受标准）
- `ensureEn()` 带 `.catch(() => null)`：en 加载失败回落 zh-CN（fallbackLocale 兜底），符合施工图「失败回落」意图

**关键决策（授权边界）**：grep 全库发现 setLocale 调用点在 `ArtistLayout.vue:363` 与 `ThemePicker.vue:78`（均**不在授权文件列表**）。未越权改这两个文件，改为让 `setLocale` 内部自行 await——调用点保持同步调用 `setLocale(...)` 即可，行为等价且无竞态。main.js 核实无需改动（仅 `import i18n` + `app.use(i18n)`）。

### B. focus-visible 补全 4 处（可访问性，不改变鼠标外观）

每处 `outline: none` 规则后补同选择器的 `:focus-visible` 焦点环（outline 2px + offset 2px），颜色沿用各文件现有 focus 边框变量：

| 文件 | 行 | 焦点环颜色 |
|------|----|-----------|
| ArtistHomeAtelier.vue | 273 | var(--atelier-accent) |
| ArtistHomeClassic.vue | 293 | var(--color-primary) |
| ArtistHomeFolio.vue | 372 | var(--pal-text) |
| ArtistHomeGallery.vue | 295 | var(--color-primary) |

`:focus-visible` 仅键盘/辅助技术触发，鼠标点击无 outline，可见外观零变化。
