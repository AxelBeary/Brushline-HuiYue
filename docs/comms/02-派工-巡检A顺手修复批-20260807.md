### 1. 🔴-1 OrderForm 画风模式复制缺明细（OrderForm.vue:845 附近 copyOrderSummary）

**问题**：copyOrderSummary 只读旧模型字段 `selectedTier.value?.name` 与 `pricePreview.value?.breakdown`；画风模式（isStyleMode）下两者为空 → 复制结果缺档位名和价格明细。

**改法**：函数内加 isStyleMode 分支。先读函数完整实现（grep `copyOrderSummary`），按现有拼装逻辑补：

```js
// 参考形态（按实际函数结构调整）：
async function copyOrderSummary() {
  let text = `${t('orderForm.orderNo')}：${orderNo}\n`
  if (isStyleMode.value) {
    // 画风模式：档位名 + 明细来自 stylePricePreview
    text += `${t('orderForm.styleStep')}：${selectedStyle.value?.name ?? ''}`
    if (selectedSize.value?.name) text += ` · ${selectedSize.value.name}`
    text += '\n'
    if (stylePricePreview.value?.addonItems?.length) {
      text += stylePricePreview.value.addonItems.map(it => `- ${it.label} ¥${it.price}`).join('\n') + '\n'
    }
  } else {
    text += `${t('orderForm.step1')}：${selectedTier.value?.name ?? ''}\n`
    if (pricePreview.value?.breakdown?.length) {
      text += pricePreview.value.breakdown.map(...).join('\n') + '\n'
    }
  }
  text += `${t('orderForm.receiptTotal')}：¥${displayPrice.value.toFixed(2)}`
  // ...原有复制逻辑（clipboard + ElMessage）
}
```

> ⚠️ **先读函数现状**：grep `copyOrderSummary` 拿完整实现，按现有变量名（`selectedStyle`/`selectedSize`/`stylePricePreview` 是否已定义，grep 确认）和现有复制逻辑拼装。与成功弹窗小票（summary-card 的画风模式模板）保持一致——读那块的字段名照抄。

### 2. 🔴-2 DeliveryPage 双卡片矛盾（DeliveryPage.vue:40）

**问题**：delivery 对象存在但 deliverables 为空数组时，L22 卡片渲染「暂无文件」空态 + L40 卡片同时渲染「尚未交付」。

**改法**（前端单侧修复即可，后端契约 = 未交付返回 `deliverables: []` 已核实）：
```vue
<!-- before -->
<el-card style="margin-top: 16px" v-if="verified && delivery">
  ...
  <div v-if="delivery.deliverables?.length">
    ...
  </div>
  <el-empty v-else :description="$t('delivery.noFiles')" :image-size="60" />
</el-card>

<!-- after：未交付不渲染文件卡（避免双卡片矛盾） -->
<el-card style="margin-top: 16px" v-if="verified && delivery && delivery.deliverables?.length">
  ...
  <div v-if="delivery.deliverables?.length">
    ...
  </div>
</el-card>
```
> 即：文件卡 `v-if` 加 `delivery.deliverables?.length`；未交付卡（L40）保留不动。这样「有文件」显示文件卡、「无文件」只显示未交付卡，不再双卡同屏。
