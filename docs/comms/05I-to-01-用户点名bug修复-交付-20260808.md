## 改动说明

### Bug 1：管理员默认流程模板只读（用户：「默认流程模板为什么不能改？怎么还是灰色的？」）

**根因**：`DefaultWorkflowEditor.vue` 以 `mode="template"` 渲染 `WorkflowPaymentEditor`，而 template 模式 = 只读预览（StageListView readonly + 增删改 API 全部 reject）。后端 PUT `/api/admin/default-workflow` 本就完整可写。

**修复**（后端零改动，仅前端）：

1. `web/src/components/artist/WorkflowPaymentEditor.vue`
   - 新增 `mode="admin"` 且无 `artistId` 的分支 = 管理员编辑默认流程模板（`isTemplateAdmin`）
   - 采用「本地编辑 + 整体保存」：因后端对默认模板**只有整体 PUT、无逐节点 API**，每次结构操作本地改 stages 后立即 `saveTemplateAll()`（组装完整 nodes → `adminApi.updateDefaultWorkflow`），由后端校验兜底（SUM_NOT_100 / BP_TOO_LOW / NO_PAYMENT_NODE），失败自动 `load()` 回滚
   - 本地比例规则与 `server/src/features/artist/workflow.service.ts` 对齐：
     - `recalcFinalLocal` 对齐 `recalcFinal`（尾款 = 10000 - 其他收款之和）
     - `refreshIsFinalLocal` 对齐 `findFinal`（最后一个收款节点 = 尾款）
     - 开收款从尾款扣 DEFAULT_NEW_BP(1000)/保底 MIN_BP(500)；关收款并入尾款；删收款节点并入尾款（对齐 updateStage/deleteStage）
   - 比例条保存（`api.save`）用 dirtyNodes 覆盖本地比例后整体 PUT
   - 话术保存拦截：**默认流程模板无话术字段**（后端表 `default_workflow_template` 无 speech 列，PUT schema `additionalProperties:false` 拒收）→ 管理员编辑模板话术时提示「默认流程模板不含话术」，不假修复
2. `web/src/views/admin/DefaultWorkflowEditor.vue`：`mode="template"` → `mode="admin"`（管理员默认流程页变为可编辑）
3. `web/src/locales/zh-CN.js` + `en.js`：新增 4 个 workflow 键（templateNoSpeech / maxInstallments / finalCannotDisable / finalCannotDelete）
4. `web/src/api/index.js`：未改动（已有 getDefaultWorkflow/updateDefaultWorkflow/resetDefaultWorkflow 够用）

**能力边界（如实说明）**：派工验收中「话术」一项，后端默认模板数据模型不支持（表无 speech 列 + PUT schema 拒收）。画师流程的话术由各画师独立维护（复制模板时填 DEFAULT_SPEECH）。若需管理员编辑模板话术，需后端加列+改 schema（超出本批授权，建议另行派工）。

**未误伤核查**：`mode="template"` 全库仅 DefaultWorkflowEditor.vue 一处使用（已改），TierManage.vue（画师端）用默认 artist 模式不受影响；画师端/管理员编辑单个画师（artistId 分支）逻辑未触碰。
