## 任务 1（核心）：倍率项百分比显示

**目标**：加购项池胶囊 / 尺寸摘要 chip / 预览明细中，kind=multiply 的增项显示 `+50%`/`+100%`（而非 ¥0），与 REQ-036 §2.7 三形态（加法 ¥50 / 数量 ¥80/位 / 倍率 +50%）一致。

**方案**：
1. 读 `addon-utils.js` 的 `formatAddonPrice` / `addonKind` 现状——理解 pricing_mode 如何映射三种形态
2. 给数据源补 `kind` 传递：API 返回的增项（style_addons 经 JOIN addon_templates）现在含 `tpl_kind`（批B 快照列）或 `kind`（addon_templates）——**先读 API 返回结构确认字段名**（可能是 `tpl_kind`）
3. `addonKind(sa)`：`tpl_kind === 'multiply'` → 返回 `'mul'`（走倍率形态）；否则按 pricing_mode
4. `formatAddonPrice` 增加 multiply 分支：`+${value}%`（value = default_price/100 或百分比语义——先确认批B 乘法项 default_price 语义 = 百分比，商用 50 → +50%）
5. 胶囊/摘要/预览三处渲染统一走 `formatAddonPrice` → 自动显示 +50%
6. 倍率项**不进加法小计**（kind=multiply 是因子——前端摘要只展示，不计入小计显示；小计/计价由后端算，前端预览只读展示后端返回）
