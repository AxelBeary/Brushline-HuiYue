## 任务 1：异步竞态修复（🟡2/🟡3/🟡4 + OrderList，统一 seq 模式）

**统一范式**（库内已有正确样板：PuzzlePage.vue renderSeq）：

```js
// 竞态保护：请求序号（慢请求不得覆盖快请求）
let reqSeq = 0
async function loadSomething() {
  const mySeq = ++reqSeq
  const res = await apiCall()
  if (mySeq !== reqSeq) return  // 已有更新请求，丢弃本次结果
  render(res)
}
```

## 任务 2：Settings.vue index key（🟡1，L80 customLinks）

customLinks 项目前无稳定 id，↑↓ 变序 + index key = 输入状态错位。
- 方案：`<div v-for="(link, index) in form.customLinks" :key="link.__k ?? index">`——moveLink/removeLink 时给每项补 `__k`（自增序号或 `link.url + index` 不够稳定——**推荐自增计数器**：`let linkKey = 1`，新增/初始化时 `link.__k = linkKey++`）
- 或者更简单：`key="link.url + '-' + index"` 虽含 index 但 URL 通常唯一；**推荐前者（自增 __k）**，最稳
- 改 moveLink/removeLink 后 key 不漂移
