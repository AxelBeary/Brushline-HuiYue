## G1 禁止页内图片拖入上传区（用户催了很久的需求）

需求：页面里已展示的图片（作品图/参考图等）不许直接拖进页内上传区。
原因：拖页内图拿到的是渲染后的图（可能压缩过/带水印），不是原文件；上传只应接受系统文件拖入和粘贴。

实现方向（一号侦察过）：区分拖拽来源看 `e.dataTransfer.types`——
操作系统文件拖拽含 `'Files'`；页内元素拖拽只有 text/html / text/plain。
drop 处理里无 'Files' → preventDefault + 警告 toast（i18n 键，zh/en 都加）。

范围：grep `drop|dragover` 枚举所有上传区（一号已见：OrderDetail 订单图库、
ManualOrder 参考图、OrderForm 参考图 el-upload、ArtworkManage 作品上传，可能还有别的）。
写一个共享工具（web/src/utils/ 或 composables/），各上传区统一接入，不要每处复制逻辑。

## G2 手动录单"手动价格"抹除增项修复（005 订单事故根因，一号已用操作日志实锤）

ManualOrder.vue 现状：
- 447-448 行：doCalc 算价后，仅当 finalPriceYuan 为 null 时自动填入计算价
- 用户先选档位（自动填 ¥200）再加增项 → 计算价变 ¥380，但字段停在 ¥200 不更新
- 582-593 行：提交时 manualCents(200) !== calcCents(380) → 误判画师有意改价 → 自动调 updatePrice 抹掉增项

修复：加「用户是否手动改过价格」脏标记（input @input 置脏 / 重置清空）；
doCalc 里未置脏 → 始终同步 finalPriceYuan = 最新计算价；已置脏 → 尊重画师手输。
重置函数（649 行附近）记得清脏标记。
