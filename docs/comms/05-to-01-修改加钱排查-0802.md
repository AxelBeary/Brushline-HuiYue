## 附加发现：节点金额不联动

`order_payment_installments` 表的 `amount_cents` 是建单时写入的静态值。添加附加工作项后：
- `final_price_cents` 正确增加（`adjustFinalPrice` 生效）
- `paid_total_cents` 不变
- 但各节点 `amount_cents` 不变 → 节点金额之和 ≠ 新总价

前端 OrderDetail 的"应收参考"（`installmentRefs`）用 `poolPaidCents` 逐期覆盖推算三态，**待收金额 = finalPrice - paidTotal 是正确的**（L856），但节点明细显示的金额是旧的。

## 修复方案（3 选）

### 方案 A：OrderDetail 加"改价"按钮（最小，推荐先做）

- OrderDetail 价格区域加一个"✏️ 修改价格"按钮（非终态可见）
- 弹窗：输入新总价（元）+ 可选报价备注
- 调用已有 `artistApi.updatePrice(id, { finalPriceCents, quoteSnapshot })`
- 工程量：**前端 ~40 行**（弹窗 + 调用 + 刷新），后端零改动
- 解决：画师能直接改总价

### 方案 B：附加工作项支持编辑（中等）

- 新增 `PUT /orders/:id/extra-items/:itemId`（改 name/priceCents）
- 改价时 delta = newCents - oldCents，调 `adjustFinalPrice(orderId, delta)`
- 前端：附加项行加"编辑"按钮，复用添加弹窗
- 工程量：后端 ~30 行 + 前端 ~30 行
- 解决：画师能改已有加钱的金额

### 方案 C：A + B 合并（完整体验）

- 改价按钮（直接改总价）+ 附加项编辑（精细调整）
- 两个入口互补：快速改总价用 A，明细调整用 B
- 工程量：~100 行前端 + ~30 行后端

### 推荐
