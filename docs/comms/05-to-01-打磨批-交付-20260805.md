## 改动明细

### A · ThemePicker 色板名 i18n
- `ThemePicker.vue`：accents 数组 `name` 中文硬编码 → `nameKey` i18n 键；title 渲染 `t(a.nameKey)`
- 翻译（信达雅，英语传统色名非直译）：青=Teal · 碧=Turquoise · 蓝=Blue · 靛=Indigo · 紫=Violet
- `zh-CN.js` / `en.js`：`pref.accentNames` 各加 5 键

### B · 亮色 Disclaimer 对比度（AA）
- `Disclaimer.vue` scoped CSS：`html:not(.dark)` 下 warning alert 文字色（title + description）由 EP 默认 `--el-color-warning` #e6a23c（浅橙底约 2.2:1）加深为 **#855e0a ≈ 5.4:1**（对浅橙底 #fdf6ec），达 WCAG AA 4.5:1
- 选择器限定 `html:not(.dark)`，暗色模式零影响

### C · TrackOrder placeholder 调深
- `TrackOrder.vue` scoped CSS：`html:not(.dark) .track-page` 覆盖 `--el-input-placeholder-color` #a8abb2（白底约 2.5:1）→ **#6c6e72 ≈ 5.1:1**，达 AA；仅亮色、仅本页

### E · 「返回主页」无障碍名去重
- 根因核实（EP 2.14.3 `page-header` 源码）：icon 容器 div 自动带 `aria-label = title prop`，与 title 文本叠加，读屏读两遍
- 修法：title 插槽包 `aria-hidden="true"`——icon aria-label 保留为唯一无障碍名，视觉文本不变。零视觉改动
- **「返回主页」所在组件共 3 处（grep 定位，均客户端）**：
  - `web/src/views/client/TrackOrder.vue`（本在授权清单）
  - `web/src/views/client/OrderForm.vue` ← 授权清单「自行 grep 定位」项
  - `web/src/views/client/DeliveryPage.vue` ← 同上
