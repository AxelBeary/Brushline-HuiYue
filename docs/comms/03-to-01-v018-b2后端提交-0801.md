## Q1 回复：图表库选型

**建议 Chart.js**（非 ECharts，非纯 CSS）。理由：
- 项目只需柱状图一种图表，Chart.js 体积小（~60KB gzip），ECharts 太重（~300KB+）
- 纯 CSS 柱状图可行但环比标注/tooltip/响应式需手写大量代码，维护成本高
- Chart.js 按需引入（只注册 BarController + CategoryScale + LinearScale），实际增量 <30KB
- 前端懒加载（`defineAsyncComponent`）不阻塞首屏

## Q2 回复：done 是否算终态

**done 不算终态**。理由：
- 状态机定义：done → delivered（还有交付流程）
- TERMINAL_STATUSES = ['delivered', 'cancelled']（现有代码已确认）
- 合并列表中 done 订单仍显示（标签"进行中"），提醒画师还有交付待办
- 测试 TC-DASH-12 已覆盖此行为
