## 任务 1：#15 瀑布流跳动根因排查（研究，不修）

**现象**：客户端画师主页瀑布流滚动加载时，图片加载完跳动挤掉上方的图。v0.29 加了骨架占位（min-height 200px + shimmer），用户反馈**依旧跳动**。

**排查方向**：
1. 瀑布流布局实现方式：搜 `masonry` / `waterfall` / `column` 在 TplGallery.vue 和 4 模板中——是 CSS columns？JS 计算列高？还是 flex？
2. 如果是 CSS `columns`：图片 onload 后高度变化会触发整列 reflow，骨架占位的固定 min-height 无法解决（因为真实高度 ≠ 200px）
3. 如果是 JS 布局（如计算每列累计高度分配）：检查是否在图片 onload 后重算——这是跳动根因
4. 后端 artworks 是否返回 width/height：搜 `width` / `height` 在 artist.service.ts 的 artworks 查询中。如果有，前端可以用 aspect-ratio 精确预留；如果没有，考虑上传时 sharp 读取尺寸存入 DB

**产出**：根因分析 + 修复方案（2-3 个方案对比 + 推荐）写入交付 comms。不实施，等一号研判后派修。
