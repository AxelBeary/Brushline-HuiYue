## 接口变更

### POST /api/artist/orders/:id/extra-items（新增）

```json
{ "name": "加一把武器", "description": "可选", "priceCents": 5000 }
```

- requireAuth + requireOwnOrder
- 终态（delivered/cancelled）→ 400 ORDER_FINAL_STATE
- 上限 20 条 → 400 EXTRA_ITEM_LIMIT
- 响应：更新后订单（含 extraItems + 重算 final_price_cents）

### DELETE /api/artist/orders/:id/extra-items/:itemId（新增）

- 归属校验（item.order_id === order.id）→ 404
- 响应：更新后订单

### GET /api/orders/track/:orderNo（扩展，向后兼容）

响应新增：
```json
{
  "extraItems": [{"name": "加一把武器", "priceCents": 5000}],
  "finalPriceCents": 55000,
  "installments": [{"name": "定金", "amountCents": 20000, "paid": true}]
}
```

客户不可见：description、id、created_at、系统备注（SPEC §5.5 硬约束）。

### getOrder()（扩展，向后兼容）

所有返回订单的接口自动携带 `extraItems` 数组。
