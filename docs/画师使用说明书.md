# 🎨 画师使用说明书

> 这份说明书面向使用本平台的画师。不需要任何代码知识，会用手机/电脑上网就行。
> 最后更新：2026-07-29（v0.11）

---

## 一、平台首页

打开平台网址，你会看到 **所有画师的列表页**，展示每位画师的头像、昵称、简介和当前状态（可约稿/已排满/休息中）。

点击任意画师卡片，即可进入该画师的个人主页。

---

## 二、登录后台

1. 打开你的画师主页链接（如 `你的域名.com/artist/alice`）
2. 在浏览器地址栏末尾加上 `/login`，如 `你的域名.com/artist/alice/login`
3. 输入你绑定的 **QQ号**，点击"获取登录码"
4. 你的QQ会收到一条 **6位数字登录码**（5分钟内有效）
5. 在网页输入登录码，点击"登录"
6. 登录成功后 7 天内免重复登录

> ⚠️ 登录码输错 5 次会锁定，别慌，等一会儿再试。

---

## 三、设置你的主页

登录后进入 **⚙ 主页设置**：

| 设置项 | 说明 |
|--------|------|
| 画师昵称 | 客户看到的名字 |
| 个人简介 | 一两句话介绍自己 |
| 主页状态 | **可约稿** / **已排满** / **休息中** — 客户打开主页第一眼看到的 |
| 身份码 | 订单号前缀（如 `ALICE`），2-10位大写字母/数字，默认自动生成 |
| 联系QQ | 客户在查询页看到的联系QQ（留空默认用登录QQ），解决换号/多号问题 |
| 微博链接 | 填了就会在主页显示"去我的微博"按钮 |
| B站链接 | 同上 |
| 客户QQ通知 | 开关：是否允许客户在下单时选择接收QQ排队提醒 |

> 💡 v0.11 起，主页设置里不再有「流程与比例」tab。流程和收款比例统一在 **💰 价格管理** 里设置（见第八节）。

---

## 四、管理价格档位

进入 **💰 价格管理**：

1. 点 **"+ 添加档位"**
2. 填写：
   - **名称**：如"头像"、"半身像"、"全身像"
   - **价格**：单位元
   - **工期**：大概几天能画完
   - **描述**：简要说明包含什么
   - **例图**（可选）：上传一张该档位的示例图，客户在主页价格表里能直接看到
3. 点保存

客户在你的主页上就能看到清晰的价格表，带例图的档位展示效果更好。

> 💡 可以随时编辑或删除档位，不影响已有订单。例图也可以随时更换或移除。

### 增项与倍率

价格管理里还有「增项」和「倍率」两个 tab：
- **增项**：如"表情差分 +30元/个"、"复杂背景 +50%"
- **倍率**：如"商用 ×2"、"加急 ×1.5"
- 客户下单时选择增项/倍率，系统自动计算总价

---

## 五、上传作品

进入 **🖼 作品管理**：

1. 把图片文件 **拖进上传区域**，或点击选择文件，或 **Ctrl+V 粘贴截图**（v0.11 新增）
2. 支持 JPG / PNG / WebP 格式
3. 上传后自动显示在主页的作品展示区
4. 鼠标悬停在图片上可以看到"删除"按钮

---

## 六、编辑约稿须知

进入 **📜 须知编辑**：

- 写清楚：不画什么、修改规则、工期说明、版权说明等
- 支持简单的 HTML 标签（`<h3>`标题、`<ul><li>`列表、`<strong>`加粗）
- 下方有实时预览
- 客户下单时 **必须滚动阅读并勾选同意** 才能提交

---

## 七、处理订单

### 方式一：客户自助下单
客户在你的主页填表提交后，订单自动进入你的队列。

### 方式二：手动录单（客户只通过QQ联系时）
1. 进入 **✍ 手动录单**
2. 填写客户QQ号、昵称、档位、需求描述（从QQ聊天复制）
3. 选择优先级（默认"中"）
4. **上传参考图**（v0.11 新增）：客户在QQ发给你的参考图，直接拖进来或 Ctrl+V 粘贴
5. **选择增项/倍率**（v0.11 新增）：和自助下单一样，选完自动计算报价
6. **QQ通知开关**（v0.11 新增）：是否允许客户接收QQ排队提醒
7. 点"录入订单" → 生成订单号，自动进入排期

> 两种方式录入的订单进同一个队列，管理方式完全一样。

---

## 八、流程与收款比例

进入 **💰 价格管理 → 流程与比例** tab：

### 流程节点
- 系统默认提供 7 个节点：定稿 → 排期确认 → 草稿确认 → 线稿确认 → 上色确认 → 完稿确认 → 交付
- 你可以 **添加/删除/改名** 节点（至少保留 1 个）
- **拖拽排序**：拖动节点调整顺序，最后一个收款节点自动成为"尾款"

### 收款比例
- 打开节点的"收款"开关，该节点变为收款节点
- 用 **比例条** 拖拽调节各收款节点的百分比（Q弹动画反馈）
- **向右拖拽**可吞并节点（关闭该期收款），向左拖到底也可移除
- 尾款比例自动计算 = 100% − 其他收款节点之和
- 限制：最多 20 个收款节点，每个最低 5%，尾款不可删除/关闭

### 节点说明
- 点击节点名称可改名
- 点击灰色说明文字可为该阶段添加描述（如"双方确认稿件需求与规格"）

### 修改次数告示（v0.11 新增）
- 在流程管理页面可以写一段 **修改次数说明**（如"每阶段含 2 次免费修改，超出按 50 元/次收取"）
- 这段文字会显示在客户看到的流程预览中，让客户下单前就知道修改规则

### 恢复默认
- 底部有"恢复默认模板"按钮，点击后确认即可重置为出厂 7 节点流程
- ⚠️ 此操作会覆盖你当前的所有自定义节点和比例，无法撤销

### 使用说明
- 流程节点标题旁有"使用说明"按钮，点击弹出详细操作指南

### 客户看到什么
客户在你的主页价格板块和下单页能看到流程预览条（含修改次数告示），了解整个约稿步骤和付款节点。

## 九、排期看板（拖拽排序）

进入 **📋 排期看板**：

- 所有活跃订单按 **优先级（高→中→低）+ 下单时间** 排列
- **拖拽卡片** 可以调整顺序：
  - 拖动后整个队列顺序更新，后端按新顺序重新分配排队位置
  - 优先级不会因拖拽改变（优先级通过订单详情页单独设置）
  - 例：把第 5 张卡片拖到第 2 位 → 它变成第 2 位，原来的 2-4 位依次后移
- 每张卡片上有快捷操作按钮：确认 / 开始制作 / 完成 / 交付 / 取消
- **焦点图**（v0.11 新增）：如果订单设置了焦点图，卡片上会直接显示角色缩略图，一眼看出这单画什么

### 优先级说明

| 优先级 | 颜色 | 适用场景 |
|--------|------|----------|
| 🔴 高 | 红色 | 加急单、老客户优先 |
| 🟡 中 | 黄色 | 默认，正常排队 |
| 🟢 低 | 绿色 | 不急的单、练习 |

## 十、订单详情与价格管理

点击任意订单进入 **订单详情** 页面：

### 状态流转
```
待确认 → 已确认 → 制作中 → 已完成 → 已交付
                      ↕
                    修改中
                      
任何状态 → 已取消
```

点击对应按钮即可切换状态。

### 报价与最终价格（v0.11 新增）

- **报价快照**：下单时系统自动生成一段可读的报价描述（如"头像 ¥200 + 表情差分×2 ¥60，加急×1.5 → 总价 ¥390"）
- **最终价格**：这单实际成交的金额。自助下单时自动填入计算器总价，你可以随时修改
- 报价快照和最终价格 **都可以编辑**——实际成交经常和计算器报价不同（面议、折扣、老客户优惠），改就完了
- 修改最终价格时，系统自动记一条备注（"价格从 ¥A 改为 ¥B"），方便回看

### 焦点图设置（v0.11 新增）

- 从订单的参考图中选一张设为"焦点图"——代表这个订单要画的角色
- 三态开关：**关**（不显示）→ **小**（缩略图）→ **大**（预览图）
- 设置后，排期看板的卡片上直接显示这张图，不用点进详情就知道画的是什么
- 没有参考图的订单，焦点图开关置灰不可用

### 参考图管理
- 订单详情页显示客户上传的参考图网格
- 可以删除参考图（v0.11 新增：删除被设为焦点图的参考图时，焦点图自动失效）

### 订单备注
- 记录客户的特殊要求、沟通要点
- 替代翻QQ聊天记录

## 十一、交付作品

1. 订单状态改为"已完成"后，出现 **📦 上传交付** 按钮
2. 点击后上传成品文件（支持 PNG/JPG/WebP/GIF/PSD/AI/PDF/ZIP/RAR/7z，最大 50MB）
3. 上传后状态自动变为"已交付"
4. 客户凭订单号在查询页或交付链接下载文件
5. 文件 **永久有效**，不会像QQ文件那样过期

## 十二、仪表盘

登录后进入 **📊 仪表盘**：

- **每日一句**：顶部问候区，按时段显示随机问候语。**点击整个区块即可换一句**（v0.11 起没有单独的"换一句"按钮了，直接点就行）
- **统计卡片**：待确认新单 / 进行中订单 / 本月收入 / 累计完成
- **快捷操作**：一键跳转排期看板 / 手动录单 / 全部订单 / 设置
- **当前状态**：切换可约稿 / 已排满 / 休息中

## 十三、客户那边看到什么？

| 客户操作 | 看到的内容 |
|----------|-----------|
| 打开平台首页 | 所有画师的卡片列表，点击进入个人主页 |
| 打开你的主页 | 头像、简介、状态、作品、价格表、流程预览（含修改次数告示）、外链 |

## 十四、主题切换

侧边栏底部有 **🎨 主题选择器**：
- **底色**：跟随系统 / 亮色 / 暗色
- **主色**：5 种配色可选（青~蓝渐变）
- 选择后自动保存，下次登录保持

客户在你的主页上也有同样的主题选择器，可以切换亮暗和主色。

## 十五、主页模板切换（v0.10.0 升级，v0.11 新增第 4 套）

进入 **⚙ 主页设置 → 主页模板** Tab，分两步定制你的主页：

### 第一步：选布局（页面怎么摆）

| 布局 | 风格 |
|------|------|
| 经典工作室 | 代表作横幅开场，桌面双栏，约稿按钮吸顶常驻 |
| 美术馆画廊 | 全屏画作开场，展签式名字，大小交错画廊 |
| 单页落地页 | 左文右图分屏开场，滚动侦测导航，适合品牌风格 |
| 画册工作室（v0.11 新增） | 暖米色纸感画册风，大图留白，作品像画集内页 |

### 第二步：选配色（页面什么气质）

| 配色 | 气质 |
|------|------|
| 纸 | 暖白宣纸，墨字，安静 |
| 墨 | 画廊深炭，层灰，克制 |
| 暮 | 蓝灰暮色，冷静 |
| 苔 | 深绿自然，温润 |

> 💡 配色只有"气质"之分，没有"亮暗"之分——喜欢亮色的客户看到浅色版，喜欢暗色的客户看到深色版，自动适配。主色（按钮/强调色）仍跟随访客的五色选择。

- 4 布局 × 4 配色 = **16 种主页风格**，随意组合
- 点选后点「保存设置」，客户刷新主页即可看到新样式
- 随时可切换，不影响档位、作品、须知等数据

## 十六、嵌入脚本（v0.9.0 新增）

如果你有自己的个人网站/博客，可以把约稿下单功能直接嵌进去：

1. 进入 **⚙ 主页设置 → 嵌入脚本** Tab
2. 点击「复制代码」，会得到一行类似这样的代码：
   ```html
   <script src="https://平台域名/embed.js" data-artist="你的子域名"></script>
   ```
3. 粘贴到你网站的 HTML 中（比如侧边栏或页面底部）
4. 保存发布，你的网站上就会出现一个约稿入口按钮

> 💡 嵌入样式独立于你的网站 CSS，不会互相干扰。客户点击后在弹窗内完成下单。

## 十七、粘贴上传（v0.11 新增）

所有上传图片的地方都支持 **Ctrl+V 粘贴**：
- 客户下单页的参考图上传
- 作品管理的作品上传
- 价格管理的档位例图上传
- 手动录单的参考图上传

截图后直接 Ctrl+V，不用先保存文件再选择。只接受图片内容，粘贴文字或其他内容会被拒绝。

## 十八、常见问题

**Q: 客户不愿意用网页怎么办？**
A: 完全没问题。让客户加你QQ聊，你自己在后台"手动录单"就行。网页只是展示和记录工具。

**Q: 我能关闭客户自助下单吗？**
A: 把主页状态改为"已排满"或"休息中"，客户就无法提交新订单了。

**Q: 参考图上传有什么限制？**
A: 每张最大 10MB，最多 5 张。仅支持 JPG/PNG/WebP 格式（后端有 MIME 白名单校验），其他格式会被拒绝。

**Q: 登录码收不到怎么办？**
A: 联系管理员检查QQ Bot是否正常运行。开发阶段登录码会直接显示在网页上。

**Q: 手机上能用吗？**
A: 能。所有页面都做了移动端适配，手机、平板、电脑都可以用。

**Q: 报价和最终价格有什么区别？**
A: 报价是客户下单时计算器算出来的参考价，最终价格是你实际收的钱。可以改。比如客户聊完说"加个背景"，你直接改最终价格就行，报价快照也可以一起改。

**Q: 焦点图是干什么的？**
A: 从参考图里选一张代表这个订单的角色。设了之后排期看板上直接显示小图，不用点进去就知道这单画的是谁。
