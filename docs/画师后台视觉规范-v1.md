## 一、设计定位

**"纸墨工作室"**——给画师（创作者）用的生产力工具。干净、有层次、克制但有温度。不是通用企业后台，不是花哨展示页。

气质关键词：纸感、墨色、朱砂点睛、文楷温度、工具效率。

## 三、字体

### 三轨分工

| 轨道 | 字体 | 用途 |
|------|------|------|
| 品牌/展示 | **LXGW WenKai（霞鹜文楷）** | 页面大标题、区块标题、品牌名、统计数字、档位名 |
| 正文 | Noto Sans SC / PingFang SC / 微软雅黑 | 所有正文、表单、表格内容 |
| 数据/编号 | JetBrains Mono（或系统等宽） | 订单号、金额、日期、进度数字（开启 tnum） |

### 字号层级

| 级别 | 大小 | 字重 | 字体 | 用途 |
|------|------|------|------|------|
| 页面标题 | 26px | bold | 文楷 | 每个页面顶部 |
| 区块标题 | 17px | bold | 文楷 | 卡片/区域标题 |
| 统计数字 | 28px | bold | 文楷 + tnum | 仪表盘统计卡 |
| 正文 | 13.5-14px | regular | 正文体 | 主要内容 |
| 辅助 | 12-12.5px | regular | 正文体 | 描述、时间 |
| 标签/表头 | 11px | medium | 正文体 | 表头、分组标签（+ letter-spacing 0.04em） |
| 极小 | 10px | medium | 正文体 | 角标、版本号 |

> 底线：正文不小于 13px，中文可读性优先。

## 五、侧边栏

| 属性 | 规格 |
|------|------|
| 宽度 | 240px（桌面），移动端抽屉 |
| 背景 | **白色** + 右边框 `#e6e3db` |
| 品牌区 | 36px 朱砂底方块（圆角 8px）内楷体"绘"字 + 楷体"绘约" + 英文副标（10px，letter-spacing 0.14em） |
| 导航分组 | 三组（工作台 / 经营 / 门面），组标签 11px 大写 tracking |
| 导航项 | 13.5px，图标 18px，padding 8px 12px，圆角 8px |
| 激活态 | 朱砂软底 `#f7e8e3` + 朱砂文字 + 左侧 3px×16px 朱砂竖条 |
| hover | 下沉面底色 `#efede8` |
| 角标 | 留言管理：朱砂底白字数字胶囊 |
| 底部 | 画师信息卡（头像 + 名称 + 编码） |

> 6 个参考中深色侧栏（项目 0/2/5）和白色侧栏（项目 1/3/6）各半。选白色：与纸色背景更协调，不割裂，更适合长时间使用。

## 六、卡片

| 属性 | 规格 |
|------|------|
| 背景 | 白色 `#ffffff` |
| 边框 | 1px `#e6e3db` |
| 圆角 | 12px |
| 阴影 | 默认极轻（见上），hover 加深 |
| 头部 | padding 16px 20px + 底部 1px 分隔线，标题 15px semibold |
| 可点击卡片 | hover 时边框加深 + 阴影升级 + 右箭头显现（opacity 过渡） |

### 统计卡片（仪表盘）

- 4 个独立卡片（grid-cols-2 → xl:4）
- 结构：标签（12px 灰字）+ 大数字（28px 楷体 bold，语义色着色）+ 底部 2px 色条
- 逾期卡：有逾期时边框变红 + 图标 pulse
- hover：浮现跳转箭头

## 八、空状态

统一组件：
- 虚线边框 `#d6d2c8`，圆角 12px
- 下沉面底色 `#efede8` / 50% 透明
- 40px 圆形图标座（内阴影）
- 楷体 15px 标题 + 12px 描述
- 可选操作按钮

用于：待办为空、订单筛选无结果、留言为空、作品为空。

## 十一、动效（克制）

| 场景 | 规格 |
|------|------|
| 卡片 hover | 阴影 + 边框 0.2s ease |
| 页面切换 | 淡入 0.15s |
| 列表入场 | stagger 延迟（每项 +0.04s），translateY 8px → 0 |
| 导航切换 | 背景色 0.15s |
| 弹窗/抽屉 | slide + fade 0.2s |

> 不引入 framer-motion（项目已有 vuedraggable 一个动效库够了）。CSS transition + Vue `<Transition>` 即可。

## 十二、参考项目评价（决策依据）

| # | 风格 | 取什么 | 不取什么 |
|---|------|--------|----------|
| 0 | 文房衬线 | 阴影克制、纸面层次 | 蓝灰主色（与语义色冲突）、无组件库 |
| 1 | 朱砂规范 | **token 体系、组件库、导航分组、排期泳道算法** | 无动效 |
| 2 | 深色靛蓝 | CSS 变量纪律 | 靛蓝主色（AI 味）、无 Header |
| 3 | 炭黑工作室 | **三字体分工、设计规范页、行内操作** | 字号偏小、token 形同虚设 |
| 5 | 手作工作室 | 排期三视图深度、陶土暖色 | 字号 8px（不可用）、单文件无抽象 |
| 6 | 纸墨朱砂 | **组件库完整度、EmptyState、tnum 数字** | 白色侧栏存在感弱、状态色偏饱和 |

**融合公式**：项目 1 的 token/组件/信息架构骨架 + 项目 6 的组件库完整度 + 项目 3 的三字体分工 + 项目 0 的纸面层次氛围。
