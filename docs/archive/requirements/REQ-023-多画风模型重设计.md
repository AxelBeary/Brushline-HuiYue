|---|--------|------|
| 1 | 一级维度 | **画风→尺寸**。用户原话："奶茶店应该先选喝哪款，再选大小杯" |
| 2 | 增项挂载 | **画风级增项 + 尺寸覆盖 + 全局增项模板**。通用费（加急/商用/买断）保持全局不变 |
| 3 | 客户端展示 | **三步走**：选画风（卡片+示例图）→ 选尺寸（列表+价格）→ 勾增项（只显示该画风×该尺寸下可用的） |

| 5 | 数据迁移 | **不猜**。所有老档位直接变成"单画风退化"状态，画师后续自行升级为多画风 |

- 额外确认：
  - 增项控件升级：开关/数量/单选三种，不用复选框
  - 增项价格支持尺寸覆盖（默认画风级，可在尺寸级覆盖）
  - 全局增项模板库：新建画风时一键导入，只改价格
  - 尺寸隐藏规则：增项可标记"在某尺寸下隐藏"（v1 只做这一条，不做完整互斥引擎）
  - 通用倍率排除：数据结构预留 `exclude_from_multiplier` 字段，v1 UI 不暴露
  - 画风加"描述/备注"字段（用户确认"加"）

## 数据模型

### 增项库（全局，平台级或画师级）

```
addon_template {
  id
  artist_id          -- 画师级（每个画师自己的增项库）
  name               -- "加人""加差分""加衣服"
  control_type       -- switch | quantity | radio
  pricing_mode       -- fixed | per_unit | per_option
  default_price      -- 建议默认价（导入画风时可改）
  options            -- radio 类型的选项列表 [{label, price}]
  unit_label         -- quantity 类型的单位（"人""张"）
}
```

### 画风（画师配置）

```
art_style {
  id
  artist_id
  name               -- "日系""厚涂""Q版"
  description        -- 画风描述/备注（客户端展示）
  cover_image        -- 示例图（客户端画风卡片）
  sort_order         -- 排序
  is_active          -- 开关
}
```

### 尺寸（挂在画风下）

```
style_size {
  id
  art_style_id
  name               -- "头像""半身""全身""插画"
  base_price         -- 基础价
  sort_order
}
```

### 画风增项（从增项库导入，可改价/禁用）

```
style_addon {
  id
  art_style_id
  addon_template_id
  is_enabled         -- 本画风是否启用
  price_override     -- 画风级价格（覆盖模板默认价）
  -- radio 类型时：options_override [{label, price}]
}
```

### 尺寸覆盖（可选，不填沿用画风默认）

```
size_addon_override {
  id
  style_size_id
  style_addon_id
  price_override     -- 尺寸级价格（覆盖画风级）
  is_hidden          -- 本尺寸下是否隐藏该增项
}
```

### 通用费（保持现有结构不变）

```
multiplier {
  id
  artist_id
  name               -- "加急""商用""买断"
  factor             -- 1.5 / 2.0 / 3.0
  exclude_from_multiplier  -- 预留字段，v1 默认 false，UI 不暴露
}
```

### 价格计算公式

```
默认（v1）：
总价 = (尺寸基础价 + Σ增项总价) × Π通用倍率

预留（v2 暴露 exclude_from_multiplier 后）：
总价 = (尺寸基础价 × Π倍率) + Σ(被排除增项原价) + Σ(其他增项 × Π倍率)
```

## 画师端配置交互

### 价格管理页结构

```
┌─ 通用费（和现在一样，不动）─────────────────┐
│  加急 ×1.5    商用 ×2    买断 ×3           │
└────────────────────────────────────────────┘

┌─ 增项库 ───────────────────────────────────┐
│  名称      控件    计价      建议默认价     │
│  加人      数量    单价×N    ¥100/人       │
│  加差分    数量    单价×N    ¥50/张        │
│  加衣服    单选    选项价    简¥80/复¥200  │
│  加背景    开关    固定      ¥150          │
│  [+ 新建增项]                              │
└────────────────────────────────────────────┘

┌─ 画风：日系 ───────────────────────────────┐
│  描述：适合清新/半写实风格                   │
│  示例图：[上传]                            │
│                                            │
│  尺寸        基础价                        │
│  头像        ¥200                          │
│  半身        ¥400                          │
│  全身        ¥600                          │
│                                            │
│  增项（从增项库导入）                       │
│  ☑ 加人      +¥100/人  [尺寸覆盖 ▾]       │
│  ☑ 加差分    +¥50/张                       │
│  ☑ 加衣服    简+¥80 复+¥200               │
│  ☑ 加背景    +¥150     [插画下隐藏 ✓]     │
│  ☐ 加Q版装饰（本画风禁用）                  │
│                                            │
│  [尺寸覆盖展开后]                           │
│  加人：头像 +¥50 / 全身 +¥200（其他沿用）   │
└────────────────────────────────────────────┘

┌─ 画风：厚涂 ───────────────────────────────┐
│  ...（同结构，从增项库导入后微调价格）       │
└────────────────────────────────────────────┘

[+ 新建画风（从增项库一键导入）]
```

### 关键交互

- 新建画风 → 弹窗"从增项库导入"→ 一键带入所有增项及默认价 → 画师微调
- 增项库新增一条 → 各画风按需启用（不自动强插）
- 尺寸覆盖：增项行末尾小箭头展开，不点开不显示，不增加日常视觉负担
- 尺寸隐藏：增项行勾选"在 XX 尺寸下隐藏"

## 客户端展示（三步走）

### 步骤 1：选画风

- 卡片形式，每张卡片：示例图 + 画风名称 + 描述
- 单画风画师：跳过此步（退化为扁平模型，直接进尺寸选择）

### 步骤 2：选尺寸

- 列表/卡片，显示尺寸名 + 基础价
- 各画风的尺寸列表可以不同（Q版没有"插画"）

### 步骤 3：勾增项

- 只显示该画风下启用的增项
- 排除该尺寸下隐藏的增项（如"插画"下不显示"加背景"）
- 价格显示该尺寸的实际价格（有覆盖显示覆盖价，无覆盖显示画风默认价）
- 控件渲染：开关→toggle，数量→步进器，单选→radio group

### 步骤 4：通用倍率

- 加急/商用/买断等通用倍率选择（和现在一致）
- 总价实时计算：(尺寸基础价 + 增项总价) × 倍率乘积

## 数据迁移

- **不猜**。所有现有扁平档位直接变成"单画风退化"状态
- 具体：为每个画师创建一个默认画风（名称可用画师名或"默认"），现有档位全部挂在这个画风下作为尺寸
- 画师后续自行升级为多画风（新建画风 → 从增项库导入 → 调整）
- 迁移后客户端体验不变（单画风退化 = 和现在看起来一样）

## 验收标准

1. 当画师配置了多个画风时，客户端约稿表单应该先显示画风选择卡片（示例图+名称+描述），选完后才显示尺寸列表
2. 当画师只有一个画风时，客户端应该跳过画风选择步骤，直接显示尺寸列表（退化为扁平模型）
3. 当画师在增项库新增"加宠物"后，各画风应该可以按需启用该增项，不需要重新创建
4. 当画师新建画风并选择"从增项库导入"时，应该一键带入所有增项及默认价格
5. 当画师对"加人"增项在"全身"尺寸下覆盖价格为 +¥200 时，客户选择该画风+全身+加人时应该显示 +¥200（而非画风默认的 +¥100）
6. 当画师将"加背景"标记为"插画尺寸下隐藏"时，客户选择插画尺寸后不应该看到"加背景"选项
7. 当增项为数量型（如"加人"）时，客户端应该显示步进器（1/2/3），总价按单价×数量计算
8. 当增项为单选型（如"加衣服"）时，客户端应该显示 radio 选项（简易+¥80 / 复杂+¥200）
9. 当客户选择加急 ×1.5 时，总价应该 = (尺寸基础价 + 增项总价) × 1.5
10. 当现有画师数据迁移完成后，客户端展示应该和迁移前完全一致（单画风退化 = 无感知）
11. 当画师在画风卡片填写描述"适合清新/半写实风格"时，客户端画风卡片应该显示该描述文字
