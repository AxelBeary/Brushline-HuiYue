> **编号**：plan-node-speech
> **作者**：四号（需求整理）

> **状态**：已实施（v0.18 第一批合入，迁移 v20）
> **关联**：流程状态机（SPEC-002）/ 订单详情页
> **用户交流记录**：2026-07-31，四号与用户三轮交流

---

## 1. 问题定义

画师推进订单到某个节点后，需要去 QQ 跟客户说一句话。社恐画师不想每次自己组织语言，希望系统直接给一段现成的话，复制粘贴发过去就行。

用户原声：
> "画师能直接复制各个节点要和客户交流的内容"

---

## 2. 核心设计

### 2.1 话术挂在节点上

在现有流程节点编辑里加一个"话术"输入框。每个节点自带一段话术。不新建页面。

**默认话术**（系统预置，画师可改）：

```
{客户名}，你的订单已{节点名}。
```

画师在节点编辑页面可以修改这段话术，改成任何内容。

### 2.2 变量

编辑框旁边放一排变量标签，点一下插入光标位置，不用画师手打花括号。

| 变量 | 示例 | 说明 |
|------|------|------|
| {客户名} | 张三 | orders.client_name |
| {客户QQ} | 123456789 | orders.client_qq |
| {订单号} | A-003 | orders.order_no |
| {档位名} | 半身像 | price_tiers.name |
| {节点名} | 线稿确认 | 当前节点名称 |
| {截稿日} | 8月5日 | orders.deadline |
| {总价} | ¥500 | final_price_cents / 100 |
| {已付} | ¥150 | 已 paid 的分期合计 |
| {待付} | ¥350 | 总价 - 已付 |

**无对应数据时**：变量替换为空字符串（如订单没设截稿日，{截稿日} 替换为空）。

### 2.3 订单详情页小块

订单详情页底部新增一个"客户沟通"小块：

```
┌─────────────────────────────────┐
│ 💬 客户沟通                     │
│                                 │
│ QQ: 123456789                   │
│ 总价¥500 / 已付¥150 / 待付¥350 │
│                                 │
│ "张三，你的订单已线稿确认。"    │
│                                 │
│ [ 复制文案并唤起QQ ]            │
└─────────────────────────────────┘
```

**价格小结**：独立一行展示（总价/已付/待付），不是话术变量，仅供参考。画师不需要复制价格信息，看就行。

**话术内容**：显示当前节点的话术（订单推到哪个节点就显示哪个节点的话术），变量已替换为实际值。

### 2.4 按钮行为

点击"复制文案并唤起QQ"：
1. 立即复制话术文本到剪贴板
2. 显示提示："已复制节点文案，正在唤起QQ"
3. 等待 1 秒
4. 跳转 `tencent://message/?uin={客户QQ}` 协议

**降级**（tencent:// 被浏览器拦截时）：浏览器会弹确认框"是否打开腾讯QQ？"，这是浏览器行为，不做额外处理。用户已验证可成功唤起。

### 2.5 节点编辑页面

在现有节点编辑（artist_workflow_stages 的编辑 UI）中新增：
- "话术"输入框（textarea，2~3 行高）
- 输入框上方一排变量标签（点击插入）
- placeholder 显示默认话术

---

## 3. 验收标准

- 当画师编辑流程节点时，应该看到"话术"输入框和一排可点击的变量标签
- 当画师点击变量标签"{客户名}"时，应该在光标位置插入"{客户名}"
- 当画师未修改话术时，默认话术应该为"{客户名}，你的订单已{节点名}。"
- 当订单处于"线稿确认"节点且客户名为张三时，订单详情页小块应该显示"张三，你的订单已线稿确认。"
- 当画师点击"复制文案并唤起QQ"时，应该先复制文案、显示提示、1 秒后唤起 QQ
- 当订单无截稿日时，话术中的{截稿日}应该替换为空（不显示"undefined"或花括号）
- 当画师修改了某节点话术后，该节点对应的订单详情页应该显示修改后的内容

## 4. 数据模型

### artist_workflow_stages 表新增字段

```sql
ALTER TABLE artist_workflow_stages ADD COLUMN speech_template TEXT DEFAULT '{客户名}，你的订单已{节点名}。';
```

存量节点回填默认话术。

## 5. 不在本规格范围

| 功能 | 原因 |
|------|------|
| 额外话术（订单级附加文字） | 用户明确"拼接不考虑，让他们自己写全，真收到反馈再考虑" |
| 话术模板库（独立页面） | 用户选 A（挂在节点编辑里），不做独立页面 |
| 自动发送消息 | 仅复制，不自动发送 |
| 小功能集合标签 | 用户占位备案（"未来做个小功能集合的标签吧"），待后续讨论 |
