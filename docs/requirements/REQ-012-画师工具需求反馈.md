# 画师反馈：工具需求（2026-08-01）

> **编号**：REQ-012
> **作者**：四号（需求整理）
> **日期**：2026-08-01
> **状态**：已澄清，部分待用户拍板
> **来源**：外部画师反馈（经奚怡熊转达 + 四号拟问题澄清）

---

## 0. 画师背景

- 月接单量：6-7 单，同时在进行 1-2 单
- 现有管理方式：全凭脑子记，经常错漏
- 排期方式：画两个接两个，无工具
- 文件管理：所有文件堆在一个文件夹，按时间排序，找老稿子要滚很久
- 主要创作工具：Clip Studio Paint（CSP）

---

## 1. 逐条澄清结果

### F1 单独部署

**画师原声**：能不能单独部署给我一个人用？

**结论**：✅ 技术可行。Docker 一键起，单画师使用无障碍。非技术障碍，是"值不值得"的运营问题。

### F2 画稿管理 / 本地文件整理

**画师原声**：
> "能让我轻松打开我本地的这个项目的 CSP 文件"
> "最好能帮我整理我电脑上的文件，我现在是乱七八糟都在一个文件夹，然后按照时间排序...要找老稿子得滚好久"

**澄清**：不是"展示作品"，是**本地文件管理**——快速打开 CSP 工程、按项目/角色归档文件。

**结论**：❌ Web 应用无法访问用户本地文件系统。要做需要桌面客户端（Electron/Tauri）或本地代理程序。**产品方向问题，不是功能问题。**

**待用户拍板**：是否考虑桌面端方向？还是坚守 Web？

### F3 时间统计

**画师原声**：需要时间统计功能。

**奚怡熊决策**（2026-08-01）：推荐画师使用专门的开源项目，**我们不做**，未来可借鉴。

**结论**：🚫 不做，备案。

### F4 记账（个人收支）

**画师原声**：需要记账功能（选 B：个人收支，包括买素材、买笔等开销）。

**奚怡熊备注**（2026-08-01 原声）：
> "就不能你自己去管理收支吗！微信支付宝又不是没有..."

**结论**：⚠️ 待用户正式拍板。奚怡熊倾向不做（微信/支付宝已有），但未明确说"不做"。

### F5 排期日历视图

**画师原声**：
> "难道我可以两个都要吗！"（看板 + 日历）

**现状**：看板（QueueBoard）已有。日历视图没有。

**结论**：🔵 **日历视图是唯一真正的新平台需求**。画师想一眼看到"这个月哪天空哪天满"，看板做不到这个。

### F6 防错漏

**画师原声**：用脑子记，经常错漏。

**结论**：✅ 平台已解决（订单跟踪 + 工作流节点 + 收款记录）。画师需要的是"用起来"，不是新功能。

## 4. 验收标准（仅 F5 日历视图，如拍板做）

1. 当画师进入排期页面时，应该能在看板和日历视图之间切换
2. 当画师查看日历视图时，应该能看到每个订单的时间段（从确认到预计交付）
3. 当某天空闲（无订单覆盖）时，日历应该明显标识"可接单"
4. 当某天已满（有订单覆盖）时，日历应该显示对应订单名
5. 当画师点击日历中的订单时，应该能跳转到订单详情

> 注：F5 验收标准为四号建议，待用户确认方向后细化。
