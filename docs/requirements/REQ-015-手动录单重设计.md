# REQ-015：手动录单重设计（全屏双栏 + 响应式）

> 状态：用户已拍板（2026-08-02）
> 来源：画师反馈 ×2（"只是一个侧边栏，能不能更直观" + "手机/窄窗口下半残废"）
> 目标版本：v0.27（v0.26 之后，不插队）

## 背景

当前手动录单是 OrderList 里的 560px 右侧抽屉（el-drawer），ManualOrder.vue 524 行零 @media 规则。画师每天高频使用，体验差。

## 用户拍板

1. ✅ 方案 A：全屏双栏录单页（替换抽屉）
2. ✅ 附加：该 QQ 历史订单小面板（+1h）

## 设计规格

### 布局（≥1024px 双栏）

**左栏「客户说了什么」**：
- 客户 QQ（输入后自动查历史订单，见下）
- 客户昵称
- 需求描述（textarea）
- **参考图上传（大块粘贴区，提到左栏最显眼位置）**——画师实际流程：QQ 收图 → 粘贴 → 再填其他
- 优先级
- 截稿日
- QQ 通知开关
- **该 QQ 历史订单面板**（输入 QQ 后自动查询显示，~1h，后端已有按 QQ 查订单能力）

**右栏「怎么录」**：
- 档位选择（**卡片式**：缩略图+名称+价格，替代下拉框）
- 增项（分组折叠，同现有）
- 倍率（用法/加急）
- **价格面板 sticky**（明细+总价，调任何选项实时可见）
- 最终价格（可手动覆盖）
- 提交按钮

### 响应式断点

| 断点 | 布局 |
|------|------|
| ≥1024px | 双栏，右栏价格面板 sticky |
| 600–1024px | 单栏，价格面板仍 sticky |
| <600px | 单栏 + **底部钉住价格条**（总价+提交按钮，点价格展开明细）——淘宝结算页模式 |

### 路由

- `/orders?action=manual` 重定向改为跳转新独立页面（如 `/manual-order` 恢复为独立路由，或 `/orders/new`）
- 旧 `/manual-order` 重定向链更新
- 侧边栏菜单入口保留，指向新页面

### 连续录单

保留"继续录入"（提交成功后重置表单，留在当前页面）+ "查看排期"按钮。

## 约束

- **API 零改动**（组件已有，纯前端重排布局）
- 历史订单查询复用已有后端能力（按 QQ 查订单）
- ManualOrder.vue 组件逻辑保留，重排布局容器
- 四模板不涉及（画师后台页面，非客户端）

## 工程量

~7-9h（双栏布局 4-6h + 响应式断点/底部价格条 2h + QQ 历史面板 1h）

## 验收标准

1. 桌面端（≥1024px）双栏布局，左客户信息/右定价，价格面板 sticky
2. 档位为卡片式选择（非下拉框）
3. 参考图粘贴区在左栏顶部显眼位置
4. 输入 QQ 后显示该客户历史订单
5. 600–1024px 单栏，价格面板仍 sticky
6. <600px 底部钉住价格条（总价+提交），点价格展开明细
7. 连续录单可用（提交后重置表单留在页面）
8. 旧路由重定向不断链
