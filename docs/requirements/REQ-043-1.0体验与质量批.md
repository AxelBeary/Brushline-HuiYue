## I1 分享预览卡片（OG tags）— 用户细化规格

**触发**：仅命中 `/artist/:subdomain` 的 **HTML 请求**时注入 og meta（非 API）

**meta 规格**（用户给定）：

| 键 | 值 |
|----|-----|
| og:type | website |
| og:site_name | 拾绘（品牌名，2026-08-11 拍板；英文 Brushline） |
| og:title | 画师名｜平台名 |
| og:description | 画师简介截断；画师有接单状态可放描述里（标题不复杂） |
| og:url | `https://<DOMAIN>/artist/<subdomain>`（HTTPS 绝对地址） |
| og:image | 画师头像；**无头像=平台默认占位图（logo 兜底）**；HTTPS 绝对地址 |
| og:image:alt | 画师名头像 |

**决策**：
- 预览图**默认用头像**；作品图后置——有数据证明作品图转化更高再做 A/B 或生成封面
- 未找到画师：**不报错**，返回默认 OG 或保持当前页面默认 meta
- 缓存：subdomain OG 数据缓存 **≥5 分钟**
- 实现：模板预留占位符，**不粗暴替换整个 HTML**
- **安全：OG 值必须消毒，防 XSS/HTML 注入**
- 数据结构：`{ title, description, image, url }`

**开发量**：1~1.5 天

## I2 开张任务卡（新手引导，升级版）

用户升级：**不要只做静态引导条**。

| 设计点 | 方案 |
|--------|------|
| 形式 | Dashboard 任务卡片/进度条（三步开张：传作品 / 设档位 / 分享主页） |
| 动态任务 | 按账号状态生成：没传作品→提示传作品；没设档位→提示设档位；已完成打勾（非固定文案） |
| 完全隐藏 | **必须有**（用户：「有些画师比较容易受到刺激」）——「关闭/不再提示」后彻底不显示 |
| 判断首次 | **后端标记**：`artists.onboarded_at` / `onboarding_dismissed_at`；前端不靠 localStorage |
| 关闭动作 | 点击关闭 → 调后端接口写入标记 |
| 埋点 | 引导展示/任务点击/关闭埋点（复用 REQ-033 体系） |

**开发量**：1~2 天

## I4 平台公告 — 最小打扰版（用户拍板「打扰越少越好」）

| 设计点 | 方案 |
|--------|------|
| 打扰度 | **零主动打扰**：不弹窗、不 banner、不自动展开 |
| 形态 | 画师面板「公告」入口（侧栏/顶部小图标），有未读时小圆点标记 |
| 内容 | 单条最新公告（platform_config：标题+内容+时间） |
| 已读 | 点开即已读（本地会话记已读时间戳/后端标记可选）；新公告重新标点 |
| 管理端 | 管理后台公告编辑（管理员） |

**开发量**：1 天

## 安全纪律（全局，用户强调：「必须做好安全防护 前端数据后端必须核验 防止攻击」）

1. **前端数据后端必须核验**：所有输入走后端 schema 校验（已有机制）+ 白名单 + 消毒；新功能（OG 注入/任务卡/公告/角标）同标准
2. OG 注入消毒（I1）；公告内容消毒（I4）；任务卡接口校验（I2）
3. 上线前安全自查（一号审核清单强化执行）：注入/XSS/权限绕过/敏感信息
4. 公开接口限流（复用 rate-limit）
