## #8 快速话术界面 + 多模板随机

### 画师原声
> 快速话术功能很好，但界面丑 + 各块大量重复显示"{客户名}{客户QQ}...{已付}{待付}"；希望一个节点有多个模板可以随机选

### 代码现状（已验证）
- **数据模型**：`artist_workflow_stages.speech_template TEXT`，每个节点仅 1 条话术（`db/init.js:171`）
- **管理 UI**：`StageListView.vue:57-83`，每个节点行下方平铺灰底话术编辑区
  - 每块含：`💬 话术` 标签 + **9 个变量小按钮**（11px）+ textarea + "保存话术"按钮
  - N 个节点 = N 排 × 9 个相同变量按钮 + N 个 textarea → **整屏重复**
- **变量替换**：`order-workflow.service.ts:185-211` `replaceSpeechVars()`，9 变量 replaceAll
- **无多模板支持**：单个 TEXT 字段，结构上不可能多模板

### 根因
| 反馈 | 根因 |
|------|------|
| 大量重复显示变量 | 变量标签行在 `v-for` 内每节点渲染一次（`StageListView.vue:61-67`） |
| 界面丑 | 话术区是节点行的附属灰块（缩进 32px、11px 按钮、无折叠、无视觉层级） |
| 多模板随机 | 数据模型是单个 TEXT 字段，不支持 |

### 验收标准
**界面改进（P2）：**
1. 当画师打开话术编辑区时，变量按钮应只显示一次（顶部公共区域），而非每个节点重复
2. 当节点数 ≥ 3 时，话术编辑区应支持折叠/展开（默认折叠，只显示节点名 + 话术前 20 字预览）
3. 话术编辑区应有清晰的视觉层级（与节点行区分，不再是附属灰块）

**多模板随机（P3）：**
4. 当画师为某节点添加多条话术模板时，系统应保存全部模板
5. 当订单推进到该节点时，系统应从多条模板中随机选取一条展示
6. 画师应能预览每条模板的变量替换效果

### 优先级：界面改进 P2，多模板随机 P3
界面改进改动小（前端重构话术区布局）。多模板随机需 DB 迁移 + 后端逻辑 + 前端管理 UI，工程量较大。

### 预估工程量：界面改进 ~2h，多模板随机 ~5h（DB + 后端 + 前端）

## #10 档位三态

### 画师原声
> 档位希望能设置：开、只展示、不展示（三态）

### 代码现状（已验证）
- **DB 无可见性字段**：`price_tiers` 表（`db/init.js:49-59`）仅有 id/artist_id/name/price/description/example_image/work_days/sort_order
- **后端无过滤**：`artist.service.ts:261` → `SELECT * FROM price_tiers`，公开 API 返回全部
- **客户端全量渲染**：4 模板全部 `<TplTierGrid :tiers="tiers">`，无过滤
- **管理端无可见性设置**：`TierManage.vue` 编辑弹窗只有名称/价格/工期/说明/示例图
- **当前只有两态**：存在（显示）/ 删除（不显示）。画师想临时下架某档位只能删除，数据不可恢复

### 三态定义（按画师原声）
| 状态 | 含义 | 客户端表现 | 画师端表现 |
|------|------|-----------|-----------|
| **开**（visible） | 正常接单 | 显示档位 + 可选 | 正常编辑 |
| **只展示**（showcase） | 展示但不接单 | 显示档位 + 灰色/标注"暂不接单" | 正常编辑 + 状态标记 |
| **不展示**（hidden） | 完全隐藏 | 不显示 | 列表中灰色显示 + 可恢复 |

### 验收标准
1. 当画师在档位管理页将某档位设为"只展示"时，客户主页应显示该档位但不可选择（灰色 + "暂不接单"标注）
2. 当画师将某档位设为"不展示"时，客户主页应完全不显示该档位
3. 当画师将"不展示"的档位改回"开"时，客户主页应立即恢复显示
4. 档位管理页应有三态切换控件（如下拉或分段按钮），默认新建档位为"开"
5. "不展示"的档位数据应完整保留（价格/工期/说明/示例图），恢复后无需重新填写

### 优先级：P1
画师明确需求，解决"临时下架只能删除"的痛点。改动链路清晰（DB 字段 → 后端过滤 → 前端管理 + 客户端渲染）。

### 预估工程量：~3h（DB 迁移 + 后端 + 前端管理页 + 4 模板客户端渲染）
