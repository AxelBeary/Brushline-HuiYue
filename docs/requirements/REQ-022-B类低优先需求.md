## F1：作品绑定档位 + 完稿转作品链路（#32 + #33）

**产品链路（用户拍板方向）**：

> 完稿交付 → 加水印 → 一键发布为作品 → 绑定档位 → 客户端按档位展示 → 客户点开看价格 → 直接下单

**功能描述**：

### 完稿转作品（#33）
- 订单完稿后，订单详情页加"发布为作品"按钮
- 点击后：选择完稿图片 → 自动加水印（水印设置从偏好读取）→ 填写作品标题/描述 → 发布
- 发布后作品出现在作品管理页，可进一步绑定档位

### 作品绑定档位（#32）
- 作品管理页：每个作品可绑定到一个或多个档位（按尺寸分组）
- 客户端：作品按档位分组展示（"半身像""全身像""Q 版"等）
- 客户点开作品 → 看到对应档位价格 → 直接下单

### 水印联动
- 水印设置从画师偏好读取（文字水印/图片水印 + 位置 + 透明度）
- 完稿转作品时自动加水印
- 也可在作品管理页手动对已有作品加水印/换水印

**验收标准**：
1. 当画师在完稿订单详情页点击"发布为作品"时，应该进入发布流程（选图 → 加水印 → 填信息 → 发布）
2. 当画师将作品绑定到"全身像"档位时，客户端应该在该档位分组下展示该作品
3. 当客户在客户端点击某作品时，应该看到对应档位的价格和"立即约稿"入口
4. 当画师开启水印时，完稿转作品应该自动加水印

**预估工时**：5 天（完稿转作品 2 天 + 绑定档位 2 天 + 水印联动 1 天）

## F2：外链打磨（#41）

**现状**：外链功能需打磨，当前是自由填 URL。

**功能描述**：
- 改为固定前缀模式：选平台（微博/B站/小红书/推特/其他）→ 填用户名
- 自动生成完整链接 + 平台图标
- "其他"平台保留自由填 URL
- 客户端展示：平台图标 + 用户名，点击跳转

**验收标准**：
1. 当画师添加外链选择"微博"并填用户名时，应该自动生成 `weibo.com/用户名` 链接
2. 当客户在画师主页看到外链时，应该显示平台图标 + 用户名

**预估工时**：1 天

## F3：约稿表单回显（#58）

**现状**：约稿表单右边摘要不回显客户填写的内容。

**功能描述**：
- 约稿表单右侧摘要区实时回显：昵称、需求描述、已选档位、已选增项、总价
- 客户每填一步，摘要区同步更新
- 摘要区只读，不可编辑

**验收标准**：
1. 当客户在约稿表单填写昵称后，右侧摘要应该立即显示该昵称
2. 当客户选择档位和增项后，右侧摘要应该显示已选项和总价

**预估工时**：1 天

---

## F4：回收站分页（#64）

**现状**：管理端回收站东西多时无分页/折叠，好长好长。

**功能描述**：
- 回收站列表加分页（每页 20 条）
- 或折叠分组（按类型：订单/作品/留言）
- 建议分页（简单直接）

**验收标准**：
1. 当回收站超过 20 条时，应该分页显示，不应该一次性全部加载

**预估工时**：0.5 天

---

## F5：留言分组/筛选（#67）

**现状**：管理端留言管理，画师多/留言多时混成一长串。

**功能描述**：
- 按画师分组（下拉选画师 / 侧边栏画师列表）
- 按状态筛选（未读/已读/已回复）
- 按时间排序（最新优先）

**验收标准**：
1. 当管理员选择某画师筛选时，应该只显示该画师的留言
2. 当管理员选择"未读"筛选时，应该只显示未读留言

**预估工时**：1 天
