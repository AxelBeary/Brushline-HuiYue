## 一、背景与现状核实

**位置**：`web/src/components/artist/ArtStyleManager.vue` L102-174（画风卡片内「增项区」），`TierManage.vue` L27-30（增项库 tab）。

**现状（代码实测）**：
- 增项区 = 每个画风卡片内一行式列表：`[✓ 增项名] [类型tag] [¥价格输入] [展开尺寸覆盖按钮]`，尺寸覆盖面板垂直展开挤占卡片空间
- 画师要加增项：先去「增项库」tab 新建模板 → 切回「画风与价格」tab → 点「从增项库导入」——**两个 tab 来回，画师反馈反直觉**
- 数据结构（已核实）：`addon_templates`（模板：name/control_type/pricing_mode/default_price，画师级）→ `style_addons`（画风实例：is_enabled/price_override，`ON DELETE CASCADE` 外键到模板）→ `size_addon_overrides`（尺寸级：price_override/is_hidden，`UNIQUE(style_size_id, style_addon_id)`）
- 计价引擎（已核实 `style-pricing.service.ts` L178-224）：`小计 = 基础价 + 增项总和`；`倍率后 = 小计 × 用途倍率 × 加急倍率`；`最终 = 倍率后 − 折扣`——**与用户要求的 `（原价+增项）×用途×加急×折扣` 一致，公式本身不用改**

**两个必修 bug（代码证实）**：
1. **切 tab 数据不刷新**：`ArtStyleManager.vue` L844 `onMounted(load)` 只在挂载时拉数据，`TierManage.vue` 的 `el-tab-pane` lazy 切回不重新挂载 → 画师在增项库建完模板切回画风页看不到新增项，**必须手动刷新页面**（画师原话：「每次加完切过来还不能加 必须先刷新页面才行」）
2. **尺寸覆盖面板位置错乱**：L147 覆盖面板 `v-for` 是独立于增项行的第二个循环，排在列表容器外 → 展开第 3 个增项的覆盖面板出现在整个列表末尾（画师原话：「尺寸覆盖 不是显示在这个增项下面 而是在左右增项下面」）

## 二、核心方案（用户拍板）

### 2.1 双入口（替换「导入增项」按钮）

画风卡片增项区头部两个并列按钮：
- **[+ 新建增项]**：直接弹表单（名称、控件类型、默认价、数量上限）→ 保存后**自动挂到本画风并沉淀进增项库**
- **[+ 从已有挑选]**：现有导入弹窗，**标记「本画风已用」**避免重复添加

### 2.2 加购项池 + 拖拽（直觉动线核心）

- 画风-尺寸下方一个大池子（默认空，只有「新建」「从已有挑选」两个按钮）
- 从第一步新加或勾选已有增项后，**出现在池子里**（胶囊形态：名称+价格+类型徽标）
- **拖拽**：从池子拖到上方尺寸行 = 该尺寸启用（**仅决定启用，不动价格**）；拖回池子 = 该尺寸停用；拖到已启用 = 无操作
- **单点**：弹窗详细设置（见 2.4 三层弹窗）
- 拖拽与点击并存：点击是精确操作，拖拽是快捷操作

### 2.3 尺寸三态（用户拍板）

| 状态 | 顾客看到 | 行为 |
|------|---------|------|
| **可约** | 尺寸显示，可勾选 | 正常接单 |
| **展示** | 尺寸显示例图+价格+增项预览，**但不可「下一步」/「去约稿」** | 画师暂不接单但想展示（练习期/排单满） |
| **关闭** | 尺寸不显示 | 完全隐藏 |

- **三态用色区分**：可约=石绿、展示=藤黄、关闭=朱砂（沿用 7 色语义，色块+文字，不只靠颜色）
- **后端必须校验**（用户问「提交的时候要做好判断吗？防止技术手段恶意下单？」→ 拍板：必须）：算价 + 下单接口校验尺寸状态，展示/关闭 → 400 拒单。**前端置灰只是 UI，防不了 F12 直调接口**

### 2.4 胶囊设置弹窗（三层编辑）

点池内胶囊 → 弹窗从上到下三个层级（**用户问「编辑里面可以改增项激活 or 改增项价格和本身价格吗」→ 拍板：能，三层全管**）：

| 层级 | 存哪 | 管什么 | 影响范围 |
|------|------|--------|---------|
| **模板级** | `addon_templates` | 本身价格、名称、控件类型 | 所有引用画风（**改基础属性弹「应用到所有画风 / 仅当前画风」确认**） |
| **画风级** | `style_addons` | 本画风激活开关、本画风价格 | 仅当前画风 |
| **尺寸级** | `size_addon_overrides` | 每尺寸启用开关、每尺寸差异价 + 批量全部启用/关闭 | 仅该尺寸 |

- 价格优先级（与后端一致）：**本尺寸 > 画风价 > 本身价**
- 底部「移除（解绑本画风）」：**画风内移除 = 解绑，不动库**；增项库 tab 保留，可再挑选找回

### 2.5 删除策略（用户拍板 C'）

- **画风内移除 = 解绑**（见 2.4）
- **增项库删除模板**：若已被画风引用 → **不阻止、不级联删**，提示「有 N 个画风在用，删除后它们将保留为独立增项（不再跟随库更新）」——画风 B/C 里的增项原样保留（价格/隐藏/尺寸覆盖全不动），只是和库断开联系
- ⚠️ **技术影响**：现状 `style_addons.addon_template_id` 外键是 `ON DELETE CASCADE`（删模板=级联删画风引用，即用户列的方案 B 是现状默认行为）。C' 需**改外键行为**（迁移：解除引用后再删，或外键改 SET NULL + 保留独立实例）

### 2.6 预览弹窗（顾客视角，只读）

- 每个尺寸基础价后「预览」按钮 → 弹窗**顾客视角**：画风+尺寸+状态标签+价格构成明细+预估合计+计价公式
- **纯只读**，无顾客流程按钮（画师自己看的；「展示不可约」语义用状态徽章文字表达）
- 复用「展示」态顾客看到的视图（一举两得）
- 计价公式示例要正确：`（基础价 + 增项）× 用途倍率 × 加急倍率 − 折扣`

### 2.7 尺寸摘要行

- 每个尺寸行下方显示「已配增项」摘要，**实时更新**（拖入即出现）：`已配增项：背景 ¥50 · 加人 ¥80/位 · 商用 +50% · 加急 +100%`
- 三种计价形态视觉可区分：加法项（¥50）、数量项（¥80/位）、倍率项（+50%）
- 对应画师原话：「在全身这个尺寸上…简介·工期，背景 50，加人100/位，vup用+50%，买断+100%，加急+100%，特别加急+200%」

### 2.8 增项库 tab

- **保留不变**，仍在 tabs 最后一个项（用户拍板）
- 定位转变：从「画师日常必经入口」→「系统沉淀资产 + 管理员预设」；画师日常操作都在画风卡片内完成

## 四、倍率轻合并（独立批次，后端核心）

**用户问题**：「数量 开关 用途 加急 这些倍率也是增项的一种可以吗？这样倍率tab也可以和增项去合并？还是你有其他更好的逻辑」

**结论（用户拍板「倍率合并接受『轻合并』」）**：
- **产品层面合并**：画师在加购项池统一看到所有加购项（加法项 + 倍率项），倍率 tab 退居预置
- **技术层面轻合并（不物理合并表）**：`addon_templates` 加 `kind` 维度（`add` 加法 / `multiply` 倍率），乘法项计价走乘法；`price_multipliers` 表保留
- 理由：增项=画风级绑定+加法，倍率=画师级全局+乘法，数据模型不同，物理合并动 schema+迁移+全链路重写 = 屎山风险
- **用途单选 + 加急单选**（用户拍板；现有引擎注释「取最高，不叠加」一致）；加法增项（背景/加人/买断）可多选共存
- ⚠️ 修正记录：**「买断」= 开关型一次买断，自身不可重复**；「可多选」仅指 quantity 型增量（加人 ×N 位），其他类型是「一次/互斥」但可与其他增项并存

## 五、布局规划（原型已实现，纸墨双主题）

见原型 `docs/04-增项交互布局原型-20260808.html`。核心结构：

```
画风卡片
├─ 卡头：⠿ 名称 [默认] [启用开关] [编辑] [删除]
├─ 描述 + 封面
├─ ▼ 尺寸与价格                    [+ 添加尺寸]
│   [三态▾] ▣ 头像 ¥300   [预览] [编辑] [删除]
│     └ 已配增项：背景 ¥50 · 加人 ¥80/位 · 商用 +50% · 加急 +100%
│   [三态▾] ▣ 半身 ¥500   [预览] [编辑] [删除]
│     └ 已配增项：背景 ¥50 · 加人 ¥80/位
│   [展示▾] ▣ 全身 ¥800   [预览] [编辑] [删除]
│     └ 已配增项：背景 ¥50 · 加人 ¥80/位 · 商用 +50% · 机甲 ¥100
└─ ▼ 加购项池                  [+ 新建增项] [+ 从已有挑选]
    [背景 ¥50] [加人 ¥80/位] [机甲 ¥100] [商用 +50%] [加急 +100%]
    ⚡ 拖到上方尺寸 = 该尺寸启用；点击胶囊 = 详细设置
```

- 尺寸为主轴，增项是挂在主轴上的配置（解决「两个纵向列表」拥挤根源）
- 视觉规范：纸墨 token（`--card/--line/--ink/--paper2`）、文楷标题+思源正文、7 色语义只用于状态、动效克制（hover 不位移、摘要 fade 淡入、一次性弹窗动画）
- 原型已验证（浏览器实测 + 语法校验）：双主题切换、三态切换、拖拽启用、摘要实时更新、三层弹窗、移除解绑、删除尺寸确认、预览只读——全部通过

## 六、验收标准（可测试）

### 画师端交互
1. 当画师在画风卡片点「+ 新建增项」时，应弹出表单（名称/控件类型/默认价/数量上限），保存后该增项应出现在本画风加购项池，且「增项库」tab 中能看到该模板（自动沉淀）
2. 当画师新建增项名称与库中已有模板同名时，应弹提示「库中已有同名：直接挂载 or 另建独立」，两种选择都应生效
3. 当画师从加购项池拖拽胶囊到某尺寸行时，该尺寸摘要行应实时出现该增项（含价格），再次拖拽到已启用尺寸应提示「已启用」且不重复添加
4. 当画师点击池内胶囊时，应弹出三层设置弹窗（模板级本身价+应用范围切换 / 画风级激活开关+画风价 / 尺寸级表格+批量启用），底部有「移除（解绑本画风）」
5. 当画师在弹窗点「应用到所有画风」并保存基础属性修改时，所有引用该模板的画风应同步更新，且其他画风弹确认提示
6. 当画师点「移除（解绑本画风）」时，该增项应从本画风池子与所有尺寸摘要消失，但增项库保留（可在「从已有挑选」找回）
7. 尺寸行应显示三态（可约/展示/关闭）且可切换；关闭态整行弱化显示；三态颜色语义正确（石绿/藤黄/朱砂）
8. 每个尺寸行应有「预览」按钮，点击弹出顾客视角只读预览：尺寸名+状态标签+价格构成明细+预估合计+计价公式；**无任何顾客流程按钮**；展示态标签显示「展示中 · 顾客可见但不可约稿」
9. 尺寸摘要行应实时显示已启用增项：加法项（¥50）/数量项（¥80/位）/倍率项（+50%）三种形态视觉可区分，加乘公式 `（原价+增项）×用途×加急×折扣` 正确
10. 「增项库」tab 应保留在 tabs 最后一个，内置 5 个系统模板（加人物×80/每/背景50/每/机甲100开关/商用+50%/加急+100%），管理员可维护（见 §四批次）
11. 切 tab 修复：画师在增项库新建模板后切回「画风与价格」，无需手动刷新即可在「从已有挑选」中看到新模板
12. 尺寸覆盖面板位置修复：展开某增项的尺寸覆盖时，面板应紧贴该增项行下方，而非列表末尾

### 后端（独立批次）
13. 当尺寸状态为「展示」或「关闭」时，算价接口（POST calc-style）应返回 400 拒绝；下单接口同理（防 F12 直调）
14. 当删除增项模板且被画风引用时，应提示引用数量并执行「保留为独立增项 + 解除引用」，画风内增项数据（价格/隐藏/尺寸覆盖）应完整保留
15. `addon_templates` 增加 `kind` 维度（add/multiply）后，乘法项按倍率计价、加法项按现有逻辑计价，结果与 `（基础价+增项）×用途×加急×折扣` 一致
