## R14：价格计算器改为"详细计价"手动展开

### 用户原声

> "用户界面那里要用户手动去点一下详细计价再跳出来，现在这样一选就全吐出来给人太压迫了。"

### 现状（已核实）

客户下单页（OrderForm.vue）：选择档位后，**增项分组（可能很多项）+ 用途/加急倍率 + 价格明细 + 分期预览** 一次性全部展开。档位增项多的画师，这一块会突然撑开很大一片，给客户压迫感。

### 需求描述

改为**渐进展开**：
1. 选完档位后，先只显示一条**紧凑价格摘要**：档位名 + 基础价 + 一个"详细计价 ▸"入口
2. 客户点击"详细计价"后，才展开增项选择、倍率选择、实时明细、分期预览
3. 展开后，选择增项/倍率时总价实时更新
4. 切换档位时，重置展开状态和已选增项

设计原则：信息分层，先给结论（基础价），细节按需展开。不改变任何计价逻辑，只改呈现节奏。

### 验收标准

1. 当客户选择档位后，应该先看到紧凑价格摘要（档位名 + 基础价 + "详细计价"入口），增项/倍率/明细不应该一次性全部展开
2. 当客户点击"详细计价"时，增项选择、倍率选择、价格明细、分期预览应该展开
3. 当客户展开后选择增项/倍率时，总价应该实时更新
4. 当客户切换档位时，展开状态和已选增项/倍率应该重置
5. 当画师没有配置任何增项/倍率时，应该只显示基础价摘要，不显示"详细计价"入口（或显示但展开无内容，不报错）
6. 当客户在手机上操作时，展开内容应该正常显示，无横向滚动

## R15：外链功能扩展为自定义链接列表

### 用户原声

> "画师主页设置里-基本资料，那个外链功能。有的画师这两平台都没有，怎么办？计划一个更好的方案。"

### 现状（已核实）

主页设置 → 基本资料里只有两个写死的外链字段：**微博链接** 和 **B站链接**。不用这两个平台的画师（比如只用 Pixiv / 小红书 / Lofter / X / 个人网站）就没法展示外链。

### 需求描述

把"两个写死的平台字段"改成**自定义链接列表**：
1. 画师可以添加任意多条外链，每条包含：**名称**（如"我的Pixiv"）+ **链接地址**
2. 可选：从预设图标里挑一个（微博/B站/Pixiv/X/小红书/Lofter/抖音/通用链接），不挑就用通用图标
3. 可以删除、调整顺序
4. 客户主页展示画师配置的全部链接（4 个模板都要支持）
5. 老数据兼容：已有的微博/B站链接自动迁移成列表的前两条，不丢

设计原则：平台会不断出现新社交渠道，写死字段每出一个平台就要改一次代码；自定义列表一次到位，画师自己决定放什么，长期零维护。

### 待确认

- [x] **C26**：~~外链数量是否设上限？~~ → **按建议执行**：最多 6 条，避免主页被链接刷屏
- [x] **C27**：~~是否保留"微博/B站"快捷入口？~~ → **按建议执行**：不保留独立字段，统一进链接列表，图标选择器里提供微博/B站图标即可

### 验收标准

1. 当画师在主页设置添加一条自定义链接（名称+地址）并保存后，客户主页应该显示这条链接
2. 当画师添加多条链接时，客户主页应该按画师设定的顺序全部显示
3. 当画师删除某条链接后，客户主页应该不再显示它
4. 当老画师（已有微博/B站链接）升级后，原有链接应该自动保留在链接列表中，不丢失
5. 当画师输入非法链接（非 http/https 开头）时，应该被拒绝并提示
6. 当画师选择预设图标时，客户主页应该显示对应图标；不选时显示通用链接图标
7. 当 4 个主页模板（classic/gallery/folio/atelier）展示链接时，应该都正常显示

## R17：订单详情优先级改为分段按钮

### 用户原声

> "详细订单里 比如alice-001。 优先级这里 现在一个下拉框太丑了，换别的交互思路。"

### 现状（已核实）

订单详情页（OrderDetail.vue:20-24）优先级用一个 `el-select` 下拉框，藏在订单信息表格里。要点开、选择、收起，三步，且无颜色感知。

### 需求描述

把下拉框换成**带颜色的分段按钮**（高/中/低 三个并排按钮）：
1. 一键点击即切换，无需展开下拉
2. 按钮带优先级颜色（🔴高=红 / 🟡中=黄 / 🟢低=绿），与排期看板的优先级色彩语言一致
3. 当前优先级高亮显示
4. 切换失败时回滚到原值并提示

设计原则：优先级只有 3 个值，下拉框是"为通用性牺牲直觉"的典型。3 个选项用分段按钮一眼可见、一键可达，且颜色即语义。手动录单页的优先级已经是 radio-button，本改动让两处交互统一。

### 验收标准

1. 当画师打开订单详情页时，优先级应该显示为三个带颜色的分段按钮（高/中/低），而不是下拉框
2. 当画师点击另一个优先级时，应该立即保存并有视觉反馈（成功提示）
3. 当优先级颜色显示时，应该与排期看板的优先级颜色一致（红/黄/绿）
4. 当保存失败时，优先级应该回滚到原值并显示错误提示
5. 当画师在手机上操作时，三个分段按钮应该完整可见，不换行错位

## R18：订单图库（画师临时图 + 客户图统一管理）

### 用户原声

> "希望给每个订单的详细订单里 有一个单独的图库，包含了画师临时上传的图片、用户的图片。点一下可以设置为焦点 并显示在排期看板里面。"
> "画师不能增减参考图。"

### 现状（已核实）

订单详情页只有"参考图"区块，仅展示**客户下单时上传的图**。画师：
- ❌ 不能往订单里加图（比如客户QQ发来的新参考、自己的草稿、进度图）
- ❌ 不能删图（删除按钮缺失 = Bug UI-1，后端 API 已存在）
- 焦点图设置是每张图下面一个独立"设为焦点"按钮，与图片管理割裂

### 需求描述

把订单详情页的"参考图"区块升级为**订单图库**——每个订单一个独立的图片空间：

1. **统一收纳**：图库同时包含客户上传的图 + 画师上传的图，用来源标记区分（"客户"/"画师"角标）
2. **画师可加图**：图库里有上传入口，支持拖拽/点击/Ctrl+V 粘贴（复用 R5 粘贴能力）
3. **画师可删图**：任何图（含客户传的）悬停显示删除按钮（吸收 Bug UI-1）
4. **点一下设焦点**：点击图库里任意一张图 = 设为该订单焦点图（替代现在的独立"设为焦点"按钮），焦点图有高亮边框/角标
5. **看板联动**：设为焦点后，排期看板对应卡片显示这张图（沿用 R4 的看板展示逻辑）

设计原则：画师的实际工作流是"围绕一个订单收集和管理一堆图"——客户发的、自己找的、画的草稿，都该进同一个地方。现在的"参考图"只是客户视角的只读列表，图库才是画师视角的工作台。"点一下设焦点"把选择和展示合成一个动作，零学习成本。

### 验收标准

1. 当画师打开订单详情页时，应该看到"订单图库"，同时包含客户上传的图和画师上传的图，并有来源标记
2. 当画师在图库上传图片（含 Ctrl+V 粘贴）时，图片应该立即加入图库并标记为"画师"来源

## R20：焦点图显示模式（关/小/大）移至排期看板

### 用户原声

> "排期看板显示（关 小 大）错误的出现在详细订单里？"

### 现状（已核实）

焦点图显示模式（关/小/大）的开关现在放在**订单详情页**的参考图区块下方（OrderDetail.vue:78-85）。但这个开关控制的是**排期看板**上焦点图的显示尺寸——放在订单详情里，画师会困惑"我改的是这里，影响的是那里"。

用户的疑问是对的：**这是一个看板显示设置，却放在了订单详情里**，位置错了。

### 需求描述

把"关/小/大"从订单详情移到**排期看板**：
1. 排期看板工具栏增加一个全局显示设置："焦点图显示：关 / 小 / 大"
2. 该设置作用于看板所有卡片（统一显示尺寸）
3. 订单详情页不再有"关/小/大"开关——详情页只负责"选哪张图当焦点"（R18 的点击设焦点）
4. 职责分离：**选图在订单详情（图库），看多大在排期看板**

设计原则：设置的归属应该跟着它影响的地方走。"焦点图在卡板上显示多大"是看板的事，不是单个订单的事。画师在一个地方统一控制"我的看板要不要显示角色图、显示多大"，比每个订单各设一次更符合直觉。

### 待确认

- [x] **C33**：~~显示模式是全局一个设置，还是每张卡片单独设置？~~ → **已确认：全局一个设置**（看板工具栏统一控制），但**存储方式调整为 localStorage**（一号审核决定，不走后端、不需要迁移）。画师几乎不会"这单显示大图、那单显示小图"，全局设置一次到位。per-order 的 `focus_image_mode` 字段废弃，改由看板工具栏全局控制 + localStorage 持久化。换设备设置会丢失（可接受，非关键偏好）。

### 验收标准

1. 当画师打开订单详情页时，应该不再有"关/小/大"显示模式开关
2. 当画师在排期看板工具栏切换"焦点图显示：小"时，所有设置了焦点图的卡片应该显示小尺寸焦点图
3. 当画师切换为"大"时，所有焦点图卡片应该显示大尺寸
4. 当画师切换为"关"时，所有卡片应该不显示焦点图
5. 当画师刷新页面/重新登录后，看板显示模式设置应该保持不丢失
6. 当画师在订单图库点击设焦点图时，该图应该按当前看板设置的尺寸显示在看板上
