## 二、核心规则

### R1 模式自动切换（对齐客户端）

画师配置了画风（styles 数量 > 0）→ 录单页右栏自动进入画风流程；未配置 → 维持现有档位流程，页面零变化。画师无需任何操作。

### R2 自定义单 = 什么都不选

- 不做"自定义"卡片、不做模式切换开关
- 画风区旁展示一行提示文字："都可以不选，直接手动填价格录入自定义单"
- 什么都不选时：价格面板隐藏计算明细，最终价格手输（现有行为）

### R3 画风模式交互（单页双栏适配，无步骤条）

录单页是单页双栏布局（不同于客户端的步骤条），画风流程适配为：

1. 展示画风卡片（多画风时一排卡片：封面图 + 画风名，视觉对齐现有档位卡片）
2. 点选某画风 → 该卡片下方展开该画风的尺寸列表 → 点选尺寸
3. 选尺寸后展开该尺寸的增项（与客户下单页同数据：后端已过滤隐藏增项）
4. 增项下方是倍率选择（用法倍率/加急倍率，现有 UI 复用，画风算价同样吃倍率）
5. **单画风退化**：只有 1 个画风时自动选中，直接展示尺寸（对齐客户端退化逻辑）
6. 切换画风 → 清空已选尺寸/增项/价格预览（对齐现有切档行为 onTierChange）

### R4 实时算价预览

选画风+尺寸+增项后，实时调 `calculate-style-price`（300ms 防抖，对齐现有 doCalc），价格面板展示 breakdown 明细 + 总价。手输价覆盖机制（G2 脏标记）原样沿用：画师没手动改过价 → 价格跟随计算；改过 → 尊重手输。

### R5 自定义增项（两条路径通用）

- **录入位置**：价格面板区域，「＋自定义增项」按钮；选了画风可录，不选的自定义单也可录
- **每条结构**：名称（必填，≤50 字）+ 金额（必填，允许负数——对应"减项/让利"场景）
- **展示**：进入价格面板明细，与基础价/目录增项并列显示
- **存储语义**：作为画师手动添加的增项条目入账。REQ-025 条目账本上线后，对应 `extra_item` 条目类型——在订单价格明细中可识别为"画师自定义添加"，与目录增项区分
- **算价语义**：与目录增项一致（参与倍率计算），统一模型不搞特例
- **数量上限**：20 条（对齐现有 addons maxItems=20）
- **可删除**：提交前可删除已录条目

### R6 图片展示开关

- 位置：右栏「怎么录」顶部，「显示图片」开关
- 默认：**开**
- 关闭效果：右栏**所有卡片的图片一起隐藏**（画风卡片 + 档位卡片，用户拍板"一起藏"），卡片退化为纯文字（名称 + 价格），整列变紧凑
- 记住方式：localStorage 本地记忆，不动后端

### R7 不变的部分（明确不动，防止实施时误改）

- F4 初始节点状态：与档位/画风选择无关（选的是工作流节点），交互不变
- 截稿日/开稿日/优先级/QQ 历史面板/参考图上传：不变
- 提交后补写截稿日/开稿日/初始状态的多步链路：不变
- 后端 createOrder 接口字段：不变（styleSizeId/styleAddons 已就位）

## 三、边界案例

| # | 场景 | 处理 |
|---|------|------|
| B1 | 画师配置了画风但全部停用（is_active=0） | 录单页取不到可用画风 → 等同未配置，走档位流程（客户端同逻辑） |
| B2 | 选了画风后切回"什么都不选" | 点已选中的画风卡取消选中（对齐现有档位卡 toggle 交互），清空尺寸/增项/算价 |
| B3 | 自定义增项金额为 0 | 允许（留痕场景：客户加需求但画师免费做），明细显示 ¥0.00 |
| B4 | 手输价与计算价不一致 + 有自定义增项 | 手输价优先（G2 脏标记），自定义增项留痕不受影响 |
| B5 | 录单过程中画师在别的页面改了画风配置 | 录单页不实时同步（提交时后端校验 ID 有效性，无效则报错提示重选） |

## 四、验收标准

1. 当画师配置了画风时，打开录单页，应该自动展示画风卡片（封面图 + 名称），不再显示档位卡片。
2. 当画师未配置画风时，录单页应该与现在完全一致（档位卡片流程）。
3. 当画师什么都不选时，应该可以手输价格提交自定义单，且画风区旁有"可不选自定义"提示。
4. 当选择画风+尺寸+增项时，价格面板应该实时显示算价明细与总价。
5. 当画师手动改过价格后，再调整增项，手输价应该不被计算价覆盖。
6. 当画师录入自定义增项（名称+金额）时，应该同时出现在价格明细与订单价格留痕中；金额为负数时应该被接受。
7. 当关闭「显示图片」开关时，右栏所有卡片（画风+档位）的图片应该一起隐藏；重新打开后应该恢复；刷新页面后开关状态应该保持。
8. 当只有 1 个画风时，应该自动选中并直接展示尺寸，不出现"选画风"步骤。
9. 当切换画风时，已选尺寸/增项/价格预览应该被清空。
