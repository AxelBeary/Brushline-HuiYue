## 产品定位

**一句话**：画师的本地工作台——管稿子、记账、出图，联网后和绘约平台无缝对接。

**核心原则**：
- 本地优先：所有核心功能不依赖网络
- 登录是"升级"不是"门槛"
- 平台是加分项，不是前提

---

## 功能清单

### F1 本地文件管理

- 按委托/项目归档本地文件（CSP、PSD、PNG 等）
- 快速打开工程文件（调起系统关联程序）
- 文件与委托记录关联（一个委托下挂多个文件）

### F2 本地委托记账

- 记录：客户名、委托类型、价格、截稿日、状态
- 纯本地，不需要网络
- 状态流转（草稿 → 进行中 → 已交付 → 已收款）由画师手动标记

### F3 约稿条生成

- **用途**：画师发社交平台（微博/小红书/米画师）招揽客户
- **输入**：拖入参考图/示例图 + 画师档案（F6）+ 档位/价格/规则文字
- **输出**：PNG 图片 + 纯文字版（复制粘贴用）
- 支持自定义排版/配色（待细化）

### F4 委托小票/回执

- **用途**：发给客户确认委托详情（"你约了什么、多少钱、什么时候交"）
- **输入**：从 F2 记账数据自动填充
- **输出**：PNG 图片 + 纯文字版
- ❌ 不做 PDF（"很多单主连 PDF 是啥都不知道"——用户原话）

### F5 平台图片缓存（登录后）

- 单个委托最多 20 张图（与平台 `REFERENCES_LIMIT` 对齐）
- 上传：拖入，逻辑与网页端一致
- 下载/缓存：首次拉取后存本地，下次打开免流量
- 不做文件同步（只缓存图片，不同步 CSP/PSD 等工程文件）

### F6 画师档案（本地）

- 字段：昵称、头像、简介、风格标签
- 约稿条（F3）和小票（F4）复用此档案
- 免登录阶段：画师手动创建/编辑
- 登录后：首次触发对比（见 F7），之后平台为准

### F7 首次登录档案对比（登录后，一次性）

- 触发条件：本地已有档案 + 平台也有档案
- 交互：左右对比界面，逐项（昵称/头像/简介/标签）让画师选哪边赢，或手动改
- 确认后：平台为 source of truth，本地变为缓存
- 本地无档案 + 平台有：直接用平台数据
- 本地有 + 平台无（新注册）：本地推上去

## 界面形态

- 整体布局参照现有管理后台 dashboard
- **左下角账号区**：

| 状态 | 显示内容 |
|------|----------|
| 免登录 | 占位头像 + "本地模式" + 按钮「登录同步」 |
| 已登录 | 画师头像 + 昵称 + 同步状态 + 「切出账号」 |

- 免登录模式：只显示本地功能（F1~F4、F6）
- 已登录模式：显示全部功能（F1~F7）

---

## 数据可见性规则

> **一条规则管所有：数据的来源决定可见性，不是当前登录状态。**

| 数据来源 | 免登录可见？ | 登录后可见？ | 切出账号后？ |
|----------|:-----------:|:-----------:|:-----------:|
| 本地创建（手动记账、本地文件） | ✅ | ✅ | ✅ 永远在 |
| 平台同步（委托单、缓存图） | ❌ | ✅ | 界面隐藏，文件留磁盘 |

- 切出账号 ≠ 没收数据：平台来源的文件保留在磁盘，下次登录免重新下载
- 不做"已同步/未同步"标签，不做混合态 UI

---

## 登录与账号

- 画师账号由**管理员后台创建**，不允许自助注册
- 凭据传递形式待定（邀请码/账号密码，等登录体系设计时确认）
- 当前网页端为开发模式（AUTH_DEV_MODE=true），桌面端登录体系属 v1.0+ 范畴

---

## 明确不做（本版本）

| 排除项 | 原因 |
|--------|------|
| 客户下单/支付 | 无登录体系，不做客户侧 |
| 云端文件同步 | 只缓存图片，不同步工程文件 |
| 多人协作 | 单画师工具 |
| 移动端 | 桌面应用 |
| PDF 输出 | 目标用户不熟悉 PDF |
| 自助注册 | 管理员建号模式不变 |
