## 建议方案

### 一、设置页重组（4 Tab 逻辑重划）

| 新 Tab | 装什么 | 心智 |
|--------|--------|------|
| **基本资料** | 头像、昵称、编码、简介、联系QQ | "我是谁"（5 个字段） |
| **主页展示** | 接稿状态、公告、外链、平台链接、灵感标签、须知 | "客户看到什么" |
| **模板与风格** | 模板、配色、强调色、封面图、预览 | "主页长什么样" |
| **偏好** | 通知开关、默认面板、快捷按钮 | "系统怎么用" |

"接稿设置" Tab 删除。

### 二、接稿状态归位

| 位置 | 建议 |
|------|------|
| 仪表盘 StatusSwitch | 保留（每天高频操作，一键切换） |
| 开稿管理 | 改为可操作（状态归属"接不接单"概念） |
| 设置-基本资料 | 删除（不再重复） |

### 三、侧边栏瘦身

- 手动录单移出菜单（订单管理页已有按钮 + 快捷操作区已有入口）
- 菜单加分隔线分组：工作（仪表盘/排期/订单）· 经营（开稿/价格/作品/留言）· 门面（设置）

### 四、仪表盘留言审核（低优先）

建议保持现状（画师每天开仪表盘顺手审留言是真实便利）。可选简化为入口卡。
