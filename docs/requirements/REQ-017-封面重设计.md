## 背景

v0.25 实施的封面功能完全偏离了用户拍板方向。当前实现是"Settings 里嵌入全部作品列表 + 星标选封面"，用户要的不是这个。封面是**主页门面图**——客户打开画师主页第一眼看到的视觉焦点，不是"设置页里的一个管理功能"。

---

## 用户硬约束（原话逐字引用，2026-08-02 拍板）

> **1. 封面是主页门面图**——客户打开画师主页第一眼看到的视觉焦点，不是"设置页里的一个管理功能"

> **2. 选中的封面不在下方图格重复展示**——设了封面的作品，在作品列表/瀑布流中不再出现（避免重复）

> **3. 设置里放一个指向作品管理的链接**，不是把作品列表搬到设置页——画师去作品管理页操作封面，设置页只做"当前封面预览 + 跳转链接"

> **4. 不同模板对封面的处理逻辑不同**——4 模板各自的门面区域结构不同，封面展示必须适配：
> - Classic：单图 Hero 横幅（一张封面撑满）
> - Gallery：轮播（多张封面自动/手动切换）
> - Folio：大图展示（封面作为作品集首图）
> - Atelier：拼图/网格（封面作为入口缩略图）

---

## 功能描述

### 1. 数据模型

- 现有 `is_cover` 布尔字段是否够用？**待确认**：
  - Gallery 模板需要多张封面轮播 → 需要 `cover_order` 排序字段（整数，越小越靠前）
  - 如果只用 `is_cover` 布尔值，多张封面时排序靠创建时间？还是加排序字段？
- **建议**（待一号/三号确认）：`is_cover` + `cover_order`（整数，默认 0），支持多封面排序

### 2. 画师端交互（作品管理页 ArtworkManage）

- 封面操作入口在**作品管理页**，不在 Settings
- 每个作品卡片上加"设为封面"操作（星标/按钮均可，视觉设计稿定）
- 多张封面时支持拖拽排序（或上下箭头调整顺序）
- 取消封面：再次点击取消，或拖出封面区

### 3. 设置页（Settings）改造

- **删除**：当前 Settings 中嵌入的全部作品列表 + 星标选封面 UI
- **替换为**：
  - 当前封面预览缩略图（无封面时显示占位提示"尚未设置封面"）
  - 一个跳转链接："管理封面 →"，点击跳转到作品管理页
- 设置页不做任何封面选择/排序操作

### 4. 客户端渲染（4 模板适配）

| 模板 | 封面区形态 | 无封面时 | 多封面行为 |
|------|-----------|---------|-----------|
| Classic | 单图 Hero 横幅，一张封面撑满门面区 | 显示默认占位图或画师头像 | 只取 cover_order 最小的一张 |
| Gallery | 轮播组件，多张封面自动/手动切换 | 显示默认占位图 | 按 cover_order 排序轮播，自动播放 + 手动左右切换 |
| Folio | 大图展示，封面作为作品集首图 | 显示默认占位图 | 只取 cover_order 最小的一张作为首图 |
| Atelier | 拼图/网格，封面作为入口缩略图 | 显示默认占位网格 | 多张封面填充网格前 N 格 |

- 封面区点击行为：跳转到作品详情/瀑布流（具体交互待设计稿定）

### 5. 去重逻辑

- 设了封面的作品（`is_cover = true`），在客户端**作品列表/瀑布流中不再出现**
- 去重范围：所有展示作品的列表组件（瀑布流、作品网格、价格表关联作品等）
- 画师端作品管理页**不做去重**（画师需要看到所有作品来管理封面）

### 6. 迁移

- 现有 Settings 中的封面管理 UI 删除
- 已有 `is_cover = true` 的数据保留，自动生效
- 如果加了 `cover_order` 字段，现有封面数据默认 `cover_order = 0`

---

## 验收标准

1. 当画师在作品管理页将某作品设为封面时，该作品在客户端主页封面区展示，且不再出现在下方作品列表/瀑布流中
2. 当画师打开设置页时，应该只看到当前封面预览缩略图和"管理封面 →"跳转链接，不应该看到作品列表或星标选择器
3. 当客户使用 Classic 模板的画师主页时，应该看到单张封面撑满 Hero 横幅区
4. 当客户使用 Gallery 模板的画师主页时，应该看到多张封面轮播（自动播放 + 手动切换）
5. 当客户使用 Folio 模板的画师主页时，应该看到封面作为作品集首图大图展示
6. 当客户使用 Atelier 模板的画师主页时，应该看到封面作为拼图/网格入口缩略图
7. 当画师未设置任何封面时，4 个模板各自显示默认占位图，不应该出现空白区域
8. 当画师取消某作品的封面标记时，该作品重新出现在客户端作品列表/瀑布流中
