## PERF-1：字体跳变（霞鹜文楷未拆分 + 无预加载）— 🔵 修复中

- **发现日期**：2026-08-01
- **发现人**：外部用户反馈（经奚怡熊转达）
- **现象**：打开网页时字体有明显跳变（先用系统字体显示，1~3 秒后突然切换为自定义字体）
- **根因**（四号代码核实）：
  1. 霞鹜文楷（LXGW WenKai）为单个完整 woff2 文件（3.3MB，7024 字符），未做 unicode-range 子集拆分
  2. 字体 CSS 通过 `main.js` import 加载，浏览器需先下载解析 JS 才发现字体 URL，字体是最后被发现的资源
  3. `font-display: swap` 导致字体未到时先用系统字体渲染
- **对比**：思源宋体/黑体（Noto）已正确拆分为 10 个子集包（`subset_noto.py` 生成），按需加载，无此问题
- **修复方向**：
  1. 霞鹜文楷用同样的子集化脚本拆分为 ~10 包（按 unicode-range 按需加载）
  2. `index.html` 加 `<link rel="preload">` 预加载首屏最可能用到的 1~2 包字体
- **不需要做**：加载暂停/骨架屏等字体方案（代价大于收益）
- **状态**：待排期
- **预估工程量**：~1h（跑脚本拆分 + index.html 加 preload + 验证）
