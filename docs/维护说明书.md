## 一、系统架构

```
用户浏览器
    │
    ▼
Cloudflare CDN（可选，加速静态资源）
    │
    ▼
Caddy（反向代理 + 自动 HTTPS）
    │  端口 80/443
    │  depends_on: web (service_healthy)
    ▼
Node.js 应用（Fastify 5，多阶段 Docker 构建）
    │  端口 3000
    │  healthcheck: /api/health（30s 间隔）
    ├── SQLite 数据库（data/commission.db）
    ├── 上传文件（uploads/）
    └── 前端构建产物（web/dist/，构建时嵌入镜像）
```

## 二、首次部署

### 前置条件
- 一台 Linux 服务器（1核1G 即可）
- 已安装 Docker + Docker Compose
- 一个域名，已做泛解析：`*.你的域名.com → 服务器IP`

### 步骤

```bash
# 1. 克隆项目
git clone <仓库地址> artist-commission
cd artist-commission

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，必须修改：
#   DOMAIN=你的域名.com
#   ADMIN_QQ=你的QQ号
#   SESSION_SECRET=（用下面命令生成）
#
# 生成 SESSION_SECRET：
#   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# 3. 启动
docker compose up -d

# 4. 初始化种子数据（可选，会创建测试画师 Alice 和 Bob）
docker compose exec web node server/src/db/seed.js

# 5. 验证
curl http://localhost:3000/api/health
# 应返回 {"status":"ok",...}
```

### 添加第一个画师

方法一：通过管理员后台
1. 用管理员 QQ 号 + 验证器 App 动态码登录（访问 `/login`，TOTP 动态口令，见「TOTP 动态口令」节）
2. 访问 `/admin/artists`
3. 点"添加画师"

方法二：通过种子数据
```bash
docker compose exec web node server/src/db/seed.js
```

## 五、域名与 HTTPS

### 泛解析 DNS 配置
在你的域名服务商添加：
```
类型: A
主机记录: *
记录值: 你的服务器IP
```

### Caddy 自动 HTTPS
Caddy 默认自动申请 Let's Encrypt 证书，无需手动配置。

如果使用 Cloudflare 代理（橙色云朵），需要：
1. 安装 Caddy 的 cloudflare DNS 插件
2. 在 Caddyfile 中配置 `acme_dns cloudflare <API_TOKEN>`
3. 或者将 Cloudflare SSL 模式设为 "Full (Strict)"

### 添加新画师
不需要任何 DNS 或 Caddy 配置变更！
只需在管理员后台"添加画师"并填写子域名即可，画师主页通过 `https://你的域名/artist/子域名` 访问。

> **Phase 2 规划**：未来将支持泛子域名（`alice.你的域名`），届时需配置泛解析 DNS 和 DNS-01 证书。

## 八、故障排查

### 应用无法启动
```bash
# 查看详细错误
docker compose logs web --tail 50

# 常见原因：
# 1. .env 文件缺失或格式错误
# 2. data/ 目录权限不足
# 3. 端口 3000 被占用
# 4. SESSION_SECRET 未设置（启动报错，v0.5 起）
# 5. SIGN_SECRET 未设置（使用默认值 'secret'，签名 URL 不安全）
```

### 数据库锁定
```bash
# SQLite WAL 模式下极少出现
# 如果出现 "database is locked"：
docker compose stop web
rm -f data/commission.db-wal data/commission.db-shm
docker compose start web
```

### 上传文件 404
```bash
# 检查 uploads 目录权限
ls -la uploads/
# 确保 Docker 容器内的用户有读写权限
chmod -R 755 uploads/

# 确认容器内路径正确（v0.3 起 UPLOAD_DIR 由 app.js 统一传入）
docker exec commission-web ls -la /app/uploads/
# 应该有 images/ 子目录
```

### HTTPS 证书问题
```bash
# 查看 Caddy 日志
docker compose logs caddy --tail 30
# 常见原因：DNS 未生效、端口 80/443 未开放
```

### Caddy 容器反复重启（本地开发）
这是正常现象——本地没有域名配置，Caddy 无法申请证书。
不影响使用，直接通过 `http://localhost:3000` 访问即可。

### 上传的图片不显示 / 作品加载失败
```bash
# 检查上传目录是否正确挂载
docker exec commission-web ls -la /app/uploads/
# 应该有 images/ 子目录

# 如果目录为空但本地 uploads/ 有文件，检查 docker-compose.yml：
# 确保 environment 中有 UPLOAD_DIR=/app/uploads
# 确保 volumes 中有 ./uploads:/app/uploads

# v0.3 起 UPLOAD_DIR 由 app.js 统一解析并传入 upload 插件，
# 不再依赖 entrypoint.sh 的 cd 行为
```

### NODE_ENV 与 AUTH_DEV_MODE（TOTP 时代，REQ-027）
```bash
# 检查当前模式：
docker compose exec web printenv NODE_ENV AUTH_DEV_MODE
```
- `NODE_ENV=production`（docker-compose 默认）：cookie 走 Secure 等生产行为
- `AUTH_DEV_MODE=true`：TOTP 绑定接口（bind-init）响应附带密钥明文 `_dev_secret`（仅开发/测试/演示辅助；**生产必须关闭**——当前生产容器已设为 `false`，2026-08-06 重建上线时关闭）

> ⚠️ v0.5 起 docker-compose.yml 默认 `NODE_ENV=production`。本地开发请手动改为 `development`。

### TOTP 动态口令：手机丢失 / 换设备自助重绑（REQ-027）

画师或管理员的手机丢失、验证器 App 删除、换手机后，动态口令登录会失败。两条解决路径：

**路径一：管理员在后台重置（画师丢失时用）**

管理员登录后台 → 画师管理 → 找到该画师 → 点「重绑」→ 生成二维码给画师扫 → 画师报出 App 上的 6 位码 → 管理员输入确认。

**路径二：服务器本机 CLI 自助重绑（管理员自己丢失 / 新部署未绑定时用）**

后台重置入口本身要先登录，管理员丢手机会形成死锁——唯一出路是服务器本机操作：

```bash
cd server
npm run totp:rebind -- <QQ号>
# 例：npm run totp:rebind -- 10003
```

脚本一次完成三件事：① 生成新密钥直接入库并标记已绑定（**旧密钥立即失效**）；② 生成二维码（`temp/totp-rebind-<QQ号>.png`），用验证器 App 扫码（扫不了可用控制台打印的密钥手动录入）；③ 自动现算动态码打真实登录接口做端到端验证。之后用 QQ 号 + App 新码登录即可。

Docker 部署时也可在容器内执行（DB 路径自动解析为容器挂载的 `/app/data/commission.db`）：

```bash
docker compose exec web npm run totp:rebind -- <QQ号>
```

> ⚠️ 安全边界：该命令只有能物理操作服务器的人可执行（不经网络、不开端口）。执行后旧验证器 App 上的动态码全部作废。
> DB 不在默认位置时可用环境变量覆盖：`DB_PATH=/路径/commission.db npm run totp:rebind -- <QQ号>`

### 速率限制（v0.5 新增）
所有公开接口均有内存桶速率限制（按 IP + 端点独立计数，阈值以代码 `guardRateLimit(...)` 调用为准）：
- TOTP 登录 verify：10次/5分钟（另有账号级防爆破：连续错误 5 次锁定 15 分钟）
- 公开下单：10次/10分钟
- 订单进度查询：20次/5分钟
- 客户留言：2次/分钟

触发限制返回 HTTP 429。限制器在进程重启后重置（无需清理）。
如需调整阈值，修改各 routes 文件中的 `guardRateLimit(...)` 调用（如 `auth.routes.ts`）。

### 焦点图破图 / 作品图加载异常（v0.11）
```bash
# 1. 确认图片文件存在
docker exec commission-web ls -la /app/uploads/images/

# 2. 检查数据库中的路径是否正确（应为相对路径，无 /uploads/ 前缀）
docker exec commission-web node -e "
const db = require('better-sqlite3')('/app/data/commission.db');
console.log(db.prepare('SELECT id, focus_image FROM artists WHERE focus_image IS NOT NULL').all());
"

# 3. 如果路径含 /uploads/ 前缀，说明是旧数据，迁移 v11 应已修复
#    若仍有问题，手动修正：
docker exec commission-web node -e "
const db = require('better-sqlite3')('/app/data/commission.db');
db.prepare(\"UPDATE artists SET focus_image = REPLACE(focus_image, '/uploads/', '') WHERE focus_image LIKE '/uploads/%'\").run();
"

# 4. 确认 @fastify/static 版本（v0.11 起为 v10）
docker exec commission-web node -e "console.log(require('/app/node_modules/@fastify/static/package.json').version)"
```

```bash
# 1. 确认前端构建包含粘贴上传组件

# 4. 如果粘贴事件触发但上传 403，检查 MIME 白名单
#    支持：jpg/png/webp/gif/pdf/psd/ai/zip/rar
```

## 十、安全注意事项

1. **不要** 把 `.env` 文件提交到 git
2. **不要** 把 `data/` 和 `uploads/` 目录暴露到公网
3. **必须** 在生产环境设置 `SESSION_SECRET`（v0.5 起未设置会启动报错）
4. **必须** 在生产环境设置 `SIGN_SECRET`（v0.7.1 起文件签名 URL 使用此密钥，默认值 `secret` 不安全）
5. **v0.6.2 / REQ-027**：开发模式辅助功能通过 `AUTH_DEV_MODE=true` 显式开启（不再依赖 NODE_ENV）。REQ-027 起语义为：TOTP 绑定接口（bind-init）响应附带密钥明文 `_dev_secret`。生产环境务必不设置或设为 `false`
6. **v0.6.2 / 环境批**：`docker-compose.yml` 默认映射 `3000:3000`（开发/自用部署直连，B3 用户拍板 2026-08-06）；生产公开部署时注释掉 ports 两行仅保留 expose，外部访问走 Caddy 反向代理（详见 `docs/开发→生产切换指南.md`）
7. **v0.6.2**：上传文件有扩展名 + MIME 双重白名单校验，交付文件前端限制 50MB
8. **v0.6.2**：所有 API 路由有 JSON Schema 输入校验，非法字段自动剥离
9. **v0.7.1**：`/uploads/` 不再全公开，交付文件和参考图通过 HMAC 签名 URL 访问（15 分钟有效），仅 `images/` 保留公开
10. **v0.7.1**：软删除画师的 token 立即失效（`requireAuth`/`requireAdmin` 检查 `deleted_at`）
11. **v0.7.1**：管理员删除画师时递增 `token_version`，强制吊销该画师所有会话
12. **v0.7.1**：全局安全响应头（X-Content-Type-Options / X-Frame-Options / X-XSS-Protection / HSTS）
13. **v0.7.1**：500 错误不再透传内部异常信息，返回固定文案 + 服务端日志
14. 定期备份数据库
15. 保持 Docker 和系统更新
16. 认证接口有速率限制（verify 10次/5分钟）；TOTP 登录另有账号级防爆破：连续错误 5 次锁定 15 分钟（`auth.service.ts`，REQ-027）
17. **v0.5 新增**：客户查询进度需 QQ号+订单号双验证，防止订单号枚举
18. **v0.5 新增**：上传文件有 MIME 白名单（jpg/png/webp/gif/pdf/psd/ai/zip/rar），非白名单返回 403
19. **v0.5 新增**：前端所有 `v-html` 均经过 `sanitizeHtml()` 消毒，防止存储型 XSS
20. **v0.5 新增**：画师后台所有操作有 `artist_id` 归属校验，防止水平越权
