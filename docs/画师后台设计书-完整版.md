# 绘约（Brushline）画师后台 — 完整设计书

> 交给专业网页设计 AI 的完整输入。包含产品全貌、每页详细规格、真实数据结构、用户工作流、视觉方向。
> 目标：产出一套可直接指导 Vue 3 + Element Plus 落地的画师后台视觉与交互设计。
> 日期：2026-08-02

---

## 第一章：这是什么

### 1.1 产品

**绘约（Brushline）** 是一个约稿平台。画师入驻后获得专属主页（`/artist/xxx`），客户在主页浏览作品和价格档位，在线下单约稿（定制头像、插画、立绘等）。画师在**画师后台**管理全部业务：录单、排期、推进制作流程、确认收款、管理作品和价格。

平台还有一套**管理后台**（平台运营者用），低频，本次设计可简化处理。

### 1.2 本次设计范围

**仅画师后台**（画师登录后的管理端，11 个页面 + 登录页）。

客户端（画师主页、下单表单、订单追踪）已有 4 套模板 × 4 套配色，视觉已完成，**不在范围内**，但画师后台的气质应与客户端的"东方文人"产品气质一致。

### 1.3 技术约束（设计时需知道）

- 前端框架：Vue 3 + Element Plus（EP）。设计稿中的组件最终要能用 EP 组件或自定义组件实现
- 已有字体资产：**霞鹜文楷（LXGW WenKai）**——产品的标志性中文字体，客户端已在用，已做 woff2 子集拆分
- 已有配色资产（仅客户端）：纸白 paper / 墨黑 ink / 暮灰 dusk / 苔绿 moss，各带深色模式
- 画师后台目前是独立的通用浅色主题，**不跟随客户端 4 色**
- 排期视图已有 vuedraggable（拖拽排序库）

## 第二章：谁在用，怎么用

### 2.1 用户画像

**画师**：创作者，非程序员。每天高频使用后台，是生产力工具不是展示页。审美敏感但需求务实——清晰、高效、有层次，不要花哨。

### 2.2 一天的工作流（设计的核心依据）

```
早上 9:00  打开后台 → 仪表盘
           看一眼：今天有几个待确认？有没有逾期？这个月赚了多少？
           顺手审批昨晚的留言（2-3 条）
           切换接稿状态（今天不想接了 → 暂停）

上午 10:00 QQ 上和客户谈好了一单
           → 手动录单页：粘贴客户发来的参考图 → 填 QQ 号（自动跳出这人的历史订单）
           → 右栏选档位卡片 → 勾增项 → 看价格预览 → 手动改个总价 → 提交
           → 继续录下一单（连续录单是真实场景）

下午 14:00 排期看板
           → 月历视图：这个月的带子排得满不满？
           → 时间条视图：拖动"小明-头像档"的右端，把截稿日从 8/15 拖到 8/18
           → 看板视图：把"线稿确认"的订单推进到下一节点

晚上 20:00 订单详情页
           → 客户付了第二笔款 → 记录收款
           → 上传成图 → 推进到"已交付"
```

**设计启示**：
- 仪表盘 = 每天第一眼，信息优先级：逾期 > 待确认 > 待办 > 收入
- 手动录单 = 最高频操作，必须快（粘贴图 → 填 QQ → 选档 → 提交， ideally 30 秒内）
- 排期 = 核心中的核心，三个视图各有用途，时间条要能拖
- 订单详情 = 单订单的完整生命周期管理

## 第四章：页面详细规格

### 4.1 仪表盘 `/dashboard`

**定位**：每天第一眼。回答三个问题：今天该干什么？有没有要逾期的？生意怎么样？

**模块与数据**：

| 模块 | 内容 | 交互 |
|------|------|------|
| 统计卡片 ×4 | 进行中 N / 待确认 N / 已逾期 N / 本月收入 ¥N | 点击跳转订单列表对应筛选 |
| 待办清单 | 需处理的订单列表（待确认、即将截稿、待收款） | 点击进订单详情 |
| 快捷操作 | 画师自定义 3~9 个入口（手动录单、查看排期、价格管理…） | 点击跳转 |
| 接稿状态切换 | 接单中 / 暂不接单，一键切换 | 切换后全局生效 |
| 留言审核（内嵌） | 最新待审核留言 2-3 条 | 行内通过/拒绝 |

**统计卡片规格**：
- 逾期卡：有逾期时视觉强调（红边/红数字/脉冲图标），无逾期时安静
- 收入卡：数字用等宽字体，¥ 符号小一号
- 每张卡可点击，hover 时浮现跳转箭头

**状态枚举**（设计需覆盖）：
- 接稿状态：`open`（接单中，绿点）/ `closed`（暂不接单，灰点）

### 4.2 排期看板 `/queue` — 核心页面

**定位**：排期的三种看法，顶部 tab 切换，共享同一份数据，切换不重新请求。

```
[ 📋 看板 ]  [ 📅 月历 ]  [ 📊 时间条 ]
```

#### 视图一：看板（按状态分列）

- 列：待确认 / 进行中 / 已完成 / 已交付（+ 已取消折叠区）
- 每列内订单卡片：客户昵称、档位名、截稿日（逾期红字）、焦点图缩略图（可开关显示模式）
- 缓冲区订单（候补）：卡片半透明 + 虚线边框
- 工作流订单：显示当前节点进度（如"线稿 2/4"）

#### 视图二：月历

- 标准 7 列月历（周一开头），`← 2026年8月 →` 翻月
- 今天高亮
- **订单色带**：每个订单从确认日（或开工日）到截稿日画一条水平带，跨格子连续
  - 带内文字：`昵称-档位`（如"小明-头像档"），超长截断
  - 同一天多订单：纵向堆叠，最多 3 条 + "+N"
  - 点击带 → 订单详情
  - hover → tooltip（订单号 + 截稿日 + 状态）
- **三种带的视觉编码**（关键设计点，用纹理不只靠颜色）：

| 类型 | 样式 |
|------|------|
| 正式订单 | 实心色块 + 圆角 |
| 缓冲位（候补） | 同色 30% 透明 + 虚线边框 |
| 未设截稿日 | 斜纹纹理 + ⚠️ 标记，从确认日画满到月末 |

- 颜色：蓝 = 进行中 / 红 = 逾期 / 绿 = 完成
- 未设截稿日的订单画满整月 = 自带催促效果（画师看到未来被不明带子占满会主动去补）

#### 视图三：时间条（类甘特图）

- 横轴：日期（默认两周，可缩放：2 周 / 1 月 / 2 月）
- 纵轴：订单列表（按确认日排序）
- 每个订单一条横条，视觉样式同月历
- 今天：竖向参考线
- **拖拽（本次设计重点）**：
  - 拖横条**右端** → 改截稿日（吸附到天，拖拽中显示浮动日期标签）
  - 拖横条**左端** → 改开工日
  - 已完成/已交付订单：无拖拽把手
  - 移动端：把手热区扩大到 24px

### 4.3 订单管理 `/orders`

- 筛选：状态 segmented（全部/待确认/进行中/已完成/已交付/已取消）+ 搜索框（QQ 号/昵称/订单号）
- 表格列：订单（双行：昵称+档位 / 订单号+QQ）| 状态 Badge | 当前节点 | 截稿日（逾期红字）| 金额（右对齐等宽）| 收款状态（已付清绿/部分琥珀/未付灰）
- 行点击 → 订单详情
- 分页
- 工具栏：「手动录单」主按钮
- 移动端：表格降级为卡片列表

### 4.4 手动录单 `/orders/new` — 高频操作页

**定位**：画师在 QQ 谈好后手动录入。左栏 = 客户说了什么，右栏 = 我怎么安排。

**布局**：桌面双栏（≥1024px），右栏价格面板 sticky；600-1024px 单栏 + sticky；<600px 单栏 + 底部钉住价格条。

**左栏字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| 客户 QQ 号 | 输入框 | 5-15 位数字，输入后防抖 500ms 自动查历史 |
| 参考图 | 粘贴/上传区 | **大块虚线区，左栏最显眼位置**（画师流程：先收图再填别的），最多 5 张，支持粘贴 |
| 客户昵称 | 输入框 | 可选 |
| 需求描述 | 文本域 | 从 QQ 聊天复制粘贴，2000 字 |
| 优先级 | 三态按钮 | 高 / 中 / 低 |
| 截稿日 | 日期选择器 | 可选 |
| QQ 通知开关 | 复选框 | 下单后通知客户 |
| **历史订单面板** | 自动面板 | QQ 有效时显示：该客户最近 5 单（订单号+档位+状态+日期），新客户显示"🎉 新客户" |

**右栏字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| 档位选择 | **卡片网格**（不是下拉框） | 每卡：示例图 + 名称 + 价格 + 工期，点击选中（✓ 角标），再点取消 |
| 增项 | 分组折叠 | 按类别分组（表情/服装/场景…），每项：数量型（input-number）/ 开关型（switch）/ 面议型（tag） |
| 倍率 | 单选按钮组 | 用途倍率（个人/商用…）+ 加急倍率 |
| 价格预览 | sticky 面板 | 实时明细（基础价 + 各增项 + 倍率 = 总价） |
| 最终价格 | 数字输入 | 可手动覆盖计算价 |
| 提交 | 主按钮 | 显示当前总价 |

**提交后**：成功弹窗（订单号 + 查看排期 / 继续录入），连续录单 = 重置表单留在页面。

**移动端底部价格条**：总价 + 提交按钮，点价格展开明细（淘宝结算页模式），safe-area 适配。

### 4.5 订单详情 `/orders/:id`

**定位**：单订单的完整生命周期管理。

**模块**：

| 模块 | 内容 |
|------|------|
| 头部 | 订单号（等宽）+ 状态 Badge + 客户信息（昵称/QQ）+ 优先级 |
| 状态推进 | 状态机按钮：待确认→确认→进行中→已完成→已交付，可取消（需二次确认） |
| 工作流节点 | 画师自定义阶段（草稿→线稿→上色→成图），每节点：名称 + 收款比例 + 话术模板，逐节点推进，当前节点高亮 |
| 收款管理 | 分期收款：已付/未付 + 三态（已付清/部分/未付）+ 收款流水列表（时间+金额+备注），记录收款按钮 |
| 日期 | 截稿日 + 开工日 date-picker（即时保存），设开工日时自动建议截稿日（+工期天数） |
| 参考图图库 | 客户上传的参考图网格，可预览 |
| 价格 | 计算明细 + 最终价格（可覆盖） |

**状态机**（设计需覆盖全部状态）：
```
pending（待确认）→ confirmed（已确认）→ wip（进行中）→ done（已完成）→ delivered（已交付）
任何非终态 → cancelled（已取消）
```

**收款三态**：`paid`（已付清，绿）/ `partial`（部分，琥珀）/ `pending`（未付，灰）

### 4.6 开稿管理 `/slots`

- 名额数量（本月正式名额 N 个）
- 月度额度
- 队列行为：缓冲区开关（正式满了后新订单进候补）
- 接稿状态切换（与仪表盘联动）
- 当前占用概览：正式 X/Y · 缓冲 Z/W

### 4.7 价格管理 `/tiers`

- 档位卡片网格，每卡：示例图 + 名称 + 价格 + 工期 + 三态开关
- **拖拽排序**（已有 vuedraggable，手柄拖拽，客户主页按此顺序）
- 档位三态：`visible`（正常展示可下单）/ `showcase`（仅展示不可下单）/ `hidden`（完全隐藏）
- 新增/编辑档位弹窗：名称、价格、工期、描述、示例图上传

### 4.8 作品管理 `/artworks`

- 图片网格（瀑布流或等高网格）
- 上传（多选）
- **星标封面图**：可多张，客户主页轮播展示
- 每张作品：标题、可见性开关

### 4.9 留言管理 `/guestbook`

- 筛选：待审核 / 已通过 / 已拒绝
- 列表：客户昵称 + 内容 + 时间 + 操作（通过/拒绝/回复）
- 侧边栏待审核角标联动

### 4.10 设置 `/settings` — 计划重组为 4 Tab

| Tab | 字段 | 心智 |
|-----|------|------|
| 基本资料 | 头像、昵称、编码、简介、联系 QQ | "我是谁" |
| 主页展示 | 接稿状态、公告、外链、平台链接、灵感标签、须知编辑 | "客户看到什么" |

| 偏好 | 通知开关、默认面板、快捷按钮自定义（3~9 个勾选） | "系统怎么用" |

### 4.11 登录 `/login`

- QQ 号 + 验证码（开发模式显示验证码）
- 品牌感强一点（这是画师对产品的第一印象）

## 第五章：视觉方向

### 5.1 产品已有视觉基因（必须延续）

- **霞鹜文楷（LXGW WenKai）**：产品标志性字体，中文楷体，温润有文人气。用于标题、品牌、数字点睛，正文不用（楷体长文易疲劳）
- **纸墨气质**：客户端 4 配色（纸白/墨黑/暮灰/苔绿）都是低饱和自然色，产品整体是"东方文人工作室"气质
- 朱砂红作为点睛色在参考稿中反复出现，与"绘约"的"绘"（绘画+约定）气质契合

### 5.2 偏好方向（从 6 份参考稿中提炼）

| 维度 | 偏好 |
|------|------|
| 底色 | 暖纸色（#f5f4f0 量级），不是纯白也不是冷灰 |
| 卡片 | 白色 + 1px 暖灰边框 + 12px 圆角 + 极轻阴影，靠边框和留白撑层次 |
| 强调色 | 朱砂红（#b04a32 量级），克制使用：主按钮、导航激活、今天线、focus ring |
| 语义色 | 低饱和自然色系（蓝 #3b6ec9 / 绿 #38834f / 红 #c2402f / 琥珀 #ba7a1f），不用高饱和系统默认色 |
| 字体 | 三轨：文楷（标题/数字）+ Noto Sans SC（正文）+ 等宽（订单号/金额/日期） |
| 侧边栏 | 白色 + 右边框，导航分组 + 激活态朱砂软底 + 左侧竖条指示 |
| 阴影 | 极克制（0.03-0.04 透明度），hover 时加深，不要大投影 |
| 动效 | 克制：hover 过渡 0.2s、列表 stagger 入场、视图切换淡入。不要全屏动画 |

### 5.3 明确不要的

- ❌ AI 默认靛蓝/紫渐变主色
- ❌ 全站玻璃拟态（backdrop-blur 滥用）
- ❌ 统一大圆角（rounded-2xl 一刀切）——圆角有阶梯：卡片 12px / 按钮输入 8px / badge 全圆
- ❌ 深色背景 + 霓虹单色点缀
- ❌ 8-9px 极小字号（中文正文底线 13px）
- ❌ 四等分统计卡片的死板模板——逾期卡要有条件强调
- ❌ 通用企业后台的廉价感（默认 Element Plus 皮肤）
- ❌ 渐变标题文字

### 5.4 关键设计点（拉开差距的地方）

1. **排期色带用纹理编码状态**：实心 / 虚线半透明 / 斜纹，不只靠颜色（色盲友好 + 信息密度）
2. **统计数字用文楷 + tnum**：大数字（28px+）是仪表盘的视觉锚点
3. **未设截稿日的订单画满整月**：斜纹带子占满未来 = 诚实 UI，让画师自己想去修
4. **手动录单双栏**：左"客户说了什么"右"我怎么安排"，对应画师真实心智
5. **空状态有温度**：虚线框 + 楷体标题 + 引导操作，不是冷冰冰的"暂无数据"

| 断点 | 布局 |
