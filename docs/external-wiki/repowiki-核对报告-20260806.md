## 二、🔴 严重过时清单（文件 + 过时段落 + 当前正确版本）

### 1. `认证接口.md` — 登录端点与机制（🔴）
- **过时**：文档通篇描述「用户名/密码登录 POST /api/auth/login → 签发 JWT，TOTP 作为可选二次认证」，并称响应含 `{ token, mfaRequired }`（§详细组件分析、§附录 API 端点清单）。
- **当前正确**：认证已改为 **TOTP 动态口令登录（REQ-027）**，唯一登录端点是 `POST /api/auth/verify`（请求体 `{ qqNumber, code }`，6 位 TOTP 码，同 IP 10 次/5 分钟）。`errors.ts` 注释明示「REQ-027: TOTP 动态口令（旧登录码错误码保留，不再使用）」。`/api/auth/login` 不存在。

### 2. `认证接口.md` — TOTP 绑定端点（🔴）
- **过时**：文档称客户端可调用 `POST /api/auth/totp/bind`（返回 `{ secret, qrUrl }`）与 `POST /api/auth/totp/verify`（提交 `{ code }`）。
- **当前正确**：认证路由只有 3 个端点（verify/me/logout）；TOTP 绑定/确认/重置是**管理员路由**：`POST /api/admin/artists/:id/totp/bind-init`、`/bind-confirm`、`/reset`（admin.routes.ts:140/162/195，需 requireAdmin）。`/api/auth/totp/bind|verify` 不存在。

### 3. `认证接口.md` — 令牌与会话机制（🔴）
- **过时**：文档称「JWT Bearer 令牌 + 刷新令牌续期 + 登出黑名单」（§JWT 令牌处理与刷新机制、§鉴权中间件解析 Authorization: Bearer）。
- **当前正确**：会话为 **httpOnly cookie `artist_token`（7 天，同 site=lax，生产 secure）**，JS 不可读防 XSS；`Authorization: Bearer` 仅作测试/旧客户端兜底（middleware/auth.ts extractToken：cookie 优先）；登出 = 递增 `token_version` 使所有旧令牌失效 + clearCookie；无刷新令牌机制。错误码为 NOT_LOGGED_IN / SESSION_EXPIRED / TOKEN_REVOKED 等。

### 4. `数据库模式设计.md` — price_tiers 表结构（🔴）
- **过时**：文档称 price_tiers 字段为 `style_name / size_name / start_date / end_date / visible`（画风×尺寸模型，ER 图同样如此）。
- **当前正确**：init.js:56 实际 DDL 为 `name / price / description / example_image / work_days / sort_order`（档位模型）。画风×尺寸模型存在于独立的 art_styles / style_sizes / style_addons / size_addon_overrides 表 + style-pricing.service.ts，wiki 的字段归属张冠李戴。

### 5. `数据库模式设计.md` — orders 表结构（🔴）
- **过时**：文档称 orders 含 `base_price / final_price`（decimal），ER 图只画了 6 个字段。
- **当前正确**：实际 DDL（init.js:93）为 `total_price_cents / final_price_cents / paid_total_cents / discount_amount_cents`（全整数分）、`price_snapshot REAL`、`quote_snapshot TEXT`、`queue_zone / queue_position / current_stage_id / source('self'|'manual') / deadline / start_date / completed_at` 等 25 列，含 status CHECK 状态机（pending/confirmed/wip/revision/done/delivered/cancelled）。

### 6. `数据库模式设计.md` — order_references / deliverables 字段（🔴）
- **过时**：文档称 order_references 为 `url`（外部参考链接）、deliverables 为 `title / file_url`。
- **当前正确**：实际为附件上传模型：order_references = `file_path / original_name / file_size / mime_type / source('client'|'artist')`；deliverables = `file_path / original_name / file_size / created_at`。deliverables 无 title/file_url 列。

### 7. `数据库模式设计.md` — artist_workflow_stages 字段（🔴）
- **过时**：文档称字段为 `stage_name / sort_order / is_default`。
- **当前正确**：实际 DDL（init.js:176）为 `name / description / sort_order / takes_payment / basis_points / speech_template / random_template`（收款节点 + 话术模板模型，v5+v20）。
